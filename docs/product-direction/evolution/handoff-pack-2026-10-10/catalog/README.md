# カタログの読み方

これらは公開済みの知識DBではなく、照合・選定・実装計画の入力案です。

reference_topics: 160項目。algorithm 103、variant 14、strategy 21、primitive 22という今回の仮分類です。この103を現行105手法行と比較して達成率にしてはいけません。

problem_scope: 80項目。問題型だけでなく評価profileと隣接問題を含みます。

domain_bridges: 24候補。両分野の採用実績・数学的対応を全件検証したリストではありません。evidence_statusを読むこと。

personas: 実ユーザー調査前の10仮説。属性から能力・学習スタイルを決めつけません。

experience_patterns: 16の表現/評価仮説。教育効果が証明済みの一覧ではありません。

decision_rule_candidates: 24の規則候補。実行可能な決定表ではなく、既存規則・原典・unknown/除外の検証後に統合します。

library_evaluation: 現行を含む11の比較/参照枠。インストールリストではありません。

source_reviewがindividual_claim_review_requiredの項目は、リンク先がその項目の全保証を支えるとみなさないでください。記載した分類資料を入口に、個別原典・定義・版の確認を行います。空欄や未照合は未収録確定ではありません。

全リストを一括審査し終えるまで記事作成を止める必要はありません。確認できた小さな集合を版付きで承認し、残りはdraft/未照合として見せたまま、辞書拡張と体験づくりを並行してください。
