# 近接勾配の最初の一手を伝える図

オーナーのレビューでは、近接勾配の図から何を伝えたいのかを読み取れなかった。
最初に伝える問いは「勾配だけで動かした係数を、なぜそのまま採用しないのか」。

## 最初に見えるもの

- 初期表示は本文と同じ最初の一手で停止する。
- 現在の係数、勾配だけの中間点、0へ縮めた後を三つの行で示す。
- 三行の横軸は同じ範囲・縮尺で、灰・青緑・橙をそれぞれの点と矢印に一貫して使う。
- 初期値は0 → 0.75 → 0.55。勾配はデータへの当てはまりを改善する方向へ動かし、
  L1の近接作用素は中間点を0へ縮める。
- λを3にすると、中間点0.75が閾値0.75の区間に入り、更新後がちょうど0になる。
- つまみを変えても最初の一手で停止し、変化の理由を比較できる。
- 入出力曲線、数式への代入、目的値・写像の診断は折りたたむ。

## 保持する境界

計算モデル、12回の予算、正則化・歩幅・始点の範囲、安定な歩幅の条件を変えない。
近接の操作だけで目的全体が必ず下がるとは書かない。
このモデルの許される歩幅で一手を完了した結果と、途中の操作を区別する。
大規模問題での速さ・変数選択の正しさは主張しない。

## 確認

文書を先に保存し、初期表示が最初の一手である限定E2Eを現行buildで失敗させる。
変更後は最初の三点、0になる例、λ=0、負の始点、再生・keyboard操作を確認する。
PCと375pxで実画面を確認し、検証後の候補だけを既存Tailscaleレビュー経路へ配信する。
