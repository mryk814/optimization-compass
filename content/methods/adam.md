Adamは、座標ごとに勾配の移動平均と勾配の二乗の移動平均を持ち、その比で一歩を決める確率的一次法です。勾配の大きさが座標ごとに何十倍違っても、各座標の一歩はおよそ学習率以下にそろい、勾配の向きがそろわない座標ほど小さくなります。

## 30秒でつかむ

[勾配降下法](#/learn/method.gradient-descent)は、坂が急なほど大股で進みます。一歩が勾配に比例するからです。
そのため、急な方向と緩やかな方向が混ざった谷では、急な方向に合わせて学習率を小さくするしかなく、緩やかな方向がなかなか進みません。

Adamは、歩幅を坂の急さで決めません。座標ごとに「最近の勾配は、ずっと同じ向きを指しているか」を見て、向きがそろっていればおよそ学習率 $\eta$ だけ進み、そろっていなければ歩幅を縮めます。

- **見るもの**: 座標ごとの勾配と、その移動平均（一次モーメント）、勾配の二乗の移動平均（二次モーメント）
- **動かすもの**: パラメータと、二つの移動平均の状態
- **前進の判断**: 損失や検証指標が下がり、一歩の大きさが落ち着いていくこと

その結果、Adamの学習率 $\eta$ は「勾配に掛ける係数」ではなく、「1回に動く距離のおよその上限」という意味になります。損失を100倍しても、Adamの動きは変わりません。

## 一手の意味

Adamは、勾配 $g_t$ を受け取るたびに、二つの移動平均を座標ごとに更新します。

$$
m_t=\beta_1m_{t-1}+(1-\beta_1)\,g_t,\qquad
v_t=\beta_2v_{t-1}+(1-\beta_2)\,g_t^2
$$

$m_t$ は勾配そのものの移動平均で、最近の勾配が平均してどちらを向いているかを表します。
$v_t$ は勾配の二乗の移動平均で、最近の勾配がどれくらいの大きさだったかを表します。二乗は座標ごとに取ります。
よく使われる $\beta_1=0.9$ はおよそ直近10回分、$\beta_2=0.999$ はおよそ直近1000回分を覚えている、と読めます。

### 初期の偏りを補正する

$m$ と $v$ は0から始まるので、最初のうちは本来の平均より小さく出ます。例えば1回目は $m_1=(1-\beta_1)g_1=0.1\,g_1$ です。
そこで、次のように割り戻した値を使います。これを偏りの補正（bias correction）と呼びます。

$$
\hat m_t=\frac{m_t}{1-\beta_1^{\,t}},\qquad \hat v_t=\frac{v_t}{1-\beta_2^{\,t}}
$$

1回目は $\hat m_1=g_1$、$\sqrt{\hat v_1}=|g_1|$ になり、平均が正しい大きさに戻ります。
補正しないと、1回目の比は $0.1\,g_1/\sqrt{0.001\,g_1^2}\approx3.16$ になり、学習率の3倍以上の一歩を踏み出してしまいます。$v$ の偏りのほうが大きいからです。

### 一歩を決める比

パラメータは、座標ごとに次のように動きます。

$$
x_{t+1}=x_t-\eta\,\frac{\hat m_t}{\sqrt{\hat v_t}+\epsilon}
$$

$\epsilon$ は0で割らないための小さな数（$10^{-8}$ など）です。この式の核は、比 $\hat m_t/\sqrt{\hat v_t}$ です。
分子も分母も勾配と同じ単位なので、比には単位がありません。勾配が6でも200でも、比の大きさは次の状況だけで決まります。

| 状況 | 平均 $\hat m$ | 大きさ $\sqrt{\hat v}$ | 比 | 一歩 |
|---|---|---|---|---|
| 同じ大きさ・同じ向きの勾配が続く | $\approx g$ | $\approx \lvert g\rvert$ | $\approx\pm1$ | 約 $\eta$ |
| 行き過ぎて、符号が交互に変わる | 打ち消し合って0に近い | 大きいまま | 0に近い | 小さい |
| 勾配のばらつき（ノイズ）が平均より大きい | 小さい | 大きい | 小さい | 小さい |
| 勾配が過去より小さくなった | 小さい | 過去の大きさを覚えている | 小さい | 小さい |

原論文は、この比がたいてい1を超えないことから、$\eta$ が「現在の点の周りで、どこまで動いてよいか」の範囲を決める、と説明しています。
ただし、これは保証ではありません。ほとんど0だった座標に突然大きな勾配が来た直後などは、比が1を超えることがあります。

## 小さな例

勾配降下法の記事と同じ細長い谷 $f(x,y)=(x-1)^2+20(y+2)^2$ を、点 $(4,\,3)$ から下ります。最小点は $(1,\,-2)$ です。
勾配は $(2(x-1),\,40(y+2))$ で、出発点では $(6,\,200)$ です。$y$ 方向の勾配が、$x$ 方向の33倍あります。
$\eta=0.1$、$\beta_1=0.9$、$\beta_2=0.999$、$\epsilon=10^{-8}$ とします。勾配に乱数は入れません。

| 歩数 $t$ | 勾配 $g$ | 平均 $\hat m$ | 大きさ $\sqrt{\hat v}$ | 比 | 動いた後の点 | $f$ |
|---:|---|---|---|---|---|---:|
| 0 | | | | | $(4,\ 3)$ | 509.0 |
| 1 | $(6,\ 200)$ | $(6,\ 200)$ | $(6,\ 200)$ | $(1.000,\ 1.000)$ | $(3.9,\ 2.9)$ | 488.6 |
| 2 | $(5.8,\ 196)$ | $(5.895,\ 197.9)$ | $(5.901,\ 198.0)$ | $(0.999,\ 0.999)$ | $(3.800,\ 2.800)$ | 468.7 |
| 3 | $(5.600,\ 192.0)$ | $(5.786,\ 195.7)$ | $(5.802,\ 196.0)$ | $(0.997,\ 0.998)$ | $(3.700,\ 2.700)$ | 449.1 |

二つの座標の勾配は33倍違うのに、比はどちらもほぼ1で、どちらも $0.1$ ずつ動いています。
その結果、点は最も急な下り方向（ほぼ真下）ではなく、斜め45°の方向へ進みます。Adamの一歩は、勾配の向きではなく、座標ごとの符号で決まっているからです。

### 動かして確かめる

その先の動きと、比の変化を次の図で追ってください。下のグラフが、座標ごとの比 $\hat m/\sqrt{\hat v}$ です。

::: explorable adam-step-ratio
橙の軌跡がAdamです。点の周りの破線の四角は、各座標が η だけ動ける範囲を表します。下のグラフは座標ごとの比（勾配の平均÷勾配の大きさ）で、一歩の大きさを η を単位にして示します。固定の二次関数と固定seedのノイズで計算した教材用の例で、ニューラルネットワークの学習での性能や良い学習率は示しません。
:::

既定の設定のまま再生すると、次の順に起きます。

1. 最初の約10歩は、両方の比が0.95以上で、四角の角へ向かって斜めに進みます。
2. $x$ は40歩目ごろに最小点の $x=1$ を通り過ぎ、53歩目には $0.82$ まで行き過ぎてから戻ります。平均 $\hat m$ が、直近の向きを覚えているためです。
3. 勾配が小さくなるにつれて、両方の比が下がっていきます。$\sqrt{\hat v}$ が出発点付近の大きな勾配を覚えているので、学習率を変えなくても一歩が自然に縮みます。120歩目の点は $(0.997,\,-2.023)$、$f=0.010$ です。

### 同じ学習率の勾配降下法と比べる

図の「同じηの勾配降下法」を選ぶと、灰色の破線が出ます。
勾配降下法の一歩は $\eta\,g$ なので、1歩目の $y$ の移動は $0.1\times200=20$ です。$y$ は $3$ から $-17$ へ飛び、$f$ は $509$ から $4506$ に増えます。以後も増え続けて発散します。
この谷での勾配降下法の安定限界は $\eta<0.05$ です。同じ $0.1$ という数でも、二つの手法では意味が違います。

これは、Adamがこの谷を速く解けるという意味ではありません。
勾配降下法に限界内の $\eta=0.045$ を選べば、$f<10^{-3}$ に49回で着きます。Adamは $\eta=0.1$ で86回かかります。
Adamが減らしてくれるのは反復の回数ではなく、学習率を問題の勾配の大きさに合わせて選び直す手間です。

### 損失の尺度を変えても動きが変わらない

目的関数全体を100倍すると、勾配も100倍になります。
勾配降下法では、安定限界も $1/100$ の $0.0005$ に下がるので、学習率を選び直す必要があります。
Adamでは、比の分子と分母がどちらも100倍になって打ち消し合い、軌跡は変わりません（次の節のコードで確かめます）。
損失に係数を掛けたり、データの件数で割ったりしても、Adamの学習率を選び直さなくてよいのはこのためです。

### ノイズのある勾配で起きること

ミニバッチで計算した勾配には、ばらつきがあります。図の「勾配のノイズ σ」を $20$ にすると、各座標の勾配に標準偏差20の乱数が足されます。

もともと勾配が200もある $y$ には、この乱数はあまり効きません。
一方、勾配が6以下の $x$ では、乱数のほうが大きいので、勾配の符号が毎回ばらばらになります。11〜60歩目の比の大きさの平均は、$x$ が $0.27$、$y$ が $0.70$ です。
その結果、60歩進んだ後の $x$ は $2.31$ で、ノイズがないとき（$0.85$）よりずっと最小点から遠いままです。
Adamは、向きを信用できない座標で一歩を縮めます。それは、そのまま進みが遅いことでもあります。

## 向く条件・避ける条件

向く条件です。

- ミニバッチの確率的勾配を使う、大規模なモデルの学習（[ニューラルネットワークの学習（PA040）](#/formulations/PA040)）
- パラメータの種類によって勾配の大きさが大きく違う（埋め込み、正規化層、出力層が混ざるなど）
- 一部の座標にだけ時々大きな勾配が来る、疎な勾配
- 学習の途中で勾配の大きさが変わっていく
- まず動く基準の設定（baseline）を早く作りたい

避ける、または切り替える条件です。

- 小規模で、決定論的な勾配が得られる滑らかな問題で、高い精度の局所解が欲しい → [BFGS](#/learn/bfgs)のような準Newton法のほうが速く、診断もしやすい
- 最終的な汎化性能が重要で、学習の予算が十分ある → 同じ条件で[Momentum SGD](#/learn/momentum-sgd)と比べる。初期の損失の下がり方が速いことは、最終の検証指標が良いことを意味しない
- weight decayで正則化したい → 損失にL2項を足す実装と、パラメータを直接縮める実装で挙動が違う。[AdamW](#/learn/adamw)を使う
- 高い精度で停止条件を判定したい → 一歩が比で決まるので、勾配が小さくなっても一歩は自動で0にならない。学習率のスケジュールと合わせて判断する

## Python

次のコードは、上の谷をAdamで120歩進めます。2行目の出力は、損失を100倍した場合です。

```python
import numpy as np


def gradient(p: np.ndarray) -> np.ndarray:
    x, y = p
    return np.array([2.0 * (x - 1.0), 40.0 * (y + 2.0)])


def adam(loss_scale: float, eta: float = 0.1, steps: int = 120) -> np.ndarray:
    beta1, beta2, epsilon = 0.9, 0.999, 1e-8
    p = np.array([4.0, 3.0])
    m = np.zeros(2)
    v = np.zeros(2)
    for t in range(1, steps + 1):
        g = loss_scale * gradient(p)
        m = beta1 * m + (1.0 - beta1) * g
        v = beta2 * v + (1.0 - beta2) * g * g
        m_hat = m / (1.0 - beta1**t)
        v_hat = v / (1.0 - beta2**t)
        p = p - eta * m_hat / (np.sqrt(v_hat) + epsilon)
    return p


print(adam(loss_scale=1.0).round(3))    # [ 0.997 -2.023]
print(adam(loss_scale=100.0).round(3))  # [ 0.997 -2.023]
```

二つの出力は小数第3位まで一致します。違いは $\epsilon$ の影響だけで、二つの軌跡の差は最大でも $10^{-8}$ 程度です。

実際の学習では、自分で書かずにフレームワークの実装を使います。PyTorchの `torch.optim.Adam`、Kerasの `keras.optimizers.Adam`、Optaxの `optax.adam` が代表です。
既定値は $\beta_1=0.9$、$\beta_2=0.999$ が共通ですが、$\epsilon$ の既定値やweight decayの扱いは実装ごとに違います。使う実装の公式ドキュメントで確認してください。

## 診断値

Adamでは、勾配の大きさと一歩の大きさが別の量になります。両方を記録します。

| 診断値 | 見方 | 判断の目安 |
|---|---|---|
| 学習損失と検証指標 | 学習が進んでいるか | 学習損失だけが下がるなら、optimizerではなく汎化の問題を疑う |
| 一歩の大きさとパラメータの大きさの比 | 1回でパラメータがどれだけ変わるか | 層ごとに極端に大きい・小さいなら、学習率を見直す |
| 比 $\hat m/\sqrt{\hat v}$ の分布 | どの座標が動いているか | ほとんどの座標で0に近いなら、ノイズが勾配を上回っているか、学習率が大きすぎて振動している |
| 勾配の大きさ（gradient norm） | 急な変化がないか | 突然跳ね上がるなら、データや数値の異常を疑う |
| 学習率のスケジュールの現在値 | いまの $\eta$ | 損失の変化と並べて読む |
| 複数のseedでのばらつき | 結果が偶然でないか | 大きければ、比較を複数seedで行う |

## 失敗・切替の兆候

| 症状 | 考えられる原因 | 対処・切替先 |
|---|---|---|
| 損失が下がらず、大きく振れる | 学習率が大きすぎる | $\eta$ を下げる。学習の初めに $\eta$ を徐々に上げる（warmup）ことも検討する |
| 学習の後半で損失が下がらなくなる | 一歩が $\eta$ 程度のまま、最小点の周りを往復している | 学習率のスケジュールで $\eta$ を下げていく |
| 大きな勾配の後、長く動かない座標がある | $\beta_2$ の長い記憶が、過去の大きな勾配を覚えている | $\beta_2$ を確認する。AMSGradなどの変種も選択肢になる |
| 低精度の計算で挙動がおかしい | $\sqrt{\hat v}$ が $\epsilon$ と同程度に小さい | $\epsilon$ と数値の精度を確認する |
| weight decayが効かない、または効きすぎる | L2項を損失に足す実装では、L2の勾配も比で正規化される | [AdamW](#/learn/adamw)のように、パラメータを直接縮める |
| 途中から再開したら挙動が変わった | $m$、$v$、歩数 $t$ を保存していない | optimizerの状態も保存して復元する |
