二つの目的を「半分ずつ」重視すれば、真ん中の答えになるのでしょうか。この例では同じ単位のままならそうなります。ところが片方の表示単位を100倍に変えると、同じ重み0.5でも、ほとんど片方だけを重視する解へ動きます。

重み付き和は、複数の目的を一つの得点に変えて解く方法です。ここでは同じ二次関数を使い、重み、最適な決定、元の二目的の値を一続きに追います。最後に「重みを細かく振れば全Pareto解が取れる」という限界も確かめます。

## 30秒でつかむ

- **固定するもの**: 元の可行集合と、各目的の最小化・最大化の向き、単位
- **動かすもの**: 非負の重み。重みを一つ変えるたびに、新しい単目的問題を解く
- **得るもの**: その重みに対する一つ以上の最適解。フロント全体や客観的な優先度が自動で決まるわけではない

二目的をどちらも最小化するなら、$0\le w\le1$ に対して

$$\min_{x\in X}\;F_w(x)=w f_1(x)+(1-w)f_2(x)$$

を解きます。一般には $\sum_i w_i f_i(x)$、$w_i\ge0$、少なくとも一つの重みが正です。全重みを同じ正の定数倍にしても最適解は変わりません。そのため二目的では和を1に揃えて表すことができます。

## 一つの例を解く

決定は $x=(x_1,x_2)\in\mathbb R^2$。二つの目標点 $(1,0)$ と $(0,1)$ からの二乗距離を小さくします。

$$f_1(x)=(x_1-1)^2+x_2^2,\qquad
f_2(x)=x_1^2+(x_2-1)^2.$$

$f_1$ だけなら $(1,0)$、$f_2$ だけなら $(0,1)$ が最良です。同時に両方を0にはできません。重みは、二つの目標の間のどこを選ぶかを決めます。

### 平方完成して、一手を手で追う

重み付き和を展開すると

$$
F_w(x)=x_1^2+x_2^2-2wx_1-2(1-w)x_2+1.
$$

さらに平方完成すれば

$$
F_w(x)=(x_1-w)^2+(x_2-(1-w))^2+2w(1-w).
$$

後ろの項は $x$ を動かしても変わりません。二つの二乗を0にする

$$x^*(w)=(w,1-w)$$

が唯一の大域最適解です。ヘッセ行列も $2I$ で正定値です。したがってここでは、単に勾配が0になる点を見つけただけでなく、全空間で最小と分かっています。

たとえば $w=0.2$ なら $x=(0.2,0.8)$。$f_1=0.8^2+0.8^2=1.28$、$f_2=0.2^2+0.2^2=0.08$ です。$f_1$ の重みが小さいので、$f_1$ の値が大きくても許す選択になります。

| $w$ | 最適な決定 $x^*$ | $f_1(x^*)$ | $f_2(x^*)$ |
|---:|---|---:|---:|
| 0 | $(0,1)$ | 2 | 0 |
| 0.2 | $(0.2,0.8)$ | 1.28 | 0.08 |
| 0.5 | $(0.5,0.5)$ | 0.50 | 0.50 |
| 0.8 | $(0.8,0.2)$ | 0.08 | 1.28 |
| 1 | $(1,0)$ | 0 | 2 |

同じ $w$ を代入して、図とコードも作ります。一般の多目的問題では、重みを等間隔にしても目的空間の点が等間隔になる保証はありません。本例でも目的値は $f_1=2(1-w)^2,f_2=2w^2$ という二乗で動きます。

左の軸は決める変数、右の軸はその結果です。同じ色が同じ解を表します。右図で両目的が小さい左下へ動かしたいのですが、曲線の上では片方を下げると他方が上がります。

右図の点線は $w f_1+(1-w)f_2=\text{一定}$ です。$0<w<1$ なら傾きは $-w/(1-w)$。同じ得点を保つには、$f_1$ を1減らす改善と、$f_2$ を $w/(1-w)$ 増やす悪化が釣り合います。これは**単位を固定した後の交換率**です。

## 同じ0.5でも単位が違えば答えが変わる

$f_1$ を別の単位で記録し、数値だけ $\tilde f_1=100f_1$ に変えます。物理的な候補やPareto支配は変わりませんが、表示上の重みをそのままにした

$$w\,100f_1+(1-w)f_2$$

は別の選好です。全体を $100w+1-w$ で割ると、元の単位での実効重みは

$$\alpha=\frac{100w}{100w+1-w}.$$

$w=0.5$ では $\alpha=100/101\approx0.9901$。最適解は $(100/101,1/101)$、元の目的値は $f_1=2/10201\approx0.000196$、$f_2=20000/10201\approx1.960592$ です。図の菱形はこの選択です。

元と同じ半々の選好を保つには、新しい表示重みを $w=1/101$ に補正します。すると $100w=1-w$ となり、再び $(0.5,0.5)$ を選びます。「同じ重み」は「同じ意思決定」を意味しません。

目的を正規化するなら、基準と幅を記録します。たとえば $(f_i-a_i)/(b_i-a_i)$ は、実質的に重みを $1/(b_i-a_i)$ 倍する操作です。理想値やナディア値の推定を変えたら、同じ表示重みでも選好は変わります。正規化をすれば客観的に公平になるわけでもありません。

## Pythonで解析解と数値解を照合する

同じ二次関数をSciPyで解き、解析解と照らします。勾配も明示し、成功状態・解・勾配残差を調べます。BFGSを使いますが、最適性の根拠は上の平方完成であり、ソルバー名だけではありません。

```python
import numpy as np
from scipy.optimize import minimize


def objectives(x):
    return np.array([(x[0] - 1)**2 + x[1]**2,
                     x[0]**2 + (x[1] - 1)**2])


def solve(w, scale=1.0):
    a, b = scale * w, 1.0 - w
    expected = np.array([a, b]) / (a + b)
    def fun(x):
        f = objectives(x)
        return a * f[0] + b * f[1]
    def jac(x):
        return 2 * (a + b) * x - 2 * np.array([a, b])
    result = minimize(fun, [0.5, 0.5], jac=jac, method="BFGS",
                      options={"gtol": 1e-10})
    assert result.success
    assert np.allclose(result.x, expected, atol=1e-8, rtol=0)
    assert np.linalg.norm(jac(result.x)) < 1e-8
    return expected, objectives(expected)


for w in (0.0, 0.2, 0.5, 0.8, 1.0):
    x, f = solve(w)
    print(w, x.round(6), f.round(6))
print("scale=100:", tuple(a.round(6) for a in solve(0.5, 100)))
print("compensated:", tuple(a.round(6) for a in solve(1/101, 100)))
```


APIと停止条件は[SciPy公式リファレンス](https://docs.scipy.org/doc/scipy/reference/generated/scipy.optimize.minimize.html)で確認できます。違うソルバーや許容誤差なら表示の末尾が違う場合があります。

## 何が保証され、どこが取れないか

### 正の重みと大域求解が揃えばPareto最適

すべての重みが正で、重み付き和を**大域的に**最小化した解はPareto最適です。仮にその解を支配する点があれば、全目的を悪化させず、少なくとも一目的を改善します。正の重みで足した値も必ず小さくなり、最小化したという前提に矛盾するからです。この方向の保証に凸性は要りません。[BoydとVandenbergheの公式講義資料「Scalarization」](https://web.stanford.edu/class/ee364a/lectures/problems.pdf)もこの関係を扱います。

重み0を許すと、無視した目的だけが悪い解を選ぶことがあり、一般に保証できるのは弱Pareto最適性です。本例の端点は各単目的の最小点が唯一なのでPareto最適ですが、これを一般化しません。局所ソルバーで局所解しか得られていない場合も、大域Pareto最適とは呼びません。

### 重み付き和で支えられないPareto点がある

逆向きに「Pareto最適なら、どれかの重みで必ず得られる」とは限りません。目的空間で非負方向を加えた集合 $f(X)+\mathbb R_+^m$ が凸である、といった支持超平面の条件が重要です。凸問題では非負で全零でない重みによる支持を考えられますが、端の解に重み0が必要な場合や、同点の解が複数ある場合もあります。「前線が凸に見える」だけで、正の重みの有限格子がすべてを返すとは言えません。幾何の前提は[凸性](#/learn/concept.convexity)へ戻って確認します。

非凸な場合、どの重みにも選ばれない非支持Pareto点（unsupported Pareto point）があり得ます。[多目的定式化の金具の例](#/learn/concept.multiobjective-optimization)では、前線が $(f_1,f_2)=(t,1-t^2)$、$0\le t\le1$。$t=0.5$ は支配されていませんが、$w=0.5$ の得点0.625は両端の0.5より大きくなります。重み付き目的が $t$ の凹関数なので、他の重みでも内部点は最小になりません。主例の二次関数とは別の反例です。

この欠落は重み格子を細かくしても直りません。[ε-constraint法](#/learn/epsilon-constraint)で許容上限を指定する方法を検討します。一方、本稿の滑らかな二次例ではすべての $w\in[0,1]$ を使えば線分上の全Pareto点を表せます。

## 診断と選び分け

まず各重みの求解が成功し、元の制約を守っているかを調べます。その後に、元の単位の目的値、重複した解、支配された候補、関心領域の空白を見ます。重み付き得点だけを保存すると、尺度や重みを変えた実行どうしを比較できません。

- 同じ点に偏る: 重みの間隔、問題固有の感度、非支持点の欠落を切り分ける
- 片方だけを極端に改善する: 単位と実効重みを計算し直す
- 各部分問題が局所解で止まる: 求解法の保証と再初期化を検討する
- 多数目的で重み格子が増える: 関心領域へ絞るか、[MOEA/D](#/learn/moead)などの分解法も比較する

フロントの品質を測るハイパーボリュームや間隔は、参照点・尺度・評価予算を揃えて使います。点が多いだけでは、取りたい妥協点が取れたとは言えません。多目的全体の整理は[多目的最適化とParetoフロント](#/learn/multi-objective)にあります。
