滑らかな損失を勾配で下げ、その後に近接作用素で正則化や制約を反映する複合凸最適化法です。

## 30秒でつかむ

データへの当てはまりを良くしつつ、不要な係数を0にしたいとします。
二乗損失には勾配がありますが、係数の絶対値を足すL1正則化には0で角があります。
近接勾配法は、一手を「損失だけを下げる」と「正則化を反映する」に分けて進みます。

- 動かすもの: 現在の係数、歩幅、正則化の強さ
- 確かめるもの: 両方を合わせた目的値と、近接勾配写像の大きさ
- 向く構造: 滑らかな凸関数と、近接作用素を安く計算できる凸関数の和

## 一手の意味

目的を、微分できる損失 $f$ と、角や制約を含む項 $g$ に分けます。

$$
\min_x F(x)=f(x)+g(x)
$$

まず、$f$ の勾配だけで進んだ中間点 $z_k$ を作ります。
この点は、まだ $g$ を反映していません。
次に、$z_k$ の近くで $g$ も小さくする点を選びます。

$$
z_k=x_k-\eta\nabla f(x_k)
$$

$$
x_{k+1}=\operatorname{prox}_{\eta g}(z_k)
$$

近接作用素は、$g$ を小さくすることと、中間点から離れすぎないことの釣り合いを取ります。
次の式を最小にする点 $u$ を返します。

$$
\underset{u}{\operatorname{argmin}}\left(g(u)+\frac{1}{2\eta}\|u-z\|^2\right)
$$

L1正則化 $g(x)=\lambda|x|$ なら、近接作用素は**ソフト閾値処理**です。
中間点の絶対値から閾値 $\tau=\eta\lambda$ を引き、符号を保ちます。
絶対値が閾値以下なら、ちょうど0にします。
多変数の $\lambda\|x\|_1$ でも、各成分に同じ処理をします。

$$
x_{k+1}=\operatorname{soft}(z_k,\tau)
=\begin{cases}
z_k-\tau & z_k>\tau,\\
0 & |z_k|\le\tau,\\
z_k+\tau & z_k<-\tau.
\end{cases}
$$

正則化の強さ $\lambda$ と歩幅 $\eta$ を動かし、中間点が0へ縮む量と、0になる区間を確かめてください。

::: explorable proximal-gradient-threshold
橙の点は更新中の候補、輪は勾配だけで進んだ中間点です。左は一手を二つの操作に分け、右は中間点とソフト閾値処理の結果を結びます。薄い帯の中の中間点は0になります。この1変数の図から、大規模問題での速度や変数選択の正しさは読み取れません。
:::

「操作」のつまみを0に戻すと、最初の一手を見られます。
「1つ進む」で勾配の一歩、もう一度で近接の一歩を確かめます。
$\lambda$ を3にすると、始点0では勾配の一歩が0.75でも、近接の一歩で0に戻ります。

ここでは $f(x)=\frac12(x-3)^2$ なので、勾配のLipschitz定数は $L=1$ です。
図の歩幅は $0<\eta\le1/L$ に収めています。

一般に $f$ は凸で、勾配が $L$-Lipschitzであることを仮定します。
$g$ は閉じた適正な凸関数とし、最小解が存在するとします。
この条件の下で、図と同じ範囲の固定歩幅を使えます。
$L$ が分からない場合は、上界の条件を確かめながら歩幅を縮める探索を使います。

## 小さな例

図の初期設定では $F(x)=\frac12(x-3)^2+0.8|x|$ を使い、始点は $x_0=0$、歩幅は $\eta=0.25$ です。
最初は勾配が $-3$ なので、中間点は $z_0=0-0.25(-3)=0.75$ になります。
閾値は $\tau=0.25\times0.8=0.2$。
0.75から0.2を引いて、次の点は0.55です。

| 一手 | 勾配で進んだ $z_k$ | 閾値 $\tau$ | 次の点 $x_{k+1}$ | $F(x_{k+1})$ |
|---|---:|---:|---:|---:|
| 1 | 0.7500 | 0.2000 | 0.5500 | 3.4413 |
| 2 | 1.1625 | 0.2000 | 0.9625 | 2.8457 |
| 3 | 1.4719 | 0.2000 | 1.2719 | 2.5107 |

損失だけなら最小点は3ですが、正則化も合わせると最小点は2.2です。
正の側の最適性条件 $x-3+0.8=0$ から求まります。
この初期設定では、12回後の点は約2.1303で、まだ最小点そのものではありません。

## 向く条件・避ける条件

| 条件 | 判断すること |
|---|---|
| 滑らかな凸損失 + L1正則化 | 勾配とソフト閾値処理を分けて安く計算できるなら候補になる |
| 単純な凸集合への制約 | $g$ を指示関数にすると近接作用素は射影になる。射影の費用を確認する |
| 大きな問題でヘッセ行列を持ちたくない | 一回の勾配と近接計算の費用を見積もる |
| $g$ の近接計算自体が難しい | 毎回の内側の最適化が支配的にならないかを確かめる |
| 非凸な項や整数変数を含む | ここで述べた凸問題の保証をそのまま使わない |

## Python

本文と図の一手を、そのまま12回計算します。
追加のライブラリは使いません。

```python

def soft_threshold(z: float, threshold: float) -> float:
    if z > threshold:
        return z - threshold
    if z < -threshold:
        return z + threshold
    return 0.0


def objective(x: float, lam: float) -> float:
    return 0.5 * (x - 3.0) ** 2 + lam * abs(x)


x, eta, lam = 0.0, 0.25, 0.8
threshold = eta * lam
for k in range(12):
    z = x - eta * (x - 3.0)
    next_x = soft_threshold(z, threshold)
    if k < 3:
        print(k + 1, f"z={z:.4f}", f"x={next_x:.4f}",
              f"F={objective(next_x, lam):.4f}")
    x = next_x

z = x - eta * (x - 3.0)
next_x = soft_threshold(z, threshold)
mapping = (x - next_x) / eta
print(f"12回後 x={x:.4f}, |G|={abs(mapping):.4f}")
```

最初の3行は表の中間点・次の点・目的値に対応します。
最後は `x=2.1303, |G|=0.0697` です。
12回は表示の予算であり、収束の判定ではありません。

## 診断値

滑らかな項の勾配だけでは、正則化も合わせた最適性を判定できません。
たとえば $\lambda=3$ のとき、$x=0$ での勾配は $\nabla f(0)=-3$ です。
それでも近接の更新は0に戻り、目的全体の最小点です。
代わりに、一手の移動を歩幅で割った**近接勾配写像**を確かめます。

$$
G_\eta(x)=\frac{x-\operatorname{prox}_{\eta g}(x-\eta\nabla f(x))}{\eta}
$$

この凸問題では $G_\eta(x)=0$ が目的全体の最適性条件に対応します。
実際の停止では、写像のノルムの許容値を問題の尺度に合わせ、目的値と併せて見ます。
係数の非ゼロ集合や、勾配・近接作用素の評価回数も記録します。
目的値の変化が小さいことや、非ゼロ集合が変わらないことだけで最適とは判断しません。

## 失敗・切替の兆候

- 目的値が増える: 勾配の実装、近接計算の精度、歩幅の上界を確認する。歩幅を縮め、上界の条件を確かめる。
- 目的値はほぼ変わらないのに写像が大きい: 停止を急がず、変数の尺度と歩幅を確認する。
- 勾配は安いのに一反復が重い: 近接計算の内側の費用を測り、別の分割を検討する。
- 基本形の進みが遅い: 加速と再始動を検討する。反復回数だけでなく、評価回数・停止基準・実時間を揃えて比較する。
