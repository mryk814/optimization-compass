CMA-ESは、正規分布から点を試し、関数値の順位だけを使って分布の平均・歩幅・形（共分散）を更新する集団法です。良い点が並んだ向きに分布の楕円を伸ばすので、勾配がなくても、細く斜めの谷の向きと細さを覚えて速く下れます。

## 30秒でつかむ

地図のない谷で、最も低い場所を探すとします。測れるのは、立った場所の高さだけです。
そこで、何人かの調査員を今の集合場所のまわりに散らばらせ、高さを測ってもらいます。低かった人たちの側へ集合場所を移し、次の散らばり方も、低かった人たちが並んでいた向きに伸ばします。
谷が細く斜めに伸びていれば、散らばり方もやがて同じ向きに細長くなり、無駄な場所を測らなくなります。これがCMA-ES（Covariance Matrix Adaptation Evolution Strategy）の考え方です。

- **見るもの**: 試した点の関数値の順位（値そのものや勾配は使いません）
- **動かすもの**: 分布の平均（集合場所）、歩幅 $\sigma$、楕円の形と向き（共分散行列 $C$）
- **前進の判断**: いちばん良い値が下がり、歩幅が縮み、楕円の形が落ち着いていくこと

まず図の「最初から」（⏮）を押してから「▶ 再生」を押し、「谷と分布」の楕円と、「分布の形と記録」の縦横比がどう変わるかを見てください。

::: explorable cmaes-shape-learning
「谷と分布」の等高線は、対角方向に細い谷 f=u²+100v² です。橙の楕円が今の分布で、実線は1σ、破線は2σの範囲です。橙の点は選ばれた上位3点、白い点は捨てた3点です。「分布の形と記録」では、楕円を同じ大きさにそろえて、破線の谷の形と比べます。固定の乱数の種で計算した2次元の教材用の例で、ほかの関数や次元での世代数は示しません。
:::

確かめてほしいことは三つあります。

1. 最初は丸い楕円が、20〜30世代で谷の向き（右上がり45°）に伸びていきます。70世代で楕円の縦横比は9.9になり、谷の縦横比10とほぼ同じ形になります。
2. 「分布の更新」を「丸のまま、歩幅だけ調整」にすると、楕円は丸いままです。細い谷を横切る点の多くが無駄になり、60世代でもいちばん良い値は0.12までしか下がりません。
3. 「谷の形」を「丸い谷」にすると、楕円はほとんど丸いままです。形を学んでも学ばなくても、関数値が10⁻⁶を切るのは37世代と42世代で、差はほとんどありません。

勾配も関数値の大きさも使わず、順位だけを使うのに、なぜ谷の向きと細さが分かるのでしょうか。

## 一手の意味

CMA-ESの1世代は、次の手順です。2変数の既定の設定では、1世代に $\lambda=6$ 点を試し、良い $\mu=3$ 点を使います。

1. **試す**: 今の平均 $m$ のまわりに、正規分布から $\lambda$ 点を作ります。$x_i=m+\sigma y_i$、$y_i\sim N(0,\,C)$ です。
2. **並べる**: $\lambda$ 点で関数を評価し、値の小さい順に並べます。
3. **平均を動かす**: 上位 $\mu$ 点の一歩 $y_{i:\lambda}$ を重み $w_i$ で平均した分だけ、平均を動かします。
4. **歩幅を決める**: 最近の平均の動きが同じ向きに続いていれば $\sigma$ を大きく、打ち消し合っていれば小さくします。
5. **形を決める**: 良かった一歩の向きに、楕円 $C$ を伸ばします。

関数を呼ぶのは手順2だけです。手順3〜5は、評価済みの点だけで計算します。

### 平均を動かす

$$
m\leftarrow m+\sigma\sum_{i=1}^{\mu}w_i\,y_{i:\lambda},\qquad (w_1,w_2,w_3)=(0.637,\ 0.285,\ 0.078)
$$

$y_{i:\lambda}$ は、$i$ 番目に良かった点の一歩です。この式は「良かった一歩ほど重く平均して、その分だけ集合場所を動かす」と読みます。重みは順位だけで決まり、関数値の大きさは使いません。

### 形を学ぶ

$$
C\leftarrow(1-c_1-c_\mu)\,C+c_1\,p_c\,p_c^\top+c_\mu\sum_{i=1}^{\mu}w_i\,y_{i:\lambda}\,y_{i:\lambda}^\top
$$

最後の項は「良かった一歩 $y$ を、その向きに細長い楕円 $y\,y^\top$ にして重ねる」と読みます。谷が細く斜めなら、良かった一歩は谷の向きにそろうので、重ねた楕円も谷の向きに伸びます。
$p_c$ は最近の平均の動きを積み重ねたベクトル（進化パス）で、何世代も同じ向きに進んでいれば、その向きにさらに楕円を伸ばします。
2変数の既定値は $c_1=0.155$、$c_\mu=0.058$ で、1世代ごとに楕円を少しずつ作り直します。

### 順位だけを使う利点

CMA-ESは、関数値を $f$ の代わりに $\log f$ や $f^3$ にしても、順位が変わらなければまったく同じ点を試します。値の尺度や、単調な変換に左右されないということです。
一方で、関数値の差の大きさは捨てています。差の情報を使う勾配法と比べると、一点あたりに得られる情報は少なくなります。

## 小さな例

対角方向に細い谷 $f(x)=u^2+100v^2$ を最小にします。$u=(x_1+x_2)/\sqrt2$ は谷に沿う座標、$v=(x_1-x_2)/\sqrt2$ は谷を横切る座標です。始めは平均 $m=(3,\,1)$、歩幅 $\sigma=1$ で、楕円は丸い $C=I$ です。谷の向きは右上がり45°で、横切る向きの曲がりは沿う向きの100倍、楕円で言えば縦横比10です。乱数の種は1とします。

### 谷の例・1世代目

最初の平均での値は $f(3,1)=208$ です。6点を試して、値の小さい順に並べると次のようになります。

| 順位 | 点 $x$ | $f(x)$ | 重み |
|---:|---|---:|---:|
| 1 | $(2.958,\ 1.088)$ | 182.880 | 0.637 |
| 2 | $(3.966,\ 2.123)$ | 188.347 | 0.285 |
| 3 | $(2.951,\ 0.819)$ | 234.305 | 0.078 |
| 4 | $(3.017,\ 0.866)$ | 238.867 | 0 |
| 5 | $(3.249,\ 0.027)$ | 524.303 | 0 |
| 6 | $(4.306,\ -0.251)$ | 1046.726 | 0 |

上位3点の重み付き平均で、次の平均は $(3.244,\ 1.362)$ になり、そこでの値は $187.8$ です。
良い点は、谷の中心線 $x_1=x_2$ に近い点です。2位の点は、平均から右上へ $(0.966,\ 1.123)$ ずれていて、この一歩が重み $0.285$ で楕円に重なります。
1世代目のあとの楕円は、縦横比 $1.05$ とほとんど丸いままで、長い軸は右上がり約53°を向きます。1世代だけでは形はほとんど変わらず、向きも世代ごとに揺れます。何世代も谷に沿う一歩が選ばれ続けることで、楕円は谷の形に近づきます。
平均の一歩が短かったので、歩幅は $\sigma=1$ から $0.834$ に縮みます。

### 谷の例・世代を重ねると

同じ乱数の種で、世代を重ねたときの記録です。縦横比は、楕円の長い軸と短い軸の比です。

| 世代 | いちばん良い値 | 歩幅 $\sigma$ | 楕円の縦横比 |
|---:|---:|---:|---:|
| 0 | 183 | 1.000 | 1.0 |
| 10 | 14.8 | 1.042 | 1.6 |
| 20 | 0.585 | 1.056 | 4.5 |
| 30 | $2.3\times10^{-3}$ | 0.180 | 6.0 |
| 70 | $2.3\times10^{-11}$ | $2.7\times10^{-4}$ | 9.9 |

20世代目ごろから楕円が谷の形に近づき、それに合わせて値が速く下がり始めます。70世代目の楕円の長い軸の向きは $(0.708,\ 0.706)$ で、谷の向き $(1,1)/\sqrt2$ とほぼ一致します。値が $10^{-6}$ を切るのは42世代目です。

### 谷の例・丸いまま歩幅だけを調整すると

手順5を止めて、楕円を丸いままにし、歩幅だけを調整します。すると60世代でもいちばん良い値は $0.121$ で、一度も $10^{-3}$ を切りません。
丸い楕円から出した点は、谷を横切る向きにも同じだけ散らばります。横切る向きは曲がりが100倍なので、その点はほとんど悪い値になり、選ばれません。6点のうち谷に沿う向きの点だけが役に立つので、一世代で進める距離が短くなります。

谷が丸い $f=u^2+v^2$ では、形を学ぶCMA-ESが37世代、丸いままの方法が42世代で $10^{-6}$ を切ります。形を学ぶ効果は、谷が細長いときに大きく現れます。

## 向く条件・避ける条件

向く条件です。

- 変数が連続で、勾配が手に入らないか信用できない。目的関数に不連続があってもよい（[微分なし最適化](#/learn/concept.derivative-free)）
- 谷が細長く、変数どうしが斜めに絡み合っている
- 次元が数個から数十個程度で、1世代の点を並列に評価できる
- 証明より、実用的に良い候補が必要

避ける、または切り替える条件です。

- 勾配が信頼できる → [BFGS](#/learn/bfgs)、[L-BFGS-B](#/learn/lbfgsb)
- 残差の形の目的関数で、ヤコビアンがある → [非線形最小二乗](#/learn/concept.nonlinear-least-squares)
- 一回の評価が極端に高価 → [ベイズ最適化](#/learn/bayesian-optimization)（[高価な低次元評価](#/formulations/PA014)）
- 変数が離散・論理的 → [CP-SAT](#/learn/cp-sat)や混合整数計画
- 次元が非常に高い → 共分散行列は次元の二乗の大きさになるので、[高次元のブラックボックス最適化](#/formulations/PA015)の別の方法も比べる

初期の歩幅 $\sigma$ は、最初にどこまで探すかを決めます。小さすぎると始点の近くだけを探し、大きすぎると上下限や無効な領域に多くの点が落ちます。変数の尺度がそろうように無次元化してから $\sigma$ を決めます。

## Python

次の例は、小さな例と同じ谷を、CMA-ESの公式実装pycmaで解きます。

```python
import cma
import numpy as np


def valley(x: np.ndarray) -> float:
    u = (x[0] + x[1]) / np.sqrt(2)
    v = (x[0] - x[1]) / np.sqrt(2)
    return u**2 + 100 * v**2


es = cma.CMAEvolutionStrategy([3.0, 1.0], 1.0, {"seed": 1, "verbose": -9, "ftarget": 1e-10})
es.optimize(valley)
print(es.popsize, es.countiter, es.countevals)  # 6 63 378
print(f"{es.result.fbest:.1e}")  # 5.1e-11
print(round(es.sm.condition_number ** 0.5, 1))  # 13.0
```

1行目は左から順に、1世代の点の数 $6$ と世代数 $63$ と関数の評価回数 $378$ です。2行目が見つけた最良の値、3行目が最後の楕円の縦横比です。
pycmaは図とは別の乱数を使うので、点の出方と世代数は小さな例と一致しません。同じなのは、1世代6点で始め、楕円を谷の向きに伸ばして下るという流れです。
pycmaの設定項目と既定値は、pycmaの公式ドキュメントと、Hansenのチュートリアルで確かめられます。

## 診断値

| 診断値 | 見方 | 判断 |
|---|---|---|
| いちばん良い値と、集団の中央値 | 集団全体が下がっているか | 中央値も下がっていれば継続します |
| 歩幅 $\sigma$ | 探索の広さ | 早い段階で極端に小さくなったら、局所解か平らな場所に閉じ込められています |
| 楕円の縦横比（共分散の条件数の平方根） | 分布がどれだけ細長いか | 小さな例では谷の比10に近づきました。極端に大きいなら、変数の尺度を見直します |
| 評価回数 | 予算をどれだけ使ったか | 再始動したときは、合計の評価回数で報告します |
| 乱数の種ごとの結果 | 一回の成功が偶然でないか | 小さな例では、種1〜3で $10^{-6}$ を切る世代が42〜45とずれました |

楕円が小さくなったことは、最も深い谷にいることの証明ではありません。複数の乱数の種と、同じ評価予算で比べます。

## 失敗・切替の兆候

| 症状 | 考えられる原因 | 対処・切替先 |
|---|---|---|
| $\sigma$ が早く極小になり、値が止まる | 局所解に集団が閉じ込められた | 再始動（IPOPなど）を使い、評価予算を分けて報告します。[Differential Evolution](#/learn/differential-evolution)とも比べます |
| 楕円の縦横比が極端に大きくなる | 変数の尺度がそろっていない | 変数を無次元化します |
| 順位がばらばらに入れ替わる | 評価のノイズが値の差より大きい | 集団を大きくする、同じ点を複数回評価する（[ノイズを含むブラックボックス](#/formulations/PA013)） |
| 上下限の外や失敗領域に点が多く落ちる | 初期の $\sigma$ が大きすぎる | 上下限の扱いと初期の $\sigma$ を見直します |
| 次元が高く、1世代が重い | 共分散が次元の二乗の大きさ | 高次元向けの方法と比べます |

## 困りごとから関連する手法へ

- 勾配が使える、または安く計算できる → [BFGS](#/learn/bfgs)：勾配の変化から曲がりを覚えるので、一点あたりの情報が多い
- 一回の評価が数分〜数時間かかる → [ベイズ最適化](#/learn/bayesian-optimization)：試す点を代理モデルで一つずつ慎重に選ぶ
- 谷がいくつもあり、集団が一つの谷に潰れる → [大域探索の選び分け](#/learn/family.global-search)
- 変数が2〜3個で、局所的に詰めたいだけ → [Nelder–Mead](#/learn/method.nelder-mead)、[MADS](#/learn/mads)
