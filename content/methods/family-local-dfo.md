勾配を使えない低〜中次元の連続問題で、Nelder–Mead、Powell、Pattern Search、COBYLA、MADSを選び分ける入口です。

## 30秒でつかむ

この手法群の気持ちは、**傾きが分からなくても、少し違う点を実際に試し、良かった方向・形・格子を次の探索へ引き継ぐこと**です。

- 見ているもの: 関数値、候補点の比較、探索点の配置、必要なら制約違反
- 動かすもの: 単体、方向集合、周囲の候補点、格子、局所モデル
- 前進の判断: 評価値の改善と探索半径・格子の縮小
- 主な弱点: 評価回数、高次元、ノイズによる差の判別限界、弱い停止診断

「微分不要」は「情報不要」ではありません。上下限、変数尺度、評価予算、失敗した評価の扱いが結果を大きく変えます。

## まず確認すること

| 確認項目 | 選択への影響 |
|---|---|
| 次元 | 次元が増えるほど候補評価が重くなる |
| 1評価の費用 | 数十〜数千回の評価が許されるか |
| 上下限・一般制約 | 無制約、単純上下限、ブラックボックス制約のどれか |
| ノイズ | 小さな改善を信頼できるか、再評価が必要か |
| 不連続・失敗 | シミュレーション失敗をどの値として扱うか |
| 求める保証 | 良い局所候補か、停留性の理論が必要か |

評価が非常に高価で回数が数十回に限られるなら、局所DFOよりBayesian Optimizationや代理モデル法を先に検討します。

## 条件付きの選び分け

| 役割 | 手法 | 優先しやすい条件 | 切り替えを考える条件 |
|---|---|---|---|
| 最も素朴な低次元候補 | [Nelder–Mead](#/learn/method.nelder-mead) | 非常に低次元、無制約または単純上下限、評価が比較的安価 | 単体退化、縮小反復、高次元 |
| 方向を再利用 | [Powell法](#/learn/powell) | 座標・方向ごとの探索が効く、滑らかだが勾配なし | 直線探索が不安定、方向集合が問題に合わない |
| 規則的な近傍探索 | [Pattern Search](#/learn/pattern-search) | 上下限内で分かりやすい周囲の候補点の評価を試したい | 格子縮小だけ続き改善しない |
| 微分なしの一般制約 | [COBYLA](#/learn/cobyla) | 低次元、非線形制約を局所線形近似で扱いたい | 制約違反が停滞、尺度が悪い |
| ブラックボックス制約と理論 | [MADS](#/learn/mads) | 評価失敗・ブラックボックス制約、探索格子上での停留性を重視 | 周囲の候補点の評価数が評価予算を圧迫、高次元 |
| 同時摂動で高次元へ | [SPSA](#/methods/M_SPSA) | ノイズあり、高次元、座標差分が高価 | 係数の変更規則が不安定、分散が大きすぎる |

同じ「関数値だけで動く」手法でも、探索状態と制約の扱いは大きく違います。

## うまくいったサインと切替サイン

追うべき値:

- それまでの最良の目的値
- 評価回数
- 単体直径 / 格子大きさ / 候補点集合の大きさ
- 改善に成功した一歩の割合
- 再評価された点や重複した点
- 制約違反
- 再評価した点の分散
- 異なる初期点・初期探索点の配置での解

切替サイン:

- 探索点の配置だけ縮み最良値が改善しない → 尺度の調整、再始動、別手法群を検討
- ノイズによる差の判別限界以下の差を追う → 再評価、頑健な比較、停止条件を変更
- 高次元で周囲の候補点の評価数が支配的 → SPSA、代理モデル、構造を使う手法へ
- 一般制約の違反が減らない → COBYLA/MADS、または滑らかなら制約付きNLPへ
- 初期点ごとに別谷へ入る → 大域探索の手法群へ

## 小さな比較の型

DFO比較では反復より目的関数の評価数が重要です。

```python
experiment = {
    "problem_instance": "same-black-box-instance",
    "bounds": [(-2.0, 2.0), (-1.0, 3.0)],
    "initial_point": [-1.2, 1.0],
    "objective_evaluation_budget": 400,
    "noise_repeats": 1,
    "methods": ["Nelder-Mead", "Powell", "MADS"],
}

assert experiment["objective_evaluation_budget"] >= 1
```

## コラム: 小さくなったことと解けたこと

単体、格子、探索半径が小さくなるのは、局所探索が細かくなったことを示します。しかし、良い谷にいることや大域最適性を証明するものではありません。

停止時には、探索点の配置だけでなく最良の目的値、制約違反、複数初期点、残り評価予算を併記します。手法固有の停留性保証がある場合も、その前提と実装の停止判定を区別します。
