全座標を個別に差分評価せず、ランダムな一方向の正負2評価から高次元勾配を確率的に推定する局所法です。

## 30秒でつかむ

多数のつまみを一つずつ試す代わりに、まとめて少し動かして音の変化を比べます。SPSAは、その正負の変化から下り方向を推定します。

変数が何千個あっても、各座標を一つずつ揺らしません。全部を同時に少し揺らした二つの評価から、下り方向をおおまかに推定します。

- 見るもの: 正負に摂動した2点の関数値
- 動かすもの: 現在点、ランダム摂動、更新幅の列
- 前進の判断: 同一点の再評価と平均的な改善。雑音つき最小観測値だけを最良解の証拠にしない

一回の勾配推定に必要な評価数が次元へ直接比例しにくい点が強みですが、推定方向は強く揺れます。

## 一手の意味

### 仕組み

各成分が独立に確率1/2で $+1$ または $-1$ を取るRademacherベクトル $\Delta_k$ を作り、二つの値を評価します。雑音のある測定では、以下の $f$ の値に観測誤差が加わります。

$$
y_+ = f(x_k+c_k\Delta_k),\qquad y_- = f(x_k-c_k\Delta_k)
$$

各成分の勾配推定は次で定義します。$\Delta_i=\pm1$ なので、成分が0になることも、0に近い値で割ることもありません。

$$
\hat g_{k,i}=\frac{y_+-y_-}{2c_k\Delta_{k,i}}
$$

その後、$x_{k+1}=x_k-a_k\hat g_k$で更新します。$a_k$と$c_k$の予定、摂動分布、再評価回数が挙動を決めます。


### 2評価で何が分かり、何が残るか

滑らかな $f$ を現在点のまわりで展開すると、中心差分から

$$
\hat g_i=\nabla_i f(x)+\sum_{j\ne i}\nabla_j f(x)\Delta_j\Delta_i+O(c^2)
$$

となります。主題は右辺の和です。他の座標の勾配がランダムな符号で混ざります。独立・対称な符号なら $\mathbb E[\Delta_j\Delta_i]=0$ なので、平均を取ったときに混ざりが消えます。一方向の2評価から各成分の勾配を正確に復元したわけではありません。$O(c^2)$ は局所で十分な滑らかさがある場合の有限差分バイアスで、目的が二次関数ならこの項は0です。

Rademacherの選択は単なる実装上の好みではありません。この逆数を使う推定式へ、そのまま正規分布の摂動を代入すると、0付近の分母が大きな問題になります。標準SPSAの分布条件、滑らかさ、雑音、係数列については、[Spallによる概説](https://www.jhuapl.edu/spsa/PDF-SPSA/Spall_An_Overview.PDF)で確認できます。

## 小さな例

$f(x)=(x_1-1)^2+(x_2-1)^2$ を $(0,0)$ から解きます。
摂動幅 $c=0.1$、更新幅 $a=0.1$ を固定し、摂動を順に $(1,1),(1,-1),(1,1)$ としました。
雑音を加えず式だけを実行した結果です。

| 更新 | 正側の値 | 負側の値 | 更新後の点 | 目的値 |
|---|---:|---:|---|---:|
| 1 | 1.62 | 2.42 | $(0.4,0.4)$ | 0.7200 |
| 2 | 0.74 | 0.74 | $(0.4,0.4)$ | 0.7200 |
| 3 | 0.50 | 0.98 | $(0.64,0.64)$ | 0.2592 |

2回目は正負の値が等しく、推定勾配がゼロになります。
真の勾配はゼロではありません。一度の推定だけで停止を決めない理由が見えます。


### 真の勾配が残っていても、方向を外すと0になる

初回の差は $1.62-2.42=-0.8$ なので、$\hat g=(-4,-4)$、移動は $(0.4,0.4)$ です。真の初期勾配 $(-2,-2)$ と既に異なっています。

2回目の現在点は $(0.4,0.4)$ です。$(1,-1)$ へ揺らすと正負の点は $(0.5,0.3)$ と $(0.3,0.5)$。どちらも値は0.74で、差が0になります。しかし真の勾配は $(-1.2,-1.2)$ です。等高線に沿う向きを引いたので、その一方向だけでは下り坂を検出できません。

![同じ二次関数の2回目。正負の摂動点は同じ等高線上にあり、推定は0。全4方向の推定を並べると、平均が真の勾配成分−1.2に一致する。](./media/spsa-two-evaluations.svg "同じ点の全4方向を別々に2回ずつ評価した比較です。8評価の平均を、1方向2評価の結果と取り違えません。")

この点で全4通りを列挙すると、$(1,1)$ と $(-1,-1)$ はどちらも推定 $(-2.4,-2.4)$、残る2方向は $(0,0)$ です。平均は $(-1.2,-1.2)$ に一致しますが、各成分の分散は1.44あります。この平均は4方向を調べた結果であり、1方向2評価の結果と取り違えません。掲載検証は各方向を別に2回ずつ評価して計8回です。

一般の二次関数でも、雑音のないRademacher推定の各成分の分散は $\sum_{j\ne i}(\nabla_j f)^2$ です。次元が増えても一推定の評価数は2のままですが、推定の質が次元に無関係という意味ではありません。

### 摂動幅を小さくしすぎると、雑音が増幅する

正負の観測に独立で平均0、分散 $\sigma^2$ の雑音があるなら、差分に由来する勾配推定の追加分散は各成分で $\sigma^2/(2c^2)$ です。$c$ を半分にすると、この分散は4倍になります。小さな $c$ は近似バイアスを減らす一方、測定雑音の影響を増やします。摂動の分散と観測雑音の分散を分けて診断します。

独立な推定を $m$ 本平均すれば分散を減らせますが、一更新の費用は $2m$ 評価になります。同じ乱数を正負のシミュレーションへ対応づける共通乱数も、誤差差の分散を減らす場合があります。ただし正負それぞれが目的どおりの測定分布を保つことを確認します。ログの同じ数を使い回すこととは異なります。

## 向く条件・避ける条件

### まず確認すること

| 項目 | 確認内容 |
|---|---|
| 次元 | 座標差分が高価になるほど大きいか |
| 雑音 | 同一点でも値が揺れるか、平均化できるか |
| 予算 | 多数の小一歩を繰り返せるか |
| 上下限 | 摂動点と更新点をどう実行可能に保つか |
| 尺度 | 座標ごとの単位差が摂動を壊さないか |

正確な自動微分を使えるなら、まず確率勾配や一階法を比較します。低次元なら通常の有限差分の方が診断しやすい場合があります。

向きやすい条件:

- 高次元で関数値だけ得られる
- 評価雑音があり、座標差分を大量に取れない
- 1回の勾配推定あたりの評価数を抑えたい
- 粗い局所改善を多数一歩で積み上げられる

避ける条件:

- 評価回数が数十回しかない高価実験
- 離散・カテゴリ変数が中心
- 厳密な停留性や大域証明が必要
- 上下限外の評価が危険で射影も意味を壊す

## Python


### 本文の3更新を再現する

ここでは乱数を使わず、摂動の順序を明示します。推定に6評価、表の更新後の値の確認に別途3評価を使います。

```python
import numpy as np

def exact_objective(x):
    return float(np.sum((x - 1.0)**2))

x = np.zeros(2)
update_calls = diagnostic_calls = 0
for k, delta in enumerate(([1, 1], [1, -1], [1, 1]), start=1):
    delta = np.asarray(delta, dtype=float)
    y_plus = exact_objective(x + 0.1 * delta)
    y_minus = exact_objective(x - 0.1 * delta)
    update_calls += 2
    estimated_gradient = (y_plus - y_minus) / (0.2 * delta)
    x -= 0.1 * estimated_gradient
    value = exact_objective(x)
    diagnostic_calls += 1
    print(k, round(y_plus, 4), round(y_minus, 4),
          np.round(estimated_gradient, 4), np.round(x, 4), round(value, 4))
print(update_calls, diagnostic_calls)
# 1 1.62 2.42 [-4. -4.] [0.4 0.4] 0.72
# 2 0.74 0.74 [ 0. -0.] [0.4 0.4] 0.72
# 3 0.5 0.98 [-2.4 -2.4] [0.64 0.64] 0.2592
# 6 3
```

### 補足：20変数・雑音つきの別実験

次は同じ二次関数の形を20変数に広げ、標準偏差0.01の独立観測雑音を加える例です。主図の再現ではありません。100更新には200評価、末尾の表示にもう1評価を使います。固定乱数は手順の再現用です。

```python
import numpy as np

rng = np.random.default_rng(7)


def objective(x: np.ndarray) -> float:
    noise = 0.01 * rng.normal()
    return float(np.sum((x - 1.0) ** 2) + noise)


x = np.zeros(20)
for iteration in range(1, 101):
    delta = rng.choice(np.array([-1.0, 1.0]), size=x.shape)
    a_k = 0.1 / (iteration ** 0.602)
    c_k = 0.1 / (iteration ** 0.101)
    y_plus = objective(x + c_k * delta)
    y_minus = objective(x - c_k * delta)
    gradient_estimate = (y_plus - y_minus) / (2.0 * c_k * delta)
    x = x - a_k * gradient_estimate

print(x[:3], objective(x))
```


NumPy 2.3.5で上の順序を実行すると、最初の3成分は約 $(1.154243,0.879246,1.057137)$、末尾の雑音つき観測値は約0.469980です。この模擬問題では正確な目的も別途計算でき、約0.467788でした。実験装置やブラックボックスでは、この「雑音を除いた真値」を観測できるとは限りません。

同じ100更新の手順を乱数種0〜29で繰り返すと、雑音を除いた最終値の中央値は約1.1171、最小は0.3113、最大は3.9078でした。種7だけを見て安定性を主張しないための、同一設定内のばらつき確認です。別手法より優れるという比較ではありません。

減衰列 $a_k=0.1/k^{0.602}$、$c_k=0.1/k^{0.101}$ を書いたことだけで、この100回の精度や全問題での収束を保証するわけではありません。標準的な確率近似では滑らかさ、雑音の条件、反復の安定性、適切な係数列が必要です。尺度の違う実問題では変数を無次元化し、最初の数回の更新量が実用範囲かを確認します。

上下限がある場合、更新後の点だけを射影しても、先に測る $x\pm c\Delta$ が範囲内とは限りません。正負をそれぞれ無造作に切り詰めると対称差分の式も変わります。摂動が安全に可能な表現や幅を先に設計し、測れない候補を発生させないようにします。

## 診断値

見る値:

- 共通の再評価予算で比較した候補の平均値。雑音つきの最小観測値は楽観的に偏り得る
- 推定勾配ノルム
- 更新量のノルム
- 正負評価差
- 同じ点の再評価分散
- 上下限への切り詰め率
- 乱数種間の結果分布

- 恐れていること: 推定分散、一歩予定の不適合、制約違反

## 失敗・切替の兆候

- 更新方向が毎回反転し最良が改善しない → 更新幅の予定と平均化を見直す
- 正負評価差が雑音以下 → 摂動幅を調整する
- 上下限へ頻繁に切り詰め → 変数の表現や射影を見直す
- 少数評価しか使えない → Bayesian Optimizationへ
- 勾配の取得手段を追加できる → 確率勾配法へ

### コラム: 2評価で勾配が正確になるわけではない

SPSAは評価数を抑える代わりに分散を受け入れます。単一一歩の方向を精密に解釈するより、複数一歩・複数の乱数種・移動平均で傾向を見ます。
