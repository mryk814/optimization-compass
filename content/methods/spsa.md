全座標を個別に差分評価せず、ランダムな一方向の正負2評価から高次元勾配を確率的に推定する局所法です。

## 30秒でつかむ

多数のつまみを一つずつ試す代わりに、まとめて少し動かして音の変化を比べます。SPSAは、その正負の変化から下り方向を推定します。

変数が何千個あっても、各座標を一つずつ揺らしません。全部を同時に少し揺らした二つの評価から、下り方向をおおまかに推定します。

- 見るもの: 正負に摂動した2点の関数値
- 動かすもの: 現在点、ランダム摂動、更新幅の列
- 前進の判断: 雑音を含むなこれまでの最良値と平均的な改善

一回の勾配推定に必要な評価数が次元へ直接比例しにくい点が強みですが、推定方向は強く揺れます。

## 一手の意味

### 仕組み

ランダムベクトル $\Delta_k$を作り、二つの値を評価します。

$$
y_+ = f(x_k+c_k\Delta_k),\qquad y_- = f(x_k-c_k\Delta_k)
$$

各成分の勾配推定は概ね次です。

$$
\hat g_{k,i}=\frac{y_+-y_-}{2c_k\Delta_{k,i}}
$$

その後、$x_{k+1}=x_k-a_k\hat g_k$で更新します。$a_k$と$c_k$の予定、摂動分布、再評価回数が挙動を決めます。

## 小さな例

$f(x)=(x_1-1)^2+(x_2-1)^2$ を $(0,0)$ から解きます。
摂動幅 $c=0.1$、更新幅 $a=0.1$ を固定し、摂動を順に $(1,1),(1,-1),(1,1)$ としました。
雑音を加えず式だけを実行した結果です。

| 更新 | 正側の値 | 負側の値 | 更新後の点 | 目的値 |
|---|---:|---:|---|---:|
| 1 | 1.62 | 2.42 | $(0.4,0.4)$ | 0.7200 |
| 2 | 0.74 | 0.74 | $(0.4,0.4)$ | 0.7200 |
| 3 | 0.50 | 0.98 | $(0.64,0.64)$ | 0.2592 |

2回目は正負の値が等しく、推定勾配がゼロになります。
真の勾配はゼロではありません。一度の推定だけで停止を決めない理由が見えます。

## 向く条件・避ける条件

### まず確認すること

| 項目 | 確認内容 |
|---|---|
| 次元 | 座標差分が高価になるほど大きいか |
| 雑音 | 同一点でも値が揺れるか、平均化できるか |
| 予算 | 多数の小一歩を繰り返せるか |
| 上下限 | 摂動点と更新点をどう実行可能に保つか |
| 尺度 | 座標ごとの単位差が摂動を壊さないか |

正確な自動微分を使えるなら、まず確率勾配や一階法を比較します。低次元なら通常の有限差分の方が診断しやすい場合があります。

向きやすい条件:

- 高次元で関数値だけ得られる
- 評価雑音があり、座標差分を大量に取れない
- 1回の勾配推定あたりの評価数を抑えたい
- 粗い局所改善を多数一歩で積み上げられる

避ける条件:

- 評価回数が数十回しかない高価実験
- 離散・カテゴリ変数が中心
- 厳密な停留性や大域証明が必要
- 上下限外の評価が危険で射影も意味を壊す

## Python

```python
import numpy as np

rng = np.random.default_rng(7)


def objective(x: np.ndarray) -> float:
    noise = 0.01 * rng.normal()
    return float(np.sum((x - 1.0) ** 2) + noise)


x = np.zeros(20)
for iteration in range(1, 101):
    delta = rng.choice(np.array([-1.0, 1.0]), size=x.shape)
    a_k = 0.1 / (iteration ** 0.602)
    c_k = 0.1 / (iteration ** 0.101)
    y_plus = objective(x + c_k * delta)
    y_minus = objective(x - c_k * delta)
    gradient_estimate = (y_plus - y_minus) / (2.0 * c_k * delta)
    x = x - a_k * gradient_estimate

print(x[:3], objective(x))
```

## 診断値

見る値:

- これまでの最良値と移動平均目的
- 推定勾配ノルム
- 更新量のノルム
- 正負評価差
- 同じ点の再評価分散
- 上下限への切り詰め率
- 乱数種間の結果分布

- 恐れていること: 推定分散、一歩予定の不適合、制約違反

## 失敗・切替の兆候

- 更新方向が毎回反転し最良が改善しない → 更新幅の予定と平均化を見直す
- 正負評価差が雑音以下 → 摂動幅を調整する
- 上下限へ頻繁に切り詰め → 変数の表現や射影を見直す
- 少数評価しか使えない → Bayesian Optimizationへ
- 勾配の取得手段を追加できる → 確率勾配法へ

### コラム: 2評価で勾配が正確になるわけではない

SPSAは評価数を抑える代わりに分散を受け入れます。単一一歩の方向を精密に解釈するより、複数一歩・複数の乱数種・移動平均で傾向を見ます。
