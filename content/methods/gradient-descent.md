現在点の勾配が示す局所的な上り方向と反対へstepを取り、滑らかな目的関数の値を反復的に下げる一次法です。

## 30秒でつかむ

霧の中で山を下りる場面を思い浮かべてください。見えるのは足元の傾きだけです。
いちばん急な下り方向へ一歩進み、また足元の傾きを測ります。この繰り返しが勾配降下法です。

- **見るもの**: 現在の目的関数値、勾配、試した一手（step）の結果
- **動かすもの**: 現在点と、一手の長さを決める係数（学習率、learning rate）
- **前進の判断**: 目的関数値が下がり、勾配の大きさ（gradient norm）が小さくなること

足元の傾きが正しいのは、足元の近くだけです。一手を長く取りすぎると、下っているつもりで谷の反対側を登ります。
挙動を左右する最初の要因は、この一手の長さです。

勾配を使えることが、この手法を選ぶ出発点です。目的関数が滑らかでも、勾配の尺度（scale）や制約の扱いが合わなければ、一手は安定しません。

## 一手の意味

勾配 $\nabla f(x_k)$ は、現在点で目的関数が最も急に増える方向です。その反対へ進む更新は次の式です。

$$
x_{k+1}=x_k-\eta_k\nabla f(x_k)
$$

式は「足元の傾きを信じて、$\eta_k$ だけ進む」と言っています。
傾きは足元でしか保証されません。有限の距離を進んだ先で目的値が下がるかは、学習率 $\eta_k$ と、進む先までの曲率で決まります。

### 学習率を読む

いちばん単純な谷で、学習率の効き方を計算してみます。
二次関数 $f(x,y)=(x-1)^2+\kappa(y+2)^2$ では、一手が座標ごとに独立に働きます。
最小点からのずれを $e$ と書くと、1回の更新でずれは次のように変わります。

$$
e_{k+1}=(1-\eta\lambda)\,e_k
$$

$\lambda$ はその方向の曲率で、$x$ 方向は $2$、$y$ 方向は $2\kappa$ です。倍率 $1-\eta\lambda$ が、ずれの行き先を決めます。

- 倍率の絶対値が1未満なら、ずれは縮みます。
- 倍率が負なら、最小点を飛び越えて符号が反転します。絶対値が1未満のあいだは、振動しながら縮みます。
- 倍率の絶対値が1を超えると、ずれは増え続けます。これが発散です。

すべての方向で絶対値が1未満になる条件は、最も急な方向の曲率を $L$ として $\eta<2/L$ です。$\kappa=20$ なら $L=40$ なので、限界は $\eta=0.05$ です。

細長い谷が厄介なのは、この限界が急な方向で決まるからです。急な方向に合わせて $\eta$ を小さくすると、ゆるやかな方向の倍率は $1$ に近づき、進みが遅くなります。
二つの方向の倍率を、同時に良くすることはできません。

次の図で、学習率と谷の細長さを動かしてください。初期点はドラッグでも動かせます。

## 小さな例

上の二次関数で、$\kappa=20$、初期点 $(4,\,3)$ の場合を追います。学習率は $\eta=0.04$ です。最初の数反復を手で確かめます。
勾配は $\nabla f=(2(x-1),\,40(y+2))$ です。最小点は $(1,\,-2)$ で、そこでの値は $0$ です。

| 反復 $k$ | $x_k$ | $y_k$ | $f(x_k,y_k)$ | 勾配のノルム |
|---:|---:|---:|---:|---:|
| 0 | 4.000 | 3.000 | 509.0 | 200.1 |
| 1 | 3.760 | −5.000 | 187.6 | 120.1 |
| 2 | 3.539 | −0.200 | 71.2 | 72.2 |
| 3 | 3.336 | −3.080 | 28.8 | 43.5 |
| 4 | 3.149 | −1.352 | 13.0 | 26.3 |

目的値は毎回下がっています。ところが、二つの座標の動き方は大きく違います。

- $y$ 方向は倍率が $1-0.04\cdot 40=-0.6$ です。最小点の上下を行き来しながら、ずれが $5,\,-3,\,1.8,\,-1.08$ と縮みます。
- $x$ 方向は倍率が $1-0.04\cdot 2=0.92$ です。ずれは $3,\,2.76,\,2.54,\,2.34$ と、ほとんど縮みません。

4反復たっても $x$ は最小点から $2.1$ 以上離れています。これが細長い谷での遅さです。

学習率を $\eta=0.06$ に上げると、$y$ 方向の倍率は $1-0.06\cdot 40=-1.4$ になります。
$y$ は $3,\,-9,\,7.8,\,-15.7,\,17.2$ と振れ幅を広げ、目的値は $509,\,987,\,1926,\,3769$ と増えます。限界 $0.05$ を超えると、こうして発散します。

## 向く条件・避ける条件

勾配降下法は、勾配が安く信頼でき、一反復を軽くしたいときの出発点です。
先に、次の項目を確認します。

| 項目 | 確認すること |
|---|---|
| 変数 | 連続変数であるか、射影できる単純な制約か |
| 目的関数 | 局所的に滑らかで、有限の値を返すか |
| 勾配 | 解析式、自動微分、検証済みの数値微分のいずれか |
| 尺度 | 座標ごとの単位や曲率が極端に違わないか |
| 目標 | 局所停留点でよいか、凸性により大域解を期待できるか |

勾配を計算できることと、勾配が正しいことは別です。実装前に、有限差分と方向微分を比べる勾配チェックを行います。

向く条件です。

- 滑らかな連続最適化である（[滑らかな無制約の最小化](#/formulations/PA006)）
- 勾配が安価で信頼できる
- 一反復を軽くして、大規模化したい
- 凸問題、または局所解でよい非凸問題である
- 確率的勾配の変種へ移行できる機械学習の問題である

避ける、または切り替える条件です。

- 離散変数やカテゴリ変数を含む
- 目的関数が不連続で、評価の失敗が頻発する
- 勾配のノイズが一手を支配している
- 強い一般制約を無視している
- 条件数が悪く極端に遅い → 尺度合わせ、前処理、[BFGS](#/learn/bfgs)系を検討する
- 上下限がある → [L-BFGS-B](#/learn/lbfgsb)のような上下限つきの手法へ切り替える（[上下限つきの滑らかな最小化](#/formulations/PA008)）
- 非滑らかな正則化がある → [近接勾配法](#/learn/proximal-gradient)へ切り替える
- 曲率情報を使える → [BFGS](#/learn/bfgs)や信頼領域法（trust-region法）と比べる

## Python

次の例は、上の二次関数に対して勾配降下法を実行する最小例です。
簡易な後退探索（backtracking）で、候補点の目的関数値が増えたときだけ学習率を半分にします。

```python
import numpy as np


def objective(x: np.ndarray) -> float:
    return float((x[0] - 1.0) ** 2 + 20.0 * (x[1] + 2.0) ** 2)


def gradient(x: np.ndarray) -> np.ndarray:
    return np.array([2.0 * (x[0] - 1.0), 40.0 * (x[1] + 2.0)])


x = np.array([4.0, 3.0])
learning_rate = 0.04
for iteration in range(2_000):
    g = gradient(x)
    if np.linalg.norm(g) < 1e-8:
        break
    candidate = x - learning_rate * g
    if objective(candidate) > objective(x):
        learning_rate *= 0.5
        continue
    x = candidate

print(iteration, x, objective(x), np.linalg.norm(gradient(x)))
# 243 [ 1. -2.] 2.27e-17 9.52e-09
```

この学習率 $0.04$ は限界 $0.05$ より小さいので、後退探索は一度も働きません。243回の更新で勾配のノルムが $10^{-8}$ を下回ります。
上の小さな例と同じ経路を、最後まで進めた結果です。

この例の簡易な後退探索は教育用です。実務ではWolfe条件など、利用する直線探索の契約（contract）を明示します。

## 診断値

目的値の変化だけで停止すると、尺度が小さいだけの点を収束と誤認することがあります。最低限、次を記録します。

- 勾配のノルム（gradient norm）
- 上下限がある場合は、射影した勾配のノルム
- 一手のノルム
- 目的関数値と、これまでの最良値
- 関数評価と勾配評価の回数
- 学習率
- NaN、オーバーフロー、直線探索の状態
- 反復回数と経過時間の予算

凸問題でも、停止許容値が粗ければ高精度な解ではありません。
非凸問題では、勾配のノルムが小さくても安心できません。局所解か鞍点か平坦な領域か、値からは区別がつかないからです。

## 失敗・切替の兆候

- 目的関数値が下がらず振動する → 学習率が限界 $2/L$ を超えている → 学習率を下げ、尺度と直線探索を確認する
- ジグザグが長く続く → 急な方向と緩やかな方向の曲率差が大きい → 尺度合わせ、前処理、Momentum、BFGS系を比べる
- 勾配のノルムが小さいのに目的値が改善しない → 鞍点や平坦な領域にいる → 停留点の種類を確認する
- 上下限や一般制約の違反が残る → 更新式が制約を知らない → 射影や、制約に対応した手法へ切り替える
