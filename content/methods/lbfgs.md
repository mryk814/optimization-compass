直近m組の移動と勾配の変化を保存し、逆ヘッセ行列を組み立てずに探索方向を求める、大規模な滑らかな無制約問題向けの準Newton法です。

## 30秒でつかむ

同じ距離だけ動いても、縦方向では傾きが大きく変わり、横方向ではあまり変わらない谷を考えます。いまの傾きだけを頼りに進むと、縦に動きすぎてしまいます。「どちらに動くと、傾きがどれだけ変わったか」を覚えておけば、進む向きを補正できます。

L-BFGS法は、その記録を直近の数組だけ残します。たくさんの変数どうしの関係を大きな表に保存する代わりに、次の一歩を計算するために必要な作用を、短い履歴から作ります。

- **見るもの**：現在の勾配、移動と勾配差の対、直線探索の結果
- **動かすもの**：現在点、探索方向、保存する履歴の窓
- **前進の判断**：目的値の減少、勾配の大きさ、直線探索の成否を確認する

「残す履歴」の図では、古い横方向の観測を外すと、「同じ勾配から出る向き」の矢印がどう変わるかを見てください。現在点は動かしていません。

![横と縦の観測を2組残す場合と、最新の縦の観測だけ残す場合で、同じ現在点から出る探索方向が変わる図](./media/lbfgs-memory-window.svg "同じ二次関数・現在点・初期尺度で履歴だけを変えた教材用の比較です。矢印の長さは統一しており、一歩の長さや収束速度を表しません。")

図から確かめられることは三つです。

1. 履歴を使わない灰色の矢印は、ほぼ縦を向いています。
2. 縦方向の観測を残すと、縦への動きすぎが補正されます。
3. 横方向の観測も残すと、横と縦の比がさらに変わります。

古い記録を捨てても、現在の位置まで巻き戻るわけではありません。変わるのは、いまの勾配から次の方向を作る計算です。

## 一手の意味

### 保存するのは位置の列ではなく二つの差

現在点を $x_k$、勾配を $g_k=\nabla f(x_k)$ とします。探索方向 $p_k$ と一歩の長さ $t_k$ を決めて移動すると、次の二つが得られます。

$$
s_k=x_{k+1}-x_k,
\qquad
 y_k=g_{k+1}-g_k.
$$

$s_k$ は「どう動いたか」、$y_k$ は「その結果、勾配がどう変わったか」です。二次関数でヘッセ行列が一定の $A$ なら、$y_k=A s_k$ が厳密に成り立ちます。したがって、この一対は曲率に関する観測になります。

滑らかな一般の関数では、勾配差は移動区間のヘッセ行列を平均した作用です。

$$
y_k=\int_0^1 \nabla^2 f(x_k+\tau s_k)s_k\,d\tau.
$$

一対から行列全体が分かるわけではありません。観測した方向についての情報を、次の方向作りに使います。

| 記号 | 意味 | 谷の例では |
|---|---|---|
| $x_k$ | 現在の変数の組 | 横と縦の位置 $(x,y)$ |
| $g_k$ | 現在の勾配 | $(2(x-1),\,40(y+2))$ |
| $(s_i,y_i)$ | 移動と勾配差の一対 | 横に1進むと勾配の横成分が2変化 |
| $m$ | 保存できる対の上限 | 1組または2組 |
| $H_k$ | 逆ヘッセ行列の近似 | 勾配の各方向を補正する作用 |
| $H_k^{(0)}$ | 履歴を適用する前の初期尺度 | 記事の手計算では $I$ |
| $t_k$ | 探索方向に進む長さ | 直線探索で選ぶ正の数 |

### 行列を保存せず 行列を掛けた結果を得る

[BFGS法](#/learn/bfgs)は、逆ヘッセ行列の近似を更新します。その更新を、正定値な初期行列 $H_k^{(0)}$ に、保持している対だけ古い順に適用したものを考えます。L-BFGSは、この行列を実際に作らず、$H_k g_k$ を求めます。

一対による逆行列側のBFGS更新は、次の形です。

$$
\rho_i=\frac{1}{y_i^T s_i},
\qquad
H^+=(I-\rho_i s_i y_i^T)H(I-\rho_i y_i s_i^T)
       +\rho_i s_i s_i^T.
$$

これを履歴の分だけ展開し、最後に掛けるベクトルから計算すると、**二重ループの再帰計算**になります。

1. $q\leftarrow g_k$ とし、新しい対から古い対へ進みます。

$$
a_i=\rho_i s_i^Tq,
\qquad
q\leftarrow q-a_i y_i.
$$

2. 初期尺度を掛けます。$H_k^{(0)}=\gamma_k I$ なら、$r\leftarrow\gamma_k q$ です。
3. 古い対から新しい対へ戻ります。

$$
b_i=\rho_i y_i^Tr,
\qquad
r\leftarrow r+s_i(a_i-b_i).
$$

最後に $p_k=-r$ とします。最初のループで求めた $a_i$ は、戻るループでも同じ値を使います。この計算と、同じ初期尺度・同じ対を使って行列を作る計算は、数学的には同じ結果になります。[Nocedalの原論文](https://courses.engr.illinois.edu/ece544na/fa2014/nocedal80.pdf)は、この限られた履歴からの更新を導いています。

### 履歴を捨てるときに起きること

上限が $m=2$ なら、保存している対は次のように移ります。

| 時点 | 保存する対 |
|---|---|
| 2組目を得た直後 | $(s_0,y_0)$、$(s_1,y_1)$ |
| 3組目を得た直後 | $(s_1,y_1)$、$(s_2,y_2)$ |

古い位置 $x_0$ へ戻る操作ではありません。また、すべての履歴をリセットする操作でもありません。現在点はそのままに、次の計算で使う対の集合を入れ替えます。

通常のBFGS行列から「古い対の分を単純に引く」とも違います。後の更新は前の更新に依存するため、引けば済む独立な足し算にはなっていません。L-BFGSは、残した対を初期尺度に適用する形で、その作用を計算し直します。

### 一反復で関数を呼ぶのはどこか

1. 現在の勾配と保存済みの対から、二重ループで探索方向を計算します。
2. 直線探索で一歩の長さを選びます。候補点の関数値や勾配の評価が必要になります。
3. 採用した移動から新しい対を作り、曲率の条件を確認して保存します。
4. 上限を超えたら最古の対を外し、停止条件を確認します。

二重ループ自体は、すでにあるベクトルへの内積と加算です。シミュレーションや大きなモデルの評価が高価な問題では、計算時間の多くが直線探索に使う関数・勾配評価に掛かることがあります。

## 小さな例

### 縦に急な谷で最初の一歩を作る

同じ谷を、次の二次関数で表します。

$$
f(x,y)=(x-1)^2+20(y+2)^2.
$$

最小点は $(1,-2)$、ヘッセ行列は $A=\operatorname{diag}(2,40)$ です。初期点は $(4,3)$、履歴の上限は $m=1$、初期尺度は毎回 $I$ に固定します。乱数は使いません。

この小例だけは、正定値二次関数に対する厳密な直線探索を使います。

$$
t_k=-\frac{g_k^Tp_k}{p_k^TAp_k}.
$$

実用のL-BFGSが一般の関数にこの式を使うわけではありません。通常は直線探索で関数や勾配を評価しながら長さを決めます。

最初は履歴がないため、$g_0=(6,200)$ から $p_0=(-6,-200)$ へ進みます。

| 量 | 計算値 |
|---|---:|
| 一歩の長さ $t_0$ | $0.0250214$ |
| 移動後 $x_1$ | $(3.849872,-2.004275)$ |
| 移動 $s_0$ | $(-0.150128,-5.004275)$ |
| 勾配差 $y_0$ | $(-0.300256,-200.170992)$ |
| 新しい勾配 $g_1$ | $(5.699744,-0.170992)$ |

縦方向の大きな勾配はほぼ消えましたが、横にはまだ最小点までの距離があります。ここで、保存した一対を使います。

$\rho_0\approx0.000998247$ で、二重ループは次の計算になります。

| 段階 | 計算結果 |
|---|---|
| 新しい対から $a_0=\rho_0s_0^Tg_1$ | 約 $0$ |
| $q=g_1-a_0y_0$ | 約 $(5.699744,-0.170992)$ |
| 初期尺度 $I$ を掛ける | 同じ値 |
| 戻りの $b_0=\rho_0y_0^Tr$ | 約 $0.0324593$ |
| 補正後の方向 $p_1=-r$ | $(-5.704617,0.008557)$ |

$g_1$ が直前の移動と直交するため、この厳密な直線探索の例では $a_0$ がほぼ0です。それでも、戻りの補正は残っています。「$a_0=0$ なら履歴を使わない」という読み方はできません。

もう一度、厳密な直線探索をすると、$t_1\approx0.499573$ で最小点 $(1,-2)$ に到達します。BFGSもまだ一対しか使わない段階なので、同じ初期尺度なら同じ方向です。この2変数の特別な例は、古い対を捨てる前に解けます。

### 同じ谷で履歴だけを変える

最古の対を外す作用は、最適化の軌跡とは分けて確かめます。同じ関数で、横と縦に一単位ずつ動かしたときの観測対を用意します。

$$
s_0=(1,0),\quad y_0=(2,0),
\qquad
s_1=(0,1),\quad y_1=(0,40).
$$

現在点を $(3,3)$、勾配を $(4,200)$ に固定します。これは履歴の働きを切り分ける教材用の入力で、上の最適化で得た軌跡ではありません。初期尺度も $I$ に固定します。

| 残す観測 | 逆ヘッセ行列近似の対角成分 | 探索方向 |
|---|---|---|
| なし | $(1,1)$ | $(-4,-200)$ |
| 最新の縦だけ | $(1,1/40)$ | $(-4,-5)$ |
| 横と縦の2組 | $(1/2,1/40)$ | $(-2,-5)$ |

最新の対は「縦の勾配は、位置の変化に対して40倍変わる」という情報です。これを反映すると、縦の勾配200をそのまま使わず、5へ補正します。

横の対も残すと、横の勾配4が2へ補正されます。最古の横の対を外すと、その方向では初期尺度の1に戻るため、探索方向の横成分は再び4になります。冒頭の図は、この表の方向を同じ長さにそろえたものです。

この対角な二次関数では、独立な二方向を観測した結果、2組で真の逆ヘッセ行列を再現できています。一般の関数で「2組あれば正しい曲率が分かる」という意味ではありません。

### 初期尺度も方向に効く

よく使われる初期尺度の選び方の一つは、最新の対から

$$
\gamma_k=\frac{s_{k-1}^Ty_{k-1}}{y_{k-1}^Ty_{k-1}}
$$

を求める方法です。[LiuとNocedalの論文](https://users.iems.northwestern.edu/~nocedal/PDFfiles/limited-memory.pdf)は、初期尺度とその更新方法も扱っています。

上の縦の対なら $\gamma=1/40$ です。縦の対だけを使い、この尺度で計算すると方向は $(-0.1,-5)$ になります。横の情報がないとき、初期尺度の選び方が横の成分にも効くからです。

したがって、履歴数 $m$ を比べるときは、現在点・履歴の元データ・初期尺度・直線探索をそろえます。履歴数だけでは、次の方向は一意には決まりません。

## 向く条件・避ける条件

| 条件 | 判断の理由 |
|---|---|
| 変数が多く、信頼できる勾配を計算できる | 行列を持たずに曲率の情報を使えるため |
| 局所的に滑らかな無制約問題 | 勾配差と直線探索を利用するため |
| 関数・勾配の値が同じ点で安定している | 一対の差を意味のある曲率として扱いやすいため |
| 非凸問題では局所的な解を許容できる | 大域最適性を保証する方法ではないため |

密な逆ヘッセ行列には概ね $O(n^2)$、$m$ 組のベクトル対には $O(mn)$ のメモリが必要です。二重ループの方向計算も $O(mn)$ です。

例えば10万変数を倍精度8バイトで扱うと、密な行列の全成分は約80GBです。10組のベクトル対だけなら約16MBになります。どちらも単純な格納量の比較で、目的関数側のメモリ、作業ベクトル、実装固有の領域は別です。

上限 $m$ を増やすと、利用する観測と1反復の計算量は増えます。ただし、方向が真のNewton方向へ単調に近づくことや、総計算時間が必ず減ることは保証されません。変数の尺度、初期尺度、直線探索、古い情報が現在の場所でも有効かが関係します。

上下限が必要なら [L-BFGS-B](#/learn/lbfgsb)、密な近似行列を持てるなら [BFGS法](#/learn/bfgs)も候補です。絶対値などの折れ目をそのまま含む目的関数では、滑らかさを仮定したL-BFGSの説明を、そのまま適用しないでください。

## Python

同じ谷をSciPyで解きます。`maxcor` が履歴の上限に対応します。`bounds` は渡していないため、上下限制約なしの問題です。

```python
import numpy as np
from scipy.optimize import minimize


def objective(z):
    x, y = z
    return (x - 1.0)**2 + 20.0 * (y + 2.0)**2


def gradient(z):
    x, y = z
    return np.array([2.0 * (x - 1.0), 40.0 * (y + 2.0)])


result = minimize(
    objective,
    x0=np.array([4.0, 3.0]),
    jac=gradient,
    method="L-BFGS-B",
    options={"maxcor": 5, "gtol": 1e-10, "ftol": 1e-15},
)
print(result.success)                 # True
print(np.round(result.x, 8))          # [ 1. -2.]
print(result.nit, result.nfev)        # 7 9
print(np.linalg.norm(result.jac, np.inf))  # 約 1.0e-12
```

出力例はSciPy 1.17.0、NumPy 2.3.5での値です。反復回数は実装や設定に依存します。手計算の2反復と異なるのは、初期尺度や直線探索を含め、同じ数値手順を指定した比較ではないためです。

`success` だけでなく、得られた点と勾配の大きさを見ます。この例では $(1,-2)$ が分かっているので、答えとのずれも確認できます。

[`maxcor`、`gtol`、`ftol`の公式説明](https://docs.scipy.org/doc/scipy-1.17.0/reference/optimize.minimize-lbfgsb.html)では、`gtol` は射影勾配に、`ftol` は目的値の相対的な減少に対応します。上下限のないこの例では、射影勾配は通常の勾配と同じです。

## 診断値

- **勾配ノルム**：今回の谷なら、横と縦のどちらに傾きが残っているかも見ます。
- **$s_i^Ty_i$**：更新に使える正の曲率情報かを確認します。値の小ささは変数や勾配の尺度と併せて判断します。
- **$g_k^Tp_k$**：負なら局所的な降下方向です。非負なら、その方向をそのまま直線探索に渡してよいかを見直します。
- **関数・勾配評価回数**：反復が少なくても、直線探索の評価が多ければ高価です。
- **停止理由**：勾配が小さくなった停止と、目的値がほとんど変わらない停止を区別します。
- **対の採用・棄却数と $m$**：履歴が多い設定でも、更新をほとんど採用できていなければ、その情報は使えていません。取得できる診断値は実装によって異なります。

## 失敗・切替の兆候

### 小さい勾配差を無条件に使う

二重ループには $1/(s_i^Ty_i)$ が入ります。丸め誤差や勾配ノイズに比べて分母が小さい対を使うと、補正が不安定になり得ます。単に分母へ小さな数を足せば、BFGSの性質がそのまま保たれるわけではありません。

正定値な初期尺度と正の $s_i^Ty_i$ は、正定値性を保つための重要な条件です。適切な直線探索や更新を採用する条件を使い、無効な対を棄却するなど、利用する実装の扱いを確認します。

### 保持した対の条件を全部厳密に満たすと思う

新しい対を取り込んだBFGS更新は、最新の割線条件 $H^+y_i=s_i$ を満たします。しかし、一般には古いすべての条件まで同時に厳密に保ちません。

同じ谷で、まず $(s_0,y_0)=((1,0),(2,0))$、次に $((1,1),(2,40))$ を使い、$I$ から2回更新すると、古い条件の $H(2,0)^T$ は約 $(2.769,-0.088)^T$ になります。元の $(1,0)^T$ とは一致しません。最新の $H(2,40)^T=(1,1)^T$ は満たします。

冒頭の横・縦の観測で両方を再現できたのは、この対角な二次関数と観測方向の組合せによるものです。「履歴を残す」は「残した等式をすべて同時に解く」と同じ意味ではありません。

### 関数の縮小をすべて収束だと思う

目的値が変わらなくなっても、横方向の勾配が残っているかもしれません。勾配の実装と変数の尺度を確認し、直線探索の失敗や、履歴を採用できない状態を分けて見ます。

同じ点で勾配の評価が大きく揺れる場合は、その差を安定した曲率と見なせるかを先に検討します。履歴数を増やすことだけで、評価の揺らぎは取り除けません。
