近接勾配法へNesterov型の外挿を加え、凸複合問題の目的ギャップをより速く減らす加速一次法です。

## 30秒でつかむ

歩く向きが続いているとき、直前の移動を次の一歩へ足して先を狙うような加速です。

FISTAは、勾配一歩の前に過去の移動を使った外挿を入れ、近接勾配法より目的ギャップを速く減らすことを狙います。

- 見ているもの: 目的値、近接勾配写像、非ゼロ成分と活性集合
- 動かしているもの: 現在点、外挿点、一歩、近接演算
- 前進の判断: 最良目的値と目的ギャップが減ること
- 恐れていること: 外挿による振動、非ゼロ成分の集合の入れ替わり、変種の違いによる比較のずれ

速さは現在の目的値の単調減少を意味しません。

## 一手の意味

### 仕組み

基本近接勾配法は現在点から勾配一歩と近接演算一歩を行います。
FISTAは過去の移動を使った外挿点 $y_k$ から一歩を行います。

$$
x_{k+1}=\operatorname{prox}_{\eta g}\left(y_k-\eta\nabla f(y_k)\right)
$$

$$
t_{k+1}=\frac{1+\sqrt{1+4t_k^2}}{2}
$$

$$
y_{k+1}=x_{k+1}+\frac{t_k-1}{t_{k+1}}(x_{k+1}-x_k)
$$

ここで $x_0=y_0$、$t_0=1$ と初期化します。$y_k$ は次の勾配を測るための外挿点で、$x_k$ と同じ役割ではありません。$y_k$ の目的値だけを現在の解の成績として扱わず、受け取る解 $x_k$ と分けて記録します。

凸でLipschitz連続な勾配を持つ $f$ と、近接演算を正確に扱える適切な閉凸関数 $g$、解の存在、固定歩幅 $0<\eta\le1/L$ などの条件の下で、標準FISTAの目的ギャップには $O(1/k^2)$ の上界があります。基本近接勾配法の代表的な $O(1/k)$ 上界より速い漸近次数です。これは各反復で必ず基本法より目的値が低いという意味でも、変数の誤差が $1/k^2$ で減るという意味でもありません。

## 小さな例

$F(x)=\frac12(x-3)^2+0.8|x|$ を更新します。
初期値は $x=y=0$ と $t=1$ です。
一歩の係数は $\eta=0.25$ とします。

| 反復 | $x$ | 次の外挿点 $y$ | $F(x)$ |
|---|---:|---:|---:|
| 1 | 0.5500 | 0.5500 | 3.4413 |
| 2 | 0.9625 | 1.0787 | 2.8457 |
| 3 | 1.3590 | 1.5312 | 2.4336 |

2反復目から、外挿点が現在点より先へ出ます。
同じ問題の近接勾配法では、3反復目は $x=1.2719$ です。
この差は固定した3反復の挙動で、実時間の性能順位を示しません。

### 三つ目の一歩を分解する

2反復後は $x_2=0.9625$、外挿点は $y_2\approx1.078723$ です。次の勾配を測る位置は $x_2$ ではなく $y_2$ になります。

1. 勾配：$f'(y_2)=y_2-3\approx-1.921277$
2. 勾配の一歩：$v_2=y_2-0.25f'(y_2)\approx1.559042$
3. 近接演算：$x_3=S_{0.2}(v_2)\approx1.359042$
4. 次の外挿：$y_3\approx1.531159$

しきい値は $\eta\lambda=0.25\times0.8=0.2$ です。外挿点に正則化をもう一度加えたり、$0.8$ をそのまましきい値にしたりしません。

### 加速していても、目的値は上がる

この問題の最小点は $x^*=2.2$、最小値は $F^*=2.08$ です。反復を少し続けると、外挿が最小点の先へ出ます。

![同じ一次元問題でのFISTAと近接勾配法の反復点、および現在と最良の目的ギャップ](./media/fista-overshoot.svg)

上段のFISTAは7反復目で $2.2$ を越えます。下段の現在の目的ギャップは8・9反復目で増えますが、記録している最良値は増えません。最良値が増えないこと自体は、その定義によるもので収束の証明ではありません。

| 反復 | $x_k$ | $F(x_k)$ | 見えていること |
|---:|---:|---:|---|
| 6 | 2.136211 | 2.082035 | 答えの手前 |
| 7 | 2.238440 | 2.080739 | 答えを越えたが、目的値は改善 |
| 8 | 2.281553 | 2.083325 | 越えすぎて目的値が増加 |
| 9 | 2.284397 | 2.083561 | もう少し行き過ぎる |
| 10 | 2.264884 | 2.082105 | 向きを戻して改善 |

基本法とFISTAには同じ歩幅 $0.25$ を与えています。ただし、この一次元二次関数では $L=1$ なので、歩幅を $1/L=1$ にすると基本近接勾配法でも一回で $2.2$ に到達します。小さめの歩幅は、外挿と行き過ぎを見えるように選んだ教材上の設定です。この図からFISTAの実用性能を順位づけしません。

### 再始動は、何を捨てる操作か

再始動では、得られた点を全部捨てるのではなく、主に外挿の記憶をリセットします。たとえば $y\leftarrow x$、$t\leftarrow1$ とし、次の一手を慣性なしで作り直します。

ただし「増加した候補を受け入れてから次回の慣性を消す」「増加した候補を棄却して基本法から再計算する」「単調FISTAの別の更新式を使う」は異なるアルゴリズムです。再始動という名前だけでは目的値の単調減少を保証しません。以下のコードと図は、これらを混ぜない **再始動なしの標準形** です。

## 向く条件・避ける条件

### まず確認すること

- 目的関数が滑らかな項と、近接演算を計算できる項の複合形になっているか
- 勾配と近接演算が安価に計算できるか
- 凸条件下の収束率を使う問題か、非凸問題として挙動を別に評価するか
- 後退探索、再始動、単調性の変種を比較条件として記録できるか

### 向く条件・避ける条件

向きやすい条件:

- 凸で滑らかな項 + 近接演算を計算できる構造
- L1など非滑らか正則化
- 勾配と近接演算が安価
- 高精度より中程度の精度を多数反復で得たい
- 基本近接勾配法が安定だが遅い

避ける条件:

- 非凸問題へ理論収束率をそのまま適用する
- 近接演算が支配的で、分解や専用ソルバーのほうが適している

## Python

本文・図と同じ一次元問題を実行します。図は30反復まで描き、下の短いコードは前半15反復を再現します。近接勾配写像は、外挿点での移動量ではなく、比較したい現在の点 $x$ に対して計算します。

```python
from math import sqrt, copysign

lam, step = 0.8, 0.25

def soft(v, threshold):
    return copysign(max(abs(v) - threshold, 0.0), v)

def objective(x):
    return 0.5*(x-3.0)**2 + lam*abs(x)

def prox_step(x):
    return soft(x - step*(x-3.0), step*lam)

def mapping(x):
    return (x - prox_step(x))/step

x = y = 0.0
t = 1.0
best = objective(x)
for k in range(1, 16):
    next_x = prox_step(y)
    next_t = (1.0 + sqrt(1.0 + 4.0*t*t))/2.0
    next_y = next_x + ((t-1.0)/next_t)*(next_x-x)
    x, y, t = next_x, next_y, next_t
    best = min(best, objective(x))
    if k in (3, 7, 8, 9, 15):
        print(k, f"{x:.6f}", f"{objective(x):.6f}", f"{best:.6f}", f"{abs(mapping(x)):.6f}")
```

```text
3 1.359042 2.433605 2.433605 0.840958
7 2.238440 2.080739 2.080739 0.038440
8 2.281553 2.083325 2.080739 0.081553
9 2.284397 2.083561 2.080739 0.084397
15 2.182310 2.080156 2.080019 0.017690
```

列は反復番号、現在点、現在の目的値、これまでの最良目的値、近接勾配写像の絶対値です。この問題では正の領域の写像は $x-2.2$ になります。15回で止めたのは図示用の予算であり、所定の最適性許容誤差へ到達したという宣言ではありません。

一般問題では、隣接する $x$ が近いことだけで止めず、同じ尺度の写像や実行可能性、上限到達か収束かを区別します。外挿と近接ステップが相殺して、移動量だけ小さくなる場合があるためです。

## 診断値

「速い」を現在の目的値だけで判断すると、外挿による一時的な増加を見落とします。

目的値の単調減少を保つ変種や適応的再始動を使うと実務上安定する場合がありますが、変種と条件を記録します。

- 最良目的値
- 現在の目的値
- 近接勾配写像
- 反復点間の差
- 非ゼロ成分と活性集合の変化
- 再始動回数

## 失敗・切替の兆候

- 目的値が大きく振動する → 再始動や目的値の単調減少を保つ変種を検討する
- 非ゼロ成分の集合が何度も入れ替わる → 一歩、尺度調整、正則化を確認する
- 後退探索で歩幅が毎回縮む → 勾配のLipschitz モデルを確認する
- 近接演算が支配的 → 分解や専用ソルバーを検討する

::: warning
FISTAという名前だけでは、実装の違いは分かりません。
後退探索／再始動／単調性／停止条件を確認します。
比較時は変種を明記します。
:::
