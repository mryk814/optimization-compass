局所二次モデルを信頼できる半径の中だけで最小化し、実測改善と予測改善の比で半径を更新する信頼領域法群を条件に応じて選び分けるための入口です。

## 30秒でつかむ

この手法群の気持ちは、**「今の二次モデルをどこまで信じてよいか」を半径として管理し、信頼できる範囲の中だけで一歩を決めること**です。直線探索が方向を先に決めてから歩幅を調整するのに対し、信頼領域法は先に「この範囲までなら信じる」という半径を決め、その中で部分問題を解いて一歩を作ります。

- 見ているもの: 目的関数値、勾配、局所二次モデルの予測改善量、実際の改善量
- 動かすもの: 現在点と信頼半径
- 前進の判断: 実測改善量と予測改善量の比が十分大きいこと
- 主な弱点: 部分問題を解く精度と微分情報の品質に依存する、実装が複雑になりやすい

「信頼領域が常に直線探索より優れている」という順位ではありません。負の曲率への対処や大域化の安定性と、部分問題を解く追加コストを交換しています。

## まず確認すること

| 確認項目 | 選択への影響 |
|---|---|
| 勾配・ヤコビ行列・ヘッセ行列とベクトルの積のどれが得られるか | 部分問題の解き方（CG打ち切り、Krylov、厳密分解）が変わる |
| 目的が一般の非線形関数か、残差の二乗和か | 一般関数ならNewton系、残差構造があるならGauss–Newton/Levenberg–Marquardt系 |
| 上下限制約の有無 | Trust-region reflectiveのように境界を反映した信頼領域が必要か |
| 変数数とヘッセ行列の扱える規模 | 密な分解が可能か、ヘッセ行列とベクトルの積だけを使うKrylov系にすべきか |
| ヘッセ行列の不定性 | 負の曲率が出る問題では、部分問題側で負曲率方向を扱える手法が必要 |
| 評価コストと精度要求 | 高精度な停留点を求めるほど、信頼領域診断を丁寧に追う価値が上がる |

ヘッセ行列とベクトルの積（HVP）は自動微分や随伴法で得られても、方向微分検算をしないと符号や単位の誤りに気づけません。

## 条件付きの選び分け

| 役割 | 手法 | 優先しやすい条件 | 切り替えを考える条件 |
|---|---|---|---|
| CG打ち切りで部分問題を近似 | [Trust-region Newton-CG](#/learn/trust-region-newton-cg) | ヘッセ行列とベクトルの積が得られる中〜大規模の一般滑らか問題で、比較的安価に部分問題を近似したい | 負の曲率が多いなどの条件で、より精密な部分問題解が全体の費用を減らせる場合はtrust-krylovと比較 |
| Krylov部分空間で部分問題を近似 | [Trust-krylov](#/learn/trust-krylov) | 大規模でヘッセ行列とベクトルの積のみ利用でき、より精密な部分問題解が欲しい | Krylov反復が伸びる、部分問題のコストが支配的 |
| 残差構造を直接利用 | [Gauss–Newtonモデルを使う信頼領域法](#/learn/gauss-newton) | 目的が非線形最小二乗で、残差ヤコビ行列から曲率近似を作れる | 残差が大きい・強い非線形性がありGN近似の質が悪い |
| 減衰付きで安定化した残差法 | [Levenberg–Marquardt（least-squares）](#/learn/least-squares) | 非線形最小二乗で、Gauss–Newton近似の不安定さを信頼領域的に抑えたい | 減衰調整だけでは収束せず、上下限制約が本質的に必要 |
| 上下限付き非線形最小二乗 | [Trust-region reflective](#/learn/trust-region-reflective) | 変数に上下限があり、境界に応じて信頼領域を変形したい | 上下限以外の一般制約が中心になる |

Gauss–Newtonは曲率モデルの作り方です。通常のGauss–Newton法が自動的に信頼領域法になるわけではなく、半径制約と受理判定を組み合わせます。SciPyの `lm` を選ぶ場合は、上下限制約非対応、密なJacobi行列を使うこと、残差数が変数数以上であることも確認します。

厳密な部分問題解法（ほぼ厳密に解く信頼領域）を使う実装もありますが、対応する記事はまだないため、名前だけの参考にとどめます。

これは一般性能順位付けではありません。同じ問題例、初期点、微分情報の入手経路、許容誤差、評価予算で比較します。

## うまくいったサインと切替サイン

うまく進んでいるときは、次の観測が揃います。

- 実際の減少が予測と大きく食い違わず、受理できる試行が得られる
- 信頼半径の縮小だけが続いて停滞することなく、受理された一歩で前進する。半径が維持される場合もある
- 部分問題の反復数（CG反復数など）が極端に増えない
- 適切な最適性残差が許容範囲へ近づく。勾配ノルムの単調減少や、非線形最小二乗の残差がゼロになることまでは要求しない

切替サイン:

- 信頼半径が縮小し続ける → モデルの品質、微分の正しさ、問題の尺度を確認する
- 実測改善量と予測改善量比が悪化し続ける → 二次モデルが問題の局所構造を捉えていない
- 部分問題の反復（CG反復など）や、棄却試行に伴う再計算・関数評価が支配的なコストになる → 費用の内訳を確認し、部分問題解法や大域化の方法を比較する
- 非線形最小二乗でGauss–Newton近似が発散気味 → Levenberg–Marquardtや境界を反映した信頼領域法へ切り替える

## 小さな比較の型

### 同じ場所で「広く信じる」と「狭く信じる」を比べる

手法間の順位を決める前に、半径の働きだけを取り出します。一次元の滑らかな関数

$$
f(x)=\frac{x^4}{4}-\frac{x^2}{2}
$$

を、現在点 $x=0.5$ で考えます。ここでは $f=-0.109375$、勾配 $g=x^3-x=-0.375$、二階微分 $B=3x^2-1=-0.25$ です。局所二次モデルは、

$$
m(p)=-0.109375-0.375p-0.125p^2
$$

です。負の曲率があるので、二次モデルは下に凸ではなく、$p$ を制限しなければ下へ際限なく下がります。しかし元の四次関数は、遠くでは大きく上がります。二つの形の違いを無視してはいけません。

信頼領域 $|p|\le\Delta$ を置くと、区間が有限なのでモデルの最小値は存在します。この例の最小点は右端 $p=\Delta$ です。一次元の特例として両端を比較すれば求まり、CGやKrylov法の実装を使う必要はありません。

![同じ現在点の四次関数と二次モデルを、大きい半径と小さい半径で比較した図](./media/trust-region-model-agreement.svg)

上段は半径2、下段は半径0.5です。両方とも現在点は $x=0.5$ のままで、横軸は移動量 $p$。大きな半径での試行を棄却したあと、同じ点で半径だけを縮めた比較です。軸の範囲が異なるので傾きの見かけは直接比べません。各図の中で実際の関数と近似の隔たりを見てください。

| 試行 | 半径 $\Delta$ | 試す点 $x+p$ | 予測減少 | 実際の減少 | 比 $r$ | 結果 |
|---|---:|---:|---:|---:|---:|---|
| 広く信じる | 2 | 2.5 | 1.25 | −6.75 | −5.4 | 棄却。現在点は0.5のまま |
| 同じ点で縮める | 0.5 | 1 | 0.21875 | 0.140625 | 約0.642857 | 受理して1へ移る |

比は、予測減少が正のときに

$$
r=\frac{f(x)-f(x+p)}{m(0)-m(p)}
$$

で計算します。大きな試行では、近似は1.25下がると言ったのに実際には6.75上がりました。負の比なので棄却です。半径を4分の1にした試行では、予測ほどではなくても実際に下がっています。

ここでは例示用に「$r>0.1$ なら受理」「$r<0.25$ なら半径を4分の1」「$r>0.75$ かつ境界まで進んだなら2倍」を使います。二回目は受理しますが、半径は拡大しません。**受理することと、半径を広げることは別の判定**です。これらの閾値は全実装共通の定数ではありません。

$x=1$ はこの関数の最小点の一つです。もう一つは $x=-1$。二回目の試行でちょうど最小点に着くのは数値を選んだこの例の性質で、一般の二試行収束を主張していません。

### Pythonで照合する

```python
def f(x):
    return x**4 / 4.0 - x**2 / 2.0

x = 0.5
g = x**3 - x
B = 3.0 * x*x - 1.0

def model(p):
    return f(x) + g*p + 0.5*B*p*p

for radius in (2.0, 0.5):
    # B<0 の一次元モデルなので、最小点は区間のどちらかの端。
    step = min((-radius, radius), key=model)
    predicted = model(0.0) - model(step)
    actual = f(x) - f(x + step)
    assert predicted > 0.0
    ratio = actual / predicted
    accepted = ratio > 0.1
    next_x = x + step if accepted else x
    print(radius, predicted, actual, round(ratio, 6), accepted, next_x)
```

```text
2.0 1.25 -6.75 -5.4 False 0.5
0.5 0.21875 0.140625 0.642857 True 1.0
```

このコードは同じ点で二つの半径を比較する教材で、汎用の信頼領域ソルバーではありません。非正の予測減少、NaN、零に近い分母を無視して比を計算する実装にはしません。予測減少が十分に小さい場合は、停止判定と数値精度も確認します。

### 手法を比較するときに揃えるもの

次に同じ対象へ複数の実装を使う段階では、目的、初期点、制約、微分の正確さ、停止基準、評価予算を揃えます。さらに、関数評価・勾配評価・HVP・線形系解法の費用を分けます。

一般のスカラー目的を取る `trust-ncg` と、残差ベクトルを取る最小二乗の `lm` は、同じ引数を渡せる別名ではありません。最小二乗を比較するなら、残差の定義と $\tfrac12\|r(x)\|^2$ などの係数を統一して、同じ数学問題に変換した上で使います。目的値や反復回数だけを並べて順位を決めないようにします。

## コラム: 信頼半径はなぜ縮んだり広がったりするのか

信頼領域法は、一歩を踏んだあとに実測改善量と予測改善量の比を計算します。比が十分大きければ「モデルは信用できた」と判断して半径を広げるか維持し、比が小さければ「モデルは今回の範囲では信用できなかった」として半径を縮めます。この仕組みにより、ヘッセ行列が不定で負の曲率が出る局面でも、半径の内側に一歩を制限し、適切なモデル精度や部分問題の減少条件の下で、収束を安定化する大域化に使えます。ここで大域化は、どの初期点からも大域最小点を保証するという意味ではありません。

半径が縮小し続ける場合は、微分情報の誤り、変数の尺度、評価ノイズ、不連続、部分問題の精度や丸め誤差を確認します。縮小だけで原因を一つに断定はできません。半径を人為的に固定して無理に前進させるより、まず微分の検算と問題の尺度の調整を見直します。
