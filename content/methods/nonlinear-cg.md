非線形共役勾配法は、今の勾配と前の探索方向を組み合わせ、少ない記憶で滑らかな無制約最小化を進める方法です。前の向きを混ぜる目的は、単に勢いをつけることではありません。曲率の大きい方向へ戻る動きを打ち消し、前に改善した方向をむやみにやり直さないことにあります。

同じ「CG」でも、[Newton-CG法](#/learn/newton-cg)の内側で連立一次方程式を解くCGとは役割が違います。本稿のCGは、目的関数上の点を直接更新する外側の最適化法です。ヘッセ行列もHVPも要求しません。

## 30秒でつかむ

- 見るものは目的値、勾配、直線探索の結果。保存するのは長さ $n$ のベクトルを数本で、作業メモリは $O(n)$ です。
- 今の下り方向 $-g_k$ に、前の方向 $p_{k-1}$ を足して、新しい探索方向を作ります。
- 向きが決まっても、そのまま進めません。直線探索で長さを決め、下降性が失われたら古い向きを捨てます。

「2変数なら2回で終わる」は、正定値二次関数・厳密直線探索・丸め誤差を無視した場合の特別な性質です。一般の非線形問題にその回数保証はありません。

## 前の向きが谷の横揺れを打ち消す

[勾配降下法](#/learn/method.gradient-descent)・[Newton法](#/learn/newton-method)・[BFGS法](#/learn/bfgs)と同じ例を使います。

$$
f(x,y)=(x-1)^2+20(y+2)^2,\qquad x_0=(4,3).
$$

最小点は $(1,-2)$、ヘッセ行列は $H=\operatorname{diag}(2,40)$ です。$y$ 方向の曲率は $x$ 方向の20倍あります。初期勾配は $(6,200)$ なので、最初の下り方向はほぼ下向きです。

ここだけは、Fletcher–Reeves（FR）係数と二次関数用の厳密直線探索を用います。後のSciPy実行とは別の、式を理解するための小さな実装です。

$$
p_0=-g_0,\qquad
\alpha_k=-\frac{g_k^\top p_k}{p_k^\top Hp_k},\qquad
x_{k+1}=x_k+\alpha_kp_k.
$$

分子はその向きに進むと目的値がどれだけ下がり始めるか、分母はその向きの曲率です。その比で、直線上の二次関数の底まで進みます。$\alpha_k$ は係数であり、実際の移動距離は $\alpha_k\|p_k\|$ です。

| 更新 $k$ | 現在点 $x_k$ | 探索方向 $p_k$ | 係数 $\alpha_k$ | 移動距離 | 更新後の目的値 |
|---:|---|---|---:|---:|---:|
| 0 | $(4,3)$ | $(-6,-200)$ | 0.0250214 | 5.006526 | 8.122135 |
| 1 | $(3.849872,-2.004275)$ | $(-5.704617,0.008557)$ | 0.499573 | 2.849875 | 約 $4.1\times10^{-30}$ |

1回目のあと、勾配は $g_1=(5.699744,-0.170992)$ です。このまま最急降下を使うなら、上向き成分 $0.170992$ を含む方向へ進みます。非線形CGはここで前の向きを少し混ぜます。

$$
\beta_1^{\rm FR}=\frac{g_1^\top g_1}{g_0^\top g_0}=0.000812177,\qquad
p_1=-g_1+\beta_1p_0.
$$

成分を分けると、何をしているかが見えます。

$$
\underbrace{(-5.699744,\ 0.170992)}_{-g_1}
+\underbrace{(-0.004873,\ -0.162435)}_{\beta_1p_0}
=\underbrace{(-5.704617,\ 0.008557)}_{p_1}.
$$

足したベクトルは小さいのに、$y$ 成分のほとんどを打ち消します。$x$ 方向には進み続け、急な壁へ戻る動きだけを抑えたわけです。

![同じ二次関数上のFR法と最急降下法の軌跡、および2更新目の方向のy成分を分解した棒グラフ](./media/nonlinear-cg-main.svg "左は両方とも厳密直線探索です。右は同一尺度で、2更新目の方向の第2成分を分解しています。")

図の左は両方とも厳密直線探索です。右は2更新目の $y$ 成分のみを同一尺度で比較しています。軌跡図の矢印の角度だけでなく、$0.170992-0.162435=0.008557$ という成分の打消しを読んでください。図と表は同じ生成コード・同じ反復点から作っています。

## 共役とは 普通の直交とは違う

正定値二次関数では、FRと厳密直線探索から得る方向は

$$
p_i^\top H p_j=0\quad(i\ne j)
$$

を満たします。これを $H$ に関する共役と呼びます。単なる $p_i^\top p_j=0$ ではなく、地形の曲率 $H$ を間に挟んだ直交です。新しい方向への更新が、以前の方向で済ませた最小化を壊さないことにつながります。

主例では $p_0^\top Hp_1\approx-7.1\times10^{-12}$、$g_0^\top g_1\approx-1.8\times10^{-13}$ でした。数学上の0からのずれは浮動小数点演算によります。2本の方向が2次元を張るため、2更新で解に着きました。最小点からの距離は約 $6.3\times10^{-16}$ です。

非二次関数では $H$ 自体が点によって変わり、直線探索も通常は厳密ではありません。「以前と干渉しない向き」は保たれなくなります。したがって、共役性の式を一般問題の毎回の保証として使ってはいけません。

## βだけでアルゴリズムは決まらない

FRのほかに、勾配の変化を使うPolak–Ribière+（PR+）があります。

$$
\beta_k^{\rm FR}=\frac{\|g_k\|_2^2}{\|g_{k-1}\|_2^2},\qquad
\beta_k^{\rm PR+}=\max\left(0,\frac{g_k^\top(g_k-g_{k-1})}{\|g_{k-1}\|_2^2}\right).
$$

PR+で括弧内が負なら、$\beta_k=0$ となり $p_k=-g_k$ に戻ります。これは自然な再出発です。しかし、係数を非負にしただけで、いつでも安全な下り方向になるとは限りません。少なくとも $g_k^\top p_k<0$ を確認し、必要なら $p_k=-g_k$ へ戻す仕組みが要ります。

直線探索にも役割があります。Armijo条件は十分な目的値減少、Wolfeの曲率条件は直線上の傾きが適切に弱まることを要求します。小さすぎる一歩を続けて「下がっているからよい」と済ませないためです。条件の意味は[BFGS法の直線探索](#/learn/bfgs)から読めます。

SciPy 1.17.0の `method="CG"` はPR+を用います。実装はWolfe探索に加え、次の方向の十分な下降性を確認する経路を持ちます。「FR＋厳密探索」の主例と同じ更新則ではありません。公開APIの停止・直線探索設定は[CGの公式リファレンス](https://docs.scipy.org/doc/scipy-1.17.0/reference/optimize.minimize-cg.html)、PR+と下降性チェックは[版固定の実装](https://github.com/scipy/scipy/blob/v1.17.0/scipy/optimize/_optimize.py)で確認できます。

補助検証ではRosenbrock関数に対し、独自のPR+、strong Wolfe探索、2更新ごとの再出発を組み合わせました。全ての採用前方向で $g_k^\top p_k<0$ を確認し、15更新で $\|g\|_\infty<10^{-5}$ に到達しました。これは「再出発を含む別の方式でも条件を検査できる」というテストです。後述するSciPyの36反復と設定が違うため、速度ランキングには使いません。

## 表とSciPy実行を別々に再現する

下の前半が表の2更新、後半がSciPyです。主例で `H` を置くのは厳密探索式のためで、実用の非線形CGにヘッセ行列を要求する意味ではありません。

```python
import numpy as np
import scipy
from scipy.optimize import minimize

H = np.diag([2.0, 40.0])
target = np.array([1.0, -2.0])
f = lambda x: (x[0] - 1)**2 + 20*(x[1] + 2)**2
grad = lambda x: H @ (x - target)

# 教材用 FR ＋厳密直線探索。SciPy CG の再実装ではない。
x = np.array([4.0, 3.0])
g = grad(x)
p = -g
for k in range(2):
    alpha = -(g @ p) / (p @ H @ p)
    xn = x + alpha*p
    gn = grad(xn)
    beta = (gn @ gn) / (g @ g)
    print(k, alpha, xn, f(xn))
    x, g, p = xn, gn, -gn + beta*p

# SciPy の PR+。停止ノルムと許容を明示する。
result = minimize(f, [4.0, 3.0], jac=grad, method="CG",
                  options={"gtol": 1e-5, "norm": np.inf,
                           "c1": 1e-4, "c2": 0.4, "maxiter": 400})
print(scipy.__version__, result.success, result.nit,
      result.nfev, result.njev, np.linalg.norm(grad(result.x), np.inf))
# SciPy 1.17.0: True, 2, 5, 5, 約 1.07e-13
```

実測環境はPython 3.12.14、NumPy 2.3.5、SciPy 1.17.0です。同じ実装・設定でRosenbrock関数 $100(y-x^2)^2+(1-x)^2$、初期点 $(-1.2,1)$ を解くと、36反復、関数78回、勾配77回、最終 $\|g\|_\infty\approx5.49\times10^{-6}$ でした。完全な再現と図生成は `generate_verify.py`、未丸め数値は `verified-numbers.json` にあります。

`nit` が2でも勾配評価は5回あります。直線探索中の試行は、外側の更新回数に数えません。比較するなら、同じ停止基準で、目的関数・勾配それぞれの呼出回数と実時間を記録します。勾配が高価なら、この差は大きくなります。

## 何をもって止まったと読むか

このコードの通常の成功終了は、勾配の最大絶対成分が $10^{-5}$ 以下になったことを意味します。一般の非凸問題で、それだけでは局所最小・大域最小を証明しません。鞍点でも勾配は小さくなります。一方、主例は正定値二次関数なので、停留点は一意な大域最小点です。

診断では次を分けて読みます。

| 記録する量 | 読み取れること |
|---|---|
| $\|g_k\|$ と採用したノルム | 停留条件に近づいたか |
| $g_k^\top p_k$ | 提案方向が下りを向いているか |
| $\alpha_k$ と $\|\alpha_kp_k\|$ | 係数が小さいのか、移動自体が小さいのか |
| 再出発回数 | 以前の向きを持ち越せているか |
| `nfev`, `njev`, 実時間 | 直線探索も含めた評価費用 |

`success=False` で直線探索が失敗したなら、停留したと読み替えません。尺度、勾配の整合性、ノイズ、探索設定を調べます。再出発自体は故障ではありませんが、ほぼ毎回なら、履歴を使う利点が乏しいかもしれません。

## 向く条件と 切り替える目安

[大規模な無制約の最小化](#/formulations/PA007)で、勾配は信頼できるが密な曲率行列は持ちたくないときに候補になります。メモリが小さいことと、総評価費用が小さいことは別です。直線探索を含む費用で[L-BFGS](#/learn/lbfgs)と比べます。

- 滑らかで、変数の尺度が揃い、追加の関数・勾配評価が許容できるなら試す価値があります。
- ノイズ、不連続、離散変数が本質なら、勾配の差を信頼する設計に無理があります。
- 上下限が必要なら[L-BFGS-B](#/learn/lbfgsb)、一般制約なら[制約付きNLP](#/formulations/PA009)を検討します。
- 小規模で曲率を持てるなら[BFGS法](#/learn/bfgs)や[Newton法](#/learn/newton-method)と比べます。標準形は[滑らかな無制約の最小化](#/formulations/PA006)です。
- 初期点ごとに違う停留点へ着くなら、[多点開始](#/learn/multi-start)で解のばらつきを調べます。それでも大域最適性の証明にはなりません。
