現在の勾配だけでなく直前までの探索方向も再利用し、少ないメモリで大規模な滑らかな無制約問題を解く局所法です。

## 30秒でつかむ

細長い谷を下るとき、毎回その場でいちばん急な向きへ曲がり直すと、谷の壁から壁へジグザグに進みます。
そこで、直前に進んでいた向きを少し引き継いで曲がります。前の一歩が稼いだ進みを捨てずに、次の一歩へ持ち越す考え方です。

- **見るもの**: 目的関数値、勾配、直線探索の結果
- **動かすもの**: 現在点と、直前の向きを混ぜた探索方向
- **前進の判断**: 目的関数値が十分に下がり、勾配のノルムが小さくなること

古い向きが今の地形に合わなくなると、混ぜた向きは下り方向でなくなります。
そのため、向きを捨てて最急降下方向へ戻す再出発が、手法の一部になっています。

## 一手の意味

現在の勾配を $g_k$、直前の探索方向を $p_{k-1}$ とします。新しい探索方向は、今の最急降下方向 $-g_k$ に、直前の方向を $\beta_k$ 倍して足したものです。

$$
p_k = -g_k + \beta_k p_{k-1}, \qquad x_{k+1}=x_k+\alpha_k p_k
$$

2本目の式は、決めた向きへ、直線探索で選んだ長さ $\alpha_k$ だけ進むという意味です。
$\beta_k$ は、直前の方向をどれだけ引き継ぐかを決める係数です。定義は複数あります。代表的な二つを挙げます。

$$
\beta_k^{\mathrm{FR}}=\frac{g_k^\top g_k}{g_{k-1}^\top g_{k-1}}, \qquad
\beta_k^{\mathrm{PR+}}=\max\left(0,\ \frac{g_k^\top (g_k-g_{k-1})}{g_{k-1}^\top g_{k-1}}\right)
$$

SciPyの `method="CG"` は、後者のPolak–Ribière型（負の値を0に切る形）です。

二次関数を厳密な直線探索で進むと、これまでの探索方向どうしは共役になります。共役とは、$p_i^\top A p_j=0$（$i\ne j$）が成り立つことです。$n$ 変数の二次関数は、高々 $n$ 回の反復で解けます。
一般の非線形関数では、この共役性が崩れます。そのため、直線探索の条件と再出発の方針を、アルゴリズムの一部として扱います。

- 再出発では、$p_k=-g_k$ へ戻します。混ぜた向きが下り方向でなくなったときや、一定の反復ごとに行います。
- 更新式の名前だけでなく、直線探索の条件と再出発の方針も記録します。

線形共役勾配法と名前は近いのですが、解いている対象も保証も同じではありません。非線形版では、直線探索と再出発を含むアルゴリズム全体が挙動を決めます。

## 小さな例

[勾配降下法](#/learn/method.gradient-descent)・[Newton法](#/learn/newton-method)・[BFGS法](#/learn/bfgs)と同じ関数 $f(x,y)=(x-1)^2+20(y+2)^2$ を、初期点 $(4,\,3)$ から解きます。
手で追いやすいように、直線探索は二次関数用の厳密な式で長さを決めます。$\beta_k$ はFletcher–Reeves型です。

| 反復 | 現在点 | 勾配 | 探索方向 $p$ | 一手の長さ | 次の点 | 目的値 |
|---:|---|---|---|---:|---|---:|
| 0 | $(4,\,3)$ | $(6,\,200)$ | $(-6,\,-200)$ | 0.02502 | $(3.850,\,-2.004)$ | 509 → 8.12 |
| 1 | $(3.850,\,-2.004)$ | $(5.700,\,-0.171)$ | $(-5.705,\,0.009)$ | 0.4996 | $(1,\,-2)$ | 8.12 → 0 |

反復0の向きは、勾配降下法と同じ最急降下の向きです。まだ引き継ぐ向きがありません。
反復1で、$\beta_1=\lVert g_1\rVert^2/\lVert g_0\rVert^2\approx 0.00081$ が使われます。

最急降下の向き $-g_1=(-5.700,\,0.171)$ に、前の向き $(-6,\,-200)$ を $0.00081$ 倍して足します。
足す量は $(-0.005,\,-0.162)$ で小さいのですが、$y$ 成分の $0.171$ をほとんど打ち消します。結果は $(-5.705,\,0.009)$ です。

この向きは、[BFGS法](#/learn/bfgs)の表の反復1と同じです。ヘッセ行列も、その近似の行列も持たずに、前の向きだけで同じ向きに整いました。
勾配降下法は同じ問題に243回の更新が必要でした。非線形共役勾配法は2回です。この回数は、厳密な直線探索を使った二次関数での結果です。

Rosenbrock関数 $f(x,y)=100(y-x^2)^2+(1-x)^2$ も、同じ手法で解けます。
初期点 $(-1.2,\,1)$ から、SciPyの `CG` は36回の反復で最小点 $(1,\,1)$ に着きます。
実行例は、下のPythonの節にあります。
この回数は、この問題と初期点、既定の許容での一例です。手法どうしの優劣ではありません。

## 向く条件・避ける条件

非線形共役勾配法は、勾配だけで動き、保持する量が少ない手法です。
先に、次の項目を確認します。

| 項目 | 確認すること |
|---|---|
| 変数 | 連続で、原則として無制約か |
| 勾配 | 信頼できる勾配を計算できるか |
| 規模 | BFGS法の密な行列を避けたいほど大きいか |
| 滑らかさ | 直線探索が意味を持つ程度に滑らかか |
| 目標 | 局所停留点でよいか、大域最適性の証明が必要か |

向く条件です。

- 高次元の滑らかな無制約問題である（[大規模な無制約の最小化](#/formulations/PA007)）
- 勾配は得られるが、ヘッセ行列や密な近似は保持したくない
- 一反復のメモリを小さくしたい
- 直線探索の追加評価を許容できる

避ける、または切り替える条件です。

- 勾配がノイズや実装ミスで不安定である
- 強い不連続、離散変数、一般制約を含む
- 一回の評価が極端に高価で、直線探索を何度も試せない
- 局所解ではなく、大域最適性の証明が必要である
- 上下限や一般制約が本質である → 変換で無理に押し込まず、[L-BFGS-B](#/learn/lbfgsb)、射影法、[制約付きNLP](#/formulations/PA009)を検討する
- 小規模で、曲率の情報を活かしたい → [BFGS法](#/learn/bfgs)や[Newton法](#/learn/newton-method)と比べる（[滑らかな無制約の最小化](#/formulations/PA006)）

## Python

次の例は、SciPyの非線形共役勾配法を、上の二次関数とRosenbrock関数に適用します。

```python
import numpy as np
from scipy.optimize import minimize


def rosenbrock(x: np.ndarray) -> float:
    return float((1.0 - x[0]) ** 2 + 100.0 * (x[1] - x[0] ** 2) ** 2)


def rosenbrock_grad(x: np.ndarray) -> np.ndarray:
    return np.array([
        -2.0 * (1.0 - x[0]) - 400.0 * x[0] * (x[1] - x[0] ** 2),
        200.0 * (x[1] - x[0] ** 2),
    ])


# 二次関数 (x-1)^2 + 20 (y+2)^2
def quad(x):
    return (x[0] - 1.0) ** 2 + 20.0 * (x[1] + 2.0) ** 2


def quad_grad(x):
    return np.array([2.0 * (x[0] - 1.0), 40.0 * (x[1] + 2.0)])


result = minimize(quad, np.array([4.0, 3.0]), jac=quad_grad, method="CG")
print(result.success, result.x, result.nit, result.njev)
# True [ 1. -2.] 2 5

result = minimize(rosenbrock, np.array([-1.2, 1.0]), jac=rosenbrock_grad, method="CG")
print(result.success, result.x, result.nit, result.njev)
# True [1.00000001 1.        ] 36 77
print(f"{result.fun:.1e} {np.linalg.norm(result.jac):.1e}")
# 1.9e-14 6.1e-06
```

`nit` は反復回数、`njev` は勾配を計算した回数です。
SciPyの直線探索は厳密ではないので、二次関数の勾配評価は、反復2回に対して5回になります。手計算の表とは一致しません。
出力はSciPy 1.18.1での結果です。利用中のバージョンのオプションと既定値は、[scipy.optimize.minimize](https://docs.scipy.org/doc/scipy/reference/generated/scipy.optimize.minimize.html)の公式リファレンスで確認します。

## 診断値

- 勾配のノルム
- 一手の長さと、直線探索の試行回数
- 勾配と探索方向の内積（負であれば下り方向）
- 再出発の回数
- 目的関数値の変化

勾配のノルムが下がり、一手の長さが極端に小さくならなければ、継続の候補です。
再出発がほぼ毎回起きるときは、前の向きを引き継ぐ利点が出ていません。

## 失敗・切替の兆候

- 直線探索の失敗が続く → 尺度の不揃い、勾配の誤り、または直線探索の条件が合っていない → 尺度と勾配を確認し、別の大域化を検討する
- 再出発がほぼ毎回起きる → 共役性を保てない地形で、最急降下と変わらない → L-BFGSや信頼領域法と比較する
- 進行は安定するが遅い → 曲率の情報が足りない → [L-BFGS](#/learn/lbfgs)や信頼領域法と比較する
- 初期点ごとに別の解へ入る → 非凸で局所解が複数ある → [多点開始](#/learn/multi-start)や大域探索の系統を検討する

## コラム: 再出発は失敗ではない

非線形共役勾配法では、再出発によって古い向きの影響を捨てることがあります。
再出発の頻度は、手法が壊れたかどうかを示すのではありません。地形が共役性を保ちにくいかどうかを読む、診断の材料です。
