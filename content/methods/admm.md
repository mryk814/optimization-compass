分離しやすい部分問題を交互に解き、主残差と双対残差を減らして一致を作る分割最適化法です。

## 30秒でつかむ

二人で同じ予定を作るとき、各自の都合を別々に直し、最後に食い違いを調整するような手法です。

変数を分け、滑らかな項と非滑らかな正則化を別々の部分問題として扱います。
制約や分散データも、構造に応じて分離します。

- 見ているもの: 主残差、双対残差、目的値、部分問題の求解誤差
- 動かしているもの: $x$、$z$、スケーリング済みの双対変数 $u=\nu/\rho$、罰則係数 $\rho$
- 前進の判断: 主残差と双対残差を、それぞれの尺度に応じた許容範囲へ近づける。どちらも毎回単調に下がるとは限らない

## 一手の意味

一致制約 $x=z$ の場合、各項を別々に最小化してから不一致を双対変数へ加えます。

$$
x_{k+1}=\arg\min_x\left(f(x)+\frac{\rho}{2}\|x-z_k+u_k\|^2\right)
$$

$$
z_{k+1}=\arg\min_z\left(g(z)+\frac{\rho}{2}\|x_{k+1}-z+u_k\|^2\right),\qquad
u_{k+1}=u_k+x_{k+1}-z_{k+1}
$$

$u$ は変数の不一致を積み重ねた補正です。単なる平均値や学習率ではありません。$x$ の更新は現在の $z_k,u_k$ を使い、$z$ の更新は **更新したばかりの $x_{k+1}$** を使います。古い $x_k$ を使った同時更新へ勝手に置き換えないようにします。

この形は二ブロックの一致制約です。一般の $Ax+Bz=c$ では各部分問題にも $A,B$ が入り、ここにある $x-z$ の式をそのまま使えるわけではありません。

### 仕組み

#### 変数を分ける理由

代表形は

$$
\min_{x,z}\; f(x)+g(z) \quad \text{subject to}\quad Ax+Bz=c
$$

です。
$f$ と $g$ を別々に扱うことで、各部分問題の解きやすい構造を使えます。
滑らかな項と非滑らかな正則化のほか、制約や分散データも分割の対象です。

スケーリングした二ブロックADMMでは、次の順序を繰り返します。

1. $x$ を更新する
2. $z$ を更新する
3. 双対変数 $u$ を更新する

## 小さな例

近接勾配法でも扱える一次元問題を、あえて二つの変数に分けます。

$$
\min_{x,z}\ \frac12(x-3)^2+0.8|z|\quad\text{s.t.}\quad x=z
$$

一致した変数を $v$ と書けば、元の目的は $F(v)=\tfrac12(v-3)^2+0.8|v|$ です。最小点は $v^*=2.2$、最小値は $2.08$。この小さな問題をADMMで解く実用上の必要はありません。分割の一手と二つの残差を透かして見るために使います。

$\rho=1$、$z_0=u_0=0$ から始めます。内側の更新は閉形式です。

$$
x_{k+1}=\frac{3+\rho(z_k-u_k)}{1+\rho},\quad
z_{k+1}=S_{0.8/\rho}(x_{k+1}+u_k),\quad
u_{k+1}=u_k+x_{k+1}-z_{k+1}
$$

$S_a(v)=\operatorname{sign}(v)\max(|v|-a,0)$ はソフトしきい値です。

最初の一手を分けて読むと、次のようになります。

1. データへの近さを受け持つ側が、$x_1=(3+0)/2=1.5$ を選ぶ
2. 疎らさを受け持つ側が、$1.5$ をしきい値 $0.8$ で縮め、$z_1=0.7$ にする
3. 不一致 $1.5-0.7=0.8$ を記憶し、$u_1=0.8$ にする

次は $x_2=(3+0.7-0.8)/2=1.45$、$z_2=S_{0.8}(1.45+0.8)=1.45$。二つの変数は一致します。しかし、答えの $2.2$ にはまだ届いていません。

| 反復 | $x$ | $z$ | $u$ | 主残差 $\lvert x-z\rvert$ | 双対残差 $\rho\lvert z-z_{\rm old}\rvert$ | 元の目的 $F(z)$ |
|---:|---:|---:|---:|---:|---:|---:|
| 1 | 1.5 | 0.7 | 0.8 | 0.8 | 0.7 | 3.205 |
| 2 | 1.45 | 1.45 | 0.8 | 0 | 0.75 | 2.36125 |
| 3 | 1.825 | 1.825 | 0.8 | 0 | 0.375 | 2.1503125 |
| 4 | 2.0125 | 2.0125 | 0.8 | 0 | 0.1875 | 2.097578125 |

![ADMMでxとzが先に一致しても、双対残差が残って更新が続く様子](./media/admm-two-residuals.svg)

上段では $x,z$ が2反復目から重なります。下段では主残差がほぼゼロになったあとも、双対残差が残っています。浮動小数点での極小の丸め誤差は図ではゼロと区別できません。固定した一例であり、一般の残差の単調性を示すものではありません。

途中の $f(x)+g(z)$ は、不一致な二つの変数で測った分割目的です。元の問題の目的として報告するなら、ここでは一致させた候補 $(z,z)$ の $F(z)$ を使います。複雑な制約がある一般問題では、$z$ を代入するだけで実行可能な候補になるとは限りません。

### なぜ、主残差だけでは足りないのか

この一致制約で、内側を正確に解いたとします。$x$ 更新の一階条件と、更新後の $u$ を組み合わせると、

$$
\nabla f(x_{k+1})+\rho u_{k+1}
=-\rho(z_{k+1}-z_k)
$$

です。一方、$z$ 更新は $\rho u_{k+1}\in\partial g(z_{k+1})$ を満たします。つまり、$x$ 側の停留性に残るずれが、符号を除いて双対残差です。

2反復目は $x=z$ でも、$\nabla f(x)+\rho u=(1.45-3)+0.8=-0.75$。一致しているだけで、最適性のつり合いはまだ崩れています。主残差は「二人が同じ値を持ったか」、双対残差は「更新された値で最適性の条件がどれだけ整ったか」を別々に点検しています。

この等式はここでの滑らかな $f$ と一致制約、正確な内側更新を使ったものです。一般の線形制約では双対残差に行列が入り、内側の求解誤差も別に管理します。

## 向く条件・避ける条件

### まず確認すること

各部分問題が閉形式、近接演算、疎な線形求解などで解きやすいときに有効です。
分割後の部分問題が元問題より難しくなる場合は、分割の利点を得にくくなります。

### 向いている条件・避ける条件

向いている:

- 凸な分離構造
- 疎な QP、L1正則化、一致、分散最適化
- 近接演算や射影が安価
- 初期解の再利用を繰り返し利用したい

避ける／条件付き:

- 分割後の部分問題が元問題より難しい
- 高精度解が必要だが残差収束が遅い
- 非凸ADMMを理論保証付き凸ADMMと同一視している
- $\rho$や尺度により残差が一方だけ停滞する

## Python

次は同じ更新を3成分へ広げたものです。第1成分が表の例、第2成分はしきい値でゼロになる例、第3成分は小さな非ゼロを残す例です。解はソフトしきい値から $(2.2,0,0.4)$ と独立に求められるので、反復結果を照合できます。

L1正則化の分割を確認する小さな例です。
次は $\frac{1}{2}\|x-b\|^2 + \lambda\|z\|_1$、$x=z$ の小さな例です。

```python
import numpy as np


def soft_threshold(value: np.ndarray, threshold: float) -> np.ndarray:
    return np.sign(value) * np.maximum(np.abs(value) - threshold, 0.0)


b = np.array([3.0, -0.4, 1.2])
lam = 0.8
rho = 1.0
x = np.zeros_like(b)
z = np.zeros_like(b)
u = np.zeros_like(b)

for _ in range(200):
    x = (b + rho * (z - u)) / (1.0 + rho)
    previous_z = z.copy()
    z = soft_threshold(x + u, lam / rho)
    u = u + x - z

    primal = np.linalg.norm(x - z)
    dual = rho * np.linalg.norm(z - previous_z)
    if primal < 1e-8 and dual < 1e-8:
        break

print(np.round(z, 6))
print(primal < 1e-8, dual < 1e-8)
assert np.allclose(z, soft_threshold(b, lam), atol=1e-8, rtol=0.0)
```

```text
[ 2.2 -0.   0.4]
True True
```

`-0.` は浮動小数点表示上の負のゼロです。反復上限へ達しただけなら成功とはしません。また、このコードの固定閾値は小さな同じ尺度の例用です。一般には絶対・相対許容誤差と変数の次元・大きさを考慮します。

## 診断値

目的値だけでは不十分です。

- 主残差: $r_k = Ax_k + Bz_k - c$
- 双対残差: 一致制約なら $s_k=\rho(z_k-z_{k-1})$（符号は規約で変わるがノルムは同じ）
- 目的値
- 部分問題の求解誤差
- 罰則係数 $\rho$

主残差だけ小さくても双対残差が大きければ、変数は制約を満たしつつまだ動いています。
逆も同様です。

::: warning
ADMMの1反復が軽いとは限りません。
各部分問題で因数分解や内側の最適化を行う場合、内側の求解の費用と精度も記録します。
:::

## 失敗・切替の兆候

$\rho$は単なる学習率ではなく、一致制約違反への重みと数値条件数へ影響します。

- 主残差が双対残差より極端に大きい → $\rho$を上げる候補
- 双対残差が極端に大きい → $\rho$を下げる候補
- 頻繁に変える → 因数分解再利用や理論条件への影響を確認

残差の大きさは単位や尺度にも左右されます。主残差と双対残差の生の数値を比べるだけで、どちらが悪いかを断定しません。

$\rho$ を変えるときは、スケーリング前の乗数 $\nu=\rho u$ を保つため、 $u\leftarrow(\rho_{\rm old}/\rho_{\rm new})u$ と調整します。$\rho$ だけを変えて $u$ を放置すると、意図せず別の乗数へ飛びます。適応規則・再スケーリング・因数分解の再利用条件を一組で記録します。

標準的な収束の議論では、適切な閉凸関数 $f,g$、元のLagrangianの鞍点の存在、各部分問題が解けて正確に更新されること、固定した $\rho>0$ などを仮定します。凸性だけ、または任意の適応的な $\rho$ だけで保証されるわけではありません。この凸二ブロックADMMの収束条件を、非凸問題や単純な多ブロック交互更新に無条件で移しません。実装によって適応的規則も異なるため、既定値を無条件に横比較しません。
