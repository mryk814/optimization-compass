凸だが非微分可能な点でも利用できる劣勾配を使い、歩幅の予定表とこれまでの最良値を管理して目的値を改善する一次法です。

## 30秒でつかむ

屋根の稜線のように、折れ曲がった地形を下る場面を想像してください。
稜線の真上には、いちばん急な下りが一つに決まりません。使える傾きの候補が、いくつも並びます。
劣勾配法は、その候補から一つを選んで進みます。選んだ向きが、その一歩で必ず下るとは限りません。そこで、これまでに見た最高記録（最良値）を手帳に残します。

- **見るもの**: 現在の目的関数値、これまでの最良値、劣勾配、下界とギャップ（分かる場合）
- **動かすもの**: 現在点、歩幅係数の予定表、必要なら射影
- **前進の判断**: 最良値またはギャップが改善し、歩幅係数が理論の条件に沿っていること

微分できない点を避けるのではなく、凸関数を下から支える傾きを一つ選んで進む手法です。
気をつける点は四つあります。目的値の鋸歯状の動き（saw-tooth）と、固定の歩幅係数による振動があります。遅い収束率と、座標ごとの尺度の不一致もあります。

## 一手の意味

凸関数 $f$ の点 $x$ で、次の式をすべての $y$ で満たすベクトル $g$ を、劣勾配と呼びます。

$$
f(y)\ge f(x)+g^T(y-x)
$$

式は「$g$ を傾きにもつ直線が、$f$ の下に収まる」と言っています。
滑らかな点では、通常の勾配が唯一の劣勾配です。$f(x)=|x|$ の $x=0$ では、区間 $[-1,1]$ のすべてが劣勾配です。

更新は次の式です。凸集合 $C$ の上で解きたいときは、射影 $\Pi_C$ を付けます。

$$
x_{k+1}=\Pi_C(x_k-\alpha_k g_k)
$$

勾配降下法と同じ形ですが、$g_k$ が劣勾配である点が違います。

### 勾配降下法との違い

負の劣勾配の向きへ有限の一手を進んでも、目的値が毎回下がるとは限りません。
そのため、現在の目的値だけでなく、最良値や平均を追います。

歩幅係数 $\alpha_k$ には、代表的な予定表があります。実際の移動距離は、射影がなければ $\alpha_k\lVert g_k\rVert$ です。係数と距離を区別します。

- 減衰する一手: $\alpha_k\to0$ かつ $\sum_k\alpha_k=\infty$
- 二乗和が有限で総和が無限の一手: $\sum_k\alpha_k^2<\infty$ かつ $\sum_k\alpha_k=\infty$
- Polyakの一手: 正確な最適値 $f^*$ が分かれば $(f(x_k)-f^*)/\lVert g_k\rVert^2$。単なる下界を代入した場合は、同じ保証とは限らない
- 固定の歩幅係数: 誤差の近傍までは入るが、厳密には収束しないことがある

## 小さな例

勾配降下法の二次関数と同じ位置に、折れ目をもつ関数を置きます。

$$
f(x,y)=|x-1|+20\,|y+2|
$$

最小点は $(1,\,-2)$、値は $0$ です。$y$ 方向の傾きの大きさが $20$ で、$x$ 方向の20倍あります。座標ごとの尺度の差を持たせています。ただし、この非滑らかな関数に二次関数のHessian条件数 $\kappa$ をそのまま定義しているわけではありません。
劣勾配は $(\mathrm{sign}(x-1),\ 20\,\mathrm{sign}(y+2))$ で、折れ目の上では $0$ を選びます。

初期点 $(4,\,3)$ から、歩幅係数を $\alpha_k=1/\sqrt{k+1}$ として追います。

| $k$ | 現在点 | 劣勾配 | 目的値 | 最良値 |
|---:|---|---|---:|---:|
| 0 | $(4,\,3)$ | $(1,\,20)$ | 103 | 103 |
| 1 | $(3,\,-17)$ | $(1,\,-20)$ | 302 | 103 |
| 2 | $(2.293,\,-2.858)$ | $(1,\,-20)$ | 18.45 | 18.45 |
| 3 | $(1.716,\,8.689)$ | $(1,\,20)$ | 214.5 | 18.45 |
| 4 | $(1.216,\,-1.311)$ | $(1,\,20)$ | 14.0 | 14.0 |
| 5 | $(0.768,\,-10.255)$ | $(-1,\,-20)$ | 165.3 | 14.0 |
| 6 | $(1.177,\,-2.090)$ | $(1,\,-20)$ | 1.98 | 1.98 |

現在の目的値は、次のように大きく上下します。

$$
103\to302\to18.5\to214.5\to14.0\to165.3\to1.98
$$

$y$ 方向の劣勾配が $20$ なので、一手ごとに $y$ が $20\alpha_k$ だけ動き、折れ目の $y=-2$ を何度も飛び越えるためです。飛び越すたびに劣勾配の符号が反転し、目的値が跳ね上がります。

下がり続けるのは、最良値だけです。最良値は $103\to18.45\to14.0\to1.98$ と進み、上がることはありません。
歩幅係数が小さくなるにつれて、飛び越える幅も縮みます。初期点を含む1000点（$k=0,\ldots,999$）を評価した最良値は約 $1.6\times10^{-5}$ です。最後に作る $x_{1000}$ の値は、この集計には含めません。

歩幅係数を固定して $1$ にすると、目的値は次のように往復します。

$$
103,\ 302,\ 101,\ 300,\ 100,\ 300,\ \dots
$$

$y$ が $3$ と $-17$ を行き来し、最良値は $100$ から下がりません。
この固定係数の例では、最良値が100に留まります。往復を収束と読まないために、最良値とギャップを見ます。

左図の番号が表の $k$ と対応します。$k=1$ は最初の一手で目的値が約3倍になった点です。右図は対数目盛なので、橙の線が平らな区間は「更新していない」のではなく「新しい記録が出ていない」ことを示します。最良値だけでなく、その値を出した点も保存すれば、最後の点が悪化していても良い候補を返せます。

### 小さく歩いても下れない場合がある

最初の大きな跳び越しは、歩幅の大きさが原因でした。一方、折れ目では方向自体が下降方向でないこともあります。同じ関数の $(4,-2)$ では $g=(1,20)$ も正しい劣勾配です。この $-g$ へ $0<\alpha<3$ だけ進むと、

$$
f(4-\alpha,-2-20\alpha)=3-\alpha+400\alpha=3+399\alpha>3.
$$

どんなに小さくしても増えます。劣勾配不等式は関数の「下側」を支える条件なので、$-g$ へ進む先の上側を抑えてはくれません。本文コードは折れ目で0成分を選ぶため、この選び方の反例とは区別します。また最小点でも非零の劣勾配を選べます。選んだ劣勾配のノルムが大きいことだけで「最適でない」とは断定できません。凸・無制約なら、最適性の条件は $0\in\partial f(x)$ です。

### 「収束する」の対象と前提

最小点 $x^*$ が存在し、反復で使う劣勾配が $\lVert g_k\rVert\le G$、初期距離が $\lVert x_0-x^*\rVert\le R$ とします。閉凸集合への正確な射影も許す場合、最初の $T$ 点の最良値には

$$
f_{\rm best,T}-f^*\le
\frac{R^2+G^2\sum_{k=0}^{T-1}\alpha_k^2}
{2\sum_{k=0}^{T-1}\alpha_k}
$$

という評価が得られます。これは現在値の単調性でも、すべての反復点の一意な最小点への収束でもありません。$\alpha_k=1/\sqrt{k+1}$ は二乗和が発散するので、「二乗和有限」の例ではありません。それでも右辺は $O(\log T/\sqrt T)$ で0へ近づきます。あらかじめ予算 $T$ と $R,G$ が分かるなら、$\alpha=R/(G\sqrt T)$ をその予算中固定することで $RG/\sqrt T$ の評価を得られます。無限に同じ係数を使い続ける話とは異なります。[Boyd・Parkの講義ノート §§2–4](https://web.stanford.edu/class/ee364b/lectures/subgrad_method_notes.pdf)

本例は $R^2=34$、$G^2=401$ です。$T=1000$ の上界は約24.56で、実測最良値 $1.62\times10^{-5}$ よりずっと緩くなります。保証は最悪の場合の安全な上限であり、特定の初期点で何回目に良い点へ偶然近づくかを予測する式ではありません。非凸や雑音つきのoracleへ、この保証を無条件に移しません。

## 向く条件・避ける条件

劣勾配法は、凸で非滑らかな目的に、最小限の道具で使える手法です。ただし、遅さを前提に選びます。

向く条件です。

- 凸だが非滑らかな目的である（[非滑らかな凸複合の最小化](#/formulations/PA010)）
- 近接作用素を計算しにくいが、劣勾配は得られる
- 巨大な問題で、安価な一反復を優先したい
- 高精度の解より、粗い解や下界の進みが重要である
- Lagrange双対の更新である

避ける、または切り替える条件です。

- 近接作用素が計算できる構造がある → [近接勾配法](#/learn/proximal-gradient)を比較する
- 滑らかで、条件数が支配的である → 勾配法や準Newton法を比較する（[滑らかな低次元無制約](#/formulations/PA006)）
- 劣勾配の情報を蓄えて安定させたい → [Bundle法](#/learn/bundle-method)を検討する
- 単体や確率など、ユークリッド距離が合わない領域である → [Mirror Descent](#/learn/mirror-descent)を検討する
- 非凸で、凸の理論をそのまま当てはめたい → 理論の適用範囲を見直す（[一般非滑らか局所](#/formulations/PA011)）

## Python

次の例は、上の関数に劣勾配法を適用し、最良値を記録する最小例です。

```python
import numpy as np


def objective(p: np.ndarray) -> float:
    return float(abs(p[0] - 1.0) + 20.0 * abs(p[1] + 2.0))


def subgradient(p: np.ndarray) -> np.ndarray:
    # 折れ目では 0 を選ぶ。oracle が返す劣勾配の選び方も、再現条件に含める。
    return np.array([np.sign(p[0] - 1.0), 20.0 * np.sign(p[1] + 2.0)])


def run(step, iterations):
    p = np.array([4.0, 3.0])
    best_value = objective(p)
    rows = []
    for k in range(iterations):
        value = objective(p)
        best_value = min(best_value, value)
        rows.append((k, p.copy(), value, best_value))
        p = p - step(k) * subgradient(p)
    return rows


rows = run(lambda k: 1.0 / np.sqrt(k + 1), 1_000)
for k, p, value, best in rows[:7]:
    print(k, np.round(p, 3), round(value, 2), round(best, 2))
# 0 [4. 3.] 103.0 103.0
# 1 [  3. -17.] 302.0 103.0
# 2 [ 2.293 -2.858] 18.45 18.45
# 3 [1.716 8.689] 214.5 18.45
# 4 [ 1.216 -1.311] 14.0 14.0
# 5 [  0.768 -10.255] 165.33 14.0
# 6 [ 1.177 -2.09 ] 1.98 1.98
print("初期点を含む1000点の最良値", rows[-1][3])
# 初期点を含む1000点の最良値 1.6159782813662815e-05

rows = run(lambda k: 1.0, 1_000)
print("固定の歩幅係数 1 の最良値", rows[-1][3])
# 固定の歩幅係数 1 の最良値 100.0
```

出力の前半が、上の表と一致します。目的値は上下しますが、最良値は下がる一方です。
反復を増やしても、最良値がすぐ更新されるとは限りません。下がるか同じ値に留まる量として読みます。

実用コードで最良点を返すには、最良値を更新したときに `best_point = p.copy()` も保存します。一反復の中心費用は劣勾配1回と、必要なら射影1回です。目的値の記録が別の高価な呼出しなら、その回数も予算へ足します。変数を再尺度化すると更新の幾何も変わるため、同じ数値の学習率をそのまま流用せず、更新量を元の単位で確かめます。

## 診断値

目的値が鋸歯状に動くこと自体は、異常ではありません。見分けたいのは三つの場合です。最良値が長く改善しない場合、一手が大きすぎる場合、ノイズの床に着いた場合です。そのために、次を記録します。

- 現在の目的値と、最良値
- 歩幅係数
- 劣勾配のノルム
- 射影した一手のノルム
- 目的値の移動平均
- 下界とギャップ（分かる場合）
- 制約違反
- 反復回数と、劣勾配の計算回数の予算

## 失敗・切替の兆候

- 近接作用素が計算できる構造がある → 劣勾配法は構造を使っていない → [近接勾配法](#/learn/proximal-gradient)を比較する
- 滑らかで、条件数が支配的である → 劣勾配より曲率を使える → 勾配法や準Newton法を比較する
- 非凸なのに、劣勾配の理論をそのまま適用している → 収束の保証が成り立たない → 理論の適用範囲を見直す
- 固定の歩幅係数の振動を、収束と誤認している → 誤差の近傍に留まっている → 最良値、ギャップ、歩幅係数を確認する
- 現在の目的値だけで停止を判定している → 鋸歯状の動きで誤判定する → 最良値や下界を併用する
- 尺度の違う座標に、同じユークリッドの一手を使っている → 劣勾配の大きい座標が振動し、ほかの座標が進まない → 尺度や変数の取り方を見直す

::: warning
劣勾配法の理論上の収束率は、一般に遅く、高精度の解には多数の反復が必要です。
「微分不要法」ではなく、凸解析の劣勾配を得る評価手段を使う方法として位置づけます。
:::
