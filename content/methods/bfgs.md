勾配の変化から逆ヘッセ行列の近似を更新し、Newton法に近い探索方向を作る準Newton法です。

## 30秒でつかむ

坂道を歩きながら、進んだ距離と傾きの変化を書き留めるところを想像してください。
「これだけ進んだら、傾きがこれだけ変わった」という記録がたまると、地面の曲がり方が推測できます。BFGS法は、この推測を使って、次に進む方向を整えます。

- **見るもの**: 目的関数値、勾配の変化、直線探索の結果
- **動かすもの**: 現在点、探索方向、逆ヘッセ行列の近似
- **前進の判断**: 直線探索が下降を確認し、最終的に勾配の大きさが許容範囲へ入ること。勾配ノルムの単調減少までは要求しない

ヘッセ行列（二階微分の行列）は直接計算しません。目的関数値と勾配を使います。

## 一手の意味

勾配降下法は、常に $-\nabla f(x_k)$ へ進みます。BFGS法は、正定値行列 $H_k$ で勾配を変形してから進みます。
次の式は、勾配に逆ヘッセ行列の近似を掛けたものを、探索方向にするという意味です。

$$
p_k = -H_k \nabla f(x_k)
$$

$H_k$ が単位行列なら勾配降下法と同じ向きです。$H_k$ が真の逆ヘッセ行列に近づくほど、Newton法の向きに近づきます。

新しい点へ移動したら、動きと勾配の変化を記録します。

- $s_k = x_{k+1} - x_k$（動いた量）
- $y_k = \nabla f(x_{k+1}) - \nabla f(x_k)$（勾配の変化）

この二つのベクトルで $H_k$ を更新します。$\rho_k = 1/(y_k^T s_k)$ として、更新式は次のとおりです。

$$
H_{k+1} = (I - \rho_k s_k y_k^T)\,H_k\,(I - \rho_k y_k s_k^T) + \rho_k s_k s_k^T
$$

更新後の $H_{k+1}$ は、$H_{k+1}\,y_k = s_k$ を満たします（セカント条件、secant condition）。
観測した勾配の変化 $y_k$ から、実際に動いた量 $s_k$ を説明できる近似になる、という条件です。
厳密算術では、$H_k$ が対称正定値で曲率条件 $y_k^T s_k>0$ が満たされると、更新後も対称正定値です。勾配が非零なら $\nabla f(x_k)^\top p_k<0$ となり、下降方向を作れます。有限精度やノイズのある実装では、曲率の閾値、更新のスキップや減衰などの保護策を検討します。

### 直線探索の役割

BFGSの名前は更新式を表しますが、実用上は一手の長さを決める直線探索と組み合わせます。一手が大きすぎると目的値が悪化し、小さすぎると曲率の情報を十分に得られません。

方向 $p$ を決めたら、一本の直線上の関数 $\phi(\alpha)=f(x+\alpha p)$ を考えます。出発点で下降方向なら $\phi'(0)=\nabla f(x)^\top p<0$ です。

**Armijo条件**は、予想される一次の減少の一部を、実際にも得られたかを確認します。

$$
\phi(\alpha)\le\phi(0)+c_1\alpha\phi'(0)
$$

しかし、小さな正の $\alpha$ はたいていこの条件を満たします。「ほとんど進まなかった一歩」を、それだけでは除けません。

**Wolfeの曲率条件**を足すと、まだ同じ向きへ急に下っている場所で早々に止まることを防ぎます。

$$
\phi'(\alpha)\ge c_2\phi'(0),\qquad 0<c_1<c_2<1
$$

強いWolfe条件では、右辺との比較を $|\phi'(\alpha)|\le c_2|\phi'(0)|$ とします。下りが急すぎるだけでなく、通り越して上りが急すぎる一歩も除きます。いずれも直線上の最小点を厳密に求める条件ではなく、十分によい歩幅の範囲を決める条件です。

#### なぜ直線探索が、曲率行列を守れるのか

$s=\alpha p$ と $y=\nabla f(x+\alpha p)-\nabla f(x)$ より、

$$
y^\top s=\alpha\,[\phi'(\alpha)-\phi'(0)]
\ge \alpha(c_2-1)\phi'(0)>0
$$

です。正の歩幅、下降方向、Wolfeの曲率条件が揃うと、BFGSが必要とする正の曲率が得られます。直線探索は目的値を下げるだけでなく、次の近似行列へ渡す観測対の品質にも関わっています。

この導出は正確な勾配と条件判定を前提にします。差分や確率的な勾配の誤差、極小の一歩による桁落ちまで消えるわけではありません。

::: warning
「BFGSを使った」だけでは、再現条件として不十分です。
次を一緒に記録します。初期点・勾配の実装・直線探索の条件・停止許容値・尺度です。
:::

## 小さな例

[勾配降下法](#/learn/method.gradient-descent)、[Newton法](#/learn/newton-method)と同じ関数 $f(x,y)=(x-1)^2+20(y+2)^2$ を、初期点 $(4,\,3)$ から解きます。
真の逆ヘッセ行列は $\mathrm{diag}(0.5,\,0.025)$ です。BFGS法はこの値を知らないまま、勾配だけで近づけます。

手で追いやすいように、直線探索は二次関数用の厳密な式で長さを決めます。実際のライブラリはWolfe条件などで近似的に決めるので、途中の数値は一致しません。
初期の近似は $H_0=I$ とします。

| 反復 | 現在点 | 勾配 | 探索方向 $p$ | 一手の長さ | 次の点 | 目的値 |
|---:|---|---|---|---:|---|---:|
| 0 | $(4,\,3)$ | $(6,\,200)$ | $(-6,\,-200)$ | 0.02502 | $(3.850,\,-2.004)$ | 509 → 8.12 |
| 1 | $(3.850,\,-2.004)$ | $(5.700,\,-0.171)$ | $(-5.705,\,0.009)$ | 0.4996 | $(1,\,-2)$ | 8.12 → 0 |

反復0の向きは、勾配降下法と同じ最急降下の向きです。$H_0=I$ なので、まだ曲率を知りません。
$s_0=(-0.150,\,-5.004)$、$y_0=(-0.300,\,-200.17)$ が得られ、$y_0^T s_0\approx 1001.8$ です。これで更新した近似は次の値になります。

$$
H_1\approx\begin{pmatrix}1.0008&-0.0008\\-0.0008&0.0250\end{pmatrix}
$$

$y$ 方向の対角成分は、表示した桁では真の値 $0.025$ と同じですが、厳密に一致したわけではありません。一回の観測が拘束するのは、座標方向を別々に当てることではなく、$H_1y_0=s_0$ というベクトルの関係です。
$x$ 方向の対角成分 $1.0008$ は、真の $0.5$ とまだ違います。一回の観測対が与えるセカント条件だけでは、行列の全方向の作用は決まりません。

反復1では、この $H_1$ が探索方向を $(-5.705,\,0.009)$ に整えます。最急降下なら $(-5.70,\,0.17)$ の向きでしたが、$y$ 方向の成分が $0.17$ から $0.009$ へ小さくなります。
二回目の更新で、近似は真の逆ヘッセ行列 $\mathrm{diag}(0.5,\,0.025)$ に一致し、最小点 $(1,\,-2)$ に着きます。

この手計算ではBFGSは2回、正確なヘッセ行列を使うNewton法は1回です。ただしBFGSにも二次関数に特化した厳密直線探索を与えています。一般問題での実時間や評価回数の順位ではありません。勾配降下法との比較には、歩幅と停止条件も揃える必要があります。
厳密算術・厳密な直線探索・正定値の初期近似の下では、正定値二次関数に対するBFGSは高々 $n$ 回で最小点へ到達します。今回は $n=2$ です。この性質を、丸め誤差のある一般非線形問題の反復上限とはしません。

### 同じ最初の一歩で、歩幅の条件を眺める

最初の方向 $p_0=(-6,-200)$ は固定します。この方向上の厳密な最小化歩幅を $\alpha_*\approx0.025021374$ とし、横軸を $t=\alpha/\alpha_*$ に変えます。$t=1$ が直線上の最小点です。

![同じ方向上で、Armijoだけなら極小の歩幅が通り、強いWolfeでは両端が除かれる図](./media/bfgs-line-search-window.svg "色帯は強いWolfe条件を満たす範囲です。試行点は説明用で、SciPyがこの順に試した点ではありません。")

縦軸は $[\phi(\alpha)-\phi(0)]/D$、$D=\phi(0)-\phi(\alpha_*)>0$ です。この二次関数では $t^2-2t$ になり、最小値は $-1$。色帯は $c_1=10^{-4},c_2=0.9$ で両条件を満たす範囲 $0.1\le t\le1.9$ です。図の試行点は条件を説明するために選んだ値で、SciPyがこの順に試した点ではありません。

| 歩幅の比 $t$ | 正規化した目的変化 | Armijo | 強い曲率条件 | 読み方 |
|---:|---:|---|---|---|
| 0.01 | −0.0199 | 満たす | 満たさない | 少し下がったが、まだ下りが急すぎる |
| 0.5 | −0.75 | 満たす | 満たす | 厳密な最小点まで行かずに受け入れられる |
| 1 | −1 | 満たす | 満たす | この直線上の最小点 |
| 1.95 | −0.0975 | 満たす | 満たさない | 出発点より低いが、通り越して上りが急すぎる |
| 2.1 | 0.21 | 満たさない | 満たさない | 目的値そのものが悪化した |

$t=1.95$ は弱いWolfeの曲率条件なら満たします。弱い条件と強い条件を混ぜず、実装がどちらを使うか記録します。この放物線の受理区間は手計算できる特例で、一般関数で同じ区間になるわけではありません。

## 向く条件・避ける条件

BFGS法は、勾配が信頼でき、変数が中程度の滑らかな問題で高精度の局所解を少ない反復で得たいときに有力です（[滑らかな無制約の最小化](#/formulations/PA006)）。

| 条件 | 理由 |
|---|---|
| 連続・滑らか | 勾配差を曲率情報として利用するため |
| 中小規模 | 密な近似行列は概ね $O(n^2)$ のメモリを使うため |
| 勾配が信頼できる | 誤った勾配は更新行列を壊すため |
| 局所解でよい | 非凸問題で大域最適性を保証する手法ではないため |

避ける、または切り替える条件です。

- 変数が多く、$n\times n$ の行列を持てない → [L-BFGS](#/learn/lbfgs)などメモリを限った方法を検討する（[大規模な無制約の最小化](#/formulations/PA007)）
- 上下限がある → [L-BFGS-B](#/learn/lbfgsb)を検討する（[上下限つきの滑らかな最小化](#/formulations/PA008)）
- 一般の制約がある → BFGS単体では制約を扱えません。目的関数値が下がっても、制約違反が残る点は解ではありません。[SLSQP](#/learn/slsqp)や[非線形内点法](#/learn/interior-point-nlp)へ切り替える（[制約付きNLP](#/formulations/PA009)、下のコラム）
- ヘッセ行列を直接計算できる → [Newton法](#/learn/newton-method)と比べる

## Python

次の例は、解析的な勾配を渡してBFGS法を実行する最小例です。上の小さな例と同じ関数を使います。

```python
import numpy as np
from scipy.optimize import minimize


def objective(x: np.ndarray) -> float:
    return float((x[0] - 1.0) ** 2 + 20.0 * (x[1] + 2.0) ** 2)


def gradient(x: np.ndarray) -> np.ndarray:
    return np.array([2.0 * (x[0] - 1.0), 40.0 * (x[1] + 2.0)])


result = minimize(
    objective,
    x0=np.array([4.0, 3.0]),
    jac=gradient,
    method="BFGS",
    options={"gtol": 1e-8, "maxiter": 200},
)

print(result.success, result.x, result.fun, result.nit, result.nfev, result.njev)
# True [ 1. -2.] 6.8e-21 9 10 10
print(result.hess_inv)
# 概数: [[0.5, 1.4e-05], [1.4e-05, 0.025]]
```

この掲載コードではSciPy 1.17.0で9回でした。実装や停止条件によって変わります。直線探索が厳密な最小化ではないため、手計算の2回という保証をこの実行には適用しません。
`hess_inv` は、最後の逆ヘッセ行列の近似です。真の $\mathrm{diag}(0.5,\,0.025)$ にほぼ一致していることを確認できます。
利用中のSciPyのオプション名や既定値は、[scipy.optimize.minimize](https://docs.scipy.org/doc/scipy-1.17.0/reference/optimize.minimize-bfgs.html)の公式リファレンスで確認します。

## 診断値

- 勾配のノルム
- 直線探索の反復回数
- 関数評価と勾配評価の回数
- 一手のノルム
- $y_k^T s_k$ が十分に正か
- 目的値の変化

## 失敗・切替の兆候

- 有限差分との勾配チェックが合わない → 勾配実装、差分幅、丸め誤差、評価ノイズを確認する
- 変数や目的値の尺度が極端に違う → 近似や直線探索が数値的に扱いにくくなることがある → 尺度と初期近似を見直す
- 直線探索が失敗する → 勾配の誤り、非滑らかさ、評価ノイズ、数値精度や探索上限などを確認する
- $y_k^T s_k$ が負、または尺度に対して小さすぎる → Wolfe条件の判定、勾配誤差、桁落ち、収束近傍かどうかを確認する
- 初期点によって異なる点へ収束する → 非凸性、解の非一意性、停止精度を確認し、目的値と最適性残差を比較する
- メモリが足りない → $n\times n$ の行列が大きすぎる → L-BFGSへ切り替える

## コラム: 制約処理はBFGSの外にある

BFGSの更新式は、一般の制約を自動では扱いません。
目的関数値が下がっても、制約違反が残る点は解ではありません。

![円内の実行可能領域に対し、制約を無視するBFGS対応の失敗経路が目的値0へ進みながら円外で終了する固定2次元実行結果。](./media/constrained-feasibility-execution.svg "BFGSそのものの性能ではなく、制約を評価しない更新を成功と数えられない理由を示す失敗例との対比です。")

橙の終了点は、目的関数だけなら最小です。
円の外にあるため、この制約付き問題の解ではありません。

[制約を無視した場合の可視化画面](#/theater/learning/SCENARIO_CONSTRAINED_DISK)では、円内の可行領域とBFGSの失敗の経路を同じ図で確認できます。
[SLSQPとの比較](#/compare/COMPARE_CONSTRAINED_FAILURE)は、同じ目的・円盤の制約・初期点・12回の教材用予算を使います。
変えるのは、制約を評価するかどうかです。

これは、可行性と目的の改善を分けて読む固定の教材です。
BFGSやSLSQPの実装内部を再現するベンチマークではなく、ソルバーの一般的な性能ランキングにも使いません。
