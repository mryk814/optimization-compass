勾配や曲率を使える連続問題で、Gradient Descent、BFGS、Newton系を条件に応じて選び分けるための入口です。

## 30秒でつかむ

この手法群の気持ちは、**現在地の近くで目的関数がどちらへ下がり、どの程度曲がっているかを使って、無駄の少ない一歩を作ること**です。

- 見ているもの: 目的関数値、勾配、必要ならヘッセ行列またはヘッセ行列とベクトルの積
- 動かすもの: 現在点と探索方向
- 前進の判断: 目的値の低下、勾配ノルムの低下、局所モデルと実際の改善の一致
- 主な弱点: 初期値依存、微分の誤り、変数尺度、非凸問題の局所解

「二階法が常に上位」という順位ではありません。1ステップの賢さと、メモリ・線形代数・微分計算の重さを交換しています。

## まず確認すること

| 確認項目 | 選択への影響 |
|---|---|
| 勾配を正確に得られるか | 得られないなら、この手法群を第一候補にしない |
| 変数数とメモリ | 密な BFGSやヘッセ行列を保持できるか |
| ヘッセ行列とベクトルの積 | Newton-CGや信頼領域を大規模化できるか |
| 上下限 | L-BFGS-Bや射影を使う手法が必要か |
| 非凸性 | 局所停留点で十分か、負の曲率を扱いたいか |
| 必要精度 | 粗い改善か、高精度な停留性か |

勾配を自動微分で得られても、正しいとは限りません。有限差分との方向微分検算、単位、バッチ平均、正則化を確認します。

## 条件付きの選び分け

| 役割 | 手法 | 優先しやすい条件 | 切り替えを考える条件 |
|---|---|---|---|
| 分かりやすい基準点 | [Gradient Descent](#/learn/method.gradient-descent) | 更新則を理解したい、巨大問題で単純ステップが必要 | 学習率調整だけで進まず評価回数が増える |
| 中小規模の標準候補 | [BFGS](#/learn/bfgs) | 滑らか、勾配が信頼できる、密な近似を保持可能 | メモリが支配的、直線探索の失敗が続く |
| 高次元・上下限 | [L-BFGS-B](#/learn/lbfgsb) | 変数が多い、上下限がある | 一般非線形制約が本質、曲率近似が不安定 |
| 二階情報を直接利用 | [Newton法](#/learn/newton-method) | ヘッセ行列が得られ、良い近傍で高精度化したい | ヘッセ行列が不定・特異、線形系が重い |
| 二階法を安全に大規模化 | [Trust-region Newton-CG](#/learn/trust-region-newton-cg) | HVPがあり、モデルを信用する範囲を制御したい | 信頼半径が縮み続ける、HVPが不正 |
| 低メモリ方向更新 | [Nonlinear CG](#/methods/M_NLCG) | 大規模無制約で勾配はあるがメモリを抑えたい | 再始動が頻発し、方向の質が保てない |

これは一般性能順位付けではありません。同じ問題例、初期点、勾配を得る計算手段、許容誤差、評価予算で比較します。

## うまくいったサインと切替サイン

うまく進んでいるときは、目的値だけでなく次も改善します。

- 勾配ノルムが一貫して小さくなる
- 直線探索の試行回数が極端に増えない
- 更新量のノルムが停止許容値へ近づく
- 信頼領域では実測改善量 / 予測改善量比が安定する
- 異なる初期値でも同程度の解へ到達する

切替サイン:

- 勾配の検算が一致しない → 微分・単位・データ処理を直す
- 直線探索の失敗が続く → 尺度の調整、信頼領域、別の大域化を検討
- メモリが支配的 → BFGSからL-BFGSやNLCGへ
- 局所解が初期値ごとに変わる → 複数の初期点を使う探索や大域探索の手法群へ
- 上下限以外の制約違反が残る → 制約付きNLPの手法群へ

## 小さな比較の型

実装比較では反復数だけを揃えません。少なくとも評価回数と停止条件を記録します。

```python
experiment = {
    "problem_instance": "same-smooth-objective",
    "initial_point": [1.0, -1.0],
    "gradient_source": "automatic-differentiation-checked",
    "objective_evaluation_budget": 500,
    "gradient_evaluation_budget": 500,
    "gradient_tolerance": 1e-6,
    "methods": ["BFGS", "L-BFGS-B", "trust-ncg"],
}

assert experiment["objective_evaluation_budget"] > 0
```

## コラム: 速い収束とは何か

Newton系の「速い」は、通常は**解の十分近くでの局所収束率**を指します。初期点が遠い、ヘッセ行列が不定、直線探索や信頼領域が候補ステップを拒否する状況では、その速さはそのまま現れません。

また、非凸問題で勾配が小さいことは大域最適性の証明ではありません。局所最小、鞍点、平坦領域を区別するには、曲率、複数初期値、問題固有の構造を追加で確認します。
