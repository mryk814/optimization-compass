Newton法は、今いる点で関数に放物線（多変数ではお椀）を当て、その底へ一気に跳ぶ最適化法です。底の近くでは反復ごとに正しい桁数がほぼ倍になります。一方で、曲がりが下向きの場所では山へ跳び、平らな場所では遠くへ跳びます。そのため、曲がりの確認や一歩の調整と組み合わせて使います。

## 30秒でつかむ

霧の中で、谷の底を探しているとします。見えるのは足元だけですが、地面の傾きと、地面がどれくらい曲がっているかは測れます。
[勾配降下法](#/learn/method.gradient-descent)は傾きだけを使い、坂を少しずつ下ります。底に近づくほど傾きが小さくなるので、歩みも遅くなります。
Newton法は、傾きと曲がりから「この先はこういう放物線だろう」と地形を思い描き、その放物線の底へ一気に跳びます。

- **見るもの**: 今いる点での関数の傾き $f'(x)$ と曲がり $f''(x)$（多変数では勾配とヘッセ行列）
- **動かすもの**: 今いる点 $x$
- **前進の判断**: 関数の値が下がり、曲がり $f''$ が正のまま、傾きが0に近づいていくこと

思い描いた放物線が本物の地形とよく合えば、一歩でほぼ底に着きます。合わない場所では、まるで見当違いの場所へ跳びます。

まず「始点 x₀」のつまみを2のままにして、「最初から」（⏮）を押し、続けて「1つ進む」（▶）を押してください。「関数と放物線」の破線が、その点で当てた放物線です。「正しい桁数」の棒が、反復ごとにどう伸びるかを見てください。

::: explorable newton-parabola-jump
「関数と放物線」の実線が f(x)=x⁴/4−x²/2 で、谷は x=±1、山は x=0 にあります。破線は今いる点で当てた放物線、白丸はその頂点です。「正しい桁数」は、向かっている点までの誤差を桁で表した棒で、灰色が同じ始点からの勾配降下法（η=0.1）です。1変数の教材用の関数で、多変数の大きな問題での計算費用は示しません。
:::

確かめてほしいことは三つあります。

1. 始点2から進むと、3回目以降の正しい桁数は 1.6 → 3.0 → 5.9 → 11.6 とほぼ倍々に増えます。灰色の勾配降下法は、1回に約0.1桁しか増えません。
2. 「始点 x₀」を0.3にすると、破線の放物線が下に開きます。その頂点は谷ではなく山なので、Newton法は山 x=0 へ向かいます。
3. 「始点 x₀」を0.6にすると、放物線がほとんど平らになり、頂点がずっと遠くにできます。一歩で x=5.4 まで跳びます。「進み方」を「曲がりを確かめ、一歩を縮める」にすると、0.3からも0.6からも谷 x=1 に着きます。

なぜ底の近くでは桁が倍々に増え、離れた場所では見当違いの方向へ跳ぶのでしょうか。

## 一手の意味

Newton法は、今いる点 $x_k$ で、値・傾き・曲がりが関数とちょうど一致する放物線を作ります。

$$
m_k(x)=f(x_k)+f'(x_k)\,(x-x_k)+\tfrac12 f''(x_k)\,(x-x_k)^2
$$

この式は「$x_k$ での値に、傾きによる変化と、曲がりによる変化を足した放物線」と読みます。$f$ の2次までのTaylor展開です。
放物線の頂点は傾きが0になる点なので、$m_k'(x)=f'(x_k)+f''(x_k)(x-x_k)=0$ を解いて、次の点を決めます。

$$
x_{k+1}=x_k-\frac{f'(x_k)}{f''(x_k)}
$$

この式は「傾きを曲がりで割った分だけ、下り坂の向きに進む」と読みます。曲がりが大きい（急に底へ向かう）ほど、一歩は短くなります。

### 頂点が底とは限らない

放物線の頂点が谷底になるのは、$f''(x_k)>0$ で放物線が上に開くときだけです。

| 今いる点の曲がり | 放物線の形 | 頂点 | Newton法の一歩 |
|---|---|---|---|
| $f''>0$ で大きい | 上に開く、急な谷 | 谷底 | 底の方向へ短く進む |
| $f''>0$ で0に近い | 上に開く、ほとんど平ら | 遠くの谷底 | 非常に遠くへ跳ぶ |
| $f''<0$ | 下に開く | 山の頂上 | 山の方向へ進む |

$f''$ が0のときは、式が0で割ることになり、一歩が決まりません。

### 多変数では、お椀の底へ跳ぶ

変数が $n$ 個あるときは、傾きが勾配 $\nabla f$、曲がりがヘッセ行列 $\nabla^2 f$（2階偏微分を並べた $n\times n$ 行列）になります。放物線はお椀になり、その底への一歩 $d$ は、次の連立一次方程式で決まります。

$$
\nabla^2 f(x_k)\,d=-\nabla f(x_k),\qquad x_{k+1}=x_k+d
$$

ヘッセ行列が正定値（どの向きにも上に開く）なら、底は一点に決まります。
[勾配降下法](#/learn/method.gradient-descent)の記事の細長い谷 $f(x,y)=(x-1)^2+20(y+2)^2$ は、それ自体がお椀です。そのため、Newton法は点 $(4,\,3)$ から一歩で最小点 $(1,\,-2)$ に着きます。勾配降下法は、谷が細長いほど学習率を小さくする必要がありました。Newton法の一歩は、谷の縦横の比が変わっても同じ点へ進みます。

## 小さな例

$f(x)=\tfrac14x^4-\tfrac12x^2$ を最小にします。傾きは $f'(x)=x^3-x$、曲がりは $f''(x)=3x^2-1$ です。
谷は $x=\pm1$ にあり、そこでの曲がりは $f''=2$ です。山は $x=0$ にあり、曲がりは $f''=-1$ です。

### 曲線の例・始点2から

始点 $x_0=2$ からNewton法で進むと、次のようになります。「正しい桁数」は $-\log_{10}|x_k-1|$ で、谷 $x=1$ までの誤差を桁で表します。

| 反復 $k$ | $x_k$ | $f'(x_k)$ | $f''(x_k)$ | 誤差 $\lvert x_k-1\rvert$ | 正しい桁数 |
|---:|---:|---:|---:|---:|---:|
| 0 | 2 | 6 | 11 | 1 | 0 |
| 1 | $1.4545454545$ | 1.623 | 5.347 | $4.5\times10^{-1}$ | 0.3 |
| 2 | $1.1510467894$ | 0.374 | 2.975 | $1.5\times10^{-1}$ | 0.8 |
| 3 | $1.0253259290$ | $5.3\times10^{-2}$ | 2.154 | $2.5\times10^{-2}$ | 1.6 |
| 4 | $1.0009084519$ | $1.8\times10^{-3}$ | 2.006 | $9.1\times10^{-4}$ | 3.0 |
| 5 | $1.0000012353$ | $2.5\times10^{-6}$ | 2.000 | $1.2\times10^{-6}$ | 5.9 |
| 6 | $1.0000000000$ | $4.6\times10^{-12}$ | 2.000 | $2.3\times10^{-12}$ | 11.6 |

1回目は $x=2$ から $x=1.4545$ へ進みます。$f'(2)=6$、$f''(2)=11$ なので、一歩は $6/11=0.545$ です。
3回目以降は、誤差がほぼ前回の誤差の2乗になります。例えば $0.025^2\approx6\times10^{-4}$ で、4回目の誤差 $9.1\times10^{-4}$ と同じくらいです。これが、正しい桁数が倍々に増える理由です。
誤差が2乗で減るのは、底の近くで $f''$ が正で、放物線が本物の曲線とよく合うからです。この性質を二次収束と呼びます。

### 曲線の例・同じ始点からの勾配降下法

同じ始点2から、学習率 $\eta=0.1$ の勾配降下法で7回進むと、$x=1.06297$ です。正しい桁数は1.2で、1回に約0.1桁ずつしか増えません。
谷 $x=1$ の近くでは、勾配降下法の誤差は1回ごとに $1-\eta f''(1)=0.8$ 倍になります。誤差が一定の割合でしか縮まないので、桁は一定の速さでしか増えません。

### 曲線の例・始点0.3と0.6から

始点 $x_0=0.3$ では $f''(0.3)=-0.73$ で、放物線は下に開きます。Newton法の一歩は $x_1=-0.0740$、次は $x_2=0.000823$ と、山 $x=0$ へ二次収束します。傾きが0になる点を探す式なので、谷と山を区別しないからです。

始点 $x_0=0.6$ では $f''(0.6)=0.08$ とほとんど平らです。一歩は $f'(0.6)/f''(0.6)=-0.384/0.08=-4.8$ で、$x_1=5.4$ まで跳びます。この例では、その後7回で $x=1.009$ まで戻ってきますが、関数によっては戻ってこられません。

二つの失敗を防ぐ簡単な方法は、曲がりを確かめることです。図の「曲がりを確かめ、一歩を縮める」は、$f''\le0.1$ なら $-f'$ の向き（勾配降下法と同じ向き）に切り替えます。そのうえで、関数の値が十分に下がるまで一歩を半分にします。始点0.3からは1回目に $x=0.573$ へ進み、5回で谷 $x=1$ に着きます。

## 向く条件・避ける条件

Newton法の一手には、ヘッセ行列を作る費用と、連立一次方程式を解く費用がかかります。変数が $n$ 個なら、ヘッセ行列は $n^2$ 個の数で、密な行列の分解には $n^3$ に比例する計算がかかります。

向く条件です。

- 勾配とヘッセ行列を、解析式や自動微分で正しく計算できる（[滑らかな無制約の最小化](#/formulations/PA006)）
- 解の近くでヘッセ行列が正定値で、解の近くから始められる、または直線探索・信頼領域と組み合わせる
- 変数の数が数百から数千程度までで、ヘッセ行列の分解を毎回できる
- 高い精度の答えが必要で、最後の数桁を少ない反復で詰めたい

避ける、または別の方法と比べる条件です。

- 変数が非常に多く、ヘッセ行列を作れない（[大規模な無制約の最小化](#/formulations/PA007)） → [Newton-CG](#/learn/newton-cg)、[L-BFGS](#/learn/lbfgs)
- ヘッセ行列を計算する手段がない → [BFGS](#/learn/bfgs)
- 目的関数にノイズや不連続がある → 放物線を当てる前提が成り立ちません

## Python

次の例は、小さな例の関数で素のNewton法を6回進め、正しい桁数を表示します。続けて、SciPyの `minimize` のNewton-CGを始点2と0.3から実行します。

```python
import numpy as np
from scipy.optimize import minimize


def f(x: np.ndarray) -> float:
    return x[0] ** 4 / 4 - x[0] ** 2 / 2


def grad(x: np.ndarray) -> np.ndarray:
    return np.array([x[0] ** 3 - x[0]])


def hess(x: np.ndarray) -> np.ndarray:
    return np.array([[3 * x[0] ** 2 - 1]])


x = np.array([2.0])
for k in range(1, 7):
    x = x - np.linalg.solve(hess(x), grad(x))
    print(k, f"{x[0]:.10f}", f"{-np.log10(abs(x[0] - 1)):.1f}")
# 1 1.4545454545 0.3
# 2 1.1510467894 0.8
# 3 1.0253259290 1.6
# 4 1.0009084519 3.0
# 5 1.0000012353 5.9
# 6 1.0000000000 11.6

for x0 in [2.0, 0.3]:
    result = minimize(f, [x0], jac=grad, hess=hess, method="Newton-CG")
    print(x0, result.x.round(6), result.nit, result.success)
# 2.0 [1.] 6 True
# 0.3 [1.] 5 True
```

前半の出力の3列目が正しい桁数で、小さな例の表と同じく倍々に増えます。
後半では、SciPyのNewton-CGが始点0.3からも谷 $x=1$ に着いています。素のNewton法は山 $x=0$ へ向かいました。ライブラリの実装は、曲がりが負の向きに出会うと勾配の向きを使います。さらに直線探索で一歩を調整するので、この例では谷に着きます。

## 診断値

- **勾配のノルム**: 0に近づいていれば、停留点に近づいています。底の近くでは、反復ごとにほぼ2乗で小さくなります。
- **ヘッセ行列の最小固有値**（1変数では $f''$）: 正なら、今いる点の放物線は上に開いています。負なら、素の一歩は山や鞍点へ向かいます。
- **一手の長さ**: 急に長くなったら、最小固有値が0に近い（ほとんど平ら）合図です。始点0.6の一歩4.8がその例です。
- **関数値の変化**: 一歩で値が上がったら、その一歩はそのまま受け入れず、縮めるか向きを変えます。

二次収束は、底の近くでヘッセ行列が正定値のときの性質です。速く収束したことは、見つけた点が全体の最小点であることを示しません。

## 失敗・切替の兆候

- 関数の値が上がり、ヘッセ行列に負の固有値がある → 放物線の頂点が山や鞍点 → 曲がりを確かめて向きを切り替えるか、[信頼領域Newton-CG法](#/learn/trust-region-newton-cg)へ
- 一手が急に巨大になる → ヘッセ行列がほぼ特異で、頂点が遠い → 直線探索で一歩を縮めるか、信頼領域で一歩の上限を決める
- ヘッセ行列の分解に時間やメモリがかかりすぎる → 変数が多すぎる → [Newton-CG](#/learn/newton-cg)、[L-BFGS](#/learn/lbfgs)
- 二次収束しない（桁が倍々に増えない） → ヘッセ行列や勾配の実装の誤り、または解でヘッセ行列が特異 → 有限差分と比べて微分を確かめる

## 困りごとから関連する手法へ

- ヘッセ行列を計算できない、または計算したくない → [BFGS](#/learn/bfgs)：勾配の変化からヘッセ行列を近似します
- 変数が多すぎてヘッセ行列を作れない → [Newton-CG](#/learn/newton-cg)：ヘッセ行列とベクトルの積だけで一手を求めます
- 曲がりが負の場所や平らな場所を通る → [信頼領域Newton-CG法](#/learn/trust-region-newton-cg)：放物線を信用できる範囲の中だけで一手を決めます
- そもそも傾きだけで足りるか比べたい → [勾配降下法](#/learn/method.gradient-descent)：一手は安いが、底の近くでは一定の割合でしか誤差が縮まりません
