上下限内に複数の谷や良い候補があるとき、複数の初期点を使う探索、領域分割、焼きなまし、集団探索を選び分ける入口です。

## 30秒でつかむ

この手法群の気持ちは、**一つの初期点から素直に下るだけでは見逃す谷があるので、探索領域を分ける、飛び移る、複数候補を同時に育てることで広く探すこと**です。

- 見ているもの: それまでの最良値、探索範囲の広がり、集団の多様性、局所探索の成功
- 動かすもの: 初期点、矩形、温度、集団、探索分布
- 前進の判断: 新しい谷の発見と暫定解改善
- 主な弱点: 評価予算、次元の呪い、有限時間での証明不足

「大域」という名前があっても、有限評価予算で大域最適性を証明するとは限りません。決定論的、確率的、理論保証、実装上の停止条件を分けて読みます。

## まず確認すること

| 確認項目 | 選択への影響 |
|---|---|
| 上下限 | 探索領域が有限か、十分狭く設定できるか |
| 次元 | 領域分割や集団評価が現実的か |
| 1評価の費用 | 数百〜数万評価を許容できるか |
| 並列性 | 集団や複数の初期点を使う探索を同時評価できるか |
| 目的関数の性質 | 滑らか、不連続、ノイズあり、多峰性 |
| 必要な保証 | 良い候補か、下界を伴う証明か |

構造を使える凸問題、グラフ問題、MILPをブラックボックスの大域探索へ隠さないでください。専用構造を使う方が強い保証と診断を得られます。

## 条件付きの選び分け

| 役割 | 手法 | 優先しやすい条件 | 切り替えを考える条件 |
|---|---|---|---|
| 複数局所探索の基準 | [Multi-start](#/methods/M_MULTI_START) | 局所法が安価で、谷差を初期点で確認したい | 初期点数だけ増え、探索範囲の広がりが偏る |
| 局所法と確率的ジャンプ | [Basin Hopping](#/methods/M_BASIN_HOPPING) | 低次元、局所最適化が有効、谷間移動を試したい | 局所求解が評価予算を支配する |
| 決定論的な領域分割 | [DIRECT](#/learn/direct-global) | 低次元上下限付きの、Lipschitz定数を明示したくない | 矩形の数が急増、高次元 |
| 位相構造を使う候補生成 | [SHGO](#/learn/shgo) | 低次元、比較的滑らか、決定論的候補が欲しい | サンプル点からなる複体が大きくなりすぎる |
| 温度で悪化ステップも許す | [Dual Annealing](#/learn/dual-annealing) | 多峰性、連続上下限、確率的探索を許容 | 温度の低下や乱数シードで結果が不安定 |
| 差分で集団を更新 | [Differential Evolution](#/learn/differential-evolution) | 並列評価可能、非滑らか・多峰性 | 一評価が高価、次元×集団の大きさが重い |
| 分布の形を学ぶ | [CMA-ES](#/learn/cma-es) | 連続、変数相関が強い、中程度の次元 | 極端な高次元、非常に少ない評価予算 |
| 柔軟な符号化 | [Genetic Algorithm](#/learn/genetic-algorithm) | 離散・混合符号化や独自操作が必要 | 符号化が意味を壊し、パラメータ調整が支配的 |

有限評価予算で証明が必要なら、凸問題の大域最適化、空間分枝限定法、問題固有界を持つ手法を別に検討します。

## うまくいったサインと切替サイン

追うべき値:

- それまでの最良値と改善間隔
- 目的関数の評価数
- 集団の多様性または探索範囲の広がり
- 谷ごとの到達頻度
- 複数乱数シードの分布
- 実行可能な候補の割合
- 局所的な改良成功率

切替サイン:

- 多様性が早期に消える → 再始動、突然変異、別集団法
- 最良値が改善しないまま評価予算を消費 → 探索範囲の上下限、構造、代理モデルを見直す
- 同じ谷ばかり再訪 → 初期化と探索範囲の広がり方針を変更
- 評価が高価すぎる → ベイズ最適化や複数の忠実度を使う手法へ
- 低次元で決定論的再現性が欲しい → DIRECTやSHGOを検討
- 局所解で十分と分かった → 滑らかな局所最適化または局所的な微分不要最適化へ戻す

## コラム: 大域性には複数の意味がある

大域探索という言葉は、少なくとも次を区別します。

1. 複数谷を探すヒューリスティクス
2. 評価予算を増やすと広く探索する漸近的性質
3. 下界と上界を詰める証明
4. 特定仮定下での理論保証

画面上で広く点が動いていることは、3番の証明ではありません。Optimization Compassでは、大域探索の候補と大域最適性の証明を別の到達点として扱います。
