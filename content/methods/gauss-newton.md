非線形最小二乗の残差ヤコビ行列から曲率近似を作り、一般目的関数として扱わず残差構造を直接利用する局所法です。

## 30秒でつかむ

複数の観測点で、モデルの予測が観測とずれています。ずれの合計だけを見るのではなく、観測ごとのずれを並べて見ます。
パラメータを少し動かすと、各観測のずれがどれだけ動くかが分かります。その動きを使い、線形化した残差の二乗和を小さくする向きを、一度の線形の計算で決めます。これがGauss–Newton法です。

- **見るもの**: 残差ベクトル（観測ごとのずれ）とヤコビ行列
- **動かすもの**: パラメータ。一手は、線形化した最小二乗問題の解で決める
- **前進の判断**: 二乗和の変化、残差の分布、最適性の量 $J^\top r$ を分けて診断する。各残差や勾配ノルムの単調減少までは要求しない

一般のNewton法は、ヘッセ行列をそのまま使います。Gauss–Newton法は、目的が残差の二乗和であることを利用して、ヘッセ行列の一部だけを近似します。

「一手の決め方」が Gauss–Newton法 のまま、「始点」を「遠い始点 (1, 0.1)」にして、「1つ進む」を2回押してください。「一手に沿った費用」で、青緑の放物線（線形モデルの予測）と橙の曲線（本当の費用）が、どこで離れるかを見ます。

::: explorable gauss-newton-lm-steps
「観測点と曲線」の実線が現在の曲線で、「パラメータ平面と一手の道すじ」の橙の矢印がその試行の一手、細い破線の矢印が最急降下の向きです。「一手に沿った費用」は、現在点から一手の方向へ割合 s だけ進んだときの、線形モデルの予測（青緑）と本当の費用（橙）で、s=1 が一手の先です。「予測した減少と実際の減少」の棒は試行ごとの比較です。5点・2パラメータの教材用の計算で、ほかのモデルで線形化がどこまで当たるかは示しません。
:::

確かめてほしいことは三つあります。

1. 1回目の「1つ進む」で、費用は $11.25$ から $2.870$ に下がります。「一手に沿った費用」では、s=1 で予測 $0.2165$ に対して本当の費用が $2.870$ と、すでに少し離れています。それでも橙は下がり続けるので、一手は受け入れてよい長さです。
2. 2回目では、青緑の放物線は s=1 で $0.2816$ まで下がるのに、橙は s=0.55 あたりで $0.028$ の底を過ぎてから急に上がり、s=1 で $29.32$ になります。「予測した減少と実際の減少」の橙の棒は下向きに端で切れ、$\rho=-10.2$ です。Gauss–Newton法は結果を見ずに受け入れるので、$k$ は $-0.03$ まで飛びます。一手の0.55倍で止めていれば、費用は $0.028$ でした。
3. 「始点」を「近い始点 (5, 0.3)」に替えて「最後まで進める」を押すと、費用は $1.369\to0.0545\to0.00427\to0.00408$ と下がります。どの試行も $\rho$ は $0.98$ から $1.01$ で、橙と青緑は s=1 までほぼ重なります。同じ手続きでも、線形化が当たる距離にいるかどうかで結果が分かれます。

では、青緑の放物線はどんな式で作られていて、どこまでを信じてよいのでしょうか。次の節で、その式を読みます。

## 一手の意味

残差 $r(x)$ を現在点の近くで線形化します。次の式は、パラメータを $p$ だけ動かしたときの残差を、ヤコビ行列で見積もるものです。

$$
r(x+p) \approx r(x) + J(x)p
$$

この見積もりの二乗和を最小にする $p$ が、一手です。線形最小二乗問題 $\min_p\|r+Jp\|^2$ の最適性条件は、次の正規方程式です。実装で必ず正規方程式を組み立てるという意味ではありません。

$$
J^T J\, p = -J^T r
$$

Newton法との関係を見ます。二乗和 $\tfrac12\|r\|^2$ の勾配は $J^T r$ で、ヘッセ行列は $J^T J$ に、残差と二階微分の項を足したものです。Gauss–Newton法は、その足す項を落とします。
省いた項は $\sum_i r_i(x)\nabla^2r_i(x)$ です。残差が小さく、残差の二階微分も過大でなければ小さくなります。「残差が小さい」という観測だけで、どんなモデルのどんな点でもよい曲率近似になるとは限りません。線形残差なら二階微分はゼロなので、この省略は厳密です。

$J$ が列フルランクなら、2-ノルム条件数は $\kappa_2(J^TJ)=\kappa_2(J)^2$ です。正規方程式を直接組み立てると、丸め誤差に弱くなり得ます。実装では、QR分解や特異値分解（SVD）を使います。疎な線形代数や信頼領域を使う実装もあります。

## 小さな例

[非線形最小二乗](#/learn/concept.nonlinear-least-squares)で学ぶ残差モデルの、別の具体例として指数減衰を当てはめます。この指数モデルは、次の[Levenberg–Marquardt法](#/learn/least-squares)でも使います。
時刻 $t=0,1,2,3,4$ で量 $y=5.1,\,3.0,\,1.9,\,1.1,\,0.7$ を観測しました。
モデル $y=a\,e^{-kt}$ の $(a,\,k)$ を求めます。初期値は $(a,k)=(1,\,0.1)$ とします。

初期値での残差 $r_i=a\,e^{-kt_i}-y_i$ とヤコビ行列です。

| $t_i$ | 残差 $r_i$ | $\partial r_i/\partial a$ | $\partial r_i/\partial k$ |
|---:|---:|---:|---:|
| 0 | −4.100 | 1.000 | 0.000 |
| 1 | −2.095 | 0.905 | −0.905 |
| 2 | −1.081 | 0.819 | −1.637 |
| 3 | −0.359 | 0.741 | −2.222 |
| 4 | −0.030 | 0.670 | −2.681 |

ここから $J^T J$ と $J^T r$ を作ります。

$$
J^T J\approx\begin{pmatrix}3.487&-5.603\\-5.603&15.629\end{pmatrix},\qquad J^T r\approx\begin{pmatrix}-7.167\\4.544\end{pmatrix}
$$

$J^T J\,p=-J^T r$ を解くと、一手は $p\approx(3.746,\,1.052)$ です。これを何回か繰り返します。

| 反復 | $a$ | $k$ | 目的値 $\tfrac12\sum r_i^2$ | 次の一手 $(\Delta a,\,\Delta k)$ |
|---:|---:|---:|---:|---|
| 0 | 1.000 | 0.100 | 11.25 | $(3.746,\ 1.052)$ |
| 1 | 4.746 | 1.152 | 2.870 | $(0.287,\ -1.177)$ |
| 2 | 5.033 | −0.025 | 29.32 | $(-0.609,\ 0.211)$ |
| 3 | 4.424 | 0.186 | 3.119 | $(0.470,\ 0.220)$ |
| 4 | 4.894 | 0.407 | 0.1854 | $(0.171,\ 0.088)$ |
| 5 | 5.065 | 0.495 | 0.005745 | $(0.013,\ 0.010)$ |
| 6 | 5.078 | 0.505 | 0.004082 | ほぼ $0$ |

最終的に $(a,k)\approx(5.0787,\,0.5049)$ に着きます。ただし、途中の反復2で目的値が $2.87$ から $29.3$ へ跳ね上がっています。
反復1の点で決めた一手は、$k$ を $1.15$ から $-0.03$ まで大きく動かします。線形化した残差が信じられるのは、現在点の近く、つまり短い一手までです。指数関数の曲がりを無視した一手は、そこまでは通用しません。

この例では、解に近い初期値から同じ手続きが素直に収束しました。初期値 $(5,\,0.3)$ の目的値は、次のように3回の更新で下がりきります。

$$
1.369 \to 0.0545 \to 0.00427 \to 0.00408
$$

一手が長すぎる問題への対策が、次に読む[非線形最小二乗とLevenberg–Marquardt法](#/learn/least-squares)の減衰項です。

### 二乗和になる前の、五つの予想を比べる

反復1の点 $(a,k)\approx(4.745921,1.152219)$ に戻ります。ここで線形最小二乗が提案する一手は $(0.287136,-1.177488)$ です。

この点は、「30秒でつかむ」の操作図の試行2の出発点です。その「一手に沿った費用」は、この表の五つの残差の二乗和の半分を、一手の途中の割合 s ごとに描いたものです。

青緑は $r+Jp$ から作る予測で、橙は $r(x+p)$ から作る本当の費用です。時刻0では残差は振幅 $a$ に線形なので一致します。時刻が進むと指数の曲がりが効き、二つが大きく離れます。

| 時刻 | 線形化の予想 $r+Jp$ | 本当の残差 $r(x+p)$ |
|---:|---:|---:|
| 0 | −0.066942 | −0.066942 |
| 1 | 0.355647 | 2.161859 |
| 2 | −0.282042 | 3.393956 |
| 3 | −0.412605 | 4.329434 |
| 4 | −0.427152 | 4.868379 |

この点の費用は約 $2.870319$。線形化では約 $0.281608$ まで下がると予想しますが、実際には約 $29.321084$ です。「線形最小二乗の計算を正確に解けた」と「その一歩の予想が本当の非線形モデルに合う」は別です。

減衰や信頼領域では、一手を短くするだけでなく、この予測と実測の食い違いを判定材料にします。計算後にパラメータ $k$ を勝手にclipするなら別の更新です。$k\ge0$ が物理的に必要な制約なら、初めから上下限として対応ソルバーへ渡します。

### 残差の符号を変えても、一手は変わらない

本記事は $r=\text{予測}-\text{観測}$ としています。逆向きに定義するなら $\tilde r=-r$ と同時に $\tilde J=-J$ とします。すると $\tilde J^\top\tilde r=J^\top r$、$\tilde J^\top\tilde J=J^\top J$ なので一手は同じです。

残差だけ符号を変えてJacobi行列をそのままにすると、右辺の向きが反転してしまいます。残差と微分は一組で定義し、方向差分 $(r(x+\epsilon v)-r(x-\epsilon v))/(2\epsilon)$ と $Jv$ を照合します。差分幅を一つだけに固定せず、丸め誤差と打切り誤差も見ます。

## 向く条件・避ける条件

先に、次の項目を確認します。

| 項目 | 確認内容 |
|---|---|
| 定式化 | 目的が、本当に残差の二乗和として意味を持つか |
| 残差 | 観測ごとの残差を返せるか |
| ヤコビ行列 | 正確に、または安定に計算できるか |
| 重み | 単位やノイズの分散に応じた重みが必要か |
| 識別可能性 | パラメータがデータから区別できるか |
| 制約 | 上下限や一般制約をどう扱うか |

線形最小二乗なら、反復法より先にQR分解やSVDを検討します（[線形最小二乗](#/learn/concept.linear-least-squares)）。
外れ値がある場合は、頑健な損失の意味を明示します。

向く条件です。

- 曲線の当てはめ、パラメータ推定、バンドル調整などの非線形最小二乗である（[非線形最小二乗](#/learn/concept.nonlinear-least-squares)）
- 残差のヤコビ行列を利用できる
- 解の近くで残差が小さい、またはモデルがよく合う
- 観測ごとの残差を診断したい

避ける、または切り替える条件です。

- 一般目的関数を、無理に一つの残差へ置き換えている → [滑らかな無制約の最小化](#/formulations/PA006)として[BFGS](#/learn/bfgs)などを検討する
- 一手が大きく振動する、初期値が遠い → 減衰や信頼領域のある[Levenberg–Marquardt法](#/learn/least-squares)へ切り替える
- 上下限が本質である → [Trust Region Reflective](#/learn/trust-region-reflective)
- 不連続、離散変数、強い外れ値を未処理のまま扱っている
- ヤコビ行列のランクが低く、この点の線形化ではパラメータの効果を区別できない方向がある
- 大域最適性の証明が必要である

## Python

次の例は、上の小さな例と同じ問題を、Gauss–Newton法で解く最小の実装です。一手は、線形最小二乗の求解関数 `lstsq` で求めます。

```python
import numpy as np

t = np.array([0.0, 1.0, 2.0, 3.0, 4.0])
y = np.array([5.1, 3.0, 1.9, 1.1, 0.7])


def residuals(p: np.ndarray) -> np.ndarray:
    a, k = p
    return a * np.exp(-k * t) - y


def jacobian(p: np.ndarray) -> np.ndarray:
    a, k = p
    e = np.exp(-k * t)
    return np.column_stack([e, -a * t * e])


def gauss_newton(p: np.ndarray, iterations: int = 8) -> tuple[np.ndarray, list[float]]:
    costs = [0.5 * float(np.sum(residuals(p) ** 2))]
    for _ in range(iterations):
        step, *_ = np.linalg.lstsq(jacobian(p), -residuals(p), rcond=None)
        p = p + step
        costs.append(0.5 * float(np.sum(residuals(p) ** 2)))
    return p, costs


for start in ([1.0, 0.1], [5.0, 0.3]):
    p, costs = gauss_newton(np.array(start))
    print(start, np.round(p, 4), [f"{c:.4g}" for c in costs[:5]])
# [1.0, 0.1] [5.0787 0.5049] ['11.25', '2.87', '29.32', '3.119', '0.1854']
# [5.0, 0.3] [5.0787 0.5049] ['1.369', '0.05453', '0.004266', '0.004082', '0.004082']
```

出力は、最終のパラメータと、最初の5回の目的値です。
二つの初期値は同じ答えに着きますが、遠い初期値では、目的値が途中で増えています。この実装には安全策がないので、実用では減衰や信頼領域を加えます。

## 診断値

残差を一つのノルムにまとめるだけでなく、観測ごとの偏りとパラメータの安定性を分けて確認します。

- 残差のノルムと、観測ごとの残差のパターン
- ヤコビ行列のランクと特異値
- 一手のノルム
- 勾配に相当する $J^T r$
- 信頼半径、または減衰の大きさ
- 初期値ごとのパラメータの差

## 失敗・切替の兆候

- 一手が大きく振動する、または目的値が増える → 線形化が長い一手では通用しない → Levenberg–Marquardt法や信頼領域法へ切り替える
- ランク不足がある → この点の線形化では、パラメータの効果を区別できない方向がある → パラメータ化、正則化、固定するパラメータを見直す
- 一部の観測だけ残差が大きい → モデルの不一致、外れ値、重みの問題がある → それぞれを確認する
- 二乗和は小さいのにパラメータが不安定 → 識別可能性、尺度、停止精度、局所解の違いを確認し、データや実験設計を見直す
- 制約が本質である → 上下限や一般制約を扱えない → 制約つきの最小二乗の手法、または一般の非線形計画へ切り替える

## コラム: 最小二乗の局所性を見落とさない

残差の二乗和が下がっても、モデルの識別性や観測の偏りまで解決したとは限りません。残差のパターンとパラメータの安定性を分けて確認します。

### 残差ベクトルと二乗和を分けて見る

[各残差を確認する実行記録](#/traces/root-finding-component-tolerance)と[二乗残差だけで止める実行記録](#/traces/root-finding-small-squared-residual)は、同じ固定問題を使います。
変えるのは、停止規則だけです。
[残差の比較](#/compare/COMPARE_ROOT_FINDING_COMPONENT_TOLERANCE)では、二乗和が小さくても、一つの成分が要求精度を満たさない状態を確認します。

これは、`root solver` と `least-squares solver` の性能比較ではありません。
Gauss–Newton法の実装、ヤコビ行列の近似、収束速度も順位付けしません。
残差の尺度と成分別の許容値を、終了判定へ残すための対比です。
