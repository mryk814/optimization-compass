COBYQAは、関数値と制約値から二次近似モデルを作る、微分不要の局所最適化法です。二次モデルには傾きだけでなく曲がり方の情報が入ります。最良値が改善しない評価にも、**次の候補を選ぶモデルを育てる役目**があります。

## 30秒でつかむ

[COBYLA](#/learn/cobyla)が局所線形モデルを使うのに対し、COBYQAは二次モデルを用いる信頼領域型の手法です。値からモデルを作り、候補を本物の関数で評価して更新を続けます。

- 見るもの：目的・制約の値と補間点の配置
- 更新するもの：二次モデル、補間集合、信頼領域、候補点
- 分けて確認するもの：最良値の改善と、モデルのための評価

二次式を使えば元の関数が常に正確に分かる、という意味ではありません。まず、二次式であることが分かっている小問題で、評価から得られる情報を確かめます。

## 同じ5点で傾きと曲率を読む

$$
f(x)=(x_1-1)^2+2(x_2+0.5)^2,
\qquad -2\le x_1,x_2\le2,\quad x_1+x_2\ge0.
$$

初期点は $(0.5,0.5)$ です。SciPy 1.17.0のCOBYQAを実行すると、目的関数の最初の5評価は次の順でした。これはcallbackではなく、実際の関数呼び出しを記録した表です。

| 評価 | 点 | 目的値 | その時点の最良値 |
|---|---|---:|---:|
| 1 | $(0.5,0.5)$ | 2.25 | 2.25 |
| 2 | $(1.5,0.5)$ | 2.25 | 2.25 |
| 3 | $(0.5,1.5)$ | 8.25 | 2.25 |
| 4 | $(-0.5,0.5)$ | 4.25 | 2.25 |
| 5 | $(0.5,-0.5)$ | 0.25 | 0.25 |

2〜4回目は最良値を更新しません。それでも中心の両側を測ると曲率を計算できます。$s=x-(0.5,0.5)$ と置き、説明用に交差項を持たない二次式

$$
m(s)=a+b_1s_1+b_2s_2+d_1s_1^2+d_2s_2^2
$$

を5点へ補間すると、

$$
m(s)=2.25-s_1+4s_2+s_1^2+2s_2^2
$$

が得られます。たとえば $s_1=\pm1$ の2点から

$$
b_1=\frac{2.25-4.25}{2}=-1,\qquad
d_1=\frac{2.25+4.25-2\times2.25}{2}=1
$$

です。「右側は中心と同じ値、左側は悪い」だけではなく、中央付近に下がってから上がる形を表せました。

![左は同一問題の最初の5評価点。中央はx2を0.5に固定した断面で線形部分と二次モデルを比較。右は全24評価の値と累積最良値。](./media/cobyqa-interpolation.svg "同じ問題の評価点、二次モデルの断面、全24評価を並べています。中央は第2変数を0.5に固定した断面です。")

中央の緑線は $x_2=0.5$ の断面です。この断面では二次モデルの最小は $s_1=0.5$ にあります。傾きだけの赤い直線は、右へ進むほどよいと予測し続けます。二次項が「進みすぎると上がる」を表しています。

## 5点で一般の二次式を決められるわけではない

2変数の一般の二次式には交差項 $s_1s_2$ もあり、係数は6個です。今回の5点はすべて $s_1s_2=0$ なので、$m(s)+\alpha s_1s_2$ はどの $\alpha$ でも同じ5点を通ります。この5点だけでは変数間の曲がり方を特定できません。

ここでは元の関数が交差項のない二次式なので、説明用モデルと真の関数が一致します。追加の点 $(0.75,-0.25)$ でも、予測と実値はともに0.1875でした。一般のブラックボックスで同じ精度が得られるという主張ではありません。

[COBYQAの公式説明](https://www.cobyqa.com/stable/)では、実際のアルゴリズムは不足決定の補間に基づく二次モデルを使う、微分不要の信頼領域SQP法とされています。上の5係数の連立方程式は、取得した評価から何が分かるかを示す教材です。内部の補間モデルやSQP小問題をそのまま取り出したものではありません。

## 信頼領域は何のためにあるか

一般形は

$$
m_k(s)=f(x_k)+g_k^\top s+\tfrac12 s^\top H_k s
$$

です。$g_k,H_k$ は値から作られます。モデルの曲面だけを際限なく下ると、測った範囲から離れて予測が外れるため、信頼領域で移動範囲を管理します。実際の改善と予測の一致、制約違反、補間点の配置を踏まえて探索を進めます。

半径を小さくしても、補間点がほぼ一直線に並ぶなど配置が悪ければ、全方向の曲率は分かりません。モデルの改善には、直接最良値を下げない評価も必要になり得ます。逆に、どんな非改善評価も有益だったと正当化せず、その費用と改善を追います。

## SciPyで同じ問題を解く

```python
import numpy as np
from scipy.optimize import Bounds, LinearConstraint, minimize

history = []


def objective(x):
    value = float((x[0] - 1)**2 + 2 * (x[1] + 0.5)**2)
    history.append((x.copy(), value))
    return value


result = minimize(
    objective, [0.5, 0.5], method="COBYQA",
    bounds=Bounds([-2, -2], [2, 2]),
    constraints=[LinearConstraint([[1, 1]], [0], [np.inf])],
    options={"initial_tr_radius": 1.0, "final_tr_radius": 1e-6,
             "feasibility_tol": 1e-8, "maxfev": 1000,
             "maxiter": 2000, "scale": False},
)
print(result.success, result.x, result.fun, result.nfev, result.maxcv)
# True [ 1.  -0.5] 9.841039792632122e-29 24 0.0
print(history[:5])
```

SciPy 1.17.0、NumPy 2.3.5で実行しました。第6評価はほぼ $(1,-0.5)$ となり、目的値は約 $9.84\times10^{-29}$、終了時の目的関数評価数は24、反復数は28でした。評価数と反復数は同じではありません。

解析的にも、二乗和は非負で $(1,-0.5)$ で0、上下限と線形制約も満たします。今回の解はこの別の検算と整合します。第6評価へ至る内部モデルや半径の履歴は取得していないため、上の簡略モデルがその一歩を完全再現したとは述べません。

## 上下限と一般制約を分ける

公式説明は、COBYQAが評価中も上下限を守ることを明記しています。この性質を非線形制約まで常に満たす保証へ広げないでください。本例では全評価が上下限と線形制約を満たすことを検査しましたが、それはこの実行の結果です。

[SciPyのCOBYQAオプション説明](https://docs.scipy.org/doc/scipy/reference/optimize.minimize-cobyqa.html)では、評価上限は`maxfev`、反復上限は`maxiter`です。変数を有限の上下限に基づいて尺度合わせする`scale`もあります。本ページの実行版は1.17.0で、参照先の最新文書と版を区別しています。`initial_tr_radius`と`final_tr_radius`の値は、変数の単位と合わせて設定します。

## 向く条件と診断

比較的滑らかで、微分を用意できない低〜中次元の連続問題が候補です。強い雑音や不連続では、値から作る二次モデルが不安定になり得ます。モデルを維持する評価予算も必要です。

- 最良値が動かない：新しい評価位置と累積評価数を見ます。callbackの繰り返しだけでは判断しません。
- 半径が縮み続ける：雑音、尺度、モデルと実評価のずれを調べます。
- 制約違反が残る：目的値と最大違反を別々に見ます。
- 初期点依存が強い：複数初期点や大域探索を比較します。
- 正確な勾配がある：SLSQPや内点法を含め、同じ評価費用で比較します。

少ない評価でこの二次関数を解けても、一般の問題での速さや大域最適性は保証しません。[局所微分不要最適化の選び分け](#/learn/family.local-dfo)では、制約、雑音、評価予算から別の方法も検討できます。
