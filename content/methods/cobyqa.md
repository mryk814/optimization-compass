関数値と制約値から局所的な二次近似モデルを育て、微分なしでboundsや一般制約を扱う信頼領域型の局所法です。

## 30秒でつかむ

平らに見える道でも、数か所測ると曲がり方が分かる感覚です。
複数点の値から目的関数と制約を二次近似し、信用できる範囲で次の点を選びます。

- 見るもの: 関数値、制約値、補間点の配置
- 動かすもの: 二次モデル、補間集合、信頼領域の半径、候補点
- 前進の判断: モデル予測と実評価の一致、可行性と目的値の改善
- 恐れていること: 補間配置の退化、悪い尺度合わせ、評価予算不足

COBYLAが局所線形近似を使うのに対し、COBYQAは二次近似を使う系統です。ただし実装設定や対応制約は必ず公式文書で確認します。

## 一手の意味

勾配と曲率を、評価点から得た $g_k,H_k$ で近似します。

$$
m_k(s)=f(x_k)+g_k^\top s+\tfrac12 s^\top H_k s.
$$

一般制約にも近似を作り、信頼領域の中で候補を求めます。

補間点で得た値から、目的関数と制約の局所モデルを作ります。候補一歩は信頼領域内でモデルを改善するよう選び、実評価後にモデルと半径を更新します。

重要なのは、二次式を使うこと自体より、**どの範囲でその近似を信頼するか**です。候補が予測どおり改善すれば半径を維持・拡大し、外れれば縮小します。補間点の配置が悪ければ配置改善用の評価も必要になります。

## 小さな例

Python例は $f(x)=(x_1-1)^2+2(x_2+0.5)^2$ を最小にします。
上下限は各変数 $[-2,2]$、一般制約は $x_1+x_2\ge0$ です。
初期点から最初の3回のコールバックを記録しました。

| 記録 | 記録された最良点 | 目的値 |
|---|---|---:|
| 1回目 | $(0.5000,0.5000)$ | 2.2500 |
| 2回目 | $(0.5000,0.5000)$ | 2.2500 |
| 3回目 | $(0.5000,0.5000)$ | 2.2500 |

初期の記録に改善がなくても、補間点の評価は近似を作るために使われます。
終了点は約 $(1.0000,-0.5000)$ でした。
目的値は約 $1.06\times10^{-28}$、制約値は約0.5です。

## 向く条件・避ける条件

### まず確認すること

| 項目 | 確認内容 |
|---|---|
| 次元 | 補間点を維持できる低〜中次元か |
| 評価 | モデルを作り直すだけの予算があるか |
| 制約 | 上下限、線形、滑らかな非線形制約のどれか |
| 雑音 | 二次モデルを壊すほど値が揺れないか |
| 尺度合わせ | 変数と制約の単位が揃っているか |
| 保証 | 局所候補でよいか、大域証明が必要か |

正確な勾配とJacobianを用意できるならSLSQPやinterior-点も比較します。一評価が極端に高価なら代理モデルに基づく 大域探索との予算比較が必要です。

### 向く条件・避ける条件

向きやすい条件:

- 微分を得られない低〜中次元連続問題
- 上下限や一般制約がある
- 比較的滑らかで局所二次モデルが役立つ
- Nelder–Meadより制約とモデル診断を重視したい

避ける条件:

- 強い雑音、不連続、頻繁な評価失敗
- 高次元で補間点数が予算を圧迫
- 離散・カテゴリ変数
- 大域最適性証明が必要

## Python

```python
import numpy as np
from scipy.optimize import Bounds, LinearConstraint, minimize


def objective(x: np.ndarray) -> float:
    return float((x[0] - 1.0) ** 2 + 2.0 * (x[1] + 0.5) ** 2)


bounds = Bounds([-2.0, -2.0], [2.0, 2.0])
constraint = LinearConstraint([[1.0, 1.0]], lb=[0.0], ub=[np.inf])
result = minimize(
    objective,
    x0=np.array([0.5, 0.5]),
    method="COBYQA",
    bounds=bounds,
    constraints=[constraint],
)
print(result.success, result.x, result.fun, result.message)
```

API対応は利用するSciPy 版で確認してください。上の例は手法とモデルの関係を示す最小形です。

## 診断値

目的値と制約違反を別々に記録します。
近似の予測改善と実際の改善、補間点の配置、信頼領域の半径を対応付けます。
半径だけが縮む場合は、雑音や尺度合わせを点検します。

## 失敗・切替の兆候

### うまくいったサインと切替サイン

見る値:

- 信頼領域の半径
- 実際の / 予測した 改善
- 制約違反
- 補間点の配置
- モデルの再構築回数
- 目的関数 / 制約評価数

切替サイン:

- 半径が縮み続ける → 雑音、尺度合わせ、モデルと実際のずれを確認
- 配置修復ばかりで進まない → 次元と予算を見直す
- 制約違反が減らない → 定式化、初期点、MADSや滑らかNLPを検討
- 評価雑音が支配的 → 繰り返し評価や雑音を考慮する手法へ
- 多峰性で初期点依存が強い → 大域探索またはmulti-startへ

### コラム: モデルに基づく DFOの評価はどこへ使われるか

すべての評価が直接最良点を改善するとは限りません。補間配置を整え、後続一歩のモデル精度を上げる評価にも価値があります。ただし教育用の小問題で有効でも、高価な実験でその追加費用が許されるとは限りません。
