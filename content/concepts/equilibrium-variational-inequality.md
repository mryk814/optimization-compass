ゲーム・均衡・変分不等式は、複数の主体がそれぞれ自分の目的を最適化した結果の釣り合い（均衡）を求める定式化です。誰も一人だけ決定を変えて得をしない点を、変分不等式という一つの条件にまとめて解きます。全員の目的の合計を最適にした答えとは、一般に一致しません。

## 30秒でつかむ

ある町で、3軒のパン屋A・B・Cが同じパンを売っています。3軒が毎朝焼く量の合計が増えるほど、パンの値段は下がります。値段は $10-(\text{3軒の量の合計})$ で、量の単位は百個です。1個あたりの費用（値段と同じ単位）は、Aが1・Bが2・Cが3です。Aのかまどは、2.5までしか焼けません。

どの店も、自分の利益が最も大きくなる量を選びたいと考えます。ところが、自分の最適な量は、ほかの2軒の量で変わります。そこで、どの店も一人だけ量を変えて得をしない組を探します。

- **決めるもの**: 3軒それぞれの1日の量 $q_A,\ q_B,\ q_C$
- **良くしたいもの**: 各店が、自分の利益を大きくすること（3軒の合計ではない）
- **守ること**: どの量も0以上、$q_A\le2.5$

次の図は、ほかの2軒を均衡の量に固定したときの自分の利益と、3つの決め方の量です。まず「① 自分の量ごとの利益」で、3つの点が曲線のどこにあるかを見てください。続いて「② 3つの決め方の量と値段」で、値段を比べてください。

![① ほかの2軒が均衡の量のとき、自分の量ごとの利益。均衡の量はA 2.50・B 2.17・C 1.17。BとCは利益の山の頂上、Aは上限2.5で止まる（Aの頂上2.83は上限の外で、破線）。② 3つの決め方の量と値段。均衡は値段4.17、上限を外して解き後で切ると4.50、3軒の利益の合計を最大にすると6.00。](./figures/equilibrium-bakery-profit.svg "パン屋の例：値段と費用は教材用の値で、実際の市場は示さない。各店は同時に量を決め、ほかの店の量を正しく見込んでいるとする")

1. 「① 自分の量ごとの利益」で、BとCの点は山の頂上にあります。どちらも一人だけ量を変えると、利益が減ります。
2. Aの山の頂上は2.83で、上限2.5の外です。Aはもっと焼きたいのですが、かまどの上限で止まっています。
3. 「② 3つの決め方の量と値段」で、3軒の利益の合計を最大にする決め方は値段が6.00で、均衡の4.17より高くなります。合計を最大にすると量を4に絞りますが、各店に任せるとそれぞれが量を増やすからです。

どの店も「山の頂上か、上限で止まっている」という条件を、1つの式で書けないでしょうか。

## 標準形を読む

次の式は「範囲 $X$ の中の点 $q^*$ で、$q^*$ から範囲の中のどこへ動いても、$F(q^*)$ との内積が負にならない点を探す」を表します。

$$
\text{find } q^*\in X \;\text{ s.t. }\; \langle F(q^*),\,q-q^*\rangle\ge 0 \quad \text{for all } q\in X
$$

$F(q^*)$ と動く向き $q-q^*$ の内積は、その向きへ少し動いたときの損の増え方です。式は「答えの点から範囲の中のどの向きへ動いても、損は減り始めない」と読みます。この形の問題を、変分不等式と呼びます。

| 記号 | 意味 | パン屋の例では |
|---|---|---|
| $q$ | 全員の決定を並べたもの | $(q_A,\ q_B,\ q_C)$ |
| $X$ | 決定がとれる範囲 | $0\le q_A\le2.5$、$q_B\ge0$、$q_C\ge0$ |
| $F(q)$ | 各主体の、自分の決定についての損の傾き | $F_i=q_i+(q_A+q_B+q_C)-(10-c_i)$。$c_i$ はその店の費用 |
| $q^*$ | 均衡 | $(2.5,\ 2.167,\ 1.167)$ |
| $F(q^*)$ | 均衡での傾き | $(-0.667,\ 0,\ 0)$ |

### なぜ、各店の傾きを並べるのか

店 $i$ の利益は $q_i\,(10-\text{合計}-c_i)$ です。自分の量 $q_i$ について微分して符号を変えると、$F_i$ になります。$F_i$ は、自分の量を少し増やしたときの利益の減り方です。

店 $i$ の利益は、自分の量について山が1つの形（$q_i^2$ の係数が負）です。そのため、店 $i$ が自分の範囲で利益を最大にしている条件は、「範囲の中で動ける向きに $F_i$ を掛けると0以上」と言い切れます。範囲が店ごとに分かれているので、3つの条件と、それらを足した式は同じです。足した式が標準形です（FacchineiとPangの教科書、S179）。

均衡では、$F(q^*)=(-0.667,\ 0,\ 0)$ です。BとCは範囲の内側にいて、傾きが0なので、山の頂上です。Aは $F_A<0$ なので、増やせば利益が増えます。ところが、Aが動ける向きは減らす向き（$q_A-2.5\le0$）だけです。$-0.667$ に0以下を掛けると0以上なので、条件を満たします。

### 合計を最適にする問題とは、傾きが違う

凸で微分できる関数 $f$ を範囲 $X$ で最小にする問題の答えは、$F=\nabla f$ とした変分不等式の答えと同じです（S055）。ところが、3軒の利益の合計を最大にする問題の傾きは、店 $i$ の成分が $F_i+(\text{ほかの2軒の量の合計})$ です。自分が量を増やすと、ほかの2軒の売値も下がります。合計の傾きはその分まで数えるので、均衡の $F$ とは違います。

この例の $F$ は、次の関数 $\Phi$ の勾配でもあります。値段が量の合計の一次式で、どの店の量にも同じ傾きで効くからです。

$$
\Phi(q)=\sum_i(c_i-10)\,q_i+\tfrac12\sum_iq_i^2+\tfrac12\Bigl(\sum_iq_i\Bigr)^2
$$

$\Phi$ は凸なので、均衡は $\Phi$ を範囲 $X$ で最小にする点でもあります。ヤコビ行列（$F$ の偏微分を並べた表）が対称でないときは、そのような関数はありません（S179）。

## 小さな例

設定は「30秒でつかむ」のパン屋です。まず手で解きます。Aが上限2.5にいると仮定すると、BとCの傾きが0になる式は $2q_B+q_C=5.5$、$q_B+2q_C=4.5$ です。解は $q_B=13/6\approx2.167$、$q_C=7/6\approx1.167$ です。このとき $F_A=2.5+5.833-9=-0.667<0$ なので、Aは上限から減らしても得をせず、仮定は正しいと分かります。

次に、同じ均衡を射影法で求めます。初期値は $q=(0,0,0)$ です。1回の更新は「$q$ から $0.25\,F(q)$ を引き、範囲 $X$ に戻す」です。1回に動く量が $10^{-6}$ 未満になったら止めます。乱数は使いません。

### パン屋の例・射影法の進み方

|---:|---:|---:|---:|---:|
| 1 | 2.250 | 2.000 | 1.750 | 0.583 |
| 2 | 2.438 | 2.000 | 1.563 | 0.396 |
| 3 | 2.500 | 2.000 | 1.422 | 0.255 |
| 10 | 2.500 | 2.139 | 1.195 | 0.028 |
| 20 | 2.500 | 2.165 | 1.168 | 0.0016 |
| 42 | 2.500 | 2.167 | 1.167 | $3\times10^{-6}$ |

1回目は、どの店も $F_i<0$ なので量を増やします。3回目にAが上限2.5に着き、そこからは範囲に戻す操作でAが2.5に留まります。残るBとCが、互いの量に合わせて少しずつ動き、42回で止まります。

2. 「② 歩幅 γ ごとの、均衡までの回数」の8つの歩幅では、0.4の25回が最も少なくなります。0.5で29回、0.55で57回と増えます。
3. 歩幅0.6では着きません。0と $(2.5,\ 4.8,\ 4.2)$ を往復し続けます。

## つまずきやすい点

- **3軒の利益の合計を最大にした量を、均衡と思う**: 合計を最大にすると $(2.5,\ 1.5,\ 0)$ で、利益の合計は18.5です。均衡の13.97より大きいのですが、$F=(-2.5,\ -2.5,\ -3)$ です。BもCも一人で増やすと得をするので、各店に任せるとこの量は守られません。均衡を知りたいなら、各店の傾きを並べた $F$ で解きます。
- **上限を外して解き、後で上限に切る**: 上限がなければ均衡は $(3,\ 2,\ 1)$ です。Aを2.5に切った $(2.5,\ 2,\ 1)$ では、$F=(-1,\ -0.5,\ -0.5)$ です。Aが減らした分だけBとCは増やすと得をするので、均衡ではありません。本当の均衡は $(2.5,\ 2.167,\ 1.167)$ です。上限は、解く前から範囲 $X$ に入れます。
- **射影法の歩幅 γ を大きくするほど速いと思う**: 歩幅0.4で25回ですが、0.5で29回、0.55で57回と増えます。歩幅0.6では、0と $(2.5,\ 4.8,\ 4.2)$ を往復して着きません。この例のヤコビ行列は対称で、固有値は1, 1, 4です。歩幅が $2/4=0.5$ より小さければ、範囲に戻す前の一歩で均衡とのずれの長さが毎回縮むので、必ず着きます。0.5と0.55で着いたのは、Aが上限に止まった後はBとCだけが動き、その部分の最大固有値が3だからです。歩幅は0.5より小さい値から試します。

## 課題から定式化する

「3軒のパン屋が互いの量を見ながら毎朝の量を決めると、どこに落ち着くか」という課題を、次の4段で式にします。

1. **主体は誰で、何を決めるか**：A・B・Cの3軒が、それぞれ自分の量 $q_i$ を決めます。
2. **各主体の目的は何か**：自分の利益 $q_i(10-\text{合計}-c_i)$ です。ほかの店の量が値段を通して入ります。
3. **各主体の範囲は何か**：どの量も0以上、Aは2.5以下です。範囲は、ほかの店の量に左右されません。
4. **何を釣り合いとみなすか**：どの店も、一人だけ量を変えて得をしない組です。各店の傾きを並べた $F$ で、変分不等式に書きます。

複数の主体がそれぞれ自分の目的を最適にし、その結果の釣り合いを知りたいとき、ゲーム・均衡・変分不等式として定式化できます。各主体の目的が自分の決定について山が1つで、範囲がほかの主体の決定によらないなら、均衡は変分不等式の答えと同じです。

## 困りごとから関連する問題へ

実際の課題で次の困りごとがあれば、リンク先を読んでください。

- 範囲が「0以上」だけで、条件が「量が0か、傾きが0か」の組になる → [相補性問題（LCP・NCP）](#/formulations/PA048)
- 1つの主体が先に決め、ほかの主体がそれを見て反応する → [二階層最適化](#/formulations/PA046)
- 1つの組織が3軒すべての量を決められ、合計を1つの目的にしてよい → [凸二次計画（凸QP）](#/formulations/PA018)

### ゲーム・均衡・変分不等式と関連する問題の関係

- [相補性問題（LCP・NCP）](#/formulations/PA048): 範囲 $X$ が非負の象限のときの変分不等式です。条件が「$q_i\ge0$、$F_i\ge0$、どちらかが0」の組になります。この例のAの上限は、乗数を1つ足すとこの形に入ります。
- [二階層最適化](#/formulations/PA046): 先に決める主体が、後の主体の反応を読んで決める形です。この記事の均衡では、全員が同時に決め、順番の差はありません。
- [凸二次計画（凸QP）](#/formulations/PA018): 1つの関数を最小にする問題です。その関数が凸で、$F$ がその勾配なら、変分不等式と同じ答えになります。この例では、凸な $\Phi$ を最小にする凸二次計画が均衡を与えます。利益の合計を最大にする問題も凸二次計画ですが、答えは均衡と違います。

## 数値計算の方法を選ぶ

答えは、どの方法でも $(2.5,\ 2.167,\ 1.167)$ です。違いは、1回に何を計算し、どんな条件で着くかです。

| 系統 | 1回の計算 | 例での様子 |
|---|---|---|
| 射影法（[射影勾配法](#/learn/projected-gradient)と同じ形） | $F$ を1回計算し、範囲に戻す | 歩幅0.25で42回。歩幅0.6では着かない |
| 順番に最善の反応をとる（Gauss–Seidel型） | 1軒ずつ、ほかの量を固定して自分の最適な量にする | 7周で、射影法の答えとのずれ $1.5\times10^{-4}$ |
| 相補性問題に書き換え、Lemke法で解く | 頂点から頂点へ移る | Aの上限に乗数 $\lambda$ を足すと4変数の相補性問題になる。答えの $\lambda$ は $-F_A=0.667$ |

表は速さの順位ではなく、1回の計算と着く条件の違いです。射影法は、$F$ が強く単調でLipschitz連続なら、十分小さい歩幅で着きます（S129）。強く単調とは、2点の差と $F$ の差の内積が、差の長さの二乗の正の定数倍以上になることです。この例の $F$ は一次式で、ヤコビ行列の固有値は1, 1, 4とすべて正なので、強く単調です。順番に最善の反応をとる方法は、この例では $\Phi$ を1変数ずつ最小にすることと同じなので着きます。$F$ が勾配でない問題では、着くとは限りません。

次のコードは、パン屋の例を射影法で解き、つまずきやすい点の3つの決め方を確かめます。

```python
import numpy as np

a = 10.0  # 値段 = 10 - (3軒の量の合計)
cost = np.array([1.0, 2.0, 3.0])  # A・B・Cの1あたりの費用
cap = np.array([2.5, np.inf, np.inf])  # Aのかまどの上限（百個）


def F(q):
    """各店の、自分の量を増やしたときの利益の減り方 -(∂利益_i/∂q_i)"""
    return q + q.sum() - (a - cost)


def profit(q):
    return q * (a - q.sum() - cost)


def projection(step, rounds=2000, tol=1e-6):
    """射影法：q から step·F(q) を引き、範囲 0 ≦ q ≦ cap に戻す。動きが tol 未満で止める"""
    q = np.zeros(3)
    for k in range(1, rounds + 1):
        nxt = np.clip(q - step * F(q), 0, cap)
        if np.abs(nxt - q).max() < tol:
            return nxt, k
        q = nxt
    return q, None  # 着かなかった


q, k = projection(0.25)
print(q.round(3), k, round(a - q.sum(), 3))  # [2.5   2.167 1.167] 42 4.167
print(F(q).round(3), profit(q).round(3))  # [-0.667 -0.     0.   ] [7.917 4.694 1.361]

# 上限を外して解き（連立一次方程式）、後で上限に切る
free = np.linalg.solve(np.ones((3, 3)) + np.eye(3), a - cost)
clipped = np.minimum(free, cap)
print(free, clipped, F(clipped))  # [3. 2. 1.] [2.5 2.  1. ] [-1.  -0.5 -0.5]

# 3軒の利益の合計を最大にする量（Aは上限まで、Cは焼かない）
joint = np.array([2.5, 1.5, 0.0])
print(profit(joint).sum(), a - joint.sum(), F(joint))  # 18.5 6.0 [-2.5 -2.5 -3. ]

# 順番に最善の反応をとる（1軒ずつ、ほかを固定して自分の最適な量にする）
best = np.zeros(3)
for _ in range(7):
    for i in range(3):
        others = best.sum() - best[i]
        best[i] = min(cap[i], max(0.0, (a - cost[i] - others) / 2))
print(best.round(4), np.abs(best - q).max().round(5))  # [2.5    2.1668 1.1666] 0.00015

for step in (0.1, 0.25, 0.5, 0.55, 0.6):
    print(step, projection(step)[1])
# 0.1 104 / 0.25 42 / 0.5 29 / 0.55 57 / 0.6 None
```

最初の2行は、射影法の答えと回数と値段、均衡での $F$ と各店の利益です。Aの $F$ だけが負で、BとCは0です。

次の2行は、つまずきやすい点の「後で切る」と「合計を最大」の量と $F$ です。どちらも、増やす向きに動けるBとCの $F$ が負なので、BもCも一人で増やすと得をします。

順番に最善の反応をとる行は、7周後の量と、射影法の答えとのずれです。最後の5行は歩幅ごとの回数で、`None` は2000回で着かなかったことを表します。

## 出典と再現条件

各主体の最適性の条件を並べて変分不等式に書くことは、FacchineiとPangの変分不等式の教科書（S179）に基づきます。$F$ が強く単調なら均衡がただ1つあることと、ヤコビ行列が対称なら $F$ が関数の勾配になることも、同じ本にあります。凸関数の最小点の条件が $\nabla f$ の変分不等式になることは、BoydとVandenbergheの『Convex Optimization』（S055）にあります。射影法は、LionsとMercierの論文（S129）の前進後退分割で、単調な作用素を扱う方法の特別な場合です。相補性問題とLemke法は、Cottleらの教科書（S171）とLemkeの論文（S172）にあります。

コードの出力は、NumPy 2.5.3 でこの記事のコードを実行して得た値です。図は、同じ式を図の生成スクリプトが標準ライブラリだけで計算した値から描いています。値段と費用は教材用の値で、実際の市場の動きは示しません。
