二階層最適化は、上位の決定を選ぶとき、下位の主体が自分の最適化でその決定への反応を決める問題です。上位は反応を見越して選びます。下位の解が一つに決まるなら、反応を上位の決定の関数として書き、一つの問題に直せます。決まらないなら、どの解を採るかを先に決めます。

## 30秒でつかむ

売り手が商品の価格 $x$ を決めます。買い手は、その価格を見て、自分にとって最も得な購入量 $y$ を決めます。買い手は、買う量が増えるほど追加の負担が重くなるので、価格が上がると買う量を減らします。

売り手が選ぶのは価格だけで、購入量は選べません。それでも売り手は、売上 $x\cdot y$ を最大にしたいので、価格を決める前に「その価格なら買い手はいくつ買うか」を読む必要があります。

- **決めるもの**: 上位の価格 $x$（0 から 6）。購入量 $y$ は、価格への反応として下位が決める
- **良くしたいもの**: 上位の売上 $x\cdot y$。下位は別に、自分の費用を最小にしている
- **守ること**: 価格の範囲 $0\le x\le 6$ と、購入量 $y\ge 0$

この例の買い手は、費用 $\tfrac12y^2+xy-4y$ を最小にする購入量を選びます。次の図の①は、その購入量を価格ごとに描いたものです。

まず「② 価格 x と売上」で、橙の直線（購入量が 3 のままだと見なした売上）と緑の曲線（買い手が反応した実際の売上）が、$x=1$ を過ぎてどう分かれるかを見てください。

![買い手の購入量と売り手の売上を価格ごとに描いた図。①では購入量が価格 0 の 4 から価格 4 の 0 まで直線で減り、4 以上では 0。②では、買い手が反応した実際の売上が x=2 で最大の 4 になり、購入量が 3 のままと見なした売上 3x は x=6 で 18 に達するが、実際の x=6 の売上は 0。](./figures/bilevel-pricing-response.svg "売り手と買い手の例：価格 x を 0 から 6 まで動かしたときの買い手の購入量と売上。この教材用の 1 組の式での計算で、実際の市場の需要は表しません")

1. ①のパネルで、購入量は価格 0 で 4、価格 2 で 2 です。価格が 4 に届くと買い手は何も買わず、購入量は 0 になります。
2. ②のパネルで、緑の曲線は $x=2$ で最大の 4 になります。橙の直線は $x=1$ で緑と同じ 3 ですが、$x=6$ では 18 まで増えます。実際の売上は、$x=6$ で 0 です。
3. 橙の直線に従うと、売り手は価格を上限の 6 まで上げます。その価格で買い手は買わないので、期待した 18 は手に入りません。

売り手が見るべきなのは、価格を固定したときの購入量ではなく、購入量が価格にどう反応するかです。この反応を、式でどう書けばよいのでしょうか。

## 標準形を読む

次の式は「上位が $x$ を選ぶ。ただし、$x$ を決めたときの $y$ は、下位が自分の目的 $f$ を最小にして決める」を表します。

$$
\min_{x\in X}\; F\big(x,y^{*}\big)\quad\text{s.t.}\quad y^{*}\in\arg\min_{y\in Y}\, f(x,y)
$$

式は「$x$ を決めると、下位の最適な反応の集合から $y^{*}$ が決まる。上位は、その $y^{*}$ を入れた目的 $F$ を最小にする $x$ を選ぶ」と読みます。上位が下位の反応を制約として持つ形で、Colson らの概説（S168）が一般の定式化として示しています。

| 記号 | 意味 | 例では |
|---|---|---|
| $x$ | 上位の決定 | 価格（0 から 6） |
| $y$ | 下位の決定。下位が自分で選ぶ | 買い手の購入量（0 以上） |
| $F(x,y)$ | 上位の目的。$x$ と下位の反応 $y$ の両方で決まる | $-xy$（売上を最大にするので符号を反転） |
| $f(x,y)$ | 下位の目的。$x$ を与えられた値として最小にする | $\tfrac12y^2+xy-4y$ |
| $X$, $Y$ | 上位と下位の許される範囲 | $0\le x\le 6$、$y\ge 0$ |
| $y^{*}$ | $x$ を決めたときの、下位の最適な反応 | $\max(0,\,4-x)$ |

### 下位の解が一つに決まるときは、一つの問題になる

下位の問題が、どの $x$ に対しても最適解を一つだけ持つなら、その解を $y^*(x)$ と書けます。このとき二階層の問題は、暗に定義された目的を持つ一段の問題

$$
\min_{x\in X}\; \varphi(x),\qquad \varphi(x)=F\big(x,\,y^{*}(x)\big)
$$

になります。この整理は Dempe の教科書（S169）にあります。例では、買い手の費用が $y$ について強い凸（二乗の項の係数が正）です。$f$ の微分 $y+x-4$ を 0 とし、$y\ge 0$ で切った $y^*(x)=\max(0,\,4-x)$ が唯一の最適解です。上位の目的は $\varphi(x)=-x\max(0,4-x)$ になり、$x$ だけの関数です。

### 下位の解が一つに決まらないときは、先に採る解を決める

下位の最適解が複数あると、$y^{*}$ が一つに決まらず、上位の目的の値も決まりません。Dempe（S169）は、この場合に楽観的な方法と悲観的な方法を区別しています。

- **楽観的**: 下位の最適解のうち、上位に最も都合のよい解を採ります。
- **悲観的**: 下位の最適解のうち、上位に最も不都合な解を採ります。

どちらを採るかで、上位の最適値が変わることや、最適な $x$ が存在するかどうかが変わることがあります。次の節の別の例で確かめます。

### 下位が凸なら、最適性の条件で置き換えられる

下位が凸の問題で、制約想定（Slater の条件など）を満たすなら、下位の最適性はKKT条件と同値です（S055）。そのため、下位の最小化を、KKT条件の等式と不等式で置き換えた一段の問題を書けます。Luo らの教科書（S170）は、このように下位をその最適性の条件へ置き換えた二階層の問題を、MPEC（均衡制約付き最適化）として扱っています。

例の下位は $y\ge 0$ の制約を持つので、KKT条件は、乗数 $\lambda\ge 0$ を使った次の三つです。

$$
y+x-4-\lambda=0,\qquad y\ge 0,\ \lambda\ge 0,\qquad \lambda\,y=0
$$

最後の $\lambda y=0$ が相補性で、$y$ と $\lambda$ の少なくとも一方が 0 であることを表します。この種の制約の性質と解き方は、[相補性問題](#/formulations/PA048)で読みます。

## 小さな例

設定は 30秒でつかむと同じです。買い手の費用 $f(x,y)=\tfrac12y^2+xy-4y$、売り手の売上 $x\,y$、価格の範囲 $0\le x\le 6$ です。

### 価格ごとに、買い手の反応と売上を表にする

| 価格 $x$ | 買い手の購入量 $y^*(x)$ | 売上 $x\,y^*(x)$ |
|---:|---:|---:|
| 0 | 4 | 0 |
| 1 | 3 | 3 |
| 2 | 2 | 4 |
| 3 | 1 | 3 |
| 4 | 0 | 0 |
| 5 | 0 | 0 |
| 6 | 0 | 0 |

$x\le 4$ では $y^*=4-x$ なので、売上は $\varphi$ の符号を戻して $x(4-x)$ です。微分 $4-2x$ が 0 になる $x=2$ で最大になり、購入量 2、売上 4 です。$x\ge 4$ では購入量が 0 なので、売上も 0 です。表の値は、後のコードの1番目の出力と一致します。

### KKT条件で置き換えると、二つの場合になる

下位を前の節のKKT条件に置き換えると、$\lambda y=0$ が場合分けを生みます。

- **$\lambda=0$ の場合**: $y=4-x$ で、$y\ge 0$ から $x\le 4$ です。売上 $x(4-x)$ を最大にして、$x=2$、売上 4 です。
- **$y=0$ の場合**: $\lambda=x-4\ge 0$ から $x\ge 4$ です。売上は 0 です。

たとえば $x=5$ では $y=0$ と $\lambda=1$ が、三つの条件をすべて満たします。二つの場合のうち売上が大きいのは前者で、最初の方法と同じ答え（$x=2$）になります。

### 別の例：下位の解が一つに決まらないとき

この小節だけ、別の例を使います。買い手は購入量 $0\le y\le 1$ を選び、費用 $(x-2)\,y$ を最小にします。売り手は同じく売上 $x\,y$ を最大にし、価格は $0\le x\le 4$ です。

- $x<2$: 係数 $x-2$ が負なので、$y=1$ だけが最適です。
- $x>2$: 係数が正なので、$y=0$ だけが最適です。
- $x=2$: 費用が $y$ によらず 0 なので、$0\le y\le 1$ のすべてが最適です。

| 価格 $x$ | 楽観的な売上 | 悲観的な売上 |
|---:|---:|---:|
| 1.99 | 1.99 | 1.99 |
| 2.00 | 2.00 | 0.00 |
| 2.01 | 0.00 | 0.00 |

$x=2$ で、楽観的なら買い手は $y=1$ を選び、売上は 2 です。悲観的なら $y=0$ を選び、売上は 0 です。楽観的な問題では、$x=2$ が売上 2 の最適な価格です。悲観的な問題では、$x=2$ の売上が 0 なので、2 に届く価格がありません。価格を 2 に近づけると、売上も 2 に近づきます。ただし 2 は超えません。

## つまずきやすい点

- **購入量 $y$ も売り手が選べると見なす**: 購入量を 0 から 4 の整数として同時に選ぶと、$x=6$ と $y=4$ で売上 24 になります。ところが、買い手は $x=6$ では買わないので、実際の売上は 0 です。$y$ は、$x$ に対する下位の最適な反応でなければなりません。
- **ある価格での購入量を、ほかの価格でも使う**: $x=1$ での購入量 3 を固定すると、売上は $3x$ で増えて $x=6$ で 18 に見えます。しかし、実際の $x=6$ の売上は 0 です。反応は価格で変わります。
- **下位を途中で打ち切る**: $x=2$ で、刻み 0.5 の勾配法を $y=0$ から始めると、1, 2, 3 回の $y$ は 1.0, 1.5, 1.75 です。そのときの売上は 2.0, 3.0, 3.5 ですが、買い手が実際に買う量は 2 で売上は 4 なので、3.5 は実際の売上ではありません。この初期値と刻みでは、打ち切っても売上を最大にする価格は $x=2$ のままですが、売上の値は真の値と違います。打ち切った回数と残差は、外側の評価と別に記録します。
- **下位の解が一つでないのに、$y^*$ と書く**: 別の例の $x=2$ では、買い手の最適解は 0 から 1 のすべての値です。楽観的なら売上 2、悲観的なら 0 で、答えが変わります。どちらを採るかを先に決めます。
- **下位が凸と確かめずに、KKT条件へ置き換える**: 置き換えが最適性と同値になることは、下位が凸で制約想定を満たすとき（S055）に確かめられます。例の下位は $y$ について強い凸で、制約が $y\ge 0$ だけなので、この条件を満たします。非凸の下位では、KKT条件を満たす点が最適とは限りません。

## 課題から定式化する

「価格を決めると相手が最適に反応し、その反応で結果が決まる」という課題だけでは、二階層とは決まりません。次の4つを順に確かめます。

1. **上位は何を決めるか**: 価格 $x$ です。下位が決める購入量 $y$ は、上位の変数に入れません。
2. **下位は何を最小にするか**: 買い手は、$x$ を所与として費用 $f(x,y)$ を最小にします。下位の目的、変数、範囲を式で書けることが条件です。
3. **下位の解は一つに決まるか**: 例では、$y$ について強い凸なので一つです。決まらないなら、楽観的か悲観的かを先に決めます。
4. **上位は何を良くしたいか**: 売上 $F=-xy$ です。下位の反応 $y^*(x)$ を入れて、$x$ の関数にします。

次の三つが揃えば、この記事の型です。下位が自分の目的で最適化して決めること。上位がその反応を見越して決めること。下位の解の選び方が決まっていること。

## 困りごとから関連する問題へ

実際の課題で、次の症状が出たら、対応する記事へ進めます。

- 学習の設定（正則化の強さなど）を決めると、学習がパラメータを決める → [ハイパーパラメータ最適化](#/formulations/PA039)
- 下位をKKT条件に置き換えると、相補性 $\lambda y=0$ が出てくる → [相補性問題](#/formulations/PA048)
- 上位と下位が順番ではなく、互いの決定を見ながら同時に決める → [ゲーム・均衡・変分不等式](#/formulations/PA047)
- 下位を何度も数値で解き、打ち切りの精度や解の選び方を記録したい → [入れ子・均衡・相補性・ハイブリッド構造](#/learn/concept.nested-equilibrium-complementarity-hybrid)

### 二階層最適化と関連する問題の関係

- [ハイパーパラメータ最適化](#/formulations/PA039): 下位が学習、上位が検証損失の最小化という二段の問題で、二階層最適化の特殊な場合です。設定ごとに学習を1回解く費用と、検証損失の見積もりの揺れは、HPOの記事で扱います。
- [相補性問題](#/formulations/PA048): 下位が凸で制約想定を満たすなら、KKT条件へ置き換えて、相補性制約付きの問題（MPCC）にできます。相補性制約の性質と解き方は、PA048の記事で読みます。
- [ゲーム・均衡・変分不等式](#/formulations/PA047): 二階層は、上位が先に決めて、下位が反応する順序を持ちます。両者が同時に、互いの決定を前提に決めるなら、均衡の問題です。
- [入れ子・均衡・相補性・ハイブリッド構造](#/learn/concept.nested-equilibrium-complementarity-hybrid): 入れ子の数値実装で、内側の許容誤差・残差・解の選択規則を記録する語彙を扱います。この記事は、一つの価格の例で、下位の解が一つに決まるときと楽観・悲観の選び方を読みました。

## 数値計算の方法を選ぶ

二階層の問題を解くときに見る点は、下位の解が一つに決まるか、下位が凸かどうかです。次の表は順位ではなく、条件ごとの入口です。

| 系統 | 進み方 | 向く条件・避ける条件 |
|---|---|---|
| 下位を解いて一つの問題にする | 外側の $x$ ごとに下位を解き、$\varphi(x)$ を外側の目的として最小にします（S169） | 下位の解が一つで、式か数値で求まるとき。評価1回が下位の求解1回なので、下位が高価だと外側の予算を圧迫します |
| 下位を最適性の条件で置き換える | KKT条件を制約として足し、上位と下位の変数を一つの問題で同時に解きます（S170） | 下位が凸で制約想定を満たすとき（S055）。相補性の扱いは[相補性問題](#/formulations/PA048)で読みます。下位が非凸なら、置き換えが最適性と同値になる保証はありません |
| 楽観・悲観を分けて扱う | 下位の解の集合から、上位に都合のよい解か不都合な解を採る規則を決めます（S169） | 下位の解が複数あるとき。採る規則を先に決めないと、上位の目的が定義されません |

どの系統でも、評価回数と下位を打ち切った精度と、採った解の規則を記録します。この記事の数値は、小さな例での挙動を読むためのもので、系統の優劣は示しません。

次のコードは、小さな例を標準ライブラリだけで確かめます。

```python
def follower_solve(x):
    """下位: min_{y>=0} 0.5*y**2 + x*y - 4*y。y について強凸なので解は一つ。"""
    return max(0.0, 4.0 - x)  # 勾配 y + x - 4 = 0 を y >= 0 で切る


def revenue(x, y):
    return x * y  # 上位は売上 x*y を最大にする


# 1. 入れ子: x ごとに下位を解き、一変数の問題にする
print([(x, follower_solve(x), revenue(x, follower_solve(x))) for x in (0, 1, 2, 3, 4)])
# [(0, 4.0, 0.0), (1, 3.0, 3.0), (2, 2.0, 4.0), (3, 1.0, 3.0), (4, 0.0, 0.0)]

grid = [i / 100 for i in range(601)]  # 価格 0 から 6 まで 0.01 刻み
best = max(grid, key=lambda x: revenue(x, follower_solve(x)))
print(best, follower_solve(best), revenue(best, follower_solve(best)))  # 2.0 2.0 4.0

# 2. 誤り: 下位の変数 y も上位が自由に選べると見なす（y は 0 から 4 の整数）
x_bad, y_bad = max(((x, y) for x in range(7) for y in range(5)), key=lambda p: p[0] * p[1])
print(x_bad, y_bad, revenue(x_bad, y_bad), revenue(x_bad, follower_solve(x_bad)))  # 6 4 24 0.0

# 3. 誤り: 購入量が x=1 のときの 3 のままだと見なす
print(3 * 6, revenue(6, follower_solve(6)))  # 18 0.0

# 4. KKT 条件（下位が凸なので最適性と同値）: y + x - 4 - lam = 0, y >= 0, lam >= 0, lam*y = 0
for x in (2, 5):
    y = follower_solve(x)
    lam = y + x - 4
    print(x, y, lam, lam * y)  # 2 2.0 0.0 0.0 / 5 0.0 1.0 0.0

# 5. 下位を k 回の勾配法で打ち切る（x=2、刻み 0.5、y=0 から開始）
for k in (1, 2, 3, 10):
    y = 0.0
    for _ in range(k):
        y -= 0.5 * (y + 2 - 4)
    print(k, y, revenue(2, y))  # 1 1.0 2.0 / 2 1.5 3.0 / 3 1.75 3.5 / 10 1.998046875 3.99609375


# 6. 下位の解が一つに決まらない例: follower は (x-2)*y を 0<=y<=1 で最小化する
def follower_set(x):  # 解の集合 [lo, hi]
    return (1.0, 1.0) if x < 2 else (0.0, 0.0) if x > 2 else (0.0, 1.0)


for x in (1.99, 2.0, 2.01):
    lo, hi = follower_set(x)
    print(x, x * hi, x * lo)  # 1.99 1.99 1.99 / 2.0 2.0 0.0 / 2.01 0.0 0.0
```

出力は上から順に次のとおりです。

- 1番目は、価格 0 から 4 までの購入量と売上で、先の表と同じです。`best` は 0.01 刻みの価格で調べた最良で、価格 2.0 のとき購入量 2.0、売上 4.0 です。
- 2番目の `6 4 24 0.0` は、購入量を自由に選ぶと売上が 24 に見えますが、買い手の反応を入れると 0 になることを示します。
- 3番目の `18 0.0` は、購入量を固定した見込みと、実際の売上です。
- 4番目は、$x=2$ で $y=2$ と $\lambda=0$、$x=5$ で $y=0$ と $\lambda=1$ です。どちらも $\lambda y=0$ を満たします。
- 5番目は、勾配法を 1, 2, 3, 10 回で打ち切ったときの $y$ と売上です。10 回でも 3.996 で、真の 4 には届きません。
- 6番目は、価格が 1.99 と 2.00 と 2.01 のときの、楽観的な売上（第2列）と悲観的な売上（第3列）です。

## 出典と再現条件

二階層最適化の一般の定式化とMPECとの関係は、Colson らの概説（S168）に基づきます。下位の解が一つなら一段の問題になること、解が一つでないときの楽観的・悲観的な方法は、Dempe の教科書（S169）に基づきます。下位を最適性の条件へ置き換えた問題は、Luo らの教科書（S170）に基づきます。凸の問題でKKT条件が最適性と同値になることは、Boyd と Vandenberghe の教科書（S055）に基づきます。例の価格と購入量は、この記事のために作った式で、実際の市場の需要は表しません。標準ライブラリのPythonでコードを実行しています。

この例は、下位の反応を入れて一つの問題にする考え方と、楽観・悲観の違いを示す小さな例です。特定の方法の性能、下位が非凸の場合の解き方、実際の価格設定の最適な決め方は示しません。
