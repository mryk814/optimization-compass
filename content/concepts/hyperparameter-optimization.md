30点のデータに、多項式の曲線を当てはめます。学習の前に決める設定は2つです。多項式の次数（2から15の整数）と、係数が大きくなりすぎないようにする罰則の強さ $\lambda$（$10^{-6}$ から $10$）です。

設定を1組決めるたびに、曲線を学習し、学習に使わなかった点で二乗誤差を測ります。この誤差を「点数」と呼びます。小さいほど良い点数です。実際のモデルなら1回に数時間かかるとして、試せるのは16回だけとします。

16回を、格子で順に使うか、でたらめに引いて使うか。そして、見つけた「最良の点数」は信じてよいのでしょうか。

16回で探していたのは、30点から作った測定値の小さい場所でした。交差検証の点数は、24点で学習した曲線を残りの6点で試した値です。選ばれた設定の点数には、この30点と分け方にたまたま合った分も入ります。ランダムの最良として選んだ0.144は、新しい点では0.173でした。

点数の差は、設定の良さの差とは限りません。最後に報告する点数は、選ぶのに使っていないデータで1回だけ測ります。

## 標準形を読む

次の式が表すのは「設定 $\theta$ を探索範囲 $\Theta$ から選び、その設定で学習した結果の検証損失を最小にする」です。

$$
\min_{\theta\in\Theta}\ \mathcal L_{\text{val}}\bigl(w^{*}(\theta)\bigr),\qquad
w^{*}(\theta)\in\arg\min_{w}\ \mathcal L_{\text{train}}(w;\theta)
$$

定式化の辞書では、設定を $\lambda$ と書きます。この記事ではリッジ回帰の罰則の強さが $\lambda$ なので、設定全体を $\theta=(d,\lambda)$ と書きます。

| 記号 | 意味 | 例では |
|---|---|---|
| $\theta$ | 学習の前に決める設定（ハイパーパラメータ） | 次数 $d$ と罰則の強さ $\lambda$ |
| $\Theta$ | 探索範囲。整数、対数目盛り、条件付きの設定を含むことがある | $d\in\{2,\dots,15\}$、$\log_{10}\lambda\in[-6,1]$ |
| $w^{*}(\theta)$ | 設定 $\theta$ で学習した結果 | 学習に使う24点で求めた多項式の係数 |
| $\mathcal L_{\text{train}}$ | 学習の目的。設定ごとに形が変わる | 二乗誤差の和に $n\lambda\lVert w\rVert^2$ を足したもの |
| $\mathcal L_{\text{val}}$ | 検証損失。学習に使っていないデータで測る | 5分割の交差検証の平均二乗誤差 |
| 評価1回 | 学習してから検証する1組の計算 | 係数を求める計算が5回 |

内側の式（学習）が1回解けることが、外側の式（設定の選択）の「目的関数を1回測る」ことにあたります。外側から見ると、$\mathcal L_{\text{val}}(w^{*}(\theta))$ は $\theta$ を入れると数が返る関数です。その中身である学習は、見えない箱として扱います。

例の点数は、30点を6点ずつの5組 $F_1,\dots,F_5$ に分けた交差検証です。$k$ 番目の組を除いて学習した曲線 $\hat f_{-k}$ が、除いた組の点をどれだけ外すかを測り、5組で平均します。

$$
\mathrm{CV}(\theta)=\frac15\sum_{k=1}^{5}\frac{1}{|F_k|}\sum_{i\in F_k}\bigl(y_i-\hat f_{-k}(x_i;\theta)\bigr)^2
$$

例の内側の問題は、リッジ回帰の正規方程式で一度に解けます。ニューラルネットなら、この内側が反復計算になり、評価1回が数時間になります。

## 探索空間を書く

$\Theta$ は、ただの箱ではありません。探し方を選ぶ前に、次の3つを探索空間に書き込みます。どれも手で確かめられます。

- **対数目盛り**: $\lambda$ は桁で効くので、$\log_{10}\lambda$ を一様に引きます。良い設定の多い帯を $\log_{10}\lambda\in[-3,-1]$ とすると、範囲 $[-6,1]$ のうち帯の幅は $2/7=0.2857$ で、16回のうち平均4.57回が帯に入ります。$\lambda$ そのものを $[10^{-6},10]$ で一様に引くと、帯の割合は $(0.1-0.001)/10=0.0099$ で、16回のうち0.16回です。
- **整数**: 次数は整数です。連続値として動かして3.6、4.0、4.4を試しても、丸めるとすべて次数4で、点数は同じです。連続値で動かす方法からは、点数が平らな段に見えます。
- **条件付き**: 罰則なしと罰則ありを選べるとき、罰則なしを選ぶと $\lambda$ は使われません。罰則の有無、次数4通り、$\lambda$ 4通りを全部組み合わせると $2\times4\times4=32$ 回ですが、罰則なしの16回から出る点数は次数ごとの4通りだけで、12回は重複です。使われない設定は、その条件のときだけ探索空間から外します。

## 選んだ点数と、選ばずに測った点数

図の例では、選んだ設定の点数が新しい点で良くなることも悪くなることもありました。格子の最良は0.192が0.175に、ランダムの最良は0.144が0.173になります。1つのデータでは、選んだ点数がどちらへずれるかは言えません。

そこで、同じ式から別の30点を100組作り、それぞれでランダム16回の最良を選びました。比べる相手は、探さずに先に決めておいた設定（次数3、$\log_{10}\lambda=-3.5$）です。どちらも、交差検証の点数と、新しい5000点での点数を測ります。

| 設定の決め方 | 交差検証の点数（中央値） | 新しい5000点（中央値） | 新しい点のほうが悪かったデータ |
|---|---:|---:|---:|
| 16回の最良を選ぶ | 0.188 | 0.198 | 64 / 100 |
| 先に決めた設定を使う | 0.200 | 0.185 | 43 / 100 |

先に決めた設定では、交差検証の点数のほうが新しい点より悪く出たデータが57組で、中央値も0.200から0.185へ良くなります。16回から選ぶと向きが逆になり、64組で、選んだときの点数のほうが良く見えました。これはこの例の計算結果で、ずれの大きさは、データの量、候補の数、ノイズで変わります。

選ぶためのデータと、報告のためのデータを分けるのは、このためです。データが少ないときは、外側の分割を報告用に取り分け、残りの中だけで交差検証をして設定を選びます（入れ子の交差検証）。テスト用のデータで設定を選び、同じ点数を報告すると、選ぶのに使ったデータで測ったことになります。

## 見分ける・移る

次の4つがそろうとき、課題はこの型です。

1. **決めるもの**が、学習の前に固定する設定である。整数、対数目盛り、条件付きの設定が混ざることが多い。
2. **評価1回**が、設定を決めて学習し、学習に使っていないデータで測る計算である。
3. **良くしたいもの**が、学習用の誤差ではなく検証損失である。
4. **予算**が評価の回数で決まり、勾配は一般に得られない。

症状が次のどれかなら、対応する記事へ進みます。

- 評価1回が数時間かかり、試せる回数が数十回しかない → [非常に高価な低次元評価](#/formulations/PA014)と、[評価費と予算](#/learn/concept.evaluation-cost)
- 同じ設定でも、測るたびに値が変わる → [noiseを含むblack-box](#/formulations/PA013)
- 設定が数十個あり、探索が広がりすぎる → [高次元black-box](#/formulations/PA015)
- 学習が発散して値が返らない設定が出る → [失敗・NaNを伴うsimulation](#/formulations/PA016)
- 内側の学習の式まで含めて、二段の問題として書きたい → [bilevel optimization](#/formulations/PA046)
- 設定が正則化の強さ1つだけで、係数がちょうど0になるかも見たい → [L1正則化つき回帰](#/formulations/PA035)

[bilevel optimization](#/formulations/PA046) から見ると、HPOはその特別な場合です。内側（学習）の解 $w^{*}(\theta)$ を外側（検証損失の最小化）へ代入した形が、標準形の2つの式です。内側が反復計算の学習なら、外側は内側を見えない箱として扱うことが多くなります。

検証損失を、1回が高価なblack-box評価として扱うと、[非常に高価な低次元評価](#/formulations/PA014)へ書き直せます。条件は、評価回数が数十回、設定が低次元で、値のばらつきが小さいことです。

## 数値計算の方法を選ぶ

どの方法も、使う情報が違います。探索空間の形、評価回数、並列度、学習の途中の成績が取れるかで分けて考えます。次の表は順位ではなく、条件ごとの入口です。

| 系統 | 使う情報 | 向く条件・避ける条件 |
|---|---|---|
| [Random Search](#/learn/random-search) | 履歴を使わない | 実装が単純で、並列にしやすく、他の方法と比べる基準になります。次元が高く有望な領域が小さいと、被覆は保証されません |
| [TPE](#/learn/tpe) | 良かった設定と残りの分布の比 | 整数、カテゴリ、条件付きの設定が混ざる探索空間で候補になります。履歴が極端に少ないときは、探索がランダムに近くなります |
| [SMAC](#/learn/smac) | ランダムフォレストによる予測 | カテゴリや条件付きの設定が多いとき、木で分岐を表せます。評価回数が少ない、連続変数中心の低次元なら、ガウス過程も候補です |
| [ベイズ最適化](#/learn/bayesian-optimization) | 観測から作る代理モデルの予測と不確実性 | 連続変数が中心で、低次元、評価が数十回のときに向きます。条件付きやカテゴリが多いと、連続値のカーネルが合いません |
| [Hyperband / ASHA](#/learn/hyperband-asha) | 学習の途中の成績 | エポックや標本数を段階的に増やせ、途中の成績が最終の成績と相関するときに向きます。相関がなければ、系統的な偏りを作ります |
| [Population Based Training](#/learn/pbt) | 並走する学習の途中成績と状態 | 学習を続けながら設定を変えるとき（学習率の予定など）に向きます。得られるのは設定の予定を含む学習の結果で、固定の設定ではありません |

各ライブラリ（Optuna、SMAC3、Ray Tuneなど）の既定のsamplerや打切り器は、そのライブラリの選択です。この記事の推奨でも、一般的な順位でもありません。

## Pythonで確かめる

次のコードは、図と同じ30点、同じ16回の格子とランダムを作り、それぞれの最良の設定を交差検証で選んでから、新しい5000点で測り直します。`cv_mse` の1回が、外側の最適化から見た目的関数の評価1回です。

```python
import math
import random

import numpy as np
from numpy.polynomial import legendre

LO, HI = -6.0, 1.0  # 探索範囲: log10 λ
DEGREES = list(range(2, 16))  # 探索範囲: 次数


def make_data(seed, n=30):
    rng = random.Random(seed)
    x = [rng.uniform(-1, 1) for _ in range(n)]
    y = [math.sin(3 * v) + 0.5 * v + 0.4 * rng.gauss(0, 1) for v in x]
    return np.array(x), np.array(y)


def fit(x, y, degree, lam):
    a = legendre.legvander(x, degree)  # Legendre 基底のリッジ回帰
    return np.linalg.solve(a.T @ a + len(x) * lam * np.eye(degree + 1), a.T @ y)


def mse(w, x, y):
    return float(np.mean((legendre.legvander(x, len(w) - 1) @ w - y) ** 2))


def cv_mse(x, y, degree, lam, k=5, split_seed=0):
    order = list(range(len(x)))
    random.Random(split_seed).shuffle(order)
    folds = [order[i::k] for i in range(k)]
    train = [[j for j in order if j not in fold] for fold in folds]
    return float(np.mean([mse(fit(x[t], y[t], degree, lam), x[f], y[f]) for t, f in zip(train, folds)]))


x, y = make_data(1)
x_new, y_new = make_data(999, 5000)  # 設定の選択に一度も使わない点
rng = random.Random(0)
runs = {
    "格子": [(d, 10.0 ** (LO + (HI - LO) * i / 3)) for d in (2, 6, 11, 15) for i in range(4)],
    "ランダム": [(rng.choice(DEGREES), 10.0 ** rng.uniform(LO, HI)) for _ in range(16)],
}
for name, settings in runs.items():
    scores = [cv_mse(x, y, d, lam) for d, lam in settings]
    d, lam = settings[int(np.argmin(scores))]
    print(name, d, round(math.log10(lam), 2), round(min(scores), 3), round(mse(fit(x, y, d, lam), x_new, y_new), 3))
    # 格子 6 -3.67 0.192 0.175
    # ランダム 3 -1.67 0.144 0.173
```

出力の各行は、選ばれた次数、$\log_{10}\lambda$、交差検証の点数、新しい5000点での点数です。`split_seed` を変えると、図で分け方を変えたときと同じく、選ばれる設定と点数が動きます。
