凸二次計画は、お椀の形をした二次の目的を、線形の等式・不等式を守りながら最小にする定式化です。線形計画と違い、最適解は頂点とは限らず、辺の途中や領域の内部にも現れます。

## 30秒でつかむ

目標の点にできるだけ近い点を、決められた範囲の中から選ぶ問題を考えます。
範囲の中に目標があれば、目標そのものが答えです。
範囲の外に目標があれば、範囲の境界の中で目標に最も近い点が答えになります。

「近さ」は距離の二乗で測ります。二乗の目的は、底のあるお椀の形をしています。
このお椀を線形の制約で切り取った問題が、凸二次計画（convex quadratic program, 凸QP）です。

- **決めるもの**: 配分比率、操作量、補正量のような連続の量
- **良くしたいもの**: 二乗誤差、分散（リスク）、エネルギーのような二次の量
- **守ること**: 予算・上下限・つり合いのような線形の条件

お椀の底が一つしかないので、局所解はそのまま大域解です。この性質を保つには、お椀が上に開いていること、つまり凸であることが必要です。

## 標準形を読む

凸二次計画は次の形に書けます。

$$
\min_{x}\; \tfrac12 x^\top Q x + c^\top x \quad \text{s.t.}\quad Ax\le b,\quad Q\succeq 0
$$

$\tfrac12 x^\top Qx$ がお椀の形を、$c^\top x$ がお椀の傾きを決めます。

| 記号 | 意味 |
|---|---|
| $Q$ | お椀の曲がり方を表す対称行列。どの方向にも下に曲がらない |
| $c$ | 目的の一次の部分。お椀の底の位置をずらす |
| $A,\,b$ | 線形の制約。線形計画と同じ |

条件 $Q\succeq 0$ は「$Q$ が半正定値」という意味です。どの方向 $d$ についても $d^\top Qd\ge 0$ で、お椀がどこでも上に開いていることを表します。
この条件が崩れると、見た目が同じでも別の定式化（非凸QP）になります。

係数 $\tfrac12$ は、微分したときに勾配が $Qx+c$ ときれいになるための慣習です。ソルバー（solver）によって $\tfrac12$ を付けるかどうかが違うので、入力前に確かめます。

## 小さな例

目標の点 $(3,2)$ に最も近い点を、$x_1+x_2\le 3$ かつ $x\ge 0$ の範囲から選びます。

$$
\min_{x}\; (x_1-3)^2+(x_2-2)^2 \quad \text{s.t.}\quad x_1+x_2\le 3,\; x\ge 0
$$

目標は $3+2=5>3$ なので範囲の外にあります。
境界の直線 $x_1+x_2=3$ へ、直線に垂直な向き $(1,1)$ に沿って戻ると、最も近い点 $(2,1)$ に着きます。目的値は $2$ です。

答え $(2,1)$ は辺の途中にあり、頂点ではありません。線形計画との大きな違いです。
目標を $(1,1)$ に変えると、目標が範囲の内部にあるので、答えは内部の $(1,1)$ になります。

### 乗数は「境界に押し戻す力」

最適点では、目的の勾配と制約の勾配がつり合います。

$$
\nabla f(x^\star)+\lambda\,\nabla g(x^\star)=0,\qquad \lambda\ge 0
$$

$f$ の勾配は $2(x-(3,2))=(-2,-2)$、制約 $g(x)=x_1+x_2-3$ の勾配は $(1,1)$ なので、$\lambda=2$ です。
$\lambda$ は、制約を少し緩めたときに目的値がどれだけ下がるかを表します。線形計画の双対値と同じ役割です。
制約が効いていない（目標が内部にある）ときは、$\lambda=0$ になります。

## 見分け方

次の兆候があれば、凸二次計画を疑います。

- 二乗誤差を、上下限や合計の条件つきで小さくしたい
- 資産の組み合わせの分散（リスク）を、予算と期待収益の条件つきで小さくしたい
- 操作量の二乗和を小さくしながら、線形モデルで予測した状態を範囲内に保ちたい（MPC）

次の兆候があれば、別の定式化を考えます。

- 変数の積 $x_ix_j$ が入り、$Q$ が半正定値だと確かめられない → 非凸QP。局所解しか保証されない
- 二乗の制約（例: $x^\top x\le r^2$）がある → 二次錐計画で書ける
- 選ぶ・選ばないの決定が混ざる → 混合整数QP

## 近い定式化

- **線形計画**: $Q=0$ の凸QPです。
- **線形最小二乗**: 制約のない凸QPです。$\|Ax-b\|^2$ を展開すると $Q=2A^\top A$ になります。
- **二次錐計画**: 目的の二次項を補助変数へ移すと、二次錐制約で書けます。凸QPは二次錐計画の特別な場合です。
- **非凸QP**: 式の形は同じで、$Q$ が不定値の場合です。難しさがまったく違います。

## 解き方の系統

凸なので、どの方法も大域解へ向かいます。問題の大きさと、同じ問題を何度解くかで選び分けます。

- **有効制約法（active-set法）**: 効いている制約の組を推測し、組を入れ替えながら解きます。中小規模で精度が高く、前回の解から再開しやすい方法です。
- **内点法**: 内部を通って進みます。大規模な疎行列の問題に安定して強い方法です。
- **ADMM系の一次法（OSQPなど）**: 行列の分解を使い回し、安い反復を重ねます。精度は中程度ですが、制御のように同じ形の問題を高速に何度も解く用途に向きます。

次の例は、CVXPYで上の問題を解きます。CVXPYが問題を凸QPと認識し、適したソルバーへ渡します。

```python
import cvxpy as cp
import numpy as np

x = cp.Variable(2)
target = np.array([3.0, 2.0])
budget = cp.sum(x) <= 3
problem = cp.Problem(cp.Minimize(cp.sum_squares(x - target)), [budget, x >= 0])
problem.solve()
print(x.value, problem.value, budget.dual_value)  # [2. 1.] 2.0 2.0
```

`dual_value` が、上で計算した乗数 $\lambda=2$ に一致します。

## つまずきやすい点

- **$Q$ が数値的に半正定値でない**: データから作った共分散行列は、丸め誤差でわずかに負の固有値を持つことがあります。ソルバーが非凸と判定して止まるので、固有値を確認し、必要なら小さな正則化を足します。
- **$\tfrac12$ の付け忘れ**: 係数の約束がソルバーごとに違うと、答えは同じでも目的値と乗数の大きさが2倍ずれます。
- **一次法の精度**: ADMM系の答えは許容誤差の範囲で制約をわずかに破ります。厳密な実行可能性が必要なら、許容誤差を締めるか、別の方法で仕上げます。
