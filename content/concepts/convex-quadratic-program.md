凸二次計画は、お椀の形をした二次の目的を、線形の等式・不等式を守りながら最小にする定式化です。有界な多角形上の線形計画では頂点に最適解を選べますが、凸QPでは頂点だけを調べると最適解を逃すことがあります。

## 30秒でつかむ

線形の制約で囲まれた領域なら、最良の点は角にあるのでしょうか。目的を線形から二乗へ変えると、同じ領域でも答えは辺の途中へ移ります。目標へ近づく一つの例で、その違いを確かめます。

目標の点にできるだけ近い点を、決められた範囲の中から選ぶ問題を考えます。
範囲の中に目標があれば、目標そのものが答えです。
範囲の外に目標があれば、範囲の境界の中で目標に最も近い点が答えになります。

「近さ」は距離の二乗で測ります。二乗の目的は、底のあるお椀の形をしています。
このお椀を線形の制約で切り取った問題が、凸二次計画（convex quadratic program, 凸QP）です。

- **決めるもの**: 配分比率、操作量、補正量のような連続の量
- **良くしたいもの**: 二乗誤差、分散（リスク）、エネルギーのような二次の量
- **守ること**: 予算・上下限・つり合いのような線形の条件

凸な目的と凸な可行集合の組合せなので、局所最小解は大域最小解です。ただし凸QP一般では、底が平らな方向もあり、最適解が一つとは限りません。以下の距離の二乗の例では、どの方向にも曲率があるため答えが一つに決まります。

## 標準形を読む

凸二次計画は次の形に書けます。

$$
\min_{x}\; \tfrac12 x^\top Q x + c^\top x \quad \text{s.t.}\quad Ax\le b,\quad Q\succeq 0
$$

$\tfrac12 x^\top Qx$ がお椀の形を、$c^\top x$ がお椀の傾きを決めます。

| 記号 | 意味 |
|---|---|
| $Q$ | お椀の曲がり方を表す対称行列。どの方向にも下に曲がらない |
| $c$ | 目的の一次の部分。目的の傾きを変える |
| $A,\,b$ | 線形の制約。線形計画と同じ |

線形等式 $Ex=d$ を追加しても凸QPです。等式を二つの不等式として表すこともできますが、実装では等式として渡せるAPIを使うのが自然です。

条件 $Q\succeq 0$ は「$Q$ が半正定値」という意味です。どの方向 $d$ についても $d^\top Qd\ge 0$ で、お椀がどこでも上に開いていることを表します。
この条件が崩れると、見た目が同じでも別の定式化（非凸QP）になります。半正定値でも、実行可能性や最小解の存在は別問題です。例えば制約なしで $Q=0$、$c\ne0$ なら目的は下に有界ではありません。

係数 $\tfrac12$ は、微分したときに勾配が $Qx+c$ ときれいになるための慣習です。ソルバーによって $\tfrac12$ を付けるかどうかが違うので、入力前に確かめます。

## 小さな例

目標の点 $(3,2)$ に最も近い点を、$x_1+x_2\le 3$ かつ $x\ge 0$ の範囲から選びます。

$$
\min_{x}\; (x_1-3)^2+(x_2-2)^2 \quad \text{s.t.}\quad x_1+x_2\le 3,\; x\ge 0
$$

目標は $3+2=5>3$ なので範囲の外にあります。
境界の直線 $x_1+x_2=3$ へ、直線に垂直な向き $(1,1)$ に沿って戻ると、最も近い点 $(2,1)$ に着きます。目的値は $2$ です。

答え $(2,1)$ は辺の途中にあり、頂点ではありません。三つの頂点の目的値を計算すると、$(0,0)$ で13、$(3,0)$ で4、$(0,3)$ で10です。頂点だけを比べれば「4が最小」と答えてしまい、本当の最小値2を逃します。

境界上で $x_1=t,\;x_2=3-t$ と置くと、同じことを一次元で確かめられます。

$$
f(t,3-t)=(t-3)^2+(1-t)^2=2(t-2)^2+2,\qquad0\le t\le3.
$$

右辺の二乗は0以上なので、$t=2$ で最小値2です。これは「どの頂点が良いか」ではなく、**辺に沿って動くときの曲がり方**が答えを決めたことを示します。

![三角形の可行領域と二乗距離の等高線。左は目標(3,2)から領域へ最も近い(2,1)が辺の途中にあり、目的と制約の勾配が反対向き。右は目標(1,1)が領域内にある。](./media/convex-qp-projection.svg "目標を中心に等高線を広げると、左では目的値2の線が初めて可行領域に触れます。矢印は∇fとλ∇gを同じ倍率で描いたものです。")

図の左では、目標を中心とする小さな円は可行領域に届きません。半径を広げて最初に触れる位置が解です。そこで等高線と制約の直線が接しています。
目標を $(1,1)$ に変えると、目標が範囲の内部にあるので、答えは内部の $(1,1)$ になります。

### 乗数は「境界に押し戻す力」

最適点では、目的の勾配と制約の勾配がつり合います。

$$
\nabla f(x^\star)+\lambda\,\nabla g(x^\star)=0,\qquad \lambda\ge 0
$$

$f$ の勾配は $2(x-(3,2))=(-2,-2)$、制約 $g(x)=x_1+x_2-3$ の勾配は $(1,1)$ なので、$\lambda=2$ です。
$\lambda$ は、制約右辺を少し緩めたときの最適値の一次の変化を表します。上限を $3+\varepsilon$ にすると、近傍では

$$
x^\star(\varepsilon)=(2+\varepsilon/2,\,1+\varepsilon/2),\qquad
v(\varepsilon)=2-2\varepsilon+\varepsilon^2/2.
$$

したがって $v'(0)=-2=-\lambda$ です。上限を0.1緩めると、一次予測の改善量は0.2、実際は $2-1.805=0.195$ になります。有限の変更に対して「改善量が必ず $\lambda\varepsilon$」という意味ではありません。線形計画の双対値と同じ感度の役割ですが、有効な制約が変わる場所にも注意します。
制約が効いていない（目標が内部にある）ときは、$\lambda=0$ になります。逆に、境界上でも乗数が0の場合があります。上限が5なら目標 $(3,2)$ が境界上にありますが、目的の勾配は0なので乗数も0です。「境界にいる」と「正の乗数を持つ」を同一視しません。

### 標準形へ直しても、何が同じで何が変わるか

目的を展開すると $x_1^2+x_2^2-6x_1-4x_2+13$ です。標準形では $Q=2I$、$c=(-6,-4)$。定数13を省いても最小点と乗数は変わりませんが、ソルバーが返す目的値は $2-13=-11$ になります。二つの実装の目的値を比較するときは、係数 $1/2$ だけでなく、省いた定数もそろえます。

## 見分け方

次の兆候があれば、凸二次計画を疑います。

- 二乗誤差を、上下限や合計の条件つきで小さくしたい
- 資産の組み合わせの分散（リスク）を、予算と期待収益の条件つきで小さくしたい
- 操作量の二乗和を小さくしながら、線形モデルで予測した状態を範囲内に保ちたい（MPC）

次の兆候があれば、別の定式化を考えます。

- 二次目的の行列 $Q$ が半正定値でないと分かる → 非凸QP。局所ソルバーの停止点を大域解とは扱えない。未確認のときは、まず対称化した行列の曲率を調べる
- 凸な二次不等式制約（例: $x^\top x\le r^2$、$r\ge0$）がある → 二次錐計画で表せる。任意の二次制約が該当するわけではない
- 選ぶ・選ばないの決定が混ざる → 混合整数QP

## 近い定式化

- **線形計画**: $Q=0$ の凸QPです。
- **線形最小二乗**: 制約のない凸QPです。$\|Ax-b\|^2$ を展開すると $Q=2A^\top A$ になります。
- **二次錐計画**: 目的の二次項を補助変数へ移すと、二次錐制約で書けます。凸QPは二次錐計画の特別な場合です。
- **非凸QP**: 式の形は同じで、$Q$ が半正定値でない場合です。難しさがまったく違います。

## 解き方の系統

凸性は最適性の保証を支えますが、どの実装でも任意の設定で解けるという意味ではありません。可行性、停止理由、残差を確認したうえで、問題の大きさと同じ問題を何度解くかで選び分けます。

- **有効制約法**: 効いている制約の組を推測し、組を入れ替えながら解きます。中小規模で精度が高く、前回の解から再開しやすい方法です。
- **内点法**: 内部を通って進みます。大規模な疎行列の問題に安定して強い方法です。
- **ADMM系の一次法（OSQPなど）**: 行列の分解を使い回し、安い反復を重ねます。中程度の精度を効率よく求める用途が典型ですが、到達精度は問題と設定によります。制御のように同じ形の問題を高速に何度も解く用途に向きます。

### 同じ例を、式とソルバーの二通りで確かめる

まず「和の制約が効き、非負の境界は効かない」と仮定して、停留条件と $x_1+x_2=3$ を連立します。

$$
\begin{bmatrix}2I&\boldsymbol1\\\boldsymbol1^\top&0\end{bmatrix}
\begin{bmatrix}x\\\lambda\end{bmatrix}
=\begin{bmatrix}2(3,2)^\top\\3\end{bmatrix}.
$$

得た点が本当に $x\ge0$ と $\lambda\ge0$ を満たすか、仮定を後から確認します。別にSLSQPで元の不等式付き問題を解き、点を照合します。これは大規模QPにSLSQPを推奨する比較ではなく、小例の独立した検算です。

```python
import numpy as np
from scipy.optimize import minimize, LinearConstraint, Bounds

target = np.array([3., 2.])
K = np.block([[2*np.eye(2), np.ones((2, 1))],
              [np.ones((1, 2)), np.zeros((1, 1))]])
solution = np.linalg.solve(K, np.r_[2*target, 3.])
x, lam = solution[:2], solution[2]
assert np.all(x >= 0) and lam >= 0

result = minimize(
    lambda z: np.sum((z-target)**2), [0.5, 0.5],
    jac=lambda z: 2*(z-target), method="SLSQP",
    constraints=[LinearConstraint([[1., 1.]], -np.inf, 3.)],
    bounds=Bounds(0., np.inf), options={"ftol": 1e-12},
)
assert result.success
print("KKT:", x, lam)                  # [2. 1.] 2.0
print("solver:", result.x.round(6), round(result.fun, 6))
print("stationarity:", np.max(np.abs(2*(x-target)+lam)))
print("feasibility:", max(0., x.sum()-3., -x.min()))
print("complementarity:", abs(lam*(x.sum()-3.)))
```

解は $(2,1)$、元の二乗距離は2、乗数は2です。解析解で計算した三つの残差はすべて0になります。数値ソルバーでは小さな丸め誤差が残るので、残差は元の単位と許容精度に照らして読みます。

## つまずきやすい点

- **$Q$ が数値的に半正定値でない**: データから作った共分散行列は、丸め誤差でわずかに負の固有値を持つことがあります。対称化の要否や固有値を、データの精度と行列の尺度に照らして確認します。正則化は目的そのものを変えるので、負の固有値を理由なく消す修正は避け、変更量と解への影響を記録します。
- **半正定値なら一意だと思う**: $f(x)=x_1^2$ は凸ですが、$x_1=0$ なら $x_2$ を変えても同じ値です。$Q\succ0$ なら、最小解が存在する限り一意です。$Q\succeq0$ だけでは一意とは限りません。
- **$\tfrac12$ の付け忘れ**: 目的全体を2倍すれば最小点は同じで乗数は2倍になります。しかし二次項だけの係数を取り違えると、一次項との比が変わり、最小点も変わり得ます。
- **一次法の精度**: ADMM系の答えは許容誤差の範囲で制約をわずかに破る場合があります。厳密な実行可能性が必要なら、許容誤差を締めるか、別の方法で仕上げます。
