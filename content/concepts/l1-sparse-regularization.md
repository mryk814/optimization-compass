L1正則化つき回帰は、二乗誤差に係数の絶対値の和（L1ノルム）の罰則を足して最小にする定式化です。罰則の強さ λ を上げると、予測にあまり役立たない係数がちょうど0になり、残った特徴量だけで予測する式が得られます。目的は凸ですが、絶対値の角で微分できないため、近接勾配法や座標降下法のように、角を一歩ごとに処理する方法で解きます。

## 30秒でつかむ

賃貸物件12件の家賃を、4つの候補から予測します。候補は、面積、築年数、駅までの徒歩（分）、階数です。4つすべてを使うと、手元の12件にはよく合います。ところが、階数のように家賃との関係が弱い候補にも、それらしい係数が付きます。

そこで、係数が大きくなることに罰則を課します。ただし、罰則に絶対値の和を使うと、効き目の弱い候補の係数は小さくなるだけでなく、ちょうど0になります。0になった候補は、予測式から外れます。「どの特徴量を使うか」を選ぶ作業が、係数を求める計算の中に入ります。

- **決めるもの**: 各候補の係数 $x_1,\dots,x_n$（ここでは4つ）
- **良くしたいもの**: 予測と観測のずれの二乗和と、係数の絶対値の和に λ をかけた罰則との合計
- **守ること**: 特になし（制約のない型です。係数に上下限があれば別の型になります）

次の図は、係数を一つだけ取り出して、罰則が何をするかを動かして確かめるものです。この図だけは、家賃の例ではなく、1変数の教材用の問題 $\tfrac12(x-3)^2+\lambda|x|$ を使います。目標の 3 は、ほかの係数を固定したとき、二乗誤差だけなら最小になる位置にあたります。まず「正則化の強さ λ」のスライダーを動かし、橙の点が0に着く λ の値を探してください。灰の点が現在の係数、青緑の点が二乗誤差の勾配だけで進んだ点、橙の点が罰則で0へ縮めた後の点です。

::: explorable proximal-gradient-threshold
灰は現在の係数、青緑は勾配だけで進んだ中間点、橙は0へ縮めた後です。青緑の中間点が薄い帯に入ると、橙の点はちょうど0になります。この1変数の教材用の計算から、家賃の例の係数や、変数選択の正しさは読み取れません。
:::

1. 初期設定（λ=0.8、歩幅 η=0.25）で「1つ進む」（▶）を押すと、灰の 0 から青緑の 0.75 へ進み、橙の 0.55 へ 0.2 だけ縮みます。縮める量は閾値 $\eta\lambda=0.25\times0.8$ です。
2. 「正則化の強さ λ」を 3 にすると、閾値が 0.75 になり、青緑の 0.75 が薄い帯に入って、橙がちょうど0になります。0.75 が閾値以内なら0、超えた分だけが残ります。
3. λ を 0 にすると縮みがなくなり、青緑の点がそのまま次の点になります。λ を 0.8 に戻して「▶ 再生」を押すと、罰則なしの最小点 3 より手前の 2.2 へ近づきます。

λ を上げると、橙の点は連続的に小さくなり、ある値で0に着いたまま動かなくなります。同じように係数を小さくするのに、なぜ絶対値の罰則だけが、ちょうど0に着くのでしょうか。標準形の式と、小さな例の計算で確かめられます。

## 標準形を読む

次の式が表すのは「係数 $x$ を選んで、予測と観測のずれの二乗和の半分と、係数の絶対値の和の λ 倍を足した値を最小にする」です。

$$
\min_{x\in\mathbb{R}^n}\ \tfrac12\|Ax-b\|_2^2+\lambda\|x\|_1,\qquad \|x\|_1=\sum_{j=1}^n |x_j|,\quad \lambda\ge 0
$$

記号は次の意味です。

| 記号 | 意味 | 家賃の例では |
|---|---|---|
| $A$ | 特徴量の行列。行が物件、列が特徴量 | $12\times4$ の行列。各列は平均0、標準偏差1にそろえる |
| $b$ | 予測したい値 | 家賃から平均 $6.267$（万円）を引いた値 |
| $x$ | 決める係数 | 面積、築年数、徒歩、階数の係数 |
| $\lambda$ | 罰則の強さ。大きいほど係数が0へ引かれる | 10（図では0から20まで動かす） |
| $\lVert x\rVert_1$ | 係数の絶対値の和 | $\lambda=10$ の解で $0.739+0.207=0.946$ |

二乗和をデータ数 $m$ で割る形（$\tfrac1{2m}\|Ax-b\|^2+\lambda\|x\|_1$）で書く資料もあります。その形の $\lambda$ は、この式の $\lambda$ の $1/m$ にあたります。$\lambda$ の数値は、式の形ごとに読み替えます。

### 「L1」「スパース」「正則化」の意味

- **L1**: 絶対値の和 $\|x\|_1$ を指します。係数の二乗の和 $\|x\|_2^2$ を使う罰則はL2（ridge）です。
- **スパース**: 多くの係数が0で、0でないものが少ない状態です。家賃の例では、4つのうち0でない係数が2つの解がスパースです。
- **正則化**: 手元のデータへの合わせすぎを抑えるために、係数に罰則を足すことです。$\lambda=0$ なら罰則がなく、[線形最小二乗](#/learn/concept.linear-least-squares)に戻ります。

切片は罰則の対象にしません。そのため、家賃も特徴量の列も、平均を引いてから計算します。例の $b$ が「平均を引いた家賃」なのは、この理由です。

### なぜ角があると0になるのか

係数 $x_j$ だけを動かし、ほかを固定した問題を考えます。二乗誤差の部分は、$x_j$ の二次式です。その二次式の $x_j=0$ での傾きは $-\rho_j$ です。ここで $\rho_j=a_j^\top\bigl(b-\sum_{k\ne j}a_kx_k\bigr)$ は、ほかの係数で説明しきれなかった家賃（残り）と、特徴量 $j$ の列の内積です。

罰則 $\lambda|x_j|$ は、$x_j=0$ で角があります。左へ動けば傾き $-\lambda$、右へ動けば傾き $+\lambda$ で、その間のどの傾きも「罰則が打ち消せる傾き」です。二乗誤差の傾きの大きさ $|\rho_j|$ が $\lambda$ 以下なら、$x_j=0$ のまま動くと目的が増えます。したがって、$x_j=0$ が最小点です。$|\rho_j|$ が $\lambda$ を超えるときだけ、$x_j$ は0から離れます。式で書くと次のとおりです。

$$
x_j=\frac{S_\lambda(\rho_j)}{\|a_j\|_2^2},\qquad
S_\lambda(\rho)=\begin{cases}\rho-\lambda&(\rho>\lambda)\\0&(|\rho|\le\lambda)\\\rho+\lambda&(\rho<-\lambda)\end{cases}
$$

$S_\lambda$ は soft-threshold（軟閾値）と呼ばれ、絶対値の罰則を一歩で処理する演算です。値を $\lambda$ だけ0へ寄せ、$\lambda$ 以内の値は0にします。

L2の罰則 $\tfrac\lambda2x_j^2$ は、$x_j=0$ で傾きが0なので、打ち消せる傾きがありません。そのため解は $\rho_j/(\|a_j\|^2+\lambda)$ となり、$\rho_j=0$ でなければ0になりません。図の「L2（ridge）の係数」が0に着かなかったのは、この理由です。

### 最小点の条件

全体の最小点 $x^\star$ では、残り $r=b-Ax^\star$ について、次が成り立ちます。

$$
a_j^\top r=\lambda\,\mathrm{sign}(x^\star_j)\ \ (x^\star_j\ne0),\qquad
|a_j^\top r|\le\lambda\ \ (x^\star_j=0)
$$

0でない係数の特徴量は、残りとの内積がちょうど $\pm\lambda$ になるまで使われます。0の係数の特徴量は、内積が $\lambda$ に届きません。$x=0$ のとき $r=b$ なので、すべての $|a_j^\top b|$ が $\lambda$ 以下、つまり $\lambda\ge\|A^\top b\|_\infty$ なら、$x=0$ が解です。家賃の例では $\|A^\top b\|_\infty=18.96$ で、図の「19.0 以上なら全部0」はこの値です。

### 保証は大域的、ただし特徴量の正しさは別の話

目的は凸なので、停留点は大域的な最小点です。$A$ の列が一次独立なら、最小点はただ一つに決まります。家賃の例は、12行4列で列が独立です。

一方で、「0にならなかった特徴量が本当に効いている」「0になった特徴量は無関係だ」という保証は、この型には含まれません。選ばれた特徴量は、この $\lambda$ とこのデータで、目的を最小にする組み合わせにすぎません。

## 小さな例

### 家賃の例・設定

12件の物件で、面積（m²）、築年数（年）、駅までの徒歩（分）、階数を並べます。家賃（万円）は、乱数で次の式から作りました。階数は家賃に効かないものとして作っています。

$$
\text{家賃}=3+0.20\times\text{面積}-0.12\times\text{築年数}-0.25\times\text{徒歩}+\text{誤差}\quad(\text{誤差の標準偏差 }0.8)
$$

以下の式、表、コードは、この12件と $\lambda=10$ に対応します。最初のコードは、データを標準化し、$A^\top b$ と、後で刻みに使う $L$（$A^\top A$ の最大固有値）を出します。

```python
import numpy as np

area = [20, 36, 19, 27, 45, 57, 35, 44, 25, 37, 39, 39]
age = [8, 14, 25, 3, 17, 9, 28, 2, 3, 28, 7, 22]
walk = [2, 7, 3, 15, 11, 6, 10, 11, 7, 12, 12, 4]
floor = [3, 4, 7, 2, 4, 4, 1, 4, 1, 2, 8, 8]
rent = np.array([6.0, 6.3, 4.6, 3.9, 6.8, 11.1, 4.1, 9.9, 5.4, 3.8, 7.3, 6.0])
names = ["面積", "築年数", "徒歩", "階数"]

X = np.array([area, age, walk, floor], dtype=float).T
A = (X - X.mean(axis=0)) / X.std(axis=0)  # 各列を平均0、標準偏差1にそろえる
b = rent - rent.mean()  # 家賃も平均0にして、切片を罰則の外に置く

Atb = A.T @ b
print(Atb.round(2), np.abs(Atb).max().round(2))
# [ 18.96 -12.8   -3.05   7.18] 18.96
L = np.linalg.eigvalsh(A.T @ A).max()
print(L.round(3))  # 17.333
```

$A^\top b$ は、各特徴量と家賃の内積です。面積が $18.96$ で最も大きく、築年数は負の $-12.8$、徒歩は $-3.05$、階数は $7.18$ です。

### 家賃の例・原点からの一歩を手で追う

係数を全部0から始めます。二乗誤差の勾配は $\nabla f(0)=-A^\top b$ で、刻み $1/L$ の勾配の一歩は、各係数を $z_j=a_j^\top b/L$ へ動かします。そのあとに、閾値 $\lambda/L=10/17.333=0.577$ の soft-threshold をかけます。

| 特徴量 | $a_j^\top b$ | $z_j=a_j^\top b/L$ | $\lvert z_j\rvert-0.577$ | 一歩後の係数 |
|---|---:|---:|---:|---:|
| 面積 | 18.96 | 1.094 | 0.517 | 0.517 |
| 築年数 | -12.80 | -0.739 | 0.162 | -0.162 |
| 徒歩 | -3.05 | -0.176 | -0.401 | 0 |
| 階数 | 7.18 | 0.414 | -0.163 | 0 |

$|z_j|$ が閾値 $0.577$ を超えた面積と築年数だけが、超えた分を残して残ります。徒歩と階数は閾値以内で、一歩目でちょうど0になります。同じ計算をコードで確かめます。

```python
def soft(z, t):
    return np.where(np.abs(z) <= t, 0.0, z - np.sign(z) * t)


lam = 10.0
z = Atb / L  # 原点 x=0 からの勾配の一歩（刻み 1/L）
print(z.round(3), round(lam / L, 3))
# [ 1.094 -0.739 -0.176  0.414] 0.577
print(soft(z, lam / L).round(3))
# [ 0.517 -0.162  0.     0.   ]
```

### 家賃の例・反復を追う

この一歩を繰り返す方法が、近接勾配法（ISTA）です。各反復は、現在の係数で勾配の一歩を踏み、soft-threshold をかけます。コードは後の節に置きます。反復の様子は次のとおりです。目的値は $\tfrac12\|Ax-b\|^2+10\|x\|_1$ で、$x=0$ では $28.983$ です。

| 反復 | 面積 | 築年数 | 徒歩 | 階数 | 目的値 |
|---:|---:|---:|---:|---:|---:|
| 1 | 0.517 | -0.162 | 0 | 0 | 25.696 |
| 2 | 0.672 | -0.199 | 0 | 0 | 25.411 |
| 3 | 0.719 | -0.206 | 0 | 0 | 25.385 |
| 4 | 0.733 | -0.207 | 0 | 0 | 25.383 |
| 8 | 0.739 | -0.207 | 0 | 0 | 25.383 |

0になる係数は、1回目の反復で決まりました。2回目以降は、0でない2つの係数が $0.739$ と $-0.207$ に近づくだけです。0でない係数の組（支え）が何回目の反復で決まるかは、問題によって違います。

最終の解 $(0.739,\ -0.207,\ 0,\ 0)$ の目的値 $25.38$ は、二乗誤差の半分 $15.92$ と、罰則 $10\times0.946=9.46$ の合計です。$\lambda=0$ の二乗誤差は $5.08$、$\lambda=10$ では $31.84$ です。罰則を課すと、手元のデータへの誤差は増えます。

### 家賃の例・0になる条件を確かめる

最小点の条件を、$\lambda=10$ の解で確かめます。残り $r=b-Ax^\star$ との内積 $A^\top r$ を出します。

```python
lam = 10.0
x_star, _ = ista(A, b, lam, tol=1e-12)  # ista は後の節で定義
r = b - A @ x_star
print(x_star.round(3), (A.T @ r).round(2))
# [ 0.739 -0.207  0.     0.   ] [ 10.   -10.    -6.02   6.24]
```

0でない係数の面積と築年数では、内積がちょうど $+10$ と $-10$（$\pm\lambda$）です。徒歩の $-6.02$ と階数の $6.24$ は、絶対値が $\lambda=10$ に届かないので、係数が0のままで条件を満たします。

### 家賃の例・L1とL2

同じ12件で、L1とL2の係数を並べます。L2は $\tfrac12\|Ax-b\|^2+\tfrac\lambda2\|x\|^2$ の最小点です。

| $\lambda$ | L1: 面積 | 築年数 | 徒歩 | 階数 |
|---:|---:|---:|---:|---:|
| 0 | 1.77 | -1.18 | -0.90 | 0.21 |
| 2 | 1.55 | -0.97 | -0.66 | 0.12 |
| 5 | 1.23 | -0.66 | -0.30 | 0 |
| 8 | 0.90 | -0.37 | 0 | 0 |
| 10 | 0.74 | -0.21 | 0 | 0 |
| 15 | 0.33 | 0 | 0 | 0 |

| $\lambda$ | L2: 面積 | 築年数 | 徒歩 | 階数 |
|---:|---:|---:|---:|---:|
| 0 | 1.77 | -1.18 | -0.90 | 0.21 |
| 2 | 1.45 | -0.99 | -0.65 | 0.26 |
| 5 | 1.16 | -0.80 | -0.45 | 0.27 |
| 8 | 0.97 | -0.67 | -0.34 | 0.26 |
| 10 | 0.88 | -0.61 | -0.29 | 0.25 |
| 15 | 0.71 | -0.49 | -0.21 | 0.22 |

$\lambda=0$ の行は、二つとも線形最小二乗の解で同じです。L1は $\lambda=5$ で階数、$\lambda=8$ で徒歩が0になります。L2は、$\lambda=15$ でも4つとも0でなく、階数は一度増えてから減ります。L1とL2の $\lambda$ は罰則の形が違うので、同じ数値の行は同じ強さを意味しません。

次の図は、同じ12件で $\lambda$ を0から20まで連続的に動かしたときの、4つの係数の経路です。パネル「L1（lasso）の係数」と「L2（ridge）の係数」を見比べます。線はすべて実線で、色は面積が緑、築年数が青、徒歩が橙、階数が灰です。白抜きの丸は、L1の係数がちょうど0になる $\lambda$ を示します。

![家賃の例で、罰則の強さ λ を0から20まで上げたときの4つの係数。L1では階数、徒歩、築年数、面積の順に係数が0に着き、L2ではどの係数も0に着かない。](./figures/l1-sparse-regularization-path.svg "家賃12件、標準化した4つの特徴量：λ と係数（L1とL2のλは意味が違うので、横軸の同じ値で強さは比べられません）")

パネル「L1（lasso）の係数」では、灰（階数）が $\lambda=4.8$、橙（徒歩）が $7.2$、青（築年数）が $12.6$、緑（面積）が $19.0$ で0の線に着き、そのまま0にとどまります。0の線の上で重なった部分は、最後まで残る緑が上に描かれます。パネル「L2（ridge）の係数」では、$\lambda=20$ でも4本とも0から離れています。$\lambda$ が $19.0$（正確には $18.96$）以上だと、L1の係数はすべて0になり、予測は家賃の平均だけになります。

### 家賃の例・三つの方法で同じ解を求める

同じ $\lambda=10$ を、近接勾配法（ISTA）、FISTA、座標降下法で解きます。停止条件は、ISTAとFISTAが「一歩で動いた長さが $10^{-8}$ 未満」、座標降下法が「一掃引での係数の最大変化が $10^{-8}$ 未満」です。

| 方法 | 反復 | 解との差の最大 | 着いた解 |
|---|---:|---:|---|
| ISTA | 17 | $2\times10^{-9}$ | $(0.739,\ -0.207,\ 0,\ 0)$ |
| FISTA | 24 | $6\times10^{-9}$ | 同じ |
| 座標降下法 | 5（掃引） | $2\times10^{-14}$ | 同じ |

停止条件を $10^{-4}$ にすると、反復は 9、11、3 です。三つとも、同じ支えと同じ係数に着きました。ただし、この表はこの4変数の問題での回数です。反復の単位も違います。ISTAの1反復は $A$ と $A^\top$ の積を1回ずつ使い、座標降下法の1掃引は4つの係数を順に更新します。FISTAは加速の理論がありますが、この小さな問題では反復が増えました。このことから、方法の優劣は読み取れません。

## つまずきやすい点

- **特徴量の単位をそろえずに $\lambda$ をかける**: 罰則は係数の大きさに課されるので、単位が変わると、同じ特徴量でも罰則の重さが変わります。家賃の例で、平均を引くだけで標準偏差をそろえない場合、$\lambda=10$ で残る特徴量は面積、築年数、徒歩の3つです（標準化では面積と築年数の2つ）。徒歩の単位を分から時間に変えると、残る特徴量が面積、築年数、階数に入れ替わります。徒歩の列が $1/60$ 倍になり、同じ予測を出す係数が60倍になるので、罰則が重くなって0になりました。列は標準偏差をそろえてから解きます。そろえないと、収束も遅くなります（17回に対して 119回と 254回）。
- **係数が0なら、その特徴量は家賃と無関係だと読む**: 家賃の式には、徒歩が $-0.25$（万円/分）の効果として入っています。それでも $\lambda=8$ で徒歩の係数は0になります。この時点では、面積と築年数の組み合わせで、罰則込みの目的が小さくなるからです。0は、「この $\lambda$ とこのデータでは、ほかの特徴量で足りる」という意味です。逆に、階数は式に入っていないのに、$\lambda=0$ では $0.21$ の係数が付いています。
- **似た特徴量があるのに、どれが選ばれたかを決まった結果と読む**: 面積（m²）と同じ面積を坪で表した列を両方入れます（1坪=3.3058 m² の逆数 $0.3025$ をかけた列）。標準化すると二つの列は同じです。$\lambda=10$ のISTAは、二つの列に $0.37$ ずつ配分し、座標降下法は最初の列に $0.739$ を全部入れ、もう一つの列を0にします。目的値はどちらも $25.383$ で、同じです。この型は、列が独立でないと解が一つに決まらず、選ばれる特徴量は方法の動きに依存します。
- **$\lambda$ の数値だけで、何個残るかを決める**: 同じ $\lambda=10$ でも、家賃を万円ではなく円で入れると、$A^\top b$ が $10^4$ 倍になり、$\lambda_{\max}$ も $10^4$ 倍の約 $1.9\times10^5$ になります。そのとき $\lambda=10$ は小さすぎて、4つの係数が全部残り、解は罰則なしの線形最小二乗とほぼ同じ $(1.77,\ -1.18,\ -0.90,\ 0.21)$ になります。残る個数は、$\lambda$ をデータごとの $\lambda_{\max}$ との比で見て決めます。

## 課題から定式化する

「家賃に効く特徴量を選びたい」という課題だけでは、まだこの型とは決まりません。次の4つを順に確かめます。

1. **何を決めるか**: 各候補の係数です。候補の数 $n$ が多く、使う特徴量を絞りたいことを確かめます。
2. **予測をどう作るか**: 予測が、係数について線形（特徴量の線形結合）であることを確かめます。係数が指数や分母に入るなら、別の型です。
3. **どのずれを減らすか**: 予測と観測のずれの二乗和です。外れ値が混ざるなら、損失を変える型を考えます。
4. **何を罰するか**: 使う特徴量の個数を直接数えるのは難しいので、係数の絶対値の和 $\lambda\|x\|_1$ で代わりに抑えます。$\lambda$ は、手元の二乗誤差では選べません。家賃の例で、手元の二乗誤差は $\lambda=0$ で最小（$5.08$）で、$\lambda$ を上げるほど増える（$\lambda=10$ で $31.84$）からです。別に取り置いたデータでの誤差など、手元の誤差と別の物差しで選びます。

こうして、係数について線形な予測、二乗のずれ、係数の絶対値の和の罰則が揃えば、この記事の型になります。

## 困りごとから関連する問題へ

実際の課題で、次の条件が必要になったら、対応する記事へ進めます。

- 特徴量が少なく、全部使ってよい → [線形最小二乗](#/learn/concept.linear-least-squares)
- 一部の物件の家賃が大きく外れていて、係数がそこへ引っ張られる → [外れ値を含む回帰（robust regression）](#/formulations/PA034)
- 特徴量を選ぶより、似た特徴量の係数を安定させたい、またはデータだけで決まらない → [正則化つきの逆問題](#/formulations/PA055)
- 係数に上下限や合計の条件がある → [凸二次計画](#/learn/concept.convex-quadratic-program)
- 予測が係数の指数や分母に入る → [非線形最小二乗](#/learn/concept.nonlinear-least-squares)
- 使う特徴量の個数をちょうど $k$ 個以下にしたい → [混合整数線形計画](#/learn/concept.mixed-integer-linear-program)
- 罰則が絶対値の和ではなく、別の角のある凸関数 → [非滑らかな凸複合の最小化](#/formulations/PA010)

### L1正則化つき回帰と関連する問題の関係

- [非滑らかな凸複合の最小化](#/formulations/PA010): この型は、その特別な場合です。滑らかな凸の部分が $\tfrac12\|Ax-b\|^2$、角のある凸の部分が $\lambda\|x\|_1$ で、後者の近接作用素が soft-threshold になります。近接作用素が安く計算できる別の凸関数なら、同じ解き方が使えます。
- [線形最小二乗](#/learn/concept.linear-least-squares): $\lambda=0$ にすると、この型は線形最小二乗です。家賃の例の $\lambda=0$ の行（$1.77,\ -1.18,\ -0.90,\ 0.21$）がその解です。
- [正則化つきの逆問題](#/formulations/PA055): 罰則を係数の二乗にすると、L2です。L2は、係数をちょうど0にしません。データだけで係数が決まらないときに解を安定させる役割で、特徴量を選ぶ役割ではありません。
- [外れ値を含む回帰](#/formulations/PA034): 名前は似ていますが、L1を置く場所が違います。この記事のL1は係数への罰則で、損失は二乗のままです。外れ値に強い回帰は、損失のほうを変えます。
- [凸二次計画](#/learn/concept.convex-quadratic-program): 係数を $x=x^+-x^-$（$x^+,x^-\ge0$）に分けると、$\|x\|_1$ を $\mathbf{1}^\top(x^++x^-)$ に書き直せます。目的は凸二次、制約は非負だけになり、二次計画として解けます。変数が2倍になります。
- [混合整数線形計画](#/learn/concept.mixed-integer-linear-program): 個数を直接制限する問題（best subset）は整数変数が要り、L1の問題より難しくなります。L1は、その個数を凸な絶対値の和で代用したものです。

## 数値計算の方法を選ぶ

どの方法も、角のある罰則を、勾配の代わりに閾値の演算や座標ごとの閉形式で処理します。凸なので、収束した点は大域的な最小点です。

| 系統 | 進み方 | 向く条件・避ける条件 |
|---|---|---|
| [近接勾配法](#/learn/proximal-gradient)（ISTA） | 勾配の一歩の後に soft-threshold | 実装が短く、刻みに $A^\top A$ の最大固有値 $L$ の見積もりが要ります。反復は多くなることがあります |
| [FISTA](#/learn/fista) | 近接勾配法に外挿を足す | 目的値の誤差の減り方が、理論上 $O(1/k)$ から $O(1/k^2)$ になります。小さな問題では、反復が増えることもあります |
| [座標降下法](#/learn/coordinate-descent) | 係数を一つずつ、閉形式で更新 | 刻みが要りません。列が疎で多いとき、一掃引が安く済みます |
| [ADMM](#/learn/admm) | 係数を二つの変数に分け、線形方程式と soft-threshold を交互に | 分散や制約を足したいときに使えます。罰則パラメータ $\rho$ の調整が要ります |
| [劣勾配法](#/learn/subgradient) | 劣勾配の向きへ一歩 | 実装は単純ですが、係数がちょうど0にならず、遅い方法です |

ライブラリに既定の方法がある場合も、それは実装上の既定であり、この型で最適だという根拠にはなりません。選ぶときは、特徴量の数、行列が疎か、$\lambda$ をいくつも試すか、を確かめます。

次のコードは、ISTA、FISTA、座標降下法を実装し、小さな例の表を再現します。`soft` と `A`、`b` は上のコードのものです。

```python
def objective(x, lam):
    return 0.5 * np.sum((A @ x - b) ** 2) + lam * np.abs(x).sum()


def ista(A, b, lam, tol=1e-8, fista=False):
    L = np.linalg.eigvalsh(A.T @ A).max()
    x = np.zeros(A.shape[1])
    y, t = x.copy(), 1.0
    for k in range(1, 100001):
        base = y if fista else x
        x_new = soft(base - A.T @ (A @ base - b) / L, lam / L)
        if fista:
            t_new = (1 + np.sqrt(1 + 4 * t * t)) / 2
            y, t = x_new + (t - 1) / t_new * (x_new - x), t_new
        if np.linalg.norm(x_new - x) < tol:
            return x_new, k
        x = x_new
    return x, k


def cd(A, b, lam, tol=1e-8):
    x = np.zeros(A.shape[1])
    r = b.copy()
    c = (A**2).sum(axis=0)
    for sweep in range(1, 100001):
        move = 0.0
        for j in range(A.shape[1]):
            x_new = soft(A[:, j] @ r + c[j] * x[j], lam) / c[j]
            r += A[:, j] * (x[j] - x_new)
            move = max(move, abs(x_new - x[j]))
            x[j] = x_new
        if move < tol:
            return x, sweep
    return x, sweep


print("lam  lasso | ridge")  # 見出し行
for lam in [0, 2, 5, 8, 10, 15]:
    lasso, _ = ista(A, b, lam)
    ridge = np.linalg.solve(A.T @ A + lam * np.eye(4), A.T @ b)
    print(f"{lam:>3}", lasso.round(2), "|", ridge.round(2))
# lam  lasso | ridge
#   0 [ 1.77 -1.18 -0.9   0.21] | [ 1.77 -1.18 -0.9   0.21]
#   2 [ 1.55 -0.97 -0.66  0.12] | [ 1.45 -0.99 -0.65  0.26]
#   5 [ 1.23 -0.66 -0.3   0.  ] | [ 1.16 -0.8  -0.45  0.27]
#   8 [ 0.9  -0.37  0.    0.  ] | [ 0.97 -0.67 -0.34  0.26]
#  10 [ 0.74 -0.21  0.    0.  ] | [ 0.88 -0.61 -0.29  0.25]
#  15 [0.33 0.   0.   0.  ] | [ 0.71 -0.49 -0.21  0.22]
```

L1の列は `ista` が返す係数で、0は `soft` が返す厳密な0です。L2の列は連立一次方程式 $(A^\top A+\lambda I)x=A^\top b$ の解です。

次のコードは、反復の表と、三つの方法の反復回数を出します。

```python
lam = 10.0
x = np.zeros(4)
for k in range(1, 5):
    x = soft(x - A.T @ (A @ x - b) / L, lam / L)
    print(k, x.round(3), round(objective(x, lam), 3))
# 1 [ 0.517 -0.162  0.     0.   ] 25.696
# 2 [ 0.672 -0.199  0.     0.   ] 25.411
# 3 [ 0.719 -0.206  0.     0.   ] 25.385
# 4 [ 0.733 -0.207  0.     0.   ] 25.383

ref = cd(A, b, lam, 1e-13)[0]
for name, (x, k) in {
    "ISTA": ista(A, b, lam),
    "FISTA": ista(A, b, lam, fista=True),
    "CD": cd(A, b, lam),
}.items():
    print(name, k, f"{np.abs(x - ref).max():.0e}", x.round(3))
# ISTA 17 2e-09 [ 0.739 -0.207  0.     0.   ]
# FISTA 24 6e-09 [ 0.739 -0.207  0.     0.   ]
# CD 5 2e-14 [ 0.739 -0.207  0.     0.   ]
```

三つとも、同じ支え $\{$面積, 築年数$\}$ に着き、解との差は停止条件の程度です。`CD` の回数は、反復ではなく掃引です。

次のコードは、二次計画への書き直しと、劣勾配法を試します。`x_plus - x_minus` に分けた8変数の問題を、非負の上下限つきの最小化として解くと、同じ解が出ます。

```python
from scipy.optimize import minimize


def split_objective(v):
    return 0.5 * np.sum((A @ (v[:4] - v[4:]) - b) ** 2) + lam * v.sum()


res = minimize(
    split_objective,
    np.ones(8),
    method="L-BFGS-B",
    bounds=[(0, None)] * 8,
    options={"ftol": 1e-14, "gtol": 1e-10},
)
print((res.x[:4] - res.x[4:]).round(3), round(res.fun, 4))
# [ 0.739 -0.207  0.     0.   ] 25.3829

x = np.zeros(4)
for k in range(1, 5001):
    g = A.T @ (A @ x - b) + lam * np.sign(x)  # 劣勾配（0では罰則の項を0とする）
    x = x - 0.05 / np.sqrt(k) * g
print(x.round(4), (x == 0).sum(), round(objective(x, lam), 4))
# [ 7.396e-01 -2.082e-01 -6.000e-04 -9.000e-04] 0 25.4007
```

分けた8変数の解は、$x^+-x^-$ が $(0.739,\ -0.207,\ 0,\ 0)$ で、目的値 $25.3829$ です。劣勾配法は、$5000$ 回の反復後も、0になった係数が一つもなく、徒歩と階数は $-0.0006$ と $-0.0009$ に残りました。目的値も $25.4007$ で、最小の $25.3829$ には届いていません。0になるべき係数を0にしたいときは、閾値の演算や座標ごとの閉形式を使う方法が向いています。

次のコードは、つまずきやすい点の数値を出します。

```python
Xc = X - X.mean(axis=0)  # 中心化だけで、標準偏差はそろえない
variants = {
    "標準化": A,
    "分のまま": Xc,
    "徒歩を時間": Xc * np.array([1, 1, 1 / 60, 1]),
}
for label, Z in variants.items():
    x, k = ista(Z, b, 10.0)
    print(label, (x != 0).astype(int), k)
# 標準化 [1 1 0 0] 17
# 分のまま [1 1 1 0] 119
# 徒歩を時間 [1 1 0 1] 254

tsubo = X[:, 0] * 0.3025  # 面積を坪で表した列
A2 = np.c_[A, (tsubo - tsubo.mean()) / tsubo.std()]
for solver in (ista, cd):
    x, k = solver(A2, b, 10.0)
    obj = 0.5 * np.sum((A2 @ x - b) ** 2) + 10.0 * np.abs(x).sum()
    print(solver.__name__, x.round(3), k, round(obj, 3))
# ista [ 0.37  -0.207  0.     0.     0.37 ] 27 25.383
# cd [ 0.739 -0.207  0.     0.     0.   ] 5 25.383

x, k = ista(A, b * 1e4, 10.0)  # 家賃を円にする
print((x / 1e4).round(3), (x != 0).sum(), k)
# [ 1.768 -1.181 -0.903  0.207] 4 64
```

1つ目の出力の 1 と 0 は、係数が0でないか0かを表します。2つ目では、ISTAが二つの同じ列に配分し、座標降下法が一つに寄せますが、目的値は同じです。3つ目は、家賃を円にすると、$\lambda=10$ が小さすぎて、4つの係数が全部残る様子です。
