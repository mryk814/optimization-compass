パン屋が、今日の小麦粉とバターで、食パンとクロワッサンを何個ずつ焼くかを決めます。
クロワッサンの方が高く売れますが、バターをたくさん使います。高く売れる方だけを焼けば、売上はいちばん大きくなるのでしょうか。

| | 食パン1個 | クロワッサン1個 | 在庫 |
|---|---:|---:|---:|
| 小麦粉 | 3 | 2 | 18 |
| バター | 1 | 3 | 13 |
| 売上 | 3 | 4 | |

単位は小麦粉が100g、バターが10g、売上が百円です。話を簡単にするため、1.5個のような半端な個数も焼けることにします。

## 図で見たことを式にする

食パンを $x_1$ 個、クロワッサンを $x_2$ 個焼くとします。図の三つの部品は、そのまま式の三つの部分になります。

$$
\max_{x_1,\,x_2}\; 3x_1+4x_2 \quad \text{s.t.}\quad 3x_1+2x_2\le 18,\quad x_1+3x_2\le 13,\quad x_1\ge 0,\; x_2\ge 0
$$

- **決めるもの**（動かした点）: $x_1$ と $x_2$
- **良くしたいもの**（橙の線）: 売上 $3x_1+4x_2$
- **守ること**（青緑の範囲と2本の棒）: 小麦粉 $3x_1+2x_2\le 18$、バター $x_1+3x_2\le 13$、個数は0以上

どの式も「個数 × 決まった数」の足し算だけでできています。食パンを1個増やすと、売上はいつも3増え、小麦粉はいつも3減ります。
売上がどの向きにも一定の割合で変わり、範囲の境界が直線だけなので、線を押していって最後に残るのは範囲の角になります。辺全体が残る場合もありますが、そのときも両端の角は最良です。
このように、目的も制約も一次式で書ける問題が線形計画（LP）です。

## 標準形と記号

教科書やソルバーの説明では、線形計画を次の形に書きます。資源の上限 $b$ を超えない範囲で、費用 $c^\top x$ が最も小さい量 $x$ を選ぶ、と読みます。

$$
\min_{x}\; c^\top x \quad \text{s.t.}\quad Ax\le b,\; x\ge 0
$$

| 記号 | 意味 | パン屋の例では |
|---|---|---|
| $x$ | 決める量（$n$ 個） | 食パンとクロワッサンの個数 |
| $c$ | 量1単位あたりの費用 | 1個あたりの売上の符号を反転した $(-3,\,-4)$ |
| $A$ | 量1単位が使う資源の量 | 1個あたりの小麦粉とバターの使用量 |
| $b$ | 資源の上限 | 在庫 $(18,\,13)$ |

最大化は、目的に $-1$ を掛けて最小化に直します。等式の制約は2本の不等式に、負にもなる変数は二つの非負の変数の差に書き換えると、この形に戻せます。

## 見分け方

次のどちらも当てはまれば、線形計画を最初に疑います。

- 量を配分する問題で、費用も制約も、量の足し算と定数倍で書ける（配合、輸送、生産量）
- 原料・時間・予算に上限がある、または需要に下限がある

次の兆候があれば、線形計画だけでは書けません。

- 個数や台数が整数でないと意味がない → [混合整数線形計画](#/learn/concept.mixed-integer-linear-program)
- 1個でも作ると発生する固定費がある → 作るかどうかの0-1変数が要るので、同じく[混合整数線形計画](#/learn/concept.mixed-integer-linear-program)
- 量の二乗や積が目的に入る（ばらつき、面積）→ [凸二次計画](#/learn/concept.convex-quadratic-program)
- 単価が量によって変わる → 量が増えるほど単価が上がる凸な区分線形の費用は、補助変数を足せば線形計画で書けます。量が増えるほど単価が下がる割引は非凸で、整数変数が要ります

## 近い定式化

- **より一般の形: [凸二次計画](#/learn/concept.convex-quadratic-program)**。目的に二次の項 $\tfrac12 x^\top Qx$ を足した形で、$Q=0$ なら線形計画です。$Q\ne 0$ のとき、最適解は角とは限りません。
- **より一般の形: [混合整数線形計画](#/learn/concept.mixed-integer-linear-program)**。一部の変数を整数に限った形で、整数の変数が一つもなければ線形計画です。逆に、整数の条件を外す（緩和する）と線形計画になり、その最適値は元の問題の限界を与えます。最小化なら下界、パン屋のような最大化なら上界です。
- **より特殊な形: [最小費用流](#/learn/concept.network-flow)**。各列が「ある地点から出て別の地点へ入る流れ」を表す線形計画です。供給と容量が整数なら、整数の最適な角が存在します。
- **書き換えると線形計画になる形: [確率計画](#/learn/concept.stochastic-programming)**。起こりうる場合（シナリオ）が有限個で、後から決める対応も線形なら、全部の場合を並べた一つの大きな線形計画になります。

## 資源の値段（双対値）

$(4,3)$ の売上 $24$ より良い計画がないことは、角を比べなくても確かめられます。
小麦粉とバターの1単位に、値段 $y_1$ と $y_2$ を付けます。どちらの品目でも「1個が使う材料の値段の合計が、1個の売上以上」になる値段だけを考え、その中で在庫全体の値段が最も小さいものを探します。これが双対問題です。

$$
\min_{y_1,\,y_2}\; 18y_1+13y_2 \quad \text{s.t.}\quad 3y_1+y_2\ge 3,\quad 2y_1+3y_2\ge 4,\quad y_1\ge 0,\; y_2\ge 0
$$

二つの「以上」の条件があるので、どの計画の売上も、その計画が使う材料の値段の合計以下です。使う材料は在庫以下なので、売上は在庫全体の値段 $18y_1+13y_2$ も超えられません。条件を満たす値段は、どれも売上の上限を与えます。
この例で最も小さい上限は $y=(5/7,\,6/7)$ のときの $18\cdot\tfrac57+13\cdot\tfrac67=24$ です。上限と $(4,3)$ の売上が一致するので、$24$ より良い計画はありません。この値段を双対値、一致することを強双対性と呼びます。

双対値は、在庫を1単位増やしたときの売上の増え方でもあります。バターを $14$ にすると、最大の売上は $24+\tfrac67\approx 24.86$ です。
ただし、この読み方が成り立つのは、使い切る材料の組み合わせが変わらない範囲だけです（下の「双対値の外挿」）。
在庫を動かして確かめる図は、[Primal Simplex法](#/learn/primal-simplex)の記事にあります。

## 解き方の系統

線形計画は凸なので、見つかった局所解はそのまま大域解です。違いは、どこを通って進み、何を計算に使うかにあります。どれが速いかは問題とソルバーの設定によるので、順位は付けません。

- **[シンプレックス法](#/learn/primal-simplex)**: 範囲の角から隣の角へ、目的が良くなる向きに移ります。角をすべて調べるわけではないので、変数が多い問題にも使えます。前回の解から再開しやすく、整数計画の内部で使われます。
- **[内点法（障壁法）](#/learn/barrier-lp-qp)**: 範囲の内部を通って最適解へ近づきます。各反復で線形方程式を解きます。角の解が要るときは、最後に近くの角へ移す後処理（クロスオーバー）を行います。
- **[一次法（PDLP）](#/learn/pdlp)**: 行列とベクトルの積だけで進みます。行列を分解しないので、分解が重い問題で候補になります。答えの精度は停止条件で決まります。

## Pythonで解く

`scipy.optimize.linprog`（内部はHiGHS）は最小化を解くので、売上の符号を反転して渡します。

```python
from scipy.optimize import linprog

# 最大化 3x1 + 4x2 を、最小化 -3x1 - 4x2 に直す
result = linprog(
    c=[-3, -4],
    A_ub=[[3, 2], [1, 3]],
    b_ub=[18, 13],
    bounds=[(0, None), (0, None)],
    method="highs",
)
print(result.status, result.x, -result.fun)  # 0 [4. 3.] 24.0
print(result.ineqlin.marginals.round(3))  # [-0.714 -0.857]
```

`marginals` は最小化の向きで表した双対値なので、符号が反転しています。絶対値が $5/7$ と $6/7$ に一致します。

## つまずきやすい点

- **終了状態を読まない**: バターの在庫を誤って $-1$ と入力すると、`linprog` は `status=2`（実行不能）を返し、`x` は `None` です。在庫の2行を両方書き忘れると、`status=3`（非有界）です。売上を読む前に `status` を確かめます。どちらも、まず制約の書き間違いを疑います。データや条件が本当にそのとおりの場合もあるので、[制約の分類](#/learn/concept.constraint-class)で、どの条件が範囲を決めているかを確かめます。
- **小数解の丸め**: バターの在庫が $12$ だと、線形計画の答えは $(30/7,\,18/7)\approx(4.29,\,2.57)$、売上は約 $23.1$ です。四捨五入した $(4,3)$ はバターを $13$ 使うので焼けません。個数を整数に限ったときの最良は $(3,3)$ の $21$ です。在庫 $13$ で答えが整数になったのは、たまたまです。
- **単位で双対値の数字が変わる**: 小麦粉をg単位で書くと（係数 $300,\,200$、在庫 $1800$）、最適な焼き方は同じ $(4,3)$ ですが、小麦粉の双対値は1gあたり $1/140\approx 0.0071$ になります。100gあたりに直すと $5/7$ で、同じ価値です。双対値を比べる前に単位をそろえます。
- **双対値の外挿**: 小麦粉の在庫を $18$ から $30$ に増やすと、売上は $24+12\cdot\tfrac57\approx 32.6$ で、値段 $5/7$ の見積もりどおりです。ところが在庫が $39$ に達すると、売上は $39$ から増えなくなります。在庫 $45$ での見積もり $24+27\cdot\tfrac57\approx 43.3$ は外れます。在庫を大きく変えたときは、解き直します。
