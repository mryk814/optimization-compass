線形計画は、決める量に比例する費用の合計を、同じく比例と足し算だけで書ける不等式を守りながら最小にする定式化です。最適解は可行領域の頂点に現れ、双対によって大域最適を確かめられます。

## 30秒でつかむ

パン屋が、小麦粉とバターの在庫の範囲で、食パンとクロワッサンを何個ずつ焼くかを考えます。
売上は個数に比例します。使う小麦粉の量も、個数に比例します。
このように、目的も制約も「量 × 係数」の足し合わせで書けるとき、問題は線形計画（LP）になります。

- **決めるもの**: 各品目の生産量、各経路の輸送量のような連続の量
- **良くしたいもの**: 量に比例する費用や利益の合計
- **守ること**: 量に比例する資源の使用量が、上限を超えないこと

比例と足し算だけで書けるので、答えは可行領域の角（頂点）に現れます。
さらに、資源の側から見た問題（双対問題）の値が最良の売上と一致すれば、それより良い計画がないことを確かめられます。

最初に、このパン屋の問題で、最良の焼き方がどこに現れるかを動かして確かめます。
青緑の四角形は、在庫の範囲で焼ける（食パン, クロワッサン）の個数の組です。数値は、後の「小さな例」の表と同じです。
「係数 c₂（クロワッサン1個の売上）」のつまみを、4から1へ下げてみてください。

::: explorable lp-vertex-walk
この図は「なぜ頂点だけを調べれば最良の焼き方が見つかるのか」を確かめるためのものです。橙の直線は、いまの位置で売上が等しい点の集まりで、橙の丸は原点から隣の頂点へ移っていく位置です。紺のひし形はドラッグか矢印キーで四角形の中を動かせ、その点の売上を表示します。在庫は記事の値に固定し、1個あたりの売上だけを動かします。実際のソルバーの手順や速さは示しません。
:::

1. 初期設定（$c=(3,4)$）では、最良の頂点は $(4,3)$ で、売上は $z=24$ です。頂点の表では、ほかの頂点の売上も読めます。原点は $0$、$(6,0)$ は $18$、$(0,13/3)$ は約 $17.3$ です。
2. 「係数 c₂」を $1$ にすると、最良の頂点は $(6,0)$ に切り替わり、売上は $18$ です。$(4,3)$ の売上は $3\cdot4+1\cdot3=15$ に下がります。原点からは1回の移動で着きます。
3. 「係数 c₂」を $2$ にすると、$(6,0)$ と $(4,3)$ の売上がどちらも $18$ になり、二つを結ぶ辺全体が最適になります。このとき橙の直線は、小麦粉の線 $3x_1+2x_2=18$ と重なります。
4. どの係数でも、紺のひし形を四角形の中で動かした売上は、最良の頂点の売上を超えません。

なぜ最良の点は、いつも四角形の角に現れるのでしょうか。
それを確かめるために、問題を式で書きます。

## 標準形を読む

線形計画は、量に比例する費用の合計を最も小さくする問題です。ただし、量に比例する資源の使用量は上限を超えてはいけません。
決める量を並べたベクトルを $x$ とすると、次の形に書けます。

$$
\min_{x}\; c^\top x \quad \text{s.t.}\quad Ax\le b,\; x\ge 0
$$

式は「資源の上限 $b$ を超えない範囲で、費用 $c^\top x$ を最も小さくする量 $x$ を選ぶ」と読みます。

| 記号 | 意味 | パン屋の例では |
|---|---|---|
| $x$ | 決める量（$n$ 個） | 食パンとクロワッサンの個数 |
| $c$ | 量1単位あたりの費用 | 1個あたり売上の符号を反転したもの |
| $A$ | 量1単位が使う資源の量 | 1個あたりの小麦粉とバターの使用量 |
| $b$ | 資源の上限 | 在庫の量 |

最大化したいときは、目的に $-1$ を掛けて最小化に直します。
等式制約や、負にもなる変数も、変数の置き換えで同じ形へ戻せます。
ソルバーごとに受け付ける形は少しずつ違いますが、上の置き換えで互いに書き直せます。

## 小さな例

食パンを $x_1$ 個、クロワッサンを $x_2$ 個焼くとします。単位は小麦粉が100g、バターが10g、売上が百円です。

| | 食パン | クロワッサン | 在庫 |
|---|---:|---:|---:|
| 小麦粉 | 3 | 2 | 18 |
| バター | 1 | 3 | 13 |
| 売上 | 3 | 4 | |

売上 $3x_1+4x_2$ を最大にします。可行領域は四角形で、頂点は原点 / $(6,0)$ / $(4,3)$ / $(0,13/3)$ の4つです。
各頂点で売上を計算すると、順に $0$ / $18$ / $24$ / 約 $17.3$ です。最大は頂点 $(4,3)$ の $24$ で、小麦粉とバターをちょうど使い切ります。

目的関数の値が等しい点は、平行な直線の束になります。
この直線を売上が増える向きへずらしていくと、可行領域から最後に離れる点が最適解です。
目的の値は一定の向きへまっすぐ増えるだけで、途中に山や谷がありません。そのため、最後に触れる点は領域の角、つまり頂点になります。辺全体で同時に触れる場合もありますが、そのときも頂点の一つは最適です。

冒頭の図で、この動きを確かめられます。係数を少しずつ回すと、最良の頂点が切り替わる瞬間に、目的の直線が可行領域の辺と重なります。

### 双対値は資源の値段になる

この問題には、資源の側から見たもう一つの問題（双対問題）が対応します。
小麦粉とバターに、それぞれ値段 $y_1, y_2$ を付けます。どの品目でも「使う資源の値段の合計が売上以上」という条件を守り、在庫全体の値段 $18y_1+13y_2$ を最小にします。
この例の答えは $y=(5/7,\,6/7)$ で、在庫全体の値段は $18\cdot 5/7+13\cdot 6/7=24$ です。

主問題の最大売上と、双対問題の最小の値段が一致しています。これが強双対性です。
一致していることが、$24$ より良い計画が存在しない証明になります。
$y_1=5/7$ は「小麦粉が100g増えると、売上が約71円増える」という限界的な価値でもあります。ただし、使い切る資源の組み合わせが変わらない範囲でしか成り立ちません。

## 見分け方

次の言葉が問題文に出てきたら、線形計画を最初に疑います。

- 配分する・混ぜる（ブレンド）・輸送する・生産量を決める
- 「合計が〜以下」「少なくとも〜」のような資源や需要の条件
- 単価が一定で、量が2倍なら費用も2倍になる

逆に、次の兆候があれば線形計画だけでは書けません。

- 個数や台数が整数でないと意味がない → [混合整数線形計画](#/learn/concept.mixed-integer-linear-program)
- 1個でも作ると発生する固定費がある → 作るかどうかの0-1変数が必要になり、[混合整数線形計画](#/learn/concept.mixed-integer-linear-program)で書きます
- 在庫をすべて守る焼き方が一つもない（実行不能）、または売上がいくらでも増える（非有界）→ 制約の書き方を見直します。[制約の分類](#/learn/concept.constraint-class)で、どの条件が領域を決めているかを確かめます
- 量の二乗や積が目的に入る（ばらつき、面積）→ [凸二次計画](#/learn/concept.convex-quadratic-program)

単価が量によって変わる場合は注意が必要です。
量が増えるほど単価が上がる凸な区分線形の費用は、補助変数を足せば線形計画で書けます。
量が増えるほど単価が下がる割引は非凸で、整数変数が必要になります。

## 近い定式化

- **より一般の形: [凸二次計画](#/learn/concept.convex-quadratic-program)**: 目的に二次項 $\tfrac12 x^\top Qx$ を足した形です。$Q=0$ のとき、線形計画はその特殊な場合です。$Q\ne0$ なら、最適解は頂点とは限りません。
- **緩和すると線形計画になる形: [混合整数線形計画](#/learn/concept.mixed-integer-linear-program)**: 一部の変数に整数条件を足した形です。整数条件を外す（緩和する）と線形計画になります。最大化のとき、その最適値は整数の問題の上限です。
- **より特殊な形: [ネットワークフロー](#/formulations/PA028)**: 係数行列が特別な構造を持つ線形計画です。各列が、ある地点から出て別の地点へ入る流れを表します。供給と容量が整数なら、整数の最適頂点が存在します。

## 解き方の系統

線形計画は凸なので、どの標準的な方法でも局所解がそのまま大域解です。違いは、どこを通って進み、何を計算に使うかにあります。どれが速いかは問題とソルバーの設定によるので、ここでは順位を付けません。

- **[シンプレックス法](#/learn/primal-simplex)**: 可行領域の頂点から隣の頂点へ、目的が良くなる方向に移ります。前回の解から再開（ウォームスタート）しやすく、整数計画の内部で使われます。
- **[内点法（障壁法）](#/learn/barrier-lp-qp)**: 可行領域の内部を通って最適解へ近づきます。各反復で線形方程式を解きます。頂点解が必要なら、最後に頂点解へ移す処理を行います。
- **[一次法（PDLP）](#/learn/pdlp)**: 行列とベクトルの積だけで進みます。行列を分解しないので、分解が重い問題で候補になります。答えの精度は停止条件で決まります。

次の例は、パン屋の問題を `scipy.optimize.linprog`（内部はHiGHS）で解きます。

```python
from scipy.optimize import linprog

# 最大化 3x1 + 4x2 を、最小化 -3x1 - 4x2 に直す
result = linprog(
    c=[-3, -4],
    A_ub=[[3, 2], [1, 3]],
    b_ub=[18, 13],
    bounds=[(0, None), (0, None)],
    method="highs",
)
print(result.status, result.x, -result.fun)  # 0 [4. 3.] 24.0
print(result.ineqlin.marginals)  # [-0.714... -0.857...]
```

`marginals` は最小化の向きで表した双対値なので、符号が反転しています。絶対値が $5/7$ と $6/7$ に一致します。

## つまずきやすい点

- **終了状態を読まない**: バターの在庫を誤って $-1$ と入力すると、`linprog` は `status=2`（実行不能）を返し、`x` は `None` です。在庫の2行を両方書き忘れると、`status=3`（非有界）です。売上を読む前に、`status` を確かめます。
- **単位で双対値の数字が変わる**: 小麦粉を100g単位ではなくg単位で書くと（係数 $300, 200$、在庫 $1800$）、最適な焼き方は同じ $(4,3)$ です。ところが小麦粉の双対値は、1gあたり $1/140\approx0.0071$ になります。100gあたりの $5/7$ と同じ値なので、双対値を比べる前に単位をそろえます。
- **小数解の丸め**: バターの在庫を $12$ にすると、線形計画の答えは $(30/7,\,18/7)\approx(4.29,\,2.57)$ です。売上は約 $23.1$ です。四捨五入した $(4,3)$ はバターを $4+3\cdot3=13$ 使うので、在庫を超えます。整数での最適は $(3,3)$ で、売上は $21$ です。
- **双対値の外挿**: 小麦粉の在庫を $18$ から $30$ に増やすと、売上は $24+12\cdot5/7\approx32.6$ です。ここまでは値段 $5/7$ の見積もりどおりです。ところが在庫が $39$ に達すると、売上は $39$ から増えなくなります。在庫 $45$ での見積もり $24+27\cdot5/7\approx43.3$ は外れます。在庫を大きく変えたときは、解き直して確かめます。
