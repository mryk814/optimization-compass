単体上の最適化は、非負で合計が1になる割合や確率を決める定式化です。可行集合は凸ですが、目的関数まで凸とは限りません。割合を保つ更新と、目的の性質に応じた保証を分けて考えます。

## 30秒でつかむ

一日の作業時間を、調査と制作と確認へ配分する場面を考えます。
配分は負にならず、全部を足すと100%になります。
この「非負で合計が1」の領域を**単体**と呼びます。

- **決めるもの**：各活動への配分比率や、各選択肢の確率
- **良くしたいもの**：配分から決まる費用、誤差、期待損失
- **守ること**：すべての成分が非負で、合計が1になること

3成分なら、単体は空間に浮かぶ三角形です。
頂点は一つの活動への全配分、辺は二つの活動への配分、内部は三つへの配分を表します。
配分を少しずつ変えるには、目的が改善するかだけでなく、この三角形に留まるかも確かめます。
最後のパネル「三角形（合計 1 の領域）の上の動き」が、この三角形を描きます。最初は辺のそばを拡大して見せ、右上の小さな三角形が拡大している場所を示します。「三角形の見え方」を「三角形全体」にすると、三角形の全体が見えます。

調査・制作・確認に「これだけ使いたい」と考えた割合（希望量）が $(0.9,\ 0.3,\ 0.05)$ で、合計が $1.25$ になっている場面です。
まず「▶ 再生」を押してください。全員から引く量 $\theta$ が動き、残った配分の合計が $1$ になる $\theta$ を、区間を半分にしながら探します。

::: explorable simplex-projection-theta
「希望量から θ を引いて、負を 0 に切る」では、橙の部分が各活動から引いた量で、緑が残った配分です。負になった棒は灰色の枠で下にはみ出し、0 に切られます。「合計メーターと、θ に対する合計」は、残った合計が 1 に戻る位置を示します。
「三角形（合計 1 の領域）の上の動き」は、合計が 1 の配分を三角形で描きます。y は合計が 1.25 で面の外にあるので、面へ垂直に落とした影を白い丸で描きます。緑の四角が射影、橙の印がいまの θ の配分です。
二乗誤差を最小にする射影の場合だけの図です。確認に最低 5% を求める制約などは描きません。
:::

確かめてほしいことは五つあります。

1. 再生の1回目は $\theta=0.45$ へ大きく動き、合計は $0.45$ まで落ちます。次は半分の $0.225$ で合計 $0.75$ です。その次の $0.1125$ でも合計 $0.975$ で、まだ $1$ に足りません。4回目の $0.05625$ では合計が $1.0875$ と $1$ を超え、今度は $\theta$ を大きくします。このように、合計が $1$ を超えれば $\theta$ を大きく、足りなければ小さくします。動かす幅は毎回半分になり、メーターが $1$ の線に近づきます。
2. 「引く量 θ」を $0.05$ から $0.1$ へ動かすと、確認の棒は $0.05$ を超えた時点で負になり、灰色の枠で0に切られます。合計は $1.1$ から $1$ へ下がり、$\theta=0.1$ でメーターが緑になって、配分は $(0.8,\ 0.2,\ 0)$ になります。
3. 「三角形（合計 1 の領域）の上の動き」で、θ を $0$ から $0.1$ へ動かします。$0.05$ までは橙の印が動きません。同じ量を引くだけでは、面の上の位置が変わらないからです。$0.05$ を超えて確認が0に切られると、印は y の影から辺へ直角に進み、$\theta=0.1$ で緑の四角に重なります。
4. $\theta$ を $0.1$ より大きくすると、$0.3$ までは同じ直線に沿って、橙の印が三角形の内側へ進みます。引きすぎで合計が $1$ を下回り、印は射影から離れていきます。
5. 「重ねて比べる」で「合計で割った配分」を選ぶと、黒い線が $(0.72,\ 0.24,\ 0.04)$ に出ます。確認が0にならず、表の目的値は $0.01805$ で、射影の $0.01125$ より大きくなります。「三角形（合計 1 の領域）の上の動き」では、黒いひし形へ向かう点線が辺に直角になりません。y の影からの距離は、射影が $0.041$、割った配分が $0.124$ です。

どうして全員から同じ量を引くのでしょうか。合計を1にする条件が、どの成分にも同じ強さで効くからです。

その強さを $\theta$ とすると、二乗距離を最小にする配分は次の形になります。

$$
x_i=\max(y_i-\theta,\ 0)
$$

希望量から $\theta$ を引き、負になった成分は0にする、という読み方です。
$\theta$ は、合計がちょうど1になるように選びます。この例では確認が $0$ に切られるので、$(0.9-\theta)+(0.3-\theta)=1$ から $\theta=0.1$ です。

## 標準形を読む

配分から決まる目的を、合計と非負性を守りながら最小にします。

$$
\min_x\; f(x)\quad\text{s.t.}\quad\sum_i x_i=1,\quad x\ge0
$$

| 記号 | 意味 | 例では |
|---|---|---|
| $x_i$ | 活動 $i$ への割合、または選択肢 $i$ の確率 | 配分 $(0.8,\ 0.2,\ 0)$ |
| $f(x)$ | 配分全体から決まる費用や損失 | $0.01125$ |
| $\sum_i x_i=1$ | 全配分を使い切る条件 | $0.8+0.2+0=1$ |
| $x\ge0$ | 各成分を負にしない条件 | 確認の $x_3=0$ がこの条件の境界に当たる |

単体は凸集合です。
二つの配分を混ぜても、非負性と合計1が保たれます。
ただし、この標準形は一般の $f$ を許します。
目的も凸なときに、局所最小が大域最小になるという保証を使えます。

「予算の一部を使わなくてもよい」なら、合計は等式ではなく不等式です。
未使用分を一つの成分として加えれば単体で表せる場合もありますが、その成分の意味を先に決めます。

## 小さな例

調査と制作と確認への希望量が $y=(0.9,0.3,0.05)$ だったとします。
合計は $1.25$ で、一日の時間を超えています。
希望量との差の二乗を最小にする配分を選びます。

$$
\min_{x\ge0,\;\sum_i x_i=1}\;\frac12\|x-y\|_2^2
$$

答えは $x=(0.8,0.2,0)$、目的値は $0.01125$ です。
希望量から共通の量 $0.1$ を引き、負になる成分を0にすると、この配分になります。

| 活動 | 希望量 $y_i$ | 最適配分 $x_i$ | 差 $x_i-y_i$ |
|---|---:|---:|---:|
| 調査 | 0.90 | 0.80 | -0.10 |
| 制作 | 0.30 | 0.20 | -0.10 |
| 確認 | 0.05 | 0.00 | -0.05 |

この操作は、希望量から単体へ垂直に戻る**射影**です。
三角形のパネルでは、y の影から辺へ直角におりた先が $x$ です。
目的が厳密に凸なので、最適配分は一つに決まります。
確認への配分が0になるのは、二乗誤差だけを目的にした結果です。
「確認は最低5%」という要求があるなら、別の制約を足す必要があります。

希望量を合計で割るだけでは、$(0.72,0.24,0.04)$ になります。
この配分も合計1ですが、目的値は $0.01805$ です。
正規化と二乗距離の射影は、異なる操作です。
三角形の面の中で測ると、y の影から射影までは $0.041$、割った配分までは $0.124$ です。
面に垂直な成分 $0.25/\sqrt3$ は、どちらの配分でも同じなので、目的値の差は面の中の距離の差から生まれます。

## 見分け方

次の言葉があれば、単体制約が使えます。

- 配分比率、混合比、構成比を決めたい
- 選択肢への確率を学習したい
- 空売りのない資産比率や、調達枠の割合を決めたい

[資産比率を配分する事例](#/gallery/portfolio-cvar-allocation)では、単体制約に集中投資の上限も加えています。
[電力調達の事例](#/gallery/energy-cvar-procurement)も、割合の合計1と枠ごとの上限を組み合わせます。
いずれも目的にはシナリオ上のCVaRを使います。
割合を守ることと、将来の損失や価格への保証は別です。

次の兆候があれば、別の型も確認します。

- 量が整数の個数である → [混合整数線形計画](#/formulations/PA023)
- 合計だけでなく非線形な条件もある → [制約付き非線形計画](#/formulations/PA009)
- 回転行列や長さ1のベクトルを決める → [回転の最適化](#/formulations/PA037)や[固有値問題](#/formulations/PA003)

単体の内部だけを見ると滑らかな平面ですが、境界には辺と角があります。
単体の更新を、回転行列のような滑らかな多様体へそのまま持ち込むことはできません。

## 近い定式化

単体制約は、線形等式1本と非負制約の組です。
したがって、[一般の制約付き非線形計画](#/formulations/PA009)の特別な場合です。
この形の簡単さを使うと、汎用の制約処理を毎回行わずに済むことがあります。

- 目的が線形なら、[線形計画](#/learn/concept.linear-program)として解けます。
- 目的が凸二次なら、[凸二次計画](#/learn/concept.convex-quadratic-program)として解けます。小さな例はこの場合です。
- 非滑らかな凸目的なら、劣勾配や近接作用素を使う系統も候補になります。

解き方を選ぶときは、単体であることに加えて、目的の滑らかさと凸性も見ます。

## 解き方の系統

- **射影勾配法**：勾配の反対へ進んでから、単体の最も近い点へ戻します。[射影勾配法の記事](#/learn/projected-gradient)で、射影後の一手を診断する理由を読めます。
- **Mirror Descent**：領域に合う距離で一手を決めます。負のエントロピーを使う場合は、成分への掛け算と正規化で割合を保ちます。[Mirror Descentの記事](#/learn/mirror-descent)で更新式を追えます。
- **一般の制約付き局所法**：目的が滑らかで追加制約がある場合は、[SLSQP](#/learn/slsqp)や内点法も候補になります。

凸な目的には、凸性と各手法の仮定に応じた大域最適の保証があります。
非凸な目的では、単体を守って進めても大域最適とは限りません。
Mirror Descentを使っても、非凸の目的が凸になるわけではありません。

次のコードは、小さな例をSLSQPで解きます。

```python
import numpy as np
from scipy.optimize import minimize

target = np.array([0.9, 0.3, 0.05])


def objective(x):
    return 0.5 * np.sum((x - target) ** 2)


result = minimize(
    objective,
    np.full(3, 1.0 / 3.0),
    jac=lambda x: x - target,
    method="SLSQP",
    bounds=[(0.0, 1.0)] * 3,
    constraints={
        "type": "eq",
        "fun": lambda x: x.sum() - 1.0,
        "jac": lambda x: np.ones(3),
    },
    options={"ftol": 1e-12},
)
print(result.success, np.round(result.x, 6), round(float(result.fun), 6))
print(round(float(result.x.sum()), 6), round(float(result.x.min()), 6))
```

```text
True [0.8 0.2 0. ] 0.01125
1.0 0.0
```

目的値と合計に加えて、最小成分も印字しています。
数値計算では微小な制約違反があり得るため、使用する許容誤差も記録します。

## つまずきやすい点

- **単体なら常に凸問題だと考える**：$f(x)=-\|x\|^2$ は、頂点 $(1,\ 0,\ 0)$ で $-1$、中心 $(1/3,\ 1/3,\ 1/3)$ で $-0.333$ です。三つの頂点がどれも局所最小で、凸最適化の保証は使えません。
  可行集合の凸性と目的の凸性は分けます。
- **正規化だけで射影したことにする**：$(0.72,\ 0.24,\ 0.04)$ は合計1ですが、目的値は $0.01805$ です。射影の $0.01125$ より大きくなります。
  どの距離で戻す操作かを決めます。
- **勾配ノルムだけで止める**：最適な $(0.8,\ 0.2,\ 0)$ でも、勾配 $x-y=(-0.1,\ -0.1,\ -0.05)$ のノルムは $0.15$ で、$0$ ではありません。
  境界の最適点では、射影後の更新量や制約付きの最適性条件を使います。
- **0の成分を対数へ入れる**：$(0.8,\ 0.2,\ 0)$ では $\log x_3=-\infty$ で、エントロピー型の更新はこの成分を計算できません。掛け算の更新では0は0のままなので、初期成分は正にします。
- **必要な下限を目的に任せる**：確認に下限 $0.05$ を制約として加えると、配分は $(0.775,\ 0.175,\ 0.05)$ になります。目的値は $0.015625$ で、制約なしの $0.01125$ より増えます。
  最低配分量が要件なら、制約として書いたうえで、この増加を受け入れるか決めます。
