オンライン最適化は、決めた後に初めて結果が分かることを何度も繰り返す場面の定式化です。後から振り返って最もよかった固定の決め方との差（後悔・regret）を小さくします。結果の並びに分布を仮定しないので、どんな並びでも後悔が日数より遅く増える決め方を選びます。

## 30秒でつかむ

小さな店が、毎朝その日の広告費を、媒体AとBに分けます。夜になると、それぞれの媒体に回した広告費1あたりの成果（申込の数）が分かります。朝の時点では、その日どちらがよいかは分かりません。

ある10日間は、1日目がA 1.5・B 1.0で、その後はBのよい日とAのよい日が交互に来ました。よい方は2、悪い方は1です。

- **決めるもの**: 毎朝、媒体Aに回す割合 $x_t$（残りはB）
- **良くしたいもの**: 後悔。後から見てよかった方の媒体に毎日全額を回した場合と比べた、成果の不足分
- **守ること**: $0\le x_t\le1$

次の図は、この10日間の成果と、2つの決め方の毎朝の配分です。まず「① 1日の成果」で、Aの緑の実線とBの灰色の破線が毎日入れ替わることを確かめてください。続いて「② 毎朝Aに回す割合 x」で、紺の点（前日までの合計で勝っている媒体に全額）と橙の点（勾配で少しずつ動かす）を比べてください。その日よかった媒体を選べているかを見ます。

![① 媒体A・Bの1日の成果。1日目はA 1.5・B 1.0、その後は偶数日にB、奇数日にAが2倍。② 毎朝Aに回す割合 x。前日までの合計が多い媒体に全額を回す決め方（紺）は、2日目から毎日、その日悪い方の媒体を選ぶ。勾配で少しずつ動かす決め方（橙、学習率 η=1/√10）は、0.34と0.66の間を行き来する。](./figures/online-budget-days.svg "広告費の例：成果は教材用の値で、実際の広告の効果は示さない。交互に入れ替わる並びは、決め方の弱点を見せるために選んだもの")

1. 「① 1日の成果」の2本の線は、2日目から毎日入れ替わります。10日間の合計は、Aが14.5、Bが15.0です。後から見ると、固定の決め方の中で最もよいのは毎日Bに全額を回すことで、成果は15.0です。
2. 「② 毎朝Aに回す割合 x」の紺の点は、2日目から毎日、その日悪い方の媒体に全額を回しています。前日までの合計で勝っている媒体は、次の日に負けるからです。10日間の成果は10.25で、後悔は $15.0-10.25=4.75$ です。
3. 橙の点は、前日の結果の差 $a_t-b_t$ に $\eta$ を掛けた分だけ、割合を動かします。橙の点も、その日悪い方の媒体に約3分の2（0.658）を回します。全額ではないので、成果は13.33、後悔は1.67です。

それなら、毎日いつも半分ずつに分ければよいのでしょうか。この10日間なら成果は14.75で、後悔は0.25です。ところが、結果の並びが変わると、話が変わります。

## 標準形を読む

次の式が、オンライン最適化の標準形です。$K$ は決定がとれる範囲です。

$$
\text{各回 } t:\ x_t\in K \text{ を選び、} f_t \text{ を観測}; \qquad R_T=\sum_{t=1}^T f_t(x_t)-\min_{x\in K}\sum_{t=1}^T f_t(x)
$$

この式は「毎回 $x_t$ を決めてから損失 $f_t$ を知る。選んだ $x_t$ の損失の合計と、後から見て最もよかった固定の $x$ の損失の合計の差を小さくする」と読みます。$R_T$ を後悔（regret）と呼びます。

| 記号 | 意味 | 広告費の例では |
|---|---|---|
| $t$ | 回（日） | 1日目〜$T$ 日目 |
| $x_t$ | $t$ 回目の決定。$f_t$ を知る前に決める | その日の朝、Aに回す割合（0〜1） |
| $K$ | 決定がとれる範囲 | $[0,1]$ |
| $f_t$ | $t$ 回目の損失。決めた後に分かる | $-(x\,a_t+(1-x)\,b_t)$。$a_t,\ b_t$ はその日のA・Bの成果 |
| $\min_{x\in K}\sum f_t(x)$ | 後から見た、最もよい固定の決定の損失 | 毎日Bに全額（交互の10日間で成果15.0） |
| $R_T$ | 後悔 | 前日までの勝ち側に全額なら4.75、いつも半分なら0.25 |

### 後悔は、「後から見た最良の固定」との差

比べる相手は、毎日その日のよい方を当てる決め方ではありません。後から見て最もよかった、毎日同じ $x$ です。交互の10日間で毎日よい方を当てられれば成果は19.5ですが、それを毎回保証できる決め方はありません。その日の結果は、朝の時点では分からないからです。

$T$ 日で後悔が $T$ より遅く増えるなら、1日あたりの後悔 $R_T/T$ は0に近づきます。日数が長くなるほど1日あたりの成果が後から見た最良の固定の決め方に近づく、と読めます。

### なぜ「どんな並びでも」を求めるのか

成果の並びに分布を仮定できるなら、期待値で比べる方法（[確率計画](#/formulations/PA049)など）が使えます。オンライン最適化は分布を仮定せず、どんな並びに対しても後悔の上限を保証します。競合の店が出稿を変えるなど、並びが自分の決め方に合わせて変わることがある場面で、この保証が意味を持ちます。ただし比べる相手は、実際に起きた並びのもとでの固定の $x$ です。並びが決め方に反応して変わるなら、別の $x$ を選んでいた場合の並びは比べていません。

### 勾配で少しずつ動かす（オンライン勾配降下法）

橙の決め方は、前日の損失の勾配の逆向きに $x$ を少しだけ動かし、0〜1の範囲に戻します。

$$
x_{t+1}=\min\Bigl(1,\ \max\bigl(0,\ x_t+\eta\,(a_t-b_t)\bigr)\Bigr)
$$

この式は「Aの方がよかった日は、差 $a_t-b_t$ に $\eta$ を掛けた分だけAへの割合を増やし、Bの方がよかった日は減らす」と読みます。$\eta$ を学習率と呼びます。

損失 $f_t$ が凸で、決定の範囲 $K$ が凸で有界とします。$K$ の範囲の大きさ（直径）を $D$、勾配の大きさの上限を $G$ とします。日数 $T$ が前もって分かるなら、学習率を $\eta=D/(G\sqrt T)$ にすると、どんな並びでも後悔は $DG\sqrt T$ 以下です。この例では $D=1$、$G=\max|a_t-b_t|=1$ なので、上限は $\sqrt T$ です。

## 小さな例

決め方は3つです。1つ目は、前日までの成果の合計が多い媒体に全額を回す決め方です（1日目は半分ずつ）。2つ目はいつも半分ずつ、3つ目は勾配で少しずつ動かす決め方です（学習率 $\eta=1/\sqrt T$、1日目は半分）。並びは2つです。交互の並びと、A・A・Bを繰り返す並び（3日のうち2日はAが2倍）です。乱数は使いません。

### 広告費の例・100日間の後悔

| 決め方 | 交互の並び | A・A・Bの繰り返し |
|---|---:|---:|
| 前日までの勝ち側に全額 | 49.75 | 0.5 |
| いつも半分 | 0.25 | 17 |
| 勾配で少しずつ（$\eta=0.1$） | 5.2 | 4.8 |

前日までの勝ち側に全額を回す決め方は、A・A・Bの並びでは2日目から毎日Aを選び、後悔は0.5にとどまります。ところが交互の並びでは毎日外れ、後悔はほぼ日数の半分（49.75）です。いつも半分は逆で、交互の並びでは0.25です。ところがA・A・Bの並びでは、Aに全額を回せば得られた成果との差が3日ごとに0.5ずつ積もり、17になります。

勾配で少しずつ動かす決め方は、どちらの並びでも5前後です。上限 $\sqrt{100}=10$ を下回ります。

次の図は、日数 $T$ を10日から1万日まで変えたときの後悔です。「① 交互に入れ替わる日」と「② A・A・Bの繰り返し」で、3本の線の傾きを、破線の $\sqrt T$ と比べてください。

![日数Tと後悔（どちらも対数目盛）。① 交互の並びでは、前日までの勝ち側に全額の後悔が T とともに増え（1万日で約5000）、いつも半分は0.25のまま、勾配で少しずつは √T に沿って増える（1万日で50.2）。② A・A・Bの並びでは、前日までの勝ち側に全額は0.5のまま、いつも半分が T とともに増え（1万日で1667）、勾配で少しずつは √T に沿って増える（1万日で46.1）。](./figures/online-regret-growth.svg "広告費の例：学習率は η=1/√T。2つの並びは教材用に選んだもので、どの決め方がよいかの順位は示さない")

傾きが1の線は、日数に比例して後悔が増える決め方です。1日あたりの後悔が減りません。勾配で少しずつ動かす決め方は、どちらのパネルでも破線と同じ傾き1/2で増え、1日あたりの後悔は1万日で0.005程度になります。

## つまずきやすい点

- **前日までの合計で勝っている方に全額を回す**: 交互の並びでは、2日目から毎日その日悪い方を選び、100日で後悔は49.75です。日数を10倍にすると後悔も10倍になります。前日までの合計だけで決めると、結果が入れ替わるたびに全額が逆側へ振れるからです。割合を少しずつ動かすか、決め方に変わりにくさ（正則化）を足します。
- **学習率を、日数と関係なく決める**: 学習率を0.5に固定すると、100日の後悔は交互の並びで25.0です。A・A・Bの並びでは17.0です。1万日では2500と1667になり、日数に比例して増えます。学習率は $1/\sqrt T$ のように日数とともに小さくします。日数が前もって分からないときは、$t$ 日目の学習率を $1/\sqrt t$ にします。このときの上限は $\tfrac32 DG\sqrt T$ です。1万日の後悔は交互の並びで99.3、A・A・Bの並びで66.5で、どちらも上限150を下回ります。
- **いつも半分なら安全だと思う**: 交互の並びでは後悔0.25ですが、A・A・Bの並びでは100日で17、1万日で1667です。並びによって、よい決め方と悪い決め方が入れ替わります。どの並びでも後悔が $\sqrt T$ 程度に収まる決め方を選びます。
- **後悔が小さければ、成果が最大だと思う**: 後悔は、後から見た最良の固定の決め方との差です。交互の10日間で、毎日よい方を当てれば成果は19.5ですが、最良の固定（毎日B）は15.0です。後悔が0でも、毎日よい方を当てる場合より4.5少ないことがあります。

## 課題から定式化する

「毎朝の広告費の分け方を、結果を見ながら決め直したい」という課題を、次の4段で式にします。

1. **毎回何を決めるか**：その日の朝、Aに回す割合 $x_t$ です。範囲は0〜1です。
2. **いつ何が分かるか**：夜に、その日のA・Bの成果 $a_t,\ b_t$ が両方分かります。損失は $f_t(x)=-(x\,a_t+(1-x)\,b_t)$ です。
3. **成果の並びに何を仮定するか**：分布を仮定しません。競合の動きなどで、並びが入れ替わることもあるとします。
4. **何と比べるか**：後から見て最もよかった固定の割合と比べた後悔 $R_T$ を、小さくします。

決めてから結果が分かることを繰り返し、結果の並びに分布を仮定できないとき、オンライン最適化として定式化できます。

## 困りごとから関連する問題へ

実際の課題で次の困りごとがあれば、リンク先を読んでください。

- 記録が最初からそろっていて、何度でも読み直せる → [大規模確率的ERM](#/formulations/PA041)
- 成果の分布が分かっていて、期待値で比べたい → [確率計画](#/formulations/PA049)
- 記録が拠点ごとに分かれ、1か所に集められない → [分散・合意最適化](#/formulations/PA051)

### オンライン最適化と関連する問題の関係

- [大規模確率的ERM](#/formulations/PA041): 記録が最初からそろっている形です。1件ずつ順に読んで係数を動かす[確率的勾配降下法](#/learn/sgd)は、オンライン勾配降下法と同じ更新式を使います。違うのは、比べる相手（後悔か全件の損失の最小値か）と、記録を読み直せるかです。
- [確率計画](#/formulations/PA049): 不確かな値を確率で表し、期待値で比べます。分布の根拠があるならこちらです。オンライン最適化は分布を仮定しない代わりに、後から見た最良の固定の決め方を比べる相手にします。
- [分散・合意最適化](#/formulations/PA051): 記録が場所で分かれる形です。オンライン最適化は、記録が時間で分かれる形です。
- 多腕バンディット: 選んだ媒体の成果しか分からず、選ばなかった方の成果は見えない形です。見えない側の成果を見積もる分だけ、後悔の上限が大きくなります。

## 数値計算の方法を選ぶ

どの方法も、毎回の決定を、それまでに分かった損失だけから作ります。違いは、過去の損失をどう使うかです。

| 系統 | 進み方 | 例での様子 |
|---|---|---|
| オンライン勾配降下法（[射影勾配法](#/learn/projected-gradient)の一歩） | 前回の勾配の逆向きに少し動かし、範囲に戻す | 100日で後悔5.2と4.8。上限は10 |
| 前日までの合計で最良の決定（Follow the Leader） | 過去の損失の合計が最小の決定を選ぶ | 交互の並びで後悔49.75 |
| 正則化付きの合計で最良の決定（Follow the Regularized Leader） | 過去の損失の合計に、決定を急に変えにくくする項を足して最小にする | Follow the Leaderの振れを抑える。この例では計算していない |
| [Mirror Descent](#/learn/mirror-descent)（エントロピーを使う版が指数重み） | 割合を、成果に応じて掛け算で更新する。選択肢が多いときの割合の配分に向く | この例では計算していない |

表は速さの順位ではなく、過去の損失の使い方の違いです。

次のコードは、広告費の例を3つの決め方で解き、日数ごとの後悔を数えます。

```python
import numpy as np


def alternating(T):
    """1日目は A 1.5・B 1.0、その後は偶数日に B、奇数日に A が2倍の成果"""
    days = [(1.5, 1.0)] + [(1.0, 2.0) if t % 2 == 0 else (2.0, 1.0) for t in range(2, T + 1)]
    return np.array(days)


def pattern(T):
    """A, A, B の繰り返し：3日のうち2日は A が2倍"""
    return np.array([(1.0, 2.0) if t % 3 == 0 else (2.0, 1.0) for t in range(1, T + 1)])


def play(results, rule, eta=None):
    """毎朝 A に回す割合 x を決め、夜に結果を見る。返り値は配分と後悔"""
    x, lead, shares, gained = 0.5, 0.0, [], 0.0
    for a, b in results:
        if rule == "leader":  # 前日までの合計が多い媒体に全額
            x = 0.5 if lead == 0 else float(lead > 0)
        elif rule == "half":
            x = 0.5
        shares.append(x)
        gained += x * a + (1 - x) * b
        lead += a - b
        if rule == "ogd":  # 損失の勾配の逆向きに少しだけ動かし、0〜1に戻す
            x = min(1.0, max(0.0, x + eta * (a - b)))
    best = results.sum(axis=0).max()  # 後から見てよかった媒体に毎日全額
    return np.round(shares, 3), round(float(best - gained), 2)


days = alternating(10)
print(days.sum(axis=0))  # [14.5 15. ]
for rule, eta in (("leader", None), ("half", None), ("ogd", 1 / np.sqrt(10))):
    print(rule, *play(days, rule, eta))
# leader [0.5 1.  0.  1.  0.  1.  0.  1.  0.  1. ] 4.75
# half [0.5 0.5 0.5 0.5 0.5 0.5 0.5 0.5 0.5 0.5] 0.25
# ogd [0.5   0.658 0.342 0.658 0.342 0.658 0.342 0.658 0.342 0.658] 1.67

for T in (10, 100, 1000, 10000):
    regrets = [play(seq(T), rule, 1 / np.sqrt(T))[1] for seq in (alternating, pattern) for rule in ("leader", "half", "ogd")]
    print(T, regrets)
# 10 [4.75, 0.25, 1.67, 0.5, 2.0, 1.63]
# 100 [49.75, 0.25, 5.2, 0.5, 17.0, 4.8]
# 1000 [499.75, 0.25, 16.05, 0.5, 167.0, 14.74]
# 10000 [4999.75, 0.25, 50.24, 0.5, 1667.0, 46.08]

print(play(pattern(100), "ogd", 0.5)[1], play(alternating(100), "ogd", 0.5)[1])  # 17.0 25.0
```

最初の出力は、交互の10日間のA・Bの成果の合計14.5と15.0です。次の3行は、10日間の毎朝の割合と後悔です。前日までの勝ち側に全額は、2日目から1と0を交互に選んで後悔4.75、勾配で少しずつは0.342と0.658を行き来して後悔1.67です。

日数ごとの出力は、前の3つが交互の並び、後の3つがA・A・Bの並びの後悔です。順に、前日までの勝ち側に全額・いつも半分・勾配で少しずつです。小さな例の表と図の値と同じです。最後の行は、学習率を0.5に固定したときの100日の後悔です。

## 出典と再現条件

オンライン最適化の定式化と後悔の定義は、Hazanの『Introduction to Online Convex Optimization』（S182）に基づきます。オンライン勾配降下法と、学習率の選び方による後悔の上限は、同じ本の該当章にあります。日数が前もって分からないときの $\tfrac32 DG\sqrt T$ の上限も同じです。損失が線形のとき、前日までの合計で最良の決定を選ぶ方法の後悔が交互の並びで日数に比例することも、同じ本の該当章にあります。正則化付きの方法・指数重み・バンディットの扱いも同じ本の該当章にあります。

コードの出力は、NumPy 2.5.3 でこの記事のコードを実行して得た値です。図は、同じ式を図の生成スクリプトが標準ライブラリだけで計算した値から描いています。成果の並びは教材用の値で、実際の広告の効果や、決め方の順位は示しません。
