多目的連続最適化は、重さとたわみのように引っ張り合う複数の目的を同時に小さくする定式化です。答えは一点ではなく、どれかを良くすると別のどれかが悪くなる点の集合（パレート集合）で、目的の空間ではパレート前線という曲線になります。前線が凹んでいると、重み付き和ではその途中の点を選べません。

## 30秒でつかむ

棚を支える金具を設計するとします。金具を厚くすると、たわみは小さくなりますが、重くなります。薄くすれば軽くなりますが、よくたわみます。
どちらも小さくしたいのに、片方を良くすると、もう片方が悪くなります。この二つを同時に扱うのが多目的最適化です。
答えは「最良の一点」ではなく、「これ以上どちらも良くできない候補の一覧」です。一覧の中からどれを選ぶかは、使う人の好み（選好）で決めます。

- **決めるもの**: 金具の厚み $x_1$ と、飾りの量 $x_2$（一般には、設計の変数）
- **良くしたいもの**: 重さ $f_1$ とたわみ $f_2$ の両方（一般には、2つ以上の目的）
- **守ること**: 厚みも飾りも0から1の範囲

まず「設計の空間」の点を動かし、「目的の空間」の点がどう動くかを見てください。「選び方」を「重み付き和」にして、「重さの重み w」のつまみを動かすと、選ばれる点がどこに現れるかも確かめてください。

::: explorable multiobjective-pareto-weights
「設計の空間」は厚みと飾りの組、「目的の空間」はその設計の重さとたわみです。青緑の太い線がパレート最適な設計と、その目的の値（パレート前線）です。橙の点線の四角は、今の点より重さもたわみも小さい領域で、赤い矢印は飾りを外したときの改善です。教材用の式で、実際の金具の重さやたわみではありません。
:::

確かめてほしいことは三つあります。

1. 「設計の空間」で飾り x₂ を0から上げると、「目的の空間」の点は真上に動きます。重さはそのままで、たわみだけが増えます。飾りがある設計は、外すだけで良くなるので、候補の一覧に入りません。
2. 「重み付き和」で重み w を0.05から0.95まで動かすと、選ばれる点は両端の2点だけで、w=0.5を境に端から端へ飛びます。前線の途中の点は、どの重みでも選ばれません。
3. 「重さの上限（ε制約）」にすると、上限 ε を動かすだけで前線のどの点も選べます。「たわみの減り方」を「薄いうちに急に減る」に変えると、重み付き和でも前線の途中の点が選ばれるようになります。

重みを少しずつ変えれば、候補の一覧を順にたどれそうに思えます。なぜ途中が抜け落ちるのでしょうか。

## 標準形を読む

次の式が表すのは「設計 $x$ を選んで、目的の値の組 $(f_1,\dots,f_m)$ を同時に小さくする」です。

$$
\min_{x\in X}\; \big(f_1(x),\dots,f_m(x)\big)
$$

値の組は、一つの数のようには大小を比べられません。そこで次の言葉を使います。

| 記号・言葉 | 意味 | 金具の例では |
|---|---|---|
| $x\in X$ | 決める変数と、守る範囲 | 厚み $x_1$ と飾り $x_2$、どちらも $[0,1]$ |
| $f_1,\dots,f_m$ | 同時に小さくしたい目的（$m\ge2$） | 重さ $f_1=x_1$、たわみ $f_2=1-x_1^2+x_2$ |
| 支配 | すべての目的で同じか良く、少なくとも一つで真に良いこと | $(0.5,\,0)$ は $(0.5,\,0.5)$ を支配する |
| パレート最適 | ほかのどの設計にも支配されないこと | 飾りのない設計 $x_2=0$ |
| パレート集合・パレート前線 | パレート最適な設計の集合と、その目的の値の集合 | 線分 $x_2=0$ と、曲線 $f_2=1-f_1^2$ |

最大化したい目的が混ざるときは、符号を反転して、すべて最小化にそろえてから支配を判定します。

### 金具の例・前線の形

飾りのない設計 $(x_1,\,0)$ では、重さ $f_1=x_1$ とたわみ $f_2=1-x_1^2$ が決まるので、前線は $f_2=1-f_1^2$ です。
この曲線は、原点から見て外側に膨らんでいます。最小化の向きで言えば「凹んだ前線」です。
厚みを少し増やしたとき、薄い金具ではたわみがあまり減らず、厚い金具ではたわみが急に減ります。そのため前線は、両端の近くで片方の目的だけが急に良くなり、途中では両方がそこそこになる形です。

### 一つの目的にまとめる二つの方法

候補の一覧から一点を選ぶには、二つの目的を一つの数にまとめて、普通の最小化として解きます。この操作をスカラー化と呼びます。

$$
\text{重み付き和：}\ \min_x\ w\,f_1(x)+(1-w)\,f_2(x)
\qquad
\varepsilon\text{制約：}\ \min_x\ f_2(x)\ \ \text{s.t.}\ \ f_1(x)\le\varepsilon
$$

重み付き和は「重さとたわみを $w:(1-w)$ の割合で足した値を小さくする」と読みます。$\varepsilon$ 制約は「重さを $\varepsilon$ 以下に抑えた中で、たわみを最も小さくする」と読みます。

## 小さな例

金具の例で、重み付き和と $\varepsilon$ 制約が選ぶ点を比べます。

### 金具の例・重み付き和

飾りは外したほうがよいので $x_2=0$ とし、厚み $x_1$ だけを考えます。重み付き和は次の式です。

$$
w\,x_1+(1-w)(1-x_1^2)
$$

この式は $x_1$ について上に凸（下に開いた放物線）なので、範囲 $[0,1]$ の中で最小になるのは、必ず端の $x_1=0$ か $x_1=1$ です。
端の値は、$x_1=0$ で $1-w$、$x_1=1$ で $w$ です。$w<0.5$ なら厚い端 $(f_1,f_2)=(1,\,0)$、$w>0.5$ なら薄い端 $(0,\,1)$ が選ばれます。

| 重み $w$ | 選ばれる厚み | 重さ $f_1$ | たわみ $f_2$ |
|---:|---:|---:|---:|
| 0.30 | 1 | 1 | 0 |
| 0.49 | 1 | 1 | 0 |
| 0.51 | 0 | 0 | 1 |
| 0.70 | 0 | 0 | 1 |

例えば前線の真ん中の $(0.5,\ 0.75)$ は、重さ0.5でたわみ0.75の、両方そこそこの金具です。$w=0.5$ のとき、この点の重み付き和は $0.625$ で、両端の $0.5$ より大きくなります。どの重みでも、この点は端に負けます。

目的の空間で見ると、重み付き和の値が一定の点は、傾き $-w/(1-w)$ の直線に並びます。重み付き和の最小化は、この直線を左下から押し当てて、前線に最初に触れた点を選ぶことです。前線が凹んでいると、直線は必ず両端のどちらかに先に触れます。

### 金具の例・ε制約

重さの上限を $\varepsilon$ にしてたわみを最小にすると、たわみは厚いほど小さいので、上限いっぱいの $x_1=\varepsilon$ が選ばれます。選ばれる点は $(\varepsilon,\ 1-\varepsilon^2)$ で、$\varepsilon=0.5$ なら前線の真ん中の $(0.5,\ 0.75)$ です。
$\varepsilon$ を0から1まで動かすと、前線のすべての点を順にたどれます。

### 金具の例・前線が凸のとき

たわみの式を $f_2=1-\sqrt{x_1}+x_2$ に変えると、薄いうちにたわみが急に減ります。前線 $f_2=1-\sqrt{f_1}$ は、原点に向かってへこんだ「凸な前線」になります。
このときの重み付き和の最小点は $x_1=\big((1-w)/(2w)\big)^2$ です。$w=0.5$ なら $x_1=0.25$、$w=0.75$ なら $x_1=1/36$ です。重みを変えると、選ばれる点が前線に沿って動きます。

## つまずきやすい点

- **重みを振れば前線をたどれると思う**: 凹んだ前線の金具の例では、重みを0.05から0.95まで振っても、出てくるのは両端の2点だけでした。点が端に偏るときは、前線が凹んでいないかを疑い、$\varepsilon$ 制約や集団による方法を試します。
- **重みを好みの比率だと思う**: 重みは単位と組みになった数です。凸な前線の例で、重さを100倍の単位で測るとします。すると同じ $w=0.5$ でも、選ばれる厚みは $0.25$ から $2.5\times10^{-5}$ に変わります。目的の尺度をそろえてから重みを決めるか、$\varepsilon$ のように単位つきの上限で好みを表します。
- **支配された点を候補に残す**: 飾り0.5の金具は、飾りを外すだけで重さはそのまま、たわみが $1.25$ から $0.75$ に下がります。候補の一覧からは、支配された点を先に除きます。
- **端の点をそのまま採用する**: 重さ0の端はたわみ1で、パレート最適でも実用にならないことがあります。最低限の性能を制約にして、範囲を先に絞ります。

## 課題から定式化する

「軽くて、たわまない金具を作りたい」という課題を、次の順で式にします。

1. **何を決めるか**：厚み $x_1$ と飾りの量 $x_2$ を、0から1の範囲で決めます。
2. **何を小さくしたいか**：重さ $f_1$ とたわみ $f_2$ の二つです。単位も意味も違うので、一つの数に足し合わせず、組のまま扱います。
3. **目的の向きはそろっているか**：どちらも小さいほど良いので、最小化のままでよいです。大きいほど良い目的は、符号を反転します。
4. **好みをいつ決めるか**：先に重みや上限を決めて一点を解くか、候補の一覧（前線）を先に作ってから選ぶかを決めます。

目的が二つ以上あり、その間の優先順位をまだ決めたくないとき、多目的最適化として定式化します。

## 困りごとから関連する問題へ

- 優先順位が決まっていて、片方は上限で表せる → [一般滑らか制約付きNLP](#/formulations/PA009)：$\varepsilon$ 制約として一つの目的で解きます
- 目的の評価が高価で、試せる回数が少ない → [高価なブラックボックス](#/formulations/PA014)：多目的のベイズ最適化などを検討します
- 機械学習で、検証の損失と学習時間の両方を見たい → [ハイパーパラメータ最適化](#/formulations/PA039)
- 目的が4つ以上あり、候補が偏る → [NSGA-III](#/learn/nsga-iii)：多数の目的向けに、前線上の点を散らばらせます

### 多目的最適化と関連する問題の関係

- [一般滑らか制約付きNLP](#/formulations/PA009): 重み付き和や $\varepsilon$ 制約でスカラー化すると、一つの目的の問題の列になります。それぞれの答えが局所解か大域解かは、使ったソルバーの保証を引き継ぎます。
- 凸性との関係: 目的と範囲がすべて凸なら、前線は凸になり、正の重みの重み付き和の答えはパレート最適です。逆に、どのパレート最適な点も、ある非負の重みの答えになります。金具の凹んだ前線は、凸でない例です。
- [重み付き和](#/learn/weighted-sum)と[ε制約法](#/learn/epsilon-constraint): どちらも前線上の一点を選ぶ方法です。重み付き和は凹んだ部分を取りこぼし、$\varepsilon$ 制約は上限が小さすぎると答えがなくなります。

## 数値計算の方法を選ぶ

- **スカラー化を繰り返す**: 重みや $\varepsilon$ を変えながら、一つの目的のソルバーで何度も解きます。前線が凹んでいる可能性があれば、$\varepsilon$ 制約を使います。
- **集団による方法（NSGA-II・NSGA-III・MOEA/D）**: 点の集団を進化させ、1回の実行で前線の近似を作ります。真の前線は分からないので、近似の質は評価回数と乱数に左右されます。[NSGA-III](#/learn/nsga-iii)と[MOEA/D](#/learn/moead)にあります。
- **考え方の全体**: 支配・パレート集合・選好を分けて扱う流れは、[多目的最適化](#/learn/multi-objective)にあります。

次の例は、金具の例をpymooのNSGA-IIで解き、続けて重み付き和の答えを格子で確かめます。

```python
import numpy as np
from pymoo.algorithms.moo.nsga2 import NSGA2
from pymoo.core.problem import ElementwiseProblem
from pymoo.optimize import minimize


class Bracket(ElementwiseProblem):
    def __init__(self) -> None:
        super().__init__(n_var=2, n_obj=2, xl=[0.0, 0.0], xu=[1.0, 1.0])

    def _evaluate(self, x, out, *args, **kwargs) -> None:
        out["F"] = [x[0], 1 - x[0] ** 2 + x[1]]


result = minimize(Bracket(), NSGA2(pop_size=40), ("n_gen", 60), seed=1)
front = result.F[np.argsort(result.F[:, 0])]
print(len(front), front[0].round(3), front[-1].round(3))  # 40 [0. 1.] [1. 0.]
print(int(((front[:, 0] > 0.1) & (front[:, 0] < 0.9)).sum()))  # 30
print(round(float(np.abs(front[:, 1] - (1 - front[:, 0] ** 2)).max()), 4))  # 0.0006

grid = np.linspace(0.0, 1.0, 101)
for w in [0.3, 0.49, 0.51, 0.7]:
    sums = w * grid + (1 - w) * (1 - grid**2)
    print(w, grid[np.argmin(sums)])
# 0.3 1.0
# 0.49 1.0
# 0.51 0.0
# 0.7 0.0
```

NSGA-IIは、40点で前線の両端 $(0,1)$ と $(1,0)$ を含み、そのうち30点が重さ0.1〜0.9の途中にあります。前線 $f_2=1-f_1^2$ からのずれは最大 $0.0006$ です。
後半の重み付き和は、小さな例の表と同じく、$w=0.49$ と $0.51$ の間で厚み1から厚み0へ飛びます。集団による方法は凹んだ前線の途中も覆えますが、近似である点は変わりません。比べるときは、評価回数と乱数の種をそろえます。
