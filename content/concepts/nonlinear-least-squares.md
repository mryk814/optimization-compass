非線形最小二乗は、パラメータについて非線形なモデルと観測のずれの二乗和を最小にする定式化です。凸性は失われますが、残差のヤコビアンを使うと一般の最小化より速く安定に解けます。

## 30秒でつかむ

放射性物質の量や薬の血中濃度は、時間とともに指数関数的に減ります。
観測から初期量 $a$ と減衰率 $k$ を推定するには、モデル $y=a\,e^{-kt}$ をデータに合わせます。
$k$ が指数の中にあるため、モデルは $k$ について線形ではありません。これが非線形最小二乗（nonlinear least squares）です。

- **決めるもの**: 物理モデルや幾何モデルのパラメータ
- **良くしたいもの**: 残差の二乗和
- **守ること**: パラメータの物理的な範囲が付くことが多い

線形最小二乗から失われるのは、「一度で解ける」ことと「大域解の保証」です。
残るのは、目的が残差の二乗和という構造です。この構造を捨てずに使うことが、この定式化を独立に扱う理由です。

## 標準形を読む

$$
\min_{x}\; \tfrac12\sum_{i=1}^m r_i(x)^2 \quad \text{s.t.}\quad \ell\le x\le u
$$

$r_i(x)$ は観測 $i$ の残差で、モデルの予測と観測値の差です。$\tfrac12$ は微分をきれいにするための慣習です。

残差を縦に並べたベクトル $r(x)$ の、各パラメータについての偏微分を並べた行列をヤコビアン $J(x)$ と呼びます。
目的の勾配は $J^\top r$ で、曲率は $J^\top J$ でよく近似できます。
二階微分を計算せずに曲率の近似が手に入ることが、残差構造を使う最大の利点です。

## 小さな例

時刻 $t=0,1,2,3,4$ で、量 $y=5.1,\,3.0,\,1.9,\,1.1,\,0.7$ を観測したとします。モデルは $y=a\,e^{-kt}$ です。

残差 $r_i=a\,e^{-kt_i}-y_i$ のヤコビアンの各行は、次の2成分です。

$$
\frac{\partial r_i}{\partial a}=e^{-kt_i},\qquad \frac{\partial r_i}{\partial k}=-a\,t_i\,e^{-kt_i}
$$

この問題を解くと $a\approx 5.08$、$k\approx 0.505$ で、目的値 $\tfrac12\sum r_i^2$ は約 $0.0041$ です。

### 対数をとって線形にする近道の落とし穴

両辺の対数をとると $\log y=\log a-kt$ となり、線形最小二乗で解けます。
同じデータで計算すると $a\approx 5.04$、$k\approx 0.498$ です。元の尺度での目的値は約 $0.0053$ で、非線形のまま解いた答えより大きくなります。

違いの原因は、残差の測り方が変わったことです。
対数の尺度では、小さな観測値の誤差が相対的に大きく扱われます。観測の誤差がどの尺度で一定なのかを先に決め、その尺度で残差を定義します。
変数変換で線形にした答えは、非線形で解くときの良い初期値として使えます。

## 見分け方

次の兆候があれば、非線形最小二乗を考えます。

- 指数減衰・反応速度・飽和曲線のように、パラメータが関数の中に入るモデルを当てはめたい
- カメラの位置や姿勢を、画像上の点の再投影誤差から推定したい
- 方程式系を満たす点を探しているが、式の数が未知数より多い

次の兆候があれば、別の型も考えます。

- パラメータについて線形にできる → [線形最小二乗](#/learn/concept.linear-least-squares)。一度で大域解が求まる
- 外れ値が混ざる → [外れ値を含むパラメータ推定](#/formulations/PA056)。損失関数を変える
- データだけでパラメータが決まらない → [逆問題](#/formulations/PA055)。正則化を足す

## 近い定式化

- **線形最小二乗**: 残差が線形な特別な場合です。Gauss–Newton法は、各反復で線形最小二乗を一回解きます。
- **上下限つきの滑らかな最小化**: 残差構造を忘れれば、一般の最小化問題として扱えます。ただし、ヤコビアンが持つ情報を捨てることになります。
- **求根**: $F(x)=0$ を $\|F(x)\|^2$ の最小化として解くと非線形最小二乗になります。$0$ でない局所最小に止まったら、根ではありません。

## 解き方の系統

どの方法も局所解までしか保証しません。初期値と、途中の一手の信頼性の扱い方で違いが出ます。

- **Gauss–Newton法**: 残差を線形に近似し、線形最小二乗を解いて一手を決めます。残差が小さく、モデルが素直なら非常に速く収束します。
- **Levenberg–Marquardt法**: Gauss–Newtonの一手に減衰項を足し、近似を信用できないときは一手を短く、勾配方向に寄せます。多くのライブラリの既定の方法です。
- **信頼領域法（Trust Region Reflectiveなど）**: 一手の大きさの上限を調整しながら進みます。上下限つきの問題を扱えます。

次の例は、上のデータを `scipy.optimize.least_squares` で解きます。

```python
import numpy as np
from scipy.optimize import least_squares

t = np.array([0.0, 1.0, 2.0, 3.0, 4.0])
y = np.array([5.1, 3.0, 1.9, 1.1, 0.7])


def residuals(p: np.ndarray) -> np.ndarray:
    a, k = p
    return a * np.exp(-k * t) - y


def jacobian(p: np.ndarray) -> np.ndarray:
    a, k = p
    e = np.exp(-k * t)
    return np.column_stack([e, -a * t * e])


result = least_squares(residuals, x0=[1.0, 0.1], jac=jacobian)
print(result.x, result.cost, result.status)  # [5.0787 0.5049] 0.00408... 2
```

`cost` は $\tfrac12\sum r_i^2$ です。`status` は停止理由を表し、正の値は許容誤差を満たして止まったことを示します。

## つまずきやすい点

- **初期値が遠い**: 非凸なので、初期値によって別の局所解や、モデルが破綻する領域へ進むことがあります。変数変換した線形の当てはめや、物理的な概算で初期値を作ります。
- **ヤコビアンの誤り**: 手で書いたヤコビアンの符号や係数を間違えると、収束が極端に遅くなります。有限差分との比較で確かめます。
- **パラメータの尺度の違い**: $a$ が $10^3$、$k$ が $10^{-3}$ のように桁が違うと、一手の向きが偏ります。`x_scale` などで尺度を揃えます。
- **識別できないパラメータ**: 二つのパラメータの効果がほぼ同じだと、$J^\top J$ がほぼ特異になり、値が定まりません。特異値を見て、モデルやデータを見直します。
