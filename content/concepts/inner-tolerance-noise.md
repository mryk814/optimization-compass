ツールが中で方程式を反復で解いていると、目的関数は式の上では滑らかでも、返る値は細かな階段になります。差分の幅がその段より細かいと、勾配から内側の量の変化が消え、ソルバーは本当の最小からずれた点で収束したと報告します。差分の幅を変えて傾きを見比べれば、この段差を見つけられます。

## 30秒でつかむ

[ソルバーが目的関数を呼ぶ点と回数](#/learn/concept.solver-evaluation-points)と同じ、鋼の熱処理の例を使います。温度 $T$（K）と炭素の量 $c$ をツールに渡すと、費用 $F$ が返ります。ツールは中で硬さ $y$ の方程式を二分法で解き、区間の幅が許容誤差より狭くなったら止めます。

1回の計算を速くしたくて、この許容誤差を $10^{-13}$ から $10^{-3}$ に緩めたとします。二分法の回数は45回から11回に減ります。同じ初期点と範囲でL-BFGS-Bを実行すると、次の結果になりました。

| 内側の許容誤差 | 評価の回数 | 答えの温度 $T$ | 報告された $F$ | 細かいツールで測り直した $F$ |
|---|---|---|---|---|
| $10^{-13}$ | 39 | 1247.73 | 0.2387 | 0.2387 |
| $10^{-6}$ | 27 | 1250.00 | 0.2390 | 0.2390 |
| $10^{-3}$ | 12 | 1250.00 | 0.2386 | 0.2390 |

$10^{-3}$ の行は、評価が少なく、報告された費用も一番小さく見えます。ところが、細かいツールで同じ点を測り直すと0.2390で、$10^{-13}$ の答えの0.2387より高くなります。$10^{-6}$ でも、答えの温度は1250.00で、本当の最小からずれています。

- **決めるもの**: 温度 $T$ と炭素の量 $c$
- **良くしたいもの**: ツールが返す費用 $F$
- **守ること**: $900\le T\le1600$、$10^{-5}\le c\le0.01$

炭素の量はどの実行でも下限の $10^{-5}$ に着くので、違いは温度だけに出ます。式は同じなのに、なぜ許容誤差を緩めると、答えが1250 Kに寄るのでしょうか。0.2386という、本当の最小より小さい費用は、どこから来たのでしょうか。

## 内側の許容誤差は値を階段にする

ツールの中の二分法は、硬さ $y$ が入る区間 $[0,2]$ を半分にし続けます。区間の幅が許容誤差より狭くなったら、最後の区間の中点を $y$ として返します。そのため、返る $y$ は、幅 $w$ の格子の上の値しか取りません。

$$
w=\frac{2}{2^{k}}
$$

ここで $k$ は、区間の幅が許容誤差より狭くなるまでに半分にした回数です。

許容誤差 $10^{-6}$ では $k=21$ で、$w$ は $9.5\times10^{-7}$ です。温度を動かしても、本当の $y$ が隣の格子の値に移るまで、返る $y$ は変わりません。

本当の硬さは、答えの温度の近くで1 Kあたり $-0.000258$ だけ変わります。返る $y$ が一段変わるには、温度を次の幅だけ動かす必要があります。

$$
\frac{w}{|dy/dT|}=\frac{9.5\times10^{-7}}{0.000258}\approx0.0037\ \text{K}
$$

許容誤差 $10^{-3}$ では $w$ が $9.8\times10^{-4}$ になり、段の幅は約3.8 Kに広がります。

次の図は、本当の最小の温度 $T^*=1247.76$ の前後0.01 Kで、硬さを描いたものです。

![T* の前後0.01 Kで、硬さ y と y(T*) の差（×10⁻⁶）を描いた図。許容誤差1e−13のyは右下がりのなめらかな直線。許容誤差1e−6のyは、高さ約9.5×10⁻⁷、幅0.0037 Kの階段。差分の幅1e−8 Kの2点は同じ段に乗り、幅0.01 Kの2点は段をまたぐ。](./figures/inner-tolerance-stair.svg "炭素の量 c=0.00001、T*=1247.76 K の前後：返る硬さの階段。教材用のツールの式で、実際の鋼の硬さは示さない")

緑の直線は細かいツールの $y$、橙の階段は許容誤差 $10^{-6}$ の $y$ です。費用 $F$ は $y$ の式なので、$F$ も同じ幅の階段になります。

## 小さな例・答えの温度で差分の傾きを作る

### 鋼の例・本当の傾きは二つの項の釣り合い

$c=10^{-5}$ のまま温度だけを動かすと、費用の温度に対する傾きは、二つの項の和です。

$$
\frac{dF}{dT}=\underbrace{2\,(y-1.05)\,\frac{dy}{dT}}_{\text{硬さの項}}+\underbrace{\frac{T-1250}{10000}}_{\text{温度の項}}
$$

$T^*=1247.76$ では、$y=0.6158$、$dy/dT=-0.000258$ です。硬さの項と温度の項は、それぞれ次のとおりです。

$$
2\,(y-1.05)\,\frac{dy}{dT}=+0.000224
$$

$$
\frac{T^*-1250}{10000}=-0.000224
$$

二つが打ち消し合って、傾きは0になります。

温度を上げると、硬さが下がって費用が増えます。一方で1250 Kに近づくので、温度の費用は減ります。最小は、この二つが釣り合う所です。

### 鋼の例・差分の幅ごとの傾き

ソルバーは、この傾きを差分 $\bigl(F(T+h)-F(T)\bigr)/h$ で作ります。$T^*$ で、差分の幅 $h$ を変えて計算すると、次のようになります。表の値は傾きを $10^{4}$ 倍したもので、$-2.24$ は傾き $-0.000224$ を表します。

| 差分の幅 $h$ | $10^{-8}$ | $10^{-4}$ | $10^{-2}$ | $10^{-1}$ |
|---|---|---|---|---|
| 許容誤差 $10^{-13}$ | +0.03 | +0.00 | +0.00 | +0.05 |
| 許容誤差 $10^{-6}$ | −2.24 | −2.24 | −0.58 | +0.04 |

許容誤差 $10^{-6}$ では、$h$ が段の幅0.0037 Kより細かいと、$T$ と $T+h$ が同じ段に乗ります。$y$ の差が0になり、差分は温度の項 $-0.000224$ だけを見ます。そのため、本当は傾き0の $T^*$ で、ソルバーには「温度を上げれば下がる」と見えます。L-BFGS-Bの差分の幅は $10^{-8}$ なので、この実行は温度の項だけが0になる1250 Kまで進みました。

$h=0.1$ は段をいくつもまたぐので、差分は本当の傾きに近い $+0.000004$ になります。$h=0.01$ は段を2〜3段しかまたがないので、その間の値になります。

![差分の幅 h（1e−9から1 K）を横軸に、T*での前進差分の傾き（×10⁻⁴）を描いた図。本当の傾きは0の破線。許容誤差1e−13ではhによらずほぼ0。1e−6ではhが段差の幅0.0037 Kより小さいと−2.24のままで、それより大きいと0のまわりで揺れたあと0に戻る。1e−3ではh=1 Kでも−1.74。](./figures/inner-tolerance-slope.svg "T*=1247.76 K、c=0.00001：差分の幅ごとの傾き。教材用のツールの式で、ほかのツールの段差の幅は示さない")

### 鋼の例・本当の最小より小さい費用

許容誤差 $10^{-3}$ では、返る $y$ が本当の値から最大で区間の幅の半分、約 $4.9\times10^{-4}$ ずれます。1250 Kでは、本当の $y=0.61527$ に対して、返る $y$ は $0.61572$ でした。目標の1.05に $4.5\times10^{-4}$ 近い値が返ったので、費用は $3.9\times10^{-4}$ だけ低く出ます。これが、本当の最小0.2387より小さい0.2386の正体です。

## つまずきやすい点

- **評価が少なく、報告された費用が小さい実行を良い結果だと考える**: 許容誤差 $10^{-3}$ の実行は、評価12回で0.2386と報告しました。細かいツールで測り直すと0.2390で、本当の最小0.2387より高い点です。速く終わったのは、段差のせいで傾きが早く0に見えたからです。報告された値は、細かい設定で測り直してから比べてください。
- **差分の幅は小さいほど正確だと考える**: 許容誤差 $10^{-6}$ の傾きは、$h=10^{-8}$ でも $10^{-4}$ でも $-0.000224$ です。本当の傾き0とは符号まで違います。差分の幅を細かくしても、段の幅0.0037 Kより細かい限り、硬さの変化は見えません。
- **勾配を使わない方法なら段差は関係ないと考える**: 許容誤差 $10^{-6}$ では、範囲を指定したNelder–Meadは $T=1247.75$ に着きました。ただし評価は133回で、細かいツールでの79回より増えています。許容誤差 $10^{-3}$ では、段の幅3.8 Kが単体より大きくなり、評価84回で $T=1250.00$ に着きました。手法を変えても、段の幅より細かい違いは見分けられません。

## 確かめ方と直し方

段差は、答えの点で差分の幅を変えて傾きを作れば見つかります。表のように、幅を $10^{-8}$ から $10^{-1}$ まで変えて傾きを作ります。傾きが幅によって大きく変わるなら、返る値に段差があると疑います。滑らかな関数なら、細かい幅ではどれもほぼ同じ傾きになります。

直し方は二つあります。

1. **内側の許容誤差を小さくする**: 差分の幅 $10^{-8}$ で、硬さは $2.6\times10^{-12}$ しか動きません。1 Kあたりの変化 $0.000258$ に幅を掛けた量です。許容誤差 $10^{-13}$ はこれより小さいので、$10^{-13}$ の行は本当の最小に着きました。ツールの許容誤差を設定できるなら、差分で動く量より小さくします。
2. **差分の幅を、段の幅より大きくする**: L-BFGS-Bの差分の幅は、`options` の `eps` で変えられます。許容誤差 $10^{-6}$ のまま `eps=0.01` にすると、評価93回で $T=1247.83$ に着き、細かいツールで測り直した費用は0.2387でした。ただし、幅を大きくしすぎると、今度は曲がり（2階微分）による誤差が増えます。値に $\varepsilon$ 程度の誤差があるとき、前進差分の幅は $\sqrt{\varepsilon}$ 程度が目安です。

許容誤差を設定できず、段の幅も分からないツールなら、値の比較だけで進む方法も候補です。その場合も、段の幅より細かい答えは得られません。

## Python

次のコードは、許容誤差を引数にした例のツールを作り、三つの確かめ方を実行します。`# →` の行は、SciPy 1.18.1で実行したときの出力です。

```python
from scipy.optimize import minimize


def hardness(T, c, tol):
    # 平衡計算の代わり: y**3 + (T/1000)*y = 1 + 200*c を、幅が tol になるまで二分法で解く
    lo, hi = 0.0, 2.0
    while hi - lo > tol:
        mid = 0.5 * (lo + hi)
        if mid**3 + T / 1000 * mid - 1 - 200 * c > 0:
            hi = mid
        else:
            lo = mid
    return 0.5 * (lo + hi)


def make_tool(tol):
    def tool(x):
        T, c = x
        if c <= 0:
            raise ValueError("炭素量が範囲外")
        y = hardness(T, c, tol)
        return (y - 1.05) ** 2 + 0.5 * ((T - 1250) / 100) ** 2 + 5000 * c

    return tool


exact = make_tool(1e-13)  # 答え合わせ用の、十分に細かいツール
x0 = [1200.0, 0.0005]
box = [(900, 1600), (1e-5, 0.01)]

# 1. 内側の許容誤差だけを変えて、L-BFGS-B を同じ条件で実行する
for tol in [1e-13, 1e-6, 1e-3]:
    res = minimize(make_tool(tol), x0, method="L-BFGS-B", bounds=box)
    print(f"tol={tol:g}: 評価 {res.nfev} 回, T={res.x[0]:.2f}, "
          f"報告 F={res.fun:.4f}, 本当の F={exact(res.x):.4f}")
# → tol=1e-13: 評価 39 回, T=1247.73, 報告 F=0.2387, 本当の F=0.2387
# → tol=1e-06: 評価 27 回, T=1250.00, 報告 F=0.2390, 本当の F=0.2390
# → tol=0.001: 評価 12 回, T=1250.00, 報告 F=0.2386, 本当の F=0.2390

# 2. 答えの温度 T*=1247.76 で、差分の幅 h を変えて傾きを作る
T_star, c = 1247.7584, 1e-5
for tol in [1e-13, 1e-6]:
    f = make_tool(tol)
    slopes = [(f([T_star + h, c]) - f([T_star, c])) / h for h in [1e-8, 1e-4, 1e-2, 1e-1]]
    print(f"tol={tol:g}:", " ".join(f"{s * 1e4:+.2f}" for s in slopes))  # 傾き×10^4
# → tol=1e-13: +0.03 +0.00 +0.00 +0.05
# → tol=1e-06: -2.24 -2.24 -0.58 +0.04

# 3. 差分の幅を段差より大きくする（L-BFGS-B の eps）
res = minimize(make_tool(1e-6), x0, method="L-BFGS-B", bounds=box, options={"eps": 1e-2})
print(f"eps=0.01: 評価 {res.nfev} 回, T={res.x[0]:.2f}, 本当の F={exact(res.x):.4f}")
# → eps=0.01: 評価 93 回, T=1247.83, 本当の F=0.2387
```

1の出力の「本当の F」は、答えの点を許容誤差 $10^{-13}$ のツールで測り直した値です。報告された値と測り直した値が違えば、返る値に段差があります。2の出力は、本文の表と同じ傾きを $10^{4}$ 倍した値です。許容誤差 $10^{-13}$ の $h=10^{-8}$ の $+0.03$ は、浮動小数点の丸めによる小さなずれです。3の出力は、差分の幅を変えるだけで、同じツールのまま答えが本当の最小に戻ることを示します。

この記事の段差は、同じ入力なら同じ値が返る点で、noiseを含むblack-boxと違います。そのため、同じ点を何度も評価して平均しても消えません。また、段の高さは許容誤差の程度で小さく、値が大きく飛ぶ不連続とも違います。勾配を差分で作るときにだけ、段差は大きな誤りとして現れます。

## 出典と再現条件

差分の誤差と、値の誤差に合わせた差分の幅の目安は、Nocedal・Wrightの教科書『Numerical Optimization』（S056）に基づきます。L-BFGS-Bの上下限の扱いはByrdらの論文（S065）に、Nelder–Meadは原論文（S063）に基づきます。`minimize` の `bounds` と `options` の `eps` は、SciPyの公式文書（S002）に基づきます。

例の数値は、SciPy 1.18.1で上のコードを実行して得た値です。$T^*=1247.7584$ は、許容誤差 $10^{-13}$ のツールで $c=10^{-5}$ のまま温度だけを最小にした値です。ツールの式は教材用で、実際の鋼の平衡計算や、ほかのツールの段差の幅は示しません。
