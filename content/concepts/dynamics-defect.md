タンクの水位は今1 mです。ポンプで入れる水の量を5分ごとに決めて、30分かけて水位を0.5 mへ下げ、そこで保つ計画を作ります。ソルバーに途中経過を出させると、水位の線は目標どおりなのに「動力学残差が大きい」と表示されました。何がずれているのでしょうか。

タンクは[ソルバーが目的関数を呼ぶ点と回数](#/learn/concept.solver-evaluation-points)から続く連載と同じもので、断面積は1 m²です。連載では流出口の面積と流入を記録に当てはめましたが、ここでは流出口を固定し、流入をポンプで決めます。ソルバーが決めるのは、5分ごとの水位6個とポンプの流量6個です。費用は、水位が目標から離れた分と流量の、それぞれの二乗和です（10 cmのずれと1 L/sの流量を同じ重みで数えます）。

「自分で動かす」を押すと、橙の丸と流量の棒を上下に動かせます。丸を1つだけ持ち上げると、残差の棒は2本動きます。その丸に届く区間と、その丸から出る区間の2つです。

## 見たことを式にする

図の青緑の線は、区間の始まりの水位 $s$ と流量 $q$ から、5分後の水位を1回の計算で出したものです。水位はm、流量はL/sで測ると、次の式になります。

$$
f_d(s,q)=s+0.3\,\bigl(q-1.772\sqrt{s}\bigr)
$$

$1.772\sqrt{s}$ は流出の量（L/s）で、0.3 は、1 L/sを5分続けたときに変わる水位（m）です。ポンプを止めて0.5 mから進めると $0.5-0.3\times1.772\times\sqrt{0.5}=0.124$ になり、図の最初のすき間 $0.5-0.124=0.376$ が出ます。

結び目 $k$ の残差は、置いた水位から、手前の結び目を式で進めた水位を引いたものです。

$$
d_k=s_k-f_d(s_{k-1},q_{k-1})
$$

6個の残差がすべて0なら、置いた水位はこの式をたどっています。図のソルバーは、$d_k=0$ を等式制約にして、費用を最小にしました。

## 定義と記号

一般には、状態を $x_k$、操作量を $u_k$ と書き、離散化した動力学 $x_{k+1}=f_d(x_k,u_k)$ に対する残差を次のように定めます。

$$
d_k=x_{k+1}-f_d(x_k,u_k)
$$

図の $s_k$ が $x_k$、$q_k$ が $u_k$ です。残差は状態と同じ単位を持つベクトルです。タンクの例で「湧いた水」と読めたのは、状態が水位1つで断面積が1 m²だったからで、一般には物理量として読めるとは限りません。

残差は、等式制約として0にする場合も、重みを付けて目的に足す場合もあります。どちらでも、費用と残差は別に読みます。

## 手法ごとに、残差が現れる場所

| 手法 | 状態の扱い | 残差が現れる場所 |
| --- | --- | --- |
| Direct Shooting | 最初の状態から積分して作る | 途中の状態を変数にしないので、継ぎ目がありません。図でいえば、丸を置かない方法です。 |
| Direct Multiple Shooting | 区間の始まりの状態も変数にする | 区間を積分した終点と、次の区間の始まりの状態との差です。図はこの形です。 |
| Direct Collocation | 格子点の状態を変数にする | 状態を近似する多項式の傾きが、選点でモデルの式と合わない分です。 |

残差の値は、積分器、選点の方式、状態の尺度で変わります。別の実装の数値と並べる前に、ノルム、正規化、時刻点、積分器を揃えます。

## 記録するもの

最大残差と二乗和は、どちらも場所を言いません。次の3つを一緒に残すと、原因を切り分けやすくなります。

- 最大残差と、それが出た時刻
- 時刻ごとの残差の列。境界、接触、操作量が急に変わる所で跳ねていないかを見ます
- 状態ごとの尺度で割った残差。単位の大きい状態だけが目立っていないかを見ます

費用は下がり続けるのに残差が止まるときは、停止の基準を緩める前に、初期軌道、尺度、正則化、格子、積分器を一つずつ分けて確かめます。

## 残差が小さくても言えないこと

残差が示すのは、離散化した式との整合だけです。実際の装置がモデルどおりに動くこと、区間の途中で経路の制約を守ること、格子を細かくしても同じ解が出ることは、残差からは分かりません。

最終候補の操作量は、ソルバーとは別の高精度の計算に通し、状態、経路の制約、終端の状態を測り直します。図の最後の2段は、その測り直しを1回だけ行ったものです。

## Python

図と同じ計算です。`# →` の行は、NumPy 2.5.3 と SciPy 1.18.1 で実行したときの出力です。

```python
import numpy as np
from scipy.integrate import solve_ivp

C = 1000 * 0.0004 * np.sqrt(2 * 9.81)  # 水位 1 m のときの流出（L/s）
N, KAPPA = 6, 0.3  # 6区間。1 L/s を5分続けると水位が 0.3 m 変わる


def f_d(s, q):
    # 5分をオイラー法の1歩で進めた水位と、その s での微分
    return s + KAPPA * (q - C * np.sqrt(s)), 1 - KAPPA * C / (2 * np.sqrt(s))


def defects(s, q):
    # d_k = s_k - f_d(s_{k-1}, q_{k-1})。最初の水位 1 m は固定
    before = np.concatenate([[1.0], s[:-1]])
    return s - f_d(before, q)[0]


def cost(s, q):
    return np.sum(((s - 0.5) / 0.1) ** 2) + np.sum(q**2)


def sqp_step(s, q):
    # 残差を等式制約にした逐次二次計画法の1歩（ヘッセ行列は目的の分だけ）
    before = np.concatenate([[1.0], s[:-1]])
    slope = f_d(before, q)[1]
    jac = np.hstack([np.eye(N) - np.diag(slope[1:], -1), -KAPPA * np.eye(N)])
    hess = np.diag([200.0] * N + [2.0] * N)
    grad = np.concatenate([200 * (s - 0.5), 2 * q])
    kkt = np.block([[hess, jac.T], [jac, np.zeros((N, N))]])
    step = np.linalg.solve(kkt, -np.concatenate([grad, defects(s, q)]))
    return s + step[:N], q + step[N : 2 * N]


s, q = np.full(N, 0.5), np.zeros(N)  # 初期推定：水位は全部 0.5 m、ポンプは止める
for i in range(4):
    worst = np.max(np.abs(defects(s, q)))
    shown = f"{worst:.1e}" if worst > 1e-9 else f"10^{np.floor(np.log10(worst)):.0f} の桁"
    print(f"反復{i}: 費用 {cost(s, q):.4f}, 最大残差 {shown}")
    if i < 3:
        s, q = sqp_step(s, q)
# → 反復0: 費用 0.0000, 最大残差 3.8e-01
# → 反復1: 費用 7.5595, 最大残差 6.5e-05
# → 反復2: 費用 7.5575, 最大残差 1.1e-08
# → 反復3: 費用 7.5575, 最大残差 10^-12 の桁

print(f"ポンプが入れる水 {np.sum(q) * 300:.0f} L")
# → ポンプが入れる水 1856 L

# 同じ流量のまま、連続時間のタンクの式を細かく解く
h, fine = 1.0, []
for flow in q:
    sol = solve_ivp(lambda t, y: [(flow - C * np.sqrt(y[0])) / 1000], (0, 300), [h], rtol=1e-11, atol=1e-13)
    h = sol.y[0, -1]
    fine.append(h)
print(f"5分の水位: 結び目 {s[0]:.3f} m, 細かく解くと {fine[0]:.3f} m")
# → 5分の水位: 結び目 0.519 m, 細かく解くと 0.582 m
print(f"30分の水位: 結び目 {s[-1]:.3f} m, 細かく解くと {fine[-1]:.3f} m")
# → 30分の水位: 結び目 0.461 m, 細かく解くと 0.476 m
```
