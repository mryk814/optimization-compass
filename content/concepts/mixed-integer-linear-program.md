混合整数線形計画は、線形計画の一部の変数に「整数であること」を加えた定式化です。この一条件で一般に可行集合の凸性が失われるため、緩和で得た界と見つけた解の差（最適性ギャップ）を詰めながら最適性を証明します。

## 30秒でつかむ

連続量の最良値が分かったら、最後に整数へ丸めるだけでよいでしょうか。MILPでは「実行できる良い整数解を見つけること」と「これより良い解がないと示すこと」を分けます。同じ小さな生産例で、この二つを追います。

トラックを2.4台買うことはできません。倉庫を半分だけ開くこともできません。
現実の決定には、個数・台数や、する・しないのような飛び飛びの値がよく現れます。
線形計画に「この変数は整数」という条件を足した定式化が、混合整数線形計画（MILP）です。

- **決めるもの**: 連続の量と、整数や0-1の決定の組み合わせ
- **良くしたいもの**: 線形計画と同じく、量に比例する費用の合計
- **守ること**: 線形の制約と、一部の変数の整数条件

整数条件は一行で書けますが、問題の性質を大きく変えます。
可行な点が飛び飛びになり、「近くの点より良ければ全体でも最良」という凸の性質が成り立たなくなります。

## 標準形を読む

$$
\min_{x}\; c^\top x \quad \text{s.t.}\quad Ax\le b,\quad x_j\in\mathbb{Z}\;\;(j\in I)
$$

添字の集合 $I$ に入る変数だけが整数です。$I$ が空なら線形計画、全部なら純粋整数計画です。
0-1変数（二値）は、整数変数に $0\le x_j\le 1$ を足したものです。

0-1変数を使うと、論理的な条件を線形の式で書けます。これがMILPの表現力の源です。

| 表したいこと | 書き方 |
|---|---|
| 作るなら固定費 $f$ がかかる | $x\le M y,\; y\in\{0,1\}$、目的に $f\,y$ を足す |
| AかBのどちらか一つだけ選ぶ | $y_A+y_B=1$ |
| Aを選ぶならBも選ぶ | $y_A\le y_B$ |

$x$ を非負の生産量として、$M$ にはモデルから導いた妥当な上限を使います。$y=0$ なら $x=0$、$x>0$ なら $y=1$ が必要になります。big-Mと呼ばれるこの上限は、値の選び方が解きやすさを左右します。小さすぎる $M$ は本来選べる生産量を除外し、大きすぎる $M$ は連続緩和を弱めます。

## 小さな例

[変数の定義域](#/learn/concept.variable-domain)で使った生産例です。Aを $x_1$ 個、Bを $x_2$ 個作り、二つの資源上限の下で利益を最大にします。

$$
\max\; 5x_1+4x_2 \quad \text{s.t.}\quad 6x_1+4x_2\le 24,\;\; x_1+2x_2\le 6,\;\; x_1,x_2\in\mathbb{Z}_{\ge 0}
$$

整数条件を外した線形計画（LP緩和）の答えは $(3,\,1.5)$ で、目的値は $21$ です。
これを丸めてみます。$(3,2)$ は $6\times3+4\times2=26>24$、$3+2\times2=7>6$ なので、2本の制約を両方とも破ります。$(3,1)$ は実行可能ですが、目的値は $19$ です。

整数の最適解は $(4,0)$ で、目的値は $20$ です。LP緩和の答えから離れた場所にあります。
丸めでは最適解に届かず、制約を破ることさえある点が、MILPを別の定式化として扱う理由です。

![左は整数可行点と連続緩和の最良点、右は手で指定した五つのLP緩和からなる分枝木。整数最適値は20、根の緩和上界は21。](./media/milp-relaxation-tree.svg "左の青点が可行な整数候補、菱形がLP緩和解、星が整数の最良解です。右は教材用の分枝順であり、HiGHSの実際の探索ログではありません。")

図の左では、整数として選べる青い点だけを見ます。LP緩和の菱形は領域には入っていますが、格子点ではありません。利益21は「実行できる計画の利益」にはまだなっていない、と読むことが大切です。破線は利益21、実線は利益20の等高線です。

### 界と最適性ギャップで進み具合を測る

LP緩和の値 $21$ は、どの整数解もこれを超えられないという**上界**です。整数候補の集合は緩和の可行集合に含まれるので、候補を増やした最大化問題の最良値より高くはなれません。最小化問題では向きが逆になり、緩和は下界を与えます。

一方、可行な整数解 $(4,0)$ が見つかれば、その利益20は最適値の**下界**です。この段階で分かることは

$$
20\;\le\;\text{整数最適値}\;\le\;21
$$

です。上界は「残る改善の余地」を、整数解は「今すぐ実行できる計画」を表します。この正の利益の例で、暫定最良値20を分母にした相対ギャップは $(21-20)/20=5\%$ です。これは探索途中の情報を説明する値で、後のMILPソルバーの最終結果のギャップではありません。

相対ギャップの定義や目的値0付近の扱いはソルバーで異なります。時間切れの報告では、相対値だけでなく、整数候補の値と界そのものも残すと意味を取り違えません。可行な整数候補がまだ見つかっていなければ、緩和値だけを実行計画として返せません。

### 5個の緩和で何を調べるか

根の解は $x_2=1.5$ です。整数なら $x_2\le1$ または $x_2\ge2$ のどちらかなので、この二つに分けても整数候補は失われません。分けた後に同じ線形計画を解き直します。

| 追加した範囲 | LP緩和解 | 利益の上界 | 次の判断 |
|---|---|---:|---|
| なし | $(3,1.5)$ | 21 | $x_2$ で分ける |
| $x_2\le1$ | $(10/3,1)$ | $62/3\approx20.667$ | まだ分数なので $x_1$ で分ける |
| $x_2\le1,\;x_1\le3$ | $(3,1)$ | 19 | 整数解であり、この枝の最良値も19 |
| $x_2\le1,\;x_1\ge4$ | $(4,0)$ | 20 | 整数解20を得る |
| $x_2\ge2$ | $(2,2)$ | 18 | 20を改善できないので終了 |

右の木の末端は、19、20、18で、それぞれの枝の整数解はこの上界を超えられません。すべての整数候補をどれかの枝が覆い、実際に利益20の整数解があるので、これで**最適値は20**だと証明できます。

「5個」はこの手で指定した枝分けを、根も含めて数えた値です。実ソルバーは前処理、カット、整数目的の界の丸め、探索順を使うので、同じ5個を解くとは限りません。図は分枝限定の仕組みを追うためのもので、ソルバーの内部を再現したログではありません。

## 見分け方

次の兆候があれば、MILPを考えます。

- 買う・買わない、開く・閉じる、割り当てる・割り当てないの決定がある
- 固定費、最小ロット、台数の上限がある
- 「どちらか一方」「Aならば B」のような論理条件がある

一方で、次の兆候があれば別の型が合うかもしれません。

- 変数がすべて0-1で、条件の多くが論理式 → SAT・制約プログラミング
- 時間の区間の重なりや順序が主役 → 制約プログラミング型スケジューリング
- 整数の供給・需要・容量を持つ通常の単一商品ネットワークフロー → 構造を利用し、LPとして整数の最適解を得られる場合がある。追加の結合制約などで整数性が失われないかを確認する

## 近い定式化

- **線形計画**: 整数条件のないMILPで、MILPの緩和でもあります。探索の内部では、線形計画が多数解かれることがあります。
- **ナップサック問題**: 制約が1本の0-1整数計画です。動的計画法でも解けます。
- **混合整数二次計画**: 線形目的を二次目的へ拡張した形です。二次項が凸か非凸かで、連続緩和の扱いも変わります。
- **SAT・スケジューリング**: MILPで書き直せますが、専用の方法の方が自然で速いことがよくあります。

## 解き方の系統

- **分枝限定法（branch-and-bound）**: 緩和で上界（最小化なら下界）を求め、変数の範囲を分けて探索木を作ります。改善できないと分かった枝は切ります。
- **branch-and-cut**: 分枝に加えて、整数解を切り落とさずに緩和を締める制約（cut）を足します。現在の商用・OSSのMILP ソルバーの標準です。
- **CP-SAT**: 論理伝播とSAT由来の学習を組み合わせます。整数・論理・スケジューリングの問題で候補になります。一般の連続変数をそのまま扱うMILPソルバーとは、対応するモデルが異なります。
- **ヒューリスティクス**: 良い整数解を早く見つけます。ソルバーの内部でも使われますが、単独では最適性を証明しません。

次のコードは、元の整数問題を `scipy.optimize.milp`（内部はHiGHS）で解きます。SciPyは最小化APIなので、利益の係数へマイナスを付けます。表示時は目的値だけでなく、双対界の符号も戻します。

```python
import numpy as np
from scipy.optimize import Bounds, LinearConstraint, milp, linprog

A = np.array([[6., 4.], [1., 2.]])
b = np.array([24., 6.])
profit = np.array([5., 4.])
result = milp(
    c=-profit, constraints=LinearConstraint(A, -np.inf, b),
    integrality=[1, 1], bounds=Bounds(0., np.inf),
    options={"mip_rel_gap": 0.},
)
print("status:", result.status, result.message)
if result.x is not None:
    print("plan/profit:", result.x, -result.fun)
    print("constraint excess:", A @ result.x - b)
    print("integrality error:", np.max(np.abs(result.x-np.round(result.x))))
    print("profit upper bound:", -result.mip_dual_bound)
    print("relative gap:", result.mip_gap)
```

この設定では $(4,0)$、利益20、利益の上界20、相対ギャップ0になります。最小化APIが内部で扱った値は−20なので、`mip_dual_bound` をそのまま「利益の下界」と読まないでください。

続いて、図の五つの緩和を手で指定して検算します。これは上のMILP呼出しの実行履歴ではありません。

```python
nodes = [
    ("root",       [(0, None), (0, None)]),
    ("x2 <= 1",    [(0, None), (0, 1)]),
    ("also x1<=3", [(0, 3),    (0, 1)]),
    ("also x1>=4", [(4, None), (0, 1)]),
    ("x2 >= 2",    [(0, None), (2, None)]),
]
for name, bounds in nodes:
    lp = linprog(-profit, A_ub=A, b_ub=b, bounds=bounds, method="highs")
    assert lp.success
    print(name, lp.x.round(6), round(-lp.fun, 6))
```

上界は表と同じ21、20.666667、19、20、18になります。表示を丸めても、分枝条件は $x_1\le3$ と $x_1\ge4$ のような元の整数条件から作ります。

## つまずきやすい点

- **big-M が大きすぎる**: $M$ を大きく取るほど緩和が緩くなり、この最大化の例では上界が締まりにくくなります。最小化なら下界が低いまま残る方向です。数値誤差の原因にもなります。モデルから妥当だと保証できる、できるだけ小さい上限を使います。
- **対称性**: 同じ性能のトラックが10台あると、入れ替えただけの同じ解が大量に生まれ、探索木が膨らみます。本当に同じ役割の変数だけを入れ替える対称性か確認してから、代表を残す順序制約などを検討します。
- **時間切れの解を最適と読む**: 停止理由と最適性ギャップを必ず記録します。最適性ギャップが残っていれば、それは「実行可能な良い解」であって最適解の証明ではありません。
- **LP解の丸め**: 例で見たとおり、丸めは実行可能性も最適性も保証しません。
