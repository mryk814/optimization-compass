ツールが中で微分方程式を解いていると、ソルバーが受け取る値は式の値ではなく、解き方の誤差を足した値です。誤差は変数につれてなめらかに変わる所と、刻みの数が変わって跳ぶ所があります。そのため、報告される値や差分の傾きは式のものからずれ、評価の回数は計算機によって変わることがあります。答えは、細かい許容誤差で測り直して確かめます。

## 30秒でつかむ

[ソルバーが目的関数を呼ぶ点と回数](#/learn/concept.solver-evaluation-points)と同じ、タンクの水位の例を使います。ツールは流出口の面積 $a$（m²）と流入量 $q$（m³/s）を受け取り、水位の式を `solve_ivp` で解きます。返すのは、31回の記録とのずれの二乗和です。

`solve_ivp` は、時間の刻みを自分で選びながら式を解きます。選び方の基準になるのが、解き方（`method`）と許容誤差（`rtol`）です。この二つだけを変えて、同じ初期点と上下限で L-BFGS-B を実行しました。

| 解き方と許容誤差 | 報告された二乗和 | 測り直した二乗和 | 評価の回数 |
|---|---|---|---|
| RK45、$10^{-3}$（既定） | $0.000498$ | $0.000497$ | 96〜126回 |
| Radau、$10^{-3}$ | $0.000503$ | $0.000497$ | 54回 |
| RK45、$10^{-8}$ | $0.000497$ | $0.000497$ | 51〜177回 |
| Radau、$10^{-8}$ | $0.000497$ | $0.000497$ | 54回 |

「測り直した二乗和」は、答えの点を許容誤差 $10^{-10}$ の Radau で解き直した値です。評価の回数は、同じ版の SciPy で、NumPy が使う行列計算の部品（OpenBLAS）を4通りに切り替えて実行したときの範囲です。

答えは、どの設定でも3桁で $(a,q)=(0.000401,\ 0.000501)$ でした。ところが、報告された二乗和は設定ごとに違います。許容誤差 $10^{-3}$ の Radau は、測り直した値より約1%大きい $0.000503$ を報告しました。RK45 の評価の回数は、計算機の部品を替えるだけで変わります。

- **決めるもの**: 流出口の面積 $a$ と流入量 $q$
- **良くしたいもの**: 計算した水位と記録のずれの二乗和
- **守ること**: $0.00001\le a,q\le0.001$

式は同じなのに、なぜ報告される値が設定で変わり、評価の回数が計算機で変わるのでしょうか。

## ツールの値は、式の値に解き方の誤差を足したもの

水位の式を正確に解いたときの二乗和を $F(a,q)$ とします。ツールが返すのは、これに解き方の誤差 $e(a,q)$ を足した値です。

$$
F_{\text{tool}}(a,q) = F(a,q) + e(a,q)
$$

この式は「ソルバーが最小にしているのは、式の二乗和ではなく、誤差を足した二乗和だ」と読みます。$e$ は、解き方と許容誤差を変えると変わります。

`solve_ivp` が選ぶ刻みは、$a$ と $q$ によって変わります。刻みの並び方が変わらない範囲では、刻みの幅が $a$ につれて少しずつ動くので、$e$ もなめらかに変わります。刻みの数が変わる所では、$e$ が跳ぶことがあります。刻みの数は、水位の式の右辺を計算した回数（`sol.nfev`）で数えられます。

次の図は、$q=0.000501$ に固定して $a$ だけを動かしたときの $e$ です。既定の RK45 で解いた二乗和から、細かい許容誤差で解いた二乗和を引きました。

![流出口の面積 a（0.00031〜0.00049）を横軸に、RK45（rtol=1e−3）で解いた二乗和と細かい許容誤差で解いた二乗和の差（×10⁻⁵）を描いた図。線は、右辺を計算した回数が同じ範囲ごとに切れていて、回数は50・62・68・74・80・86回と増える。a=0.000329 で−6.79×10⁻⁵、a=0.000447 で−1.23×10⁻⁵ の段差がある。ほかの3か所では、線は折れるが跳ばない。答えの a=0.000401 は、回数68回の範囲の中にある。](./figures/inner-solver-steps.svg "q=0.000501、RK45、rtol=1e−3：二乗和の、式からのずれ。SciPy 1.18.1 での計算で、ほかの解き方や記録での段差の位置は示さない")

図から、次の三つが読めます。

1. $e$ は0のまわりではなく、$-0.00024$ から $+0.00009$ まで、$a$ につれて大きく変わります。答えの近くで $e$ が0に近いのは、この記録とこの範囲での偶然です。
2. 右辺の回数が変わる5か所のうち、2か所で $e$ が跳びます。残りの3か所では、線は跳ばずに折れます。
3. 答えの $a=0.000401$ は、回数68回の範囲の中にあり、近くに段差はありません。

## 小さな例・段差と傾きのずれを数値で見る

### タンクの例・a を 10⁻¹² 動かすと二乗和が跳ぶ

$q=0.000501$ のまま、$a$ を $0.0003288929879$ から $0.0003288929889$ へ、$10^{-12}$ だけ動かします。RK45 の右辺の回数は50回から62回に増え、ツールが返す二乗和は $0.331977$ から $0.331909$ に下がります。差は $-0.000068$ です。

式の二乗和は、この点で $a$ について傾き $-10790$ で変わります。$10^{-12}$ 動かしたときの変化は、次の大きさしかありません。

$$
-10790\times10^{-12}\approx-1\times10^{-8}
$$

ツールが返した差 $-0.000068$ は、その約6000倍です。この差は、式の変化ではなく、解き方の段差から来ています。

### タンクの例・段差をまたぐ差分の傾き

L-BFGS-B は、変数を $10^{-8}$ ずらした差分で勾配を作ります。同じ幅で、段差をまたぐ差分とまたがない差分を作ると、次の値になりました。

| 差分の取り方（幅 $10^{-8}$） | $a$ についての傾き |
|---|---|
| 段差をまたぐ | $-17492$ |
| 段差の手前でまたがない | $-10754$ |
| 式の傾き | $-10790$ |

段差をまたぐ差分は、式の傾きより約60%急です。差のほとんどは、段差の大きさを幅で割った量です。

$$
\frac{-6.79\times10^{-5}}{10^{-8}}\approx-6790
$$

段差のない所では、差分は式の傾きの近くに出ます。ただし、それは式の傾きではなく、$F_{\text{tool}}$ の傾きです。

### タンクの例・答えの近くの傾きのずれ

答えの点 $(0.000401,\ 0.000501)$ で、$a$ をずらす幅 $10^{-9}$ の中心差分で傾きを作ると、次の値になりました。

| 何の傾きか | $a$ についての傾き |
|---|---|
| RK45、$10^{-3}$ のツール | $-12.6$ |
| Radau、$10^{-3}$ のツール | $-14.5$ |
| 式（Radau、$10^{-10}$） | $-14.2$ |

答えの近くでは、RK45 の $e$ は $a$ が $10^{-6}$ 増えるごとに約 $1.6\times10^{-6}$ 増えます。$e$ の傾き約 $+1.6$ が、式の傾き $-14.2$ に足されて $-12.6$ になります。段差がない所でも、差分の傾きは誤差の傾きの分だけ式とずれます。

このずれは、答えの位置をほとんど動かしません。答えの近くで二乗和は急な谷になっていて、傾き1.6程度のずれで谷底の位置が動く量は、表示した3桁より小さいからです。

### タンクの例・評価の回数が計算機で変わる

同じ点を同じ設定で解いても、ツールの値の下の桁は計算機の部品によって変わります。初期点 $(0.0001,\ 0.0001)$ の二乗和は、RK45 では次のように14桁目から違いました。Radau の値も、同じ程度に違います。

| 計算の部品 | RK45 の二乗和 |
|---|---|
| SkylakeX | $4.6618963990685724$ |
| Prescott | $4.6618963990688789$ |

L-BFGS-B は終わりに近づくと、このくらい小さな差しかない値どうしを比べて、次の点や止めるかどうかを決めます。SkylakeX の部品での RK45（$10^{-3}$）の実行は108回でした。64回目から先の45回は、どれも答えから $1.2\times10^{-7}$ 以内の点で、その間に二乗和は $10^{-17}$ 程度しか下がっていません。こうした比べ合いの結果が部品によって変わり、評価の回数が96回から126回までばらつきました。この例の Radau の実行では、4通りの部品のどれでも54回でした。

## つまずきやすい点

- **評価の回数で、設定の良し悪しを比べる**: 許容誤差 $10^{-8}$ の RK45 は、ある部品では51回で別の部品では177回でした。同じ設定でも回数は計算機で変わるので、回数の差を設定の差と読まないでください。回数は計算時間の見積もりに使います。設定を比べるときは、同じ計算機で答えと測り直した二乗和を並べます。
- **報告された二乗和を、当てはまりの良さとして比べる**: 許容誤差 $10^{-3}$ の Radau は $0.000503$ を報告しました。同じ点を測り直すと $0.000497$ です。約1%の差は、解き方の誤差です。二つのモデルや二つの記録の当てはまりを比べるときは、同じ細かい許容誤差で測り直した値を使ってください。
- **許容誤差を締めれば、評価の回数も揃うと考える**: RK45 の許容誤差を $10^{-8}$ に締めても、回数は51回から177回に分かれました。締めると $e$ は小さくなりますが、終わりの比べ合いが下の桁で決まることは変わりません。
- **差分の傾きを、式の傾きだと考える**: 答えの点での傾きは、RK45（$10^{-3}$）のツールで $-12.6$ でした。式の傾きは $-14.2$ です。段差をまたぐと、$-17492$ と $-10790$ のように大きく外れます。勾配が正しいかを差分で確かめるときは、ツールの許容誤差を締めた値でも作って比べてください。

## 確かめ方と直し方

1. **答えを、細かい許容誤差で測り直す**: 報告された二乗和の代わりに、答えの点を許容誤差 $10^{-10}$ 程度で解き直した値を報告します。例では、どの設定の答えも $0.000497$ でした。
2. **答えの近くに段差がないか確かめる**: 答えの点と、そこから差分の幅だけずらした点で、右辺の回数（`sol.nfev`）を比べます。例の答えの近くは、回数68回の範囲の中で、段差はありませんでした。差分の幅を $10^{-9}$ と $10^{-8}$ のように変えて傾きを作り、大きく違えば段差を疑います。
3. **外側で比べる差より、内側の誤差を小さくする**: 許容誤差を $10^{-8}$ に締めると、報告された二乗和は測り直した値と表示した桁で一致しました。答えの点の RK45 の傾きも $-14.2$ になり、式と一致します。
4. **回数を見積もるなら、使う計算機で数える**: 評価の回数は、計算時間の見積もりの材料です。ほかの計算機での回数や、ほかの設定の回数から見積もらず、実際に使う計算機と設定で数えてください。

## Python

次のコードは、解き方と許容誤差を引数にした例のツールで、表と小さな例の値を計算します。`# →` の行は、SciPy 1.18.1 で実行したときの出力です。評価の回数は計算機によって変わるので、出力に入れていません。回数は `res.nfev` で確かめられます。

```python
import numpy as np
from scipy.integrate import solve_ivp
from scipy.optimize import minimize

G, AREA, H0 = 9.81, 1.0, 1.0  # 重力加速度、タンクの断面積 1 m²、最初の水位 1 m
t = np.arange(0, 1801, 60.0)  # 30分間、1分おきに31回測る


def simulate(a, q, method="Radau", rtol=1e-3):
    # 水位の式 AREA * dh/dt = q - a * sqrt(2 g h) を、指定した解き方と許容誤差で解く
    def rhs(_, h):
        return [(q - a * np.sqrt(2 * G * h[0])) / AREA]

    return solve_ivp(rhs, (0, t[-1]), [H0], t_eval=t, rtol=rtol, method=method)


# 教材用の記録：a=0.0004、q=0.0005 の水位に、測定のばらつきを足したもの
rng = np.random.default_rng(0)
observed = simulate(4e-4, 5e-4, rtol=1e-10).y[0] + rng.normal(0, 0.005, t.size)


def tool(x, method="Radau", rtol=1e-3):
    sol = simulate(*x, method, rtol)
    if sol.status != 0 or not np.all(np.isfinite(sol.y)):
        raise ValueError("タンクが空になり、水位を計算できない")
    return float(np.sum((sol.y[0] - observed) ** 2))


def model(x):
    # 答え合わせ用：十分に細かい許容誤差で解いた二乗和
    return tool(x, "Radau", 1e-10)


x0 = [1e-4, 1e-4]
box = [(1e-5, 1e-3), (1e-5, 1e-3)]

# 1. 内側の解き方と許容誤差だけを変えて、L-BFGS-B を同じ条件で実行する
for method, rtol in [("RK45", 1e-3), ("Radau", 1e-3), ("RK45", 1e-8), ("Radau", 1e-8)]:
    res = minimize(tool, x0, args=(method, rtol), method="L-BFGS-B", bounds=box)
    a, q = res.x
    print(f"{method} {rtol:g}: a={a:.3g}, q={q:.3g}, 報告 {res.fun:.6f}, 測り直し {model(res.x):.6f}")
# → RK45 0.001: a=0.000401, q=0.000501, 報告 0.000498, 測り直し 0.000497
# → Radau 0.001: a=0.000401, q=0.000501, 報告 0.000503, 測り直し 0.000497
# → RK45 1e-08: a=0.000401, q=0.000501, 報告 0.000497, 測り直し 0.000497
# → Radau 1e-08: a=0.000401, q=0.000501, 報告 0.000497, 測り直し 0.000497

# 2. q を固定して a を少し動かすと、右辺を計算した回数が変わる所で二乗和が跳ぶ
q = 0.000501
for a in [0.0003288929879, 0.0003288929889]:
    sol = simulate(a, q, "RK45")
    print(f"a={a:.13f}: 右辺 {sol.nfev} 回, 二乗和 {tool([a, q], 'RK45'):.6f}")
# → a=0.0003288929879: 右辺 50 回, 二乗和 0.331977
# → a=0.0003288929889: 右辺 62 回, 二乗和 0.331909

# 3. 段差をまたぐ差分と、またがない差分（幅 1e-8）
jump, h = 0.0003288929884, 1e-8
across = (tool([jump + h / 2, q], "RK45") - tool([jump - h / 2, q], "RK45")) / h
beside = (tool([jump - 2 * h, q], "RK45") - tool([jump - 3 * h, q], "RK45")) / h
exact = (model([jump + h / 2, q]) - model([jump - h / 2, q])) / h
print(f"またぐ {across:.0f}, またがない {beside:.0f}, 式の傾き {exact:.0f}")
# → またぐ -17492, またがない -10754, 式の傾き -10790

# 4. 答えの点で、a についての傾きを中心差分で作る
x = np.array([0.000401, 0.000501])
d = np.array([1e-9, 0.0])
for label, f in [("RK45 1e-3", lambda y: tool(y, "RK45")), ("Radau 1e-3", tool), ("式", model)]:
    print(f"{label}: 傾き {(f(x + d) - f(x - d)) / 2e-9:.1f}")
# → RK45 1e-3: 傾き -12.6
# → Radau 1e-3: 傾き -14.5
# → 式: 傾き -14.2
```

1の出力では、答えはどの設定でも同じで、報告された二乗和だけが設定で変わります。測り直した値は、どれも $0.000497$ です。2の出力は、$a$ の $10^{-12}$ の違いで右辺の回数が50回から62回に変わり、二乗和が $0.000068$ 下がることを示します。3の出力の「またぐ」と「またがない」の差は、その段差を幅 $10^{-8}$ で割った量です。4の出力は、段差のない答えの点でも、RK45（$10^{-3}$）のツールの傾きが式の傾きと違うことを示します。

この記事のずれと段差は、同じ入力なら同じ値が返る点で、noiseを含むblack-boxと違います。同じ点を何度評価しても、平均で消すことはできません。また、段差の大きさは二乗和の0.02%程度で、決定論的だが不連続なsimulationが扱う大きな飛びとも違います。差分で勾配を作るときと、二乗和の下の桁を比べるときにだけ、はっきり現れます。

## 出典と再現条件

差分の誤差が、値の誤差を差分の幅で割った量だけ大きくなることは、Nocedal・Wright の教科書『Numerical Optimization』（S056）に基づきます。L-BFGS-B は Byrd らの論文（S065）に、`minimize` の `args`・`bounds`・`nfev` は SciPy の公式文書（S002）に基づきます。

例の数値は、SciPy 1.18.1 と NumPy 2.5.3 で上のコードを実行して得た値です。次の値と処理は SciPy 1.18.1 の実装の性質で、根拠はそのソースと実行の記録です。

- `solve_ivp` が、誤差の見積もりと許容誤差から時間の刻みを選ぶこと
- `solve_ivp` の `nfev` が、右辺を計算した回数であること
- L-BFGS-B の差分の幅 $10^{-8}$

評価の回数は、OpenBLAS の計算の部品を SkylakeX・Haswell・Sandybridge・Prescott に切り替えて数えました。ほかの計算機では、表の範囲の外の回数になることもあります。図のずれは、$a$ を $10^{-6}$ ずつ動かした181点で計算し、段差の位置は右辺の回数が変わる所を二分法で探しました。タンクの数値は教材用で、実際の設備の値や、ほかの式での段差の位置は示しません。
