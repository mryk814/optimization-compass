単体は非負の成分の和が1になる集合で、配合比・確率・資源配分を最適化するときに、可行性を保つ更新則と境界の意味を明確にします。

## 直感: 比率の集合

$n$成分の確率単体は、非負の成分の和が1になる集合です。

$$
\Delta^{n-1}=\left\{x\in\mathbb{R}^n \mid x_i\geq0,\ \sum_{i=1}^{n}x_i=1\right\}.
$$

成分は、各選択肢への確率、混合比、予算配分、注意機構の重みなどを表します。自由度は$n$ではありません。和が1という等式制約を除いた$n-1$です。

ここでいう単体は、LPの基底を辿る**Primal Simplex法**や、Nelder–Meadの探索点を並べた**単体**とは別の意味です。このページは「解ベクトルが比率として存在する集合」を扱います。

## ユークリッドステップで失われるもの

無制約の勾配ステップ $y=x-\eta\nabla f(x)$ は、一般に負の成分を作ります。成分の和も1からずれます。たとえば`[-0.1, 0.6, 0.5]`は合計こそ1でも、確率・配合比としては不正です。

`y / y.sum()`のような正規化も万能ではありません。負の成分を直せず、和が0に近いと不安定です。最も近い単体上の点を選ぶ操作でもありません。解釈できる比率を各反復で保ちたいなら、更新後にどの方法で集合へ戻すかを最初に決めます。

| 方策 | 常に保つもの | 境界の0を表せるか | 主な注意 |
| --- | --- | ---: | --- |
| ユークリッド射影 | 非負・和1 | はい | 射影の費用と有効な面を確認 |
| ソフトマックスパラメータ化 | 正・和1 | 通常はいいえ | ロジットに同じ定数を足しても解が同じ |
| エントロピーを使うミラー法の更新 | 正・和1（正の初期値なら） | 通常はいいえ | 対数 / アンダーフロー、ミラー写像とステップ設定 |
| 罰則だけを加える | 反復中の可行性は保証しない | 場合による | 罰則係数と残る違反を別に診断 |

## 射影とパラメータ化を分けて選ぶ

ユークリッド射影は、更新候補$y$に最も近い単体上の点を求めます。

$$
\Pi_{\Delta}(y)=\arg\min_{x\in\Delta^{n-1}}\|x-y\|_2^2.
$$

この方法では、最適解がある成分をちょうど0にするなら、その境界へ到達できます。「混合物から成分を完全に外す」「配分先をゼロにする」ことが必要なら、射影は自然な候補です。

[射影勾配法](#/learn/projected-gradient)では、この射影を各勾配ステップの後に行います。

一方、ロジット $z\in\mathbb{R}^n$ をソフトマックスで変換するパラメータ化は

$$
x_i=\frac{\exp(z_i)}{\sum_j\exp(z_j)}
$$

により内部点を保ちます。`z`に同じ定数を加えても$x$は変わらないため、ロジット自体の一意性はありません。有限のロジットでは$x_i=0$を厳密には表せません。これは欠点ではありません。境界の解を必要とするかどうかで選ぶ性質です。

## Mirror Descentは比率の幾何を使う

[Mirror Descent](#/learn/mirror-descent)では、負のエントロピーのようなミラー写像を使い、単体上で乗法的な更新を作れます。正の初期値から始める指数勾配型の更新は、正の成分と和1を保ちます。そのため、確率・オンライン配分ではユークリッド距離より自然な場合があります。

ただし、エントロピーの幾何が常に優れるわけではありません。境界の0が必要な場合、対数を取る成分がアンダーフローする場合、選んだミラー写像で双対側の計算が難しい場合は、射影や別のパラメータ化を比較します。方法名だけでなく、ミラー写像・初期点・ステップ設定を記録します。

## Python

次の関数は、任意の実ベクトルを和が1かつ非負な点へ射影します。更新後に`sum`と最小成分を確認するところまでを、最小の検証単位にします。

```python
import numpy as np


def project_to_simplex(values: np.ndarray) -> np.ndarray:
    descending = np.sort(values)[::-1]
    offsets = np.cumsum(descending) - 1.0
    indices = np.arange(1, values.size + 1)
    active = np.nonzero(descending - offsets / indices > 0.0)[0]
    threshold = offsets[active[-1]] / indices[active[-1]]
    return np.maximum(values - threshold, 0.0)


candidate = np.array([-0.30, 0.85, 1.20, -0.05])
probability = project_to_simplex(candidate)

print(probability)
assert np.all(probability >= -1e-12)
assert np.isclose(probability.sum(), 1.0)
```

これは単体制約を保つための部品です。目的関数が凸か、勾配が正しいか、ステップ幅が適切かは別に確認します。射影後の可行性だけから大域最適性を結論付けません。

## 診断値と切替の兆候

- 成分和の誤差と最小成分（数値上の可行性）
- 0に張り付く成分と有効な面の変化
- 射影距離またはBregman ステップの大きさ
- 目的、射影勾配写像、またはリグレット
- ステップ幅、直線探索、アンダーフロー / オーバーフロー
- 0成分を許すべき問題なのにソフトマックス内部点に張り付いていないか

切替の目安は次のとおりです。射影が計算時間を支配するなら、パラメータ化・分解・別の主双対法を検討します。ソフトマックスで必要な0配分へ近づけないなら、境界を表せる射影へ戻します。成分が頻繁に0と正を行き来するなら、ステップ幅、尺度、目的のノイズ、または配分の粗さを見直します。

::: warning
単体上の可行解は「配分として成立する」ことを意味しますが、実験・生産・制御の下限量、整数ロット、時間変化する制約までは含みません。元の問題にある制約を別途評価します。
:::
