凸性は、局所的な改善を問題全体の最適性へ結び付ける条件です。ただし、目的関数だけでなく可行集合も凸であることを確認します。

## 近くに低い点がなければ、探索を終えてよいか

坂を下り、周囲のどこへ動いても高くなる点に着いたとします。そこが「今いる谷の底」だとは言えても、別の場所にもっと低い谷がないとは普通は言えません。凸性は、この区別をなくすための条件です。

ただし確認するのは二つです。**関数の形が凸か。そして、選べる点の集合が凸か。** ここでは一つの二次関数について、図で値を読むところから、その条件が全点で成り立つ理由までを順に示します。

## 直感

凸関数では、グラフ上の二点を結ぶ線分がグラフより下へ入りません。
ある点の近くで下げる方向がなくなったとき、その点より離れた場所にも低い谷はないと判断できます。

この性質は、目的関数だけを眺めても決まりません。
制約が作る可行集合に穴や分離があれば、問題全体は凸最適化問題ではありません。

次の操作図で、二点を結ぶ線分の動きを見ます。最初は「関数」が「二次関数（凸）」で、点aが−2、点bが2に置かれています。まず「▶ θを0から1へ動かして再生」を押してください。

曲線上の青緑の点と弦上の橙の点の間にある縦の破線が、混合比θに合わせて伸び縮みします。「差の記録」には、その破線の長さ（弦の高さ − 曲線の高さ）がθごとに描かれます。点aとbは0.1刻みで動き、つまみを選んで←→キーを押すと0.1、Shiftを押しながらなら0.5ずつ動きます。二つの谷では、差が0を下回った瞬間に枠と点が赤く点滅します。

1. 二次関数のまま、再生を最後まで見てください。「差の記録」の線は、θ=0の0から立ち上がり、θ=0.5で頂点1.4に達して、θ=1で0へ戻ります。図が示す式 $0.35\,\theta(1-\theta)(a-b)^2$ に値を入れた結果と同じ高さです。
2. 点aを選んで Shift+→ を2回押すと、aが−1になります。もう一度再生すると、山の高さが1.4から0.7875（$0.35\times0.25\times3^2$）へ下がります。山の高さは点aと点bの距離の二乗に比例し、θ=0.5で最大になります。図の判定の文（赤または緑の文）は「凸」のまま変わりません。
3. 「関数」を「二つの谷（凸ではない）」に切り替えると、点aは−1.5、点bは1.5に置き直されます。再生すると、θがわずかに動いた時点で線が0を下回り、赤く変わります。同時に図の枠が赤く点滅し、「差の記録」に「0を下回った: 弦が曲線より下」と出ます。θ=0.5で−1.11375まで深くなり、θ=1に近づくと0へ戻ります。
4. 二つの谷のまま、点aを選んで Shift+→ を6回押し、aを1.5にします。「aから勾配降下で下ってみる」を押すと、球が右の谷で止まり、x=1.51、f=0.66と表示されます。図の「全体の最小」の丸は、左の谷の x=−1.65、f=−0.13 にあります。下れなくなっても、全体の最小とは限りません。
5. 「関数」を「二次関数（凸）」に戻し、「可行集合」を「C=[−2,−1]∪[2,3]」にします。aが−1、bが2に置き直されます。θは0.5のままで、混ぜた入力は x=0.5 になり、帯の外なので灰色になり、図の下の文に「可行集合 C の外です」と出ます。「差の記録」の山は0.7875のままです。関数の凸性は変わらず、変わるのは、混ぜた点を選べるかどうかです。続けて点aを Shift+← で2回押して−2に戻し、「aから勾配降下で下ってみる」を押すと、球は帯の端 x=−1.00（f=0.55）で止まります。それより先は C の外です。

## 定義を式で読む

凸集合 $C$ 上の関数 $f$ を考えます。
任意の $x,y\in C$ と $0\leq\theta\leq1$ に対して、次が成り立つとき $f$ は凸です。

$$
f(\theta x + (1-\theta)y) \leq \theta f(x) + (1-\theta)f(y)
$$

左辺は二点の間にある入力での関数値です。
右辺は二つの関数値を同じ比率で混ぜた値です。
不等式は「入力を混ぜた結果が、出力を混ぜた線分より上へ出ない」ことを表します。

### 図と同じ数を入れる

操作図の「二次関数」は $f(x)=0.35x^2+0.2$ です。$x^2$ を縦に縮めて少し持ち上げたもので、凸性の読み方は変わりません。まず $a=-2$、$b=2$、$\theta=1/2$ とします。

- 入力を先に混ぜると、$z=\theta a+(1-\theta)b=0$。曲線上の値は $f(z)=0.2$ です。
- 出力を先に混ぜると、両端の値はどちらも1.6なので、弦の高さは1.6です。
- 「弦の高さ − 曲線の高さ」は $1.6-0.2=1.4$。非負なので、この二点と混合比では凸性の不等式を満たします。

操作図の確認1で見た山の頂点1.4は、この計算と同じ値です。

### 一度の成功を、全点での保証に変える

二次関数の式を展開すると、差は次のようになります。

$$
\underbrace{\theta f(a)+(1-\theta)f(b)}_{\text{弦の高さ}}
-\underbrace{f(\theta a+(1-\theta)b)}_{\text{曲線の高さ}}
=0.35\,\theta(1-\theta)(a-b)^2\ge0.
$$

$0\le\theta\le1$ なら各因子は非負です。この式は、図で試した点だけでなく、**任意の $a,b,\theta$** に対して成り立ちます。ここまで言えて初めて、数値実験から凸性の証明へ進んだことになります。$a=b$ または $\theta\in\{0,1\}$ では等号になることも、同じ式から読めます。

### 反例を見る操作は、別の問い

次に「二つの谷」を例にします。操作図で使う関数は $w(x)=0.18x^4-0.9x^2+0.25x+1.4$ です。$a=-1.5$、$b=1.5$、$\theta=1/2$ にすると、曲線は1.4、弦は0.28625で、差は−1.11375です。一組でも不等式が破れれば、凸ではないと結論できます。破れが見つからない有限回の試行とは、この点が違います。

確認4のとおり、右の谷付近から勾配降下を試すと、左の谷へ渡らず、右の谷へ近づきます。右の局所最小は約 $x=1.5065$、値0.6612で、左の局所最小約 $x=-1.6465$、値−0.1286の方が低くなります。操作図の有限回のアニメーションが、これらの点へ厳密に到達するという意味ではありません。

「絶対値（凸だが滑らかでない）」は、尖った点を持つ別の凸関数です。凸であることは、滑らかであることを要求しません。二階微分で調べられない関数も、定義の不等式では調べられます。

```python
# 操作図と同じ関数。NumPyなどは不要。
f = lambda x: 0.35 * x*x + 0.2
w = lambda x: 0.18*x**4 - 0.9*x*x + 0.25*x + 1.4

def reading(fun, a, b, theta):
    z = theta*a + (1-theta)*b
    chord = theta*fun(a) + (1-theta)*fun(b)
    return tuple(round(v, 5) for v in (z, fun(z), chord, chord-fun(z)))

for theta in (0., 0.25, 0.5, 1.):
    print(theta, reading(f, -2., 2., theta))
print("counterexample:", reading(w, -1.5, 1.5, 0.5))
```

各組は「混ぜた入力、曲線の高さ、弦の高さ、差」です。二次関数の差は順に0、1.05、1.4、0。最後の反例では−1.11375になります。丸めは表示だけに用い、符号の判定や証明を丸めた小数へ依存させません。

一変数の滑らかな関数なら、二階微分が非負かを見る方法があります。
多変数ではヘッセ行列が半正定値かを調べます。
ただし、微分による判定は定義域と滑らかさの条件を確認して使います。

## 可行集合も同時に確認する

可行集合 $C$ が凸であるとは、二つの可行点を結ぶ線分がすべて $C$ に残ることです。
線形等式と線形不等式が作る集合は凸です。
一方、整数変数や排他的な選択は離散的な可行集合を作ります。

操作図の確認5で使った $f(x)=0.35x^2+0.2$、$C=[-2,-1]\cup[2,3]$ を数で読みます。
右の帯では $x=2$ が最小で値1.6です。左の帯の $x=-1$ なら値0.55で、こちらが $C$ の中の最小です。
$-1$ と2の中間は0.5で、可行ではありません。そこでの曲線の高さは0.2875、弦の高さは1.075で、差は0.7875です。関数としては凸の不等式が成り立っていても、その中間点は選べません。

関数を変えず、集合を二つに分けただけで、低い方の谷へ向かう途中の点を選べなくなりました。
右の帯の点から勾配降下で下ると、帯の端 $x=2$ で止まります。左の帯の0.55には、$C$ の外を通らないと着けません。

凸な目的関数を使っていても、可行集合が非凸なら問題全体へ凸最適化の結論は適用できません。
変数変換を行った場合は、変換後の目的と可行集合をもう一度確認します。

::: note
「目的が凸」と「問題が凸」は同じ主張ではありません。目的、制約、定義域を一組で記録します。
:::

## 最適化で何が言えるか

凸目的と凸可行集合からなる問題では、局所最小解は大域最小解です。
理由は、もっと低い可行点が遠くにあったと仮定すると、そこへ向かう線分上の点も可行だからです。
その線分上では、凸性の不等式によって少し進むだけで値が下がります。これは「近くに改善先はない」という局所最小の条件と矛盾します。

一歩を選べるのは集合が凸だからで、その一歩で値が下がるのは関数が凸だからです。
どちらか一方だけでは論法がつながりません。

微分可能なら、勾配と制約の条件を使って最適性を調べられます。
最小解が存在するなら、厳密凸性はその一意性を保証します。
強凸性と滑らかさなど、解法に合う条件がそろえば収束率も評価できます。
凸性だけでは解の存在も一意性も保証されず、例えば定数関数はすべての可行点が最小です。

凸性だけで数値計算が簡単になるとは限りません。
悪い尺度や境界近くの解は、ソルバーの進み方を難しくします。
実装では最適性条件と数値残差を分けて監視します。

## 凸性がない・分からないとき

非凸であることは、最適化できないことを意味しません。
ただし、一つの初期点から得た停止点を大域解として扱えなくなります。
複数初期点と下界を使って解の位置付けを確認します。
既知解や問題固有の構造も判断材料になります。

凸性を証明できない場合も、安易に凸と仮定しません。
局所モデルとして凸近似を使うなら、元の目的と制約で候補を再評価します。
近似問題の最適性と元の問題の最適性を区別して記録します。

## 診断値

| 診断値 | 読み方 |
| --- | --- |
| 目的値の隔たりまたは下界 | 得られた値が既知の下界へ近いか |
| 勾配ノルム | 制約なし問題の一階停止条件へ近いか |
| 制約残差 | 候補が制約を満たしているか |
| KKT残差 | 制約付き問題の局所的な最適性条件へ近いか |
| 初期点ごとの結果 | 非凸性や数値的不安定性の影響が見えるか |

## 失敗・切替の兆候

- 初期点ごとに異なる停止点へ到達する場合は、非凸性、解の非一意性、停止精度やソルバー設定を調べます。
- 制約残差が残る場合は、目的値だけで候補を比較しません。
- ヘッセ行列の負の曲率が見つかる場合は、凸性の仮定を見直します。
- 凸近似の解が元の問題で悪化する場合は、近似範囲と受理条件を見直します。
