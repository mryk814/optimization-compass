混合整数非線形計画は、目的か制約に非線形の式を含む問題で、一部の変数に整数条件を加えた定式化です。整数条件を外した連続緩和が凸なら、その最適値が下界になり、分枝限定法で最適性を示せます。連続緩和が凸でないと、局所解法が返す値は下界とは限らず、大域的な下界を作る手法が要ります。

## 30秒でつかむ

工場で、同じ機械を何台動かすかを決めます。1台動かすごとに固定費 $6$ がかかります。各台は負荷 $q$ で動かし、販売益は1台あたり $8q$、運転費は $q^2$ です。負荷は $2.4$ まで、市場が引き取る総量は $10$ までとします。
台数は整数で、負荷は連続です。負荷を上げると販売益は増えますが、運転費は二乗で増えます。そのため、台数を増やして負荷を分けるほうが得かどうかが、固定費との引き合いになります。

- **決めるもの**: 台数 $n$（整数）と、各台の負荷 $q$（連続）
- **良くしたいもの**: 固定費と運転費の合計から販売益を引いた値 $f$。小さいほど良く、負なら黒字です
- **守ること**: $0\le q\le 2.4$、総量 $nq\le10$、$1\le n\le6$

運転費が $q^2$ なので、$n$ と $q$ の積を含む非線形の式になります。整数条件を外すと台数が $4.17$ 台のような値になり、台数を整数に戻すと、どの整数を選ぶかを比べる必要があります。

次の図で、まず「① 台数 n を実数にした緩和」のパネルにある橙の丸（台数を実数にした最小点）を探してください。次に、紺の点（整数の台数）と値を見比べてください。最後に、「② 4と5の間を除いて分ける」のパネルで、枠で囲まれた点を確かめてください。

1. 「① 台数 n を実数にした緩和」の最小は、$n=25/6\approx4.17$ で値 $-31.0$ です。台数が整数でないので、実行できる計画ではありません。
2. 整数の台数に丸めた $n=4$ の値は $-29.76$ です。ところが、整数の台数の中で最良なのは $n=5$ で、値は $-30.0$ です。四捨五入では最良の台数に届きません。
3. 「② 4と5の間を除いて分ける」では、$n\le4$ の節点の最良が $-29.76$、$n\ge5$ の節点の最良が $-30.0$ です。どちらの節点も整数の台数で最良に着いたので、$-30.0$ が最適値だと言えます。

台数を実数にした値 $-31.0$ が、整数の最適値 $-30.0$ の下界だと言えるのは、どんな条件のときでしょうか。

## 標準形を読む

次の式は「いくつかの変数に整数条件を課し、非線形の目的 $f$ を、非線形の制約 $g\le0$ のもとで最小にする」を表します。

$$
\min_{x}\; f(x) \quad \text{s.t.}\quad g(x)\le 0,\quad x_j\in\mathbb{Z}\;\;(j\in I)
$$

添字の集合 $I$ に入る変数だけが整数で、残りは連続です。$f$ か $g$ のどちらかに非線形の式が入っていれば、この型です。

| 記号 | 意味 | 機械の例では |
|---|---|---|
| $x$ | 決める変数。$I$ の変数は整数 | $(n,\ q)$、台数と負荷 |
| $f(x)$ | 最小にする目的 | $6n+nq^2-8nq$ |
| $g(x)\le0$ | 制約の式 | $q-2.4\le0$、$nq-10\le0$、$1-n\le0$、$n-6\le0$ |
| $I$ | 整数にする変数の添字 | $\{n\}$ |

### 連続緩和が凸かどうかで、下界の保証が分かれる

整数条件 $x_j\in\mathbb{Z}$ を外した問題を、連続緩和と呼びます。最小化では、緩和の最適値は整数の最適値以下なので、下界になります。ただし、これが下界として使えるのは、緩和の最適値を実際に求められたときです。

- 連続緩和が凸（$f$ が凸関数、$g$ のそれぞれが凸関数）なら、局所解がそのまま大域解です。局所解法が返す値を、下界として使えます。この条件を満たす問題を凸MINLPと呼びます。
- 連続緩和が凸でないと、局所解法が返す点は大域解とは限りません。返った値が真の下界より大きいと、その値で枝を切ると、最適解を含む枝を捨てることがあります。

同じ機械の例でも、書き方で凸かどうかが変わります。$(n,\ q)$ で書いた目的 $6n+nq^2-8nq$ の Hessian は次の行列です。

$$
\begin{pmatrix}0&2q-8\2q-8&2n\end{pmatrix}
$$

この行列式は $-(2q-8)^2$ です。$q\ne4$ なら負なので、固有値の符号が異なり、凸ではありません。
総量 $x=nq$ を変数にすると、目的は $6n+x^2/n-8x$ に変わります。制約 $x\le2.4n$ と $x\le10$ は線形です。この目的の Hessian の行列式は $n>0$ で $0$ になり、固有値は $0$ と正の値です。そのため、$n>0$ で凸関数です。
どちらも同じ問題を表しますが、凸性を確かめられるのは後者です。

### 保証は条件つきで、MILPやMIQPとは次の点で分かれる

| 型 | 非線形の入り方 | 連続緩和 |
|---|---|---|
| [混合整数線形計画](#/formulations/PA023) | 入らない | 線形計画。常に凸 |
| [混合整数二次計画](#/formulations/PA024) | 目的の二次式だけ。制約は線形 | $Q$ が半正定値なら凸QP |
| この型 | 目的か制約の任意の非線形の式 | $f$ と $g$ が凸関数のときだけ凸 |

機械の例は、$x^2/n$ の項があるので、目的が二次式ではありません。そのため、MIQPではなく、この型で扱います。

## 小さな例

固定費 $6$ の機械を、販売益 $8q$、運転費 $q^2$ で動かします。負荷の上限は $2.4$、総量の上限は $10$ です。台数 $n$ は $1$ から $6$ の整数、負荷 $q$ は連続とし、どの台も同じ負荷で動かします。乱数は使いません。

### 機械の例・台数を固定して全列挙する

$n$ を固定すると、残る変数は $q$ だけです。$q$ の傾き $n(2q-8)$ は $q<4$ で負なので、$q$ は上限 $\min(2.4,\ 10/n)$ まで上げるのが最良です。

| 台数 $n$ | 負荷 $q$ | 値 $f$ |
|---:|---:|---:|
| 1 | 2.4 | −7.44 |
| 2 | 2.4 | −14.88 |
| 3 | 2.4 | −22.32 |
| 4 | 2.4 | −29.76 |
| 5 | 2 | −30.0 |
| 6 | 1.667 | −27.33 |

4台までは、台数を増やすたびに値が $7.44$ ずつ下がります。5台では総量の上限 $10$ に当たって負荷が $2$ に下がり、値は $-30.0$ です。6台では負荷が $1.667$ まで下がり、固定費の増加が上回って値は上がります。最適は $n=5$ で、値は $-30.0$ です。

### 機械の例・台数を実数にした緩和を解く

$x=nq$ を使った形 $6n+x^2/n-8x$ で、$n$ を実数にして解きます。総量が上限 $10$ に当たる点では、$f=6n+100/n-80$ で、この式の最小は $n\approx4.08$ です。ところが、負荷の上限 $2.4$ から $n\ge10/2.4=25/6\approx4.167$ が必要です。そのため、最小は負荷の上限と総量の上限が同時に効く $n=25/6$ で、値は次のとおりです。

$$
6\cdot\frac{25}{6}+\frac{100}{25/6}-80=25+24-80=-31
$$

緩和の最小 $-31$ は、整数の最適値 $-30$ より $1$ 小さい値です。機械の例の連続緩和は、$x^2/n$ の形で書くと凸なので、この $-31$ は整数の最適値の下界です。

### 機械の例・$n$ を $4$ と $5$ の間で分ける

緩和の最適解 $n=25/6$ は整数ではありません。整数の $n$ は $n\le4$ か $n\ge5$ のどちらかなので、この二つに分けても、整数の候補は失われません。

| 追加した範囲 | 緩和の最適解 | 下界 | 次の判断 |
|---|---|---|---|
| $1\le n\le6$ | $n=25/6,\ x=10$ | −31.0 | $n$ で分ける |
| $n\le4$ | $n=4,\ x=9.6$ | −29.76 | 整数解。暫定解にする |
| $n\ge5$ | $n=5,\ x=10$ | −30.0 | 整数解。暫定解を更新する |

二つの節点とも整数の台数で最良に着いたので、分けた範囲の外に、これらより良い整数解はありません。最適値は $-30.0$ で、台数は $5$ です。
$n\ge5$ の節点を先に解いていれば、暫定解 $-30.0$ が先に決まります。$n\le4$ の節点の下界 $-29.76$ は $-30.0$ より大きいので、この枝にはこれ以上良い解がなく、探索を打ち切れます。

## つまずきやすい点

- **台数を実数にした緩和の解を丸めて答えにする**: 緩和の $n=4.17$ を丸めると $n=4$ で、値は $-29.76$ です。最適な $n=5$ の $-30.0$ より $0.24$ 大きくなります。丸めた点は、実行できる計画ではあっても、最良の計画ではありません。
- **緩和の値を、達成できる値と読む**: 緩和の $-31.0$ は台数を実数にした値なので、整数の台数では達成できません。整数の最適値 $-30.0$ との差 $1.0$ が、整数条件の分の差です。下界は「これより良い値は出ない」という保証で、達成できる値ではありません。
- **非凸な形のまま、局所解法の値を下界と読む**: $(n,\ q)$ の形の Hessian は固有値が $-1.12$ と $9.12$ で、凸ではありません。非凸な緩和で局所解が真の下界より大きいと、その値で枝を切ったときに最適解を含む枝を捨てます。この形に局所解法を6つの出発点から当てると、全部が $n=4.167$、値 $-31.0$ に着きます。一致したのは、この例の形が素直だったからです。凸性は一致の回数から導けません。凸性が確かめられた $x=nq$ の形なら、一回の解で下界の保証が得られます。

## 課題から定式化する

「機械を何台動かし、各台をどれだけの負荷で動かすか決めたい」という課題から、次の4つを順に確かめます。

1. **何を決めるか**: 台数と負荷です。台数は整数で、負荷は連続です。整数の変数と連続の変数が混ざります。
2. **何を良くしたいか**: 固定費と運転費から販売益を引いた値を小さくします。運転費が負荷の二乗なので、目的は非線形です。
3. **何を守るか**: 負荷の上限、総量の上限、台数の範囲です。制約はすべて線形に書けます。非線形になるのは目的です。
4. **どこまで保証がほしいか**: 最適性の証明がほしいなら、連続緩和が凸になる書き方を探します。機械の例では、総量 $x=nq$ を変数にすると凸になります。

整数変数があり、目的か制約に非線形の式が入るなら、この型です。

## 困りごとから関連する問題へ

実際の課題で次の症状が出たら、対応する記事へ進みます。

- 非線形の式がなく、目的も制約も線形 → [混合整数線形計画](#/formulations/PA023)
- 非線形が目的の凸な二次式だけで、制約は線形 → [混合整数二次計画](#/formulations/PA024)
- 整数条件を外した連続緩和の解き方を知りたい → [一般滑らか制約付きNLP](#/formulations/PA009)
- 整数変数がなく、二次の式が非凸 → [非凸QP/QCQP](#/formulations/PA019)
- 整数変数は選ぶ・選ばないだけで、制約が容量1本 → [ナップサック問題・集合被覆問題](#/formulations/PA032)

### 混合整数非線形計画と関連する問題の関係

- [混合整数線形計画](#/formulations/PA023): 非線形の式を線形にすると MILP です。MILP は連続緩和が線形計画なので常に凸で、分枝限定法の各節点の下界が正しくなります。MINLP では、この下界の正しさが連続緩和の凸性に依存します。
- [混合整数二次計画](#/formulations/PA024): 目的が二次式で制約が線形のとき、MINLP の特別な場合です。条件は $Q$ が半正定値かどうかで、MINLP の凸か非凸かの区別と同じ形です。機械の例は $x^2/n$ の項があり、二次式ではないので、MIQP の範囲を出ます。
- [一般滑らか制約付きNLP](#/formulations/PA009): 整数条件を外すと、この型になります。ただし、一般の NLP では局所解しか保証されないので、緩和の値は下界とは限りません。
- [非凸QP/QCQP](#/formulations/PA019): 整数変数がなくても非凸な二次式があると、局所解が大域解とは限りません。MINLP の連続緩和が非凸のとき、同じ困難が各節点に現れます。

## 数値計算の方法を選ぶ

次の表は順位ではなく、連続緩和が凸かどうかに応じた入口です。

| 系統 | 進み方 | 向く条件・避ける条件 |
|---|---|---|
| [分枝限定法](#/learn/branch-and-bound) | 連続緩和のNLPを各節点で解き、整数変数を分けて下界で枝を切る | 緩和が凸なら、各節点の下界が正しく、最適性を示せます。非凸なら、局所解の値で枝を切ると最適解を失うことがあります |
| [Outer Approximation](#/learn/outer-approximation-minlp) | 整数を固定した連続NLPと、凸な式の接平面を集めたMILPを交互に解く | 凸MINLPのときの方法です。非凸だと接平面が最適解を切り落とすことがあります |
| [空間分枝限定法](#/learn/spatial-branch-and-bound) | 連続変数の範囲も分け、各領域で凸な下界を作る | 非凸MINLPで大域的な下界が要るときの候補です。計算は重くなります |
| [branch-and-cut](#/learn/branch-and-cut) | 分枝に加えて、緩和を締める制約を足す | 線形の部分が大きいときに、下界と暫定解の差を縮めます |
| 全列挙 | 整数変数の組合せごとに連続NLPを解く | 整数変数が少ないときだけです。機械の例は6通りです |

ライブラリの既定の設定は、そのライブラリの選択です。この記事の推奨でも、手法の順位でもありません。ソルバーが凸のMINLPだけを前提にするか、非凸も大域的に扱うかは、製品とバージョンで違います。たとえばKnitroの文書は、主に凸の問題を対象に設計されたと述べています。非凸の問題では、大域解への収束を保証しないとも述べています。
次のコードは、機械の例を SciPy の SLSQP で解きます。ここでは、分枝限定法を手で実装し、各節点で連続NLPを解いています。節点の数は、この例と、分ける変数の選び方での数です。

```python
import numpy as np
from scipy.optimize import minimize

FIXED, PRICE, Q_MAX, MARKET = 6.0, 8.0, 2.4, 10.0


def cost(n, q):
    """n 台が負荷 q で動くときの、固定費 + 運転費 - 販売益"""
    return FIXED * n + n * q**2 - PRICE * n * q


# 1. n を固定して全列挙する。傾き n(2q-8) は q<4 で負なので、q は上限まで上げる
for n in range(1, 7):
    q = min(Q_MAX, MARKET / n)
    print(n, round(q, 4), round(cost(n, q), 2))
# 1 2.4 -7.44
# 2 2.4 -14.88
# 3 2.4 -22.32
# 4 2.4 -29.76
# 5 2.0 -30.0
# 6 1.6667 -27.33


# 2. 総出力 x = n q に置き換えると、目的は 6n + x^2/n - 8x。n の範囲を渡して緩和を解く
def relax(lo, hi):
    def f(v):
        return FIXED * v[0] + v[1] ** 2 / v[0] - PRICE * v[1]

    cons = [{"type": "ineq", "fun": lambda v: Q_MAX * v[0] - v[1]}]
    r = minimize(f, [(lo + hi) / 2, MARKET / 2], method="SLSQP", constraints=cons,
                 bounds=[(lo, hi), (0, MARKET)], options={"ftol": 1e-12})
    return r.x[0], r.fun


print(*np.round(relax(1, 6), 4))  # 4.1667 -31.0

# 3. 凸性の確かめ: (n, q) の形と (n, x) の形で、目的の Hessian の固有値を比べる
print(np.linalg.eigvalsh([[0, 2 * 2.4 - 8], [2 * 2.4 - 8, 2 * 4]]).round(2))  # [-1.12  9.12]
worst = min(
    np.linalg.eigvalsh([[2 * x**2 / n**3, -2 * x / n**2], [-2 * x / n**2, 2 / n]])[0]
    for n in np.linspace(1, 6, 26) for x in np.linspace(0, 10, 26)
)
print(worst > -1e-9)  # True

# 3b. (n, q) の形のまま、出発点を変えて局所解法で緩和を解く
ends = set()
for start in [(1, 0.5), (3, 1), (6, 2), (2, 2.4), (6, 0.2), (5, 2)]:
    r = minimize(lambda v: cost(*v), start, method="SLSQP", bounds=[(1, 6), (0, Q_MAX)],
                 constraints=[{"type": "ineq", "fun": lambda v: MARKET - v[0] * v[1]}])
    ends.add((round(float(r.x[0]), 3), round(float(r.fun), 3)))
print(ends)  # {(4.167, -31.0)}

# 4. 分枝限定法: 緩和値を下界にして、n を整数の境で二つに分ける
best, queue, log = np.inf, [(1, 6)], []
while queue:
    lo, hi = queue.pop()
    n, bound = relax(lo, hi)
    if bound >= best - 1e-9:
        log.append(f"n in [{lo}, {hi}]: 下界 {bound:.2f} で枝刈り")
    elif abs(n - round(n)) < 1e-6:
        best = bound
        log.append(f"n in [{lo}, {hi}]: n={round(n)} 整数解 {bound:.2f}")
    else:
        log.append(f"n in [{lo}, {hi}]: n={n:.4f} 下界 {bound:.2f}、n<={int(n)} と n>={int(n) + 1} に分枝")
        queue += [(int(n) + 1, hi), (lo, int(n))]
print(*log, sep="\n")
# n in [1, 6]: n=4.1667 下界 -31.00、n<=4 と n>=5 に分枝
# n in [1, 4]: n=4 整数解 -29.76
# n in [5, 6]: n=5 整数解 -30.00
print(best)  # -30.0
```

最初の6行は全列挙で、最良の $n=5$ の値 $-30.0$ を示します。`4.1667 -31.0` は、台数を実数にした緩和の最小です。続く `[-1.12  9.12]` は、$(n,\ q)$ の形の Hessian が凸でないことを示します。`True` は、$(n,\ x)$ の形の Hessian が格子上で半正定値であることを示します。`{(4.167, -31.0)}` は、凸でない形でも6つの出発点が同じ点に着いたことを表します。最後の4行が分枝限定法の記録で、全列挙と同じ $-30.0$ に着きます。

## 出典と再現条件

分枝限定法が各節点で連続緩和を解くことは、[Knitro の文書](https://www.artelys.com/app/docs/knitro/2_userGuide/minlp.html)の記述に基づきます。この文書は、凸の問題では最適性が示され、非凸の問題では大域解への収束が保証されないとも述べています。MIP と MINLP を扱うソルバーの枠組みは [SCIP の文書](https://www.scipopt.org/doc/html/)に基づきます。凸関数での局所解と大域解の一致は、Nocedal と Wright の教科書『Numerical Optimization』に基づきます。`minimize` の引数は [SciPy の文書](https://docs.scipy.org/doc/scipy/reference/generated/scipy.optimize.minimize.html)に基づきます。コードは SciPy 1.18.1 と NumPy 2.5.3 で実行しています。

機械の例は、教材用に作った2変数の式です。実際の工場の費用や、手法の一般的な速さは示しません。
