SATは、真か偽かを決める変数に対し、「AかBの少なくとも一方」のような論理の節をすべて満たす割り当てがあるかを問う定式化です。すべては満たせないとき、節に重みを付け、満たした節の重みの合計を最大にするのがMaxSATです。答えが「ない」ときも、ないことの証明を返せます。

## 30秒でつかむ

週末の勉強会に、A〜Eの5人のうち誰を呼ぶかを決めます。呼び方には、次の4つの決まりがあります。

| 決まり | 理由 |
|---|---|
| AかBの少なくとも一人を呼ぶ | 会場の鍵を持つのはAとBだけ |
| AとCを両方は呼ばない | AとCは同じ店の店番で、二人とも抜けると店を開けられない |
| Bを呼ぶならDも呼ぶ | BはDの車に乗って来る |
| DとEを両方は呼ばない | DとEも別の店で一緒に店番をしている |

さらに、希望が3つあります。Cに講師をしてほしい（重み3）、Eを呼びたい（重み2）、Aを呼びたい（重み2）です。ところが、どう呼んでも、すべての希望はかないません。決まりを守る呼び方を全部調べ、かなった希望の重みの合計が最も大きいものを選びます。

- **決めるもの**: 5人それぞれを呼ぶか呼ばないか（真か偽か）
- **良くしたいもの**: かなった希望の重みの合計
- **守ること**: 4つの決まり

次の図は、5人の呼び方32通りを並べたものです。まず「×」のない枠がいくつあるかを数えてください。続いて、橙の枠（最も重い組）と紺の枠（重い希望から順にかなえた組）の数字を比べてください。

![32通りの呼び方を、行はAとBの呼び方、列はC・D・Eの呼び方で並べた表。決まりを守るのは6通りで、かなった希望の重みはBDが0、BCDが3、Aが2、AEが4、ADが2、ABDが2。最も重いのはAとEを呼ぶ組の4（橙の枠）。重い希望から順にかなえると、B・C・Dを呼ぶ組の3（紺の枠）。](./figures/sat-invite-grid.svg "勉強会の例：5人・決まり4つ・希望3つ。重みは教材用の値で、実際の人の希望の測り方は示さない")

1. 「×」のない枠は6つです。32通りのうち26通りは、4つの決まりのどれかを破ります。
2. 最も重いのは、AとEを呼ぶ組で4です。Eの希望（2）とAの希望（2）がかないます。講師役のCは呼びません。
3. 最も重いCの希望から順にかなえると、B・C・Dを呼ぶ組になり、重みは3です。EもAも呼べなくなるからです。

Cを呼ぶと決めただけで、なぜEもAも呼べなくなるのでしょうか。

## 標準形を読む

次の式は「各変数を真か偽かに決め、満たした節の重みの合計を最大にする」を表します。

$$
\max_{x\in\{0,1\}^n}\; \sum_k w_k\,\mathbb{1}\bigl[C_k(x)\bigr]
$$

$\mathbb 1[C_k(x)]$ は、節 $C_k$ が満たされれば1、満たされなければ0です。必ず守る節（決まり）は、重みを無限大と考えるか、制約として別に書きます。決まりの節だけを並べて「すべてを満たす割り当てはあるか」と問うのがSATで、希望の節を重み付きで加えて合計を最大にするのがMaxSATです。

| 記号 | 意味 | 勉強会の例では |
|---|---|---|
| $x$ | 真偽の変数（1が真） | $x_A,\dots,x_E$。1なら呼ぶ。最も重い組は $x_A=x_E=1$、ほかは0 |
| $C_k$ | 節。リテラルの「または」 | 決まり4つ（鍵・店番・車・店番）と、希望3つ（C・E・A） |
| リテラル | 変数か、その否定 | $A$（Aを呼ぶ）、$\lnot A$（Aを呼ばない） |
| $w_k$ | 節の重み | 決まりは必ず守る。希望はCが3、Eが2、Aが2 |

### 決まりを節に書く

節は、リテラルを「または（$\lor$）」でつないだものです。4つの決まりは、次の4つの節になります。

$$
(A\lor B)\land(\lnot A\lor\lnot C)\land(\lnot B\lor D)\land(\lnot D\lor\lnot E)
$$

この式は「AかBを呼ぶ。かつ、AかCの少なくとも一方は呼ばない。かつ、Bを呼ばないかDを呼ぶ。かつ、DかEの少なくとも一方は呼ばない」と読みます。節を「かつ（$\land$）」でつないだこの形を、連言標準形（CNF）と呼びます。

3つ目の節は「Bを呼ぶならDも呼ぶ」です。「PならばQ」は「Pでない、またはQ」と同じ意味なので、$\lnot B\lor D$ と書きます。Bを呼んでDを呼ばないときだけ、この節は偽になります。

### 1つ決めると、残りが決まっていく

節のリテラルのうち、偽と決まっていないものが1つしか残らなければ、そのリテラルは真にするしかありません。これを単位伝播と呼びます。

次の図は、Cを呼ぶと決めたときと、Eを呼ぶと決めたときの単位伝播です。「① Cを呼ぶと」と「② Eを呼ぶと」の箱を、最初の箱から順に読んでください。箱の間の文字は、使った決まりです。

![① Cを呼ぶと、店番の決まりから¬A、鍵の決まりからB、車の決まりからD、店番の決まりから¬E。② Eを呼ぶと、店番の決まりから¬D、車の決まりから¬B、鍵の決まりからA、店番の決まりから¬C。](./figures/sat-invite-chain.svg "勉強会の例：決まりの4つの節だけで単位伝播した結果。¬A は「Aを呼ばない」")

Cを呼ぶと、店番の決まりからAは呼べません。Aがいないので、鍵のためにBを呼びます。BはDの車で来るのでDも呼び、DとEは店番が同じなのでEは呼べません。こうして、Cの希望を一つかなえるだけで、AとEの希望が両方かなわなくなります。図で生まれた疑問の答えは、この連鎖です。

### 「ない」と答えるときも、証明がある

「CもEも呼べるか」は、決まりの節に $C$ と $E$ の2つの節を足して、すべてを満たせるかを問うSATです。単位伝播すると、$C$・$E$・$\lnot A$・$\lnot D$・$B$ と決まります。すると、車の決まり $\lnot B\lor D$ のリテラルがどちらも偽になります。どの節も満たせない矛盾に着いたので、CとEを両方呼ぶ方法はありません。

この矛盾までの道筋は、32通りを一つずつ調べなくても確かめられる証明です。SATの答えは、満たす割り当て（あるとき）か、矛盾の導出（ないとき）のどちらかになります。

## 小さな例

設定は30秒でつかむの決まり4つと希望3つです。乱数は使いません。

### 勉強会の例・決まりを守る6通り

| 呼ぶ人 | Cの希望（3） | Eの希望（2） | Aの希望（2） | 重みの合計 |
|---|:---:|:---:|:---:|---:|
| B・D | | | | 0 |
| B・C・D | ○ | | | 3 |
| A | | | ○ | 2 |
| A・E | | ○ | ○ | 4 |
| A・D | | | ○ | 2 |
| A・B・D | | | ○ | 2 |

Cを呼ぶ組はB・C・Dの1通りしかありません。単位伝播で、Cを呼べばB・Dが決まり、A・Eが外れるからです。Aを呼ぶ組は4通りあり、その中でEも呼べるのは、DとBを呼ばないA・Eだけです。

### 勉強会の例・同時にはかなわない希望の組

希望を2つずつ組にして、決まりと一緒に満たせるかを調べると、次の2組は同時にかないません。

- CとE：上の単位伝播で矛盾に着きます
- CとA：店番の決まり $\lnot A\lor\lnot C$ そのものです

このように、同時にはかなわない希望の組をコア（core）と呼びます。どちらのコアからも、少なくとも一つの希望をあきらめる必要があります。Cをあきらめれば両方のコアが解消し、失う重みは3です。CをあきらめずにEとAをあきらめると、失う重みは $2+2=4$ です。だから、Cをあきらめる組が最も重く、残る重みは $7-3=4$ です。これがA・Eの組です。

## つまずきやすい点

- **重い希望から順にかなえる**: 最も重いCの希望（3）を先にかなえると、単位伝播でAとEが外れ、重みの合計は3です。最も重い組A・Eの4より小さくなります。比べるのは一つの希望の重さではなく、一緒にかなう希望の重みの合計です。この例では、Cの3と、E・Aの合計4を比べます。
- **「ならば」の向きを逆に書く**: 「Bを呼ぶならDも呼ぶ」を、逆向きの $\lnot D\lor B$（Dを呼ぶならBも呼ぶ）と書いたとします。決まりを守る組は、6通りから11通りに増えます。最も重い組はB・C・Eの5になり、Dの車がないのにBが来ることになります。節を書いたら、その節を偽にする割り当て（ここではBを呼んでDを呼ばない）を一つ書き出し、それが本当に禁止したい場合かを確かめます。
- **重みを、希望の順位だけで付ける**: Cの重みを3から4にすると、B・C・DとA・Eが4で並びます。5にすると、最も重い組はB・C・Dに変わります。重みは「CとE・Aのどちらを取るか」を決める量です。順位の1・2・3を重みにすると、意図しない組が選ばれることがあります。
- **「CもEも呼べない」を、探し方が足りないと読む**: 32通りのどれも、決まりとCとEを同時には満たしません。単位伝播の矛盾は、そのことの証明です。探し直す前に、どの決まりが矛盾に関わっているか（ここでは鍵・車・2つの店番）を読み、決まりそのものを変えられるかを考えます。

## 課題から定式化する

「決まりを守りながら、なるべく希望がかなう呼び方を決めたい」という課題を、次の4段で式にします。

1. **何を真偽で決めるか**：5人それぞれを呼ぶかどうかです。数や順番を決める課題も、「Aを1番目にするか」のような真偽の変数に分けて書けます。
2. **決まりをどう節にするか**：「少なくとも一人」は「または」、「両方は呼ばない」は否定の「または」、「ならば」は $\lnot P\lor Q$ と書きます。
3. **必ず守るものと、できれば守るものを分ける**：鍵・店番・車は必ず守る決まり、講師やEとAを呼ぶことは希望です。
4. **希望の重みを決める**：あきらめるときの損の大きさとして、希望ごとに重みを付けます。

決める量が真偽の組み合わせで、条件が論理の節で書けるとします。すべてを満たせるかを問うならSAT、満たした節の重みの合計を最大にするならMaxSATとして定式化できます。

## 困りごとから関連する問題へ

実際の課題で次の条件が必要になったら、次の記事が役に立ちます。

- 費用や人数の合計のような数の条件が多い → [混合整数線形計画](#/formulations/PA023)。節は0-1変数の線形不等式として書けます
- 時刻や順番、「同時に1つまで」のような条件が中心 → [制約プログラミングによるスケジューリング](#/formulations/PA026)
- 決まりと希望を、どのソルバーでどう書けばよいかを知りたい → [CP-SATと制約プログラミング](#/learn/cp-sat)
- 節が非常に多く、よい呼び方を早く一つ見つけたい（最良かどうかの証明はいらない） → [組合せ局所探索](#/learn/local-search-combinatorial)

### SAT・MaxSATと関連する問題の関係

- [混合整数線形計画](#/formulations/PA023): 各節は0-1変数の線形不等式に書き直せます。$A\lor B$ は $x_A+x_B\ge1$、$\lnot A\lor\lnot C$ は $(1-x_A)+(1-x_C)\ge1$ です。希望は、かなったときだけ1になる変数 $y_k\le x$ を足し、重み付きの和を最大にします。下のコードはこの書き方で解き、A・Eの4を返します。
- [制約プログラミングによるスケジューリング](#/formulations/PA026): 整数の変数と「同時に1つまで」のような大きな制約をそのまま書けます。CP-SATのようなソルバーは、内部で節を学習するSATの技法を使っています。
- [組合せ局所探索](#/learn/local-search-combinatorial): 割り当てを少しずつ変えて重みを上げます。よい割り当てを早く見つけることはありますが、「これより重い組はない」「満たす割り当てはない」という証明は返しません。

## 数値計算の方法を選ぶ

例の答えは、どの方法でもA・Eの4です。違いは、何を証明として返すかと、問題の大きさにどう対応するかです。

| 系統 | 進み方 | 例での様子 |
|---|---|---|
| 全部の割り当てを調べる | $2^n$ 通りを一つずつ確かめる | 32通り。30人なら約10億通り、60人なら約 $10^{18}$ 通り |
| [CDCL SAT](#/learn/cdcl-sat) | 決める・単位伝播する・矛盾から新しい節を学ぶ、を繰り返す | 「CもEも」は、伝播だけで矛盾に着く |
| コアを使うMaxSAT | SATソルバーに解かせ、同時にかなわない希望の組（コア）を集めて、あきらめる希望を決める | コアはC・EとC・Aの2組で、Cをあきらめる |
| 0-1の整数計画 | 節を線形不等式にし、分枝限定法で解く | 下のコード。`milp` が4を返す |
| [CP-SAT](#/learn/cp-sat) | 節の学習・伝播と、線形の緩和を組み合わせる | 重み付きの目的をそのまま書ける |
| [組合せ局所探索](#/learn/local-search-combinatorial) | 一人ずつ呼ぶ・呼ばないを入れ替えて、重みを上げる | 最良の証明は返さない |

表は速さの順位ではなく、何を手がかりに進み、何を返すかの違いです。

次のコードは、例を全部の割り当て・単位伝播・コアの列挙・0-1の整数計画の順に調べます。

```python
import itertools

import numpy as np
from scipy.optimize import Bounds, LinearConstraint, milp

names = "ABCDE"  # 変数1〜5。真なら呼ぶ。-3 は「Cを呼ばない」
hard = [[1, 2], [-1, -3], [-2, 4], [-4, -5]]  # 鍵、店番、車、店番
soft = [([3], 3), ([5], 2), ([1], 2)]  # Cを呼びたい3、Eを呼びたい2、Aを呼びたい2


def holds(clause, x):
    return any((lit > 0) == x[abs(lit) - 1] for lit in clause)


def label(x):
    return "".join(n for n, b in zip(names, x) if b)


plans = [x for x in itertools.product([False, True], repeat=5) if all(holds(c, x) for c in hard)]
weight = {label(x): sum(w for c, w in soft if holds(c, x)) for x in plans}
print(len(plans), weight)  # 6 {'BD': 0, 'BCD': 3, 'A': 2, 'AE': 4, 'AD': 2, 'ABD': 2}


def propagate(clauses):
    """単位伝播：まだ真の値がなく、残りが1つだけの節があれば、その値に決める"""
    value, steps, changed = {}, [], True
    while changed:
        changed = False
        for clause in clauses:
            if any(value.get(abs(lit)) == (lit > 0) for lit in clause):
                continue
            free = [lit for lit in clause if abs(lit) not in value]
            if not free:
                return None, steps + ["矛盾"]
            if len(free) == 1:
                value[abs(free[0])] = free[0] > 0
                steps.append(("" if free[0] > 0 else "¬") + names[abs(free[0]) - 1])
                changed = True
    return value, steps


print(propagate(hard + [[3]])[1])  # ['C', '¬A', 'B', 'D', '¬E']
print(propagate(hard + [[3], [5]])[1])  # ['C', 'E', '¬A', '¬D', 'B', '矛盾']

# 同時にはかなわない希望の組（コア）
for a, b in itertools.combinations(range(len(soft)), 2):
    together = hard + [soft[a][0], soft[b][0]]
    if not any(all(holds(c, x) for c in together) for x in itertools.product([False, True], repeat=5)):
        print("コア", names[soft[a][0][0] - 1], names[soft[b][0][0] - 1])
# コア C E
# コア C A

# MaxSAT を0-1の整数計画で解く：x_A..x_E と、希望ごとの y_k（かなうなら1）
n, m = 5, len(soft)
rows, lower = [], []
for clause in hard:  # 正のリテラルは x、否定は 1 - x として、節の値の和が1以上
    row = np.zeros(n + m)
    for lit in clause:
        row[abs(lit) - 1] += 1 if lit > 0 else -1
    rows.append(row)
    lower.append(1 - sum(lit < 0 for lit in clause))
for k, (clause, _) in enumerate(soft):  # y_k <= x（その人を呼ぶときだけ希望がかなう）
    row = np.zeros(n + m)
    row[abs(clause[0]) - 1], row[n + k] = 1, -1
    rows.append(row)
    lower.append(0)
c = -np.r_[np.zeros(n), [w for _, w in soft]]
res = milp(c, constraints=LinearConstraint(np.array(rows), lower, np.inf), integrality=np.ones(n + m), bounds=Bounds(0, 1))
print(round(-res.fun), label(res.x[:n] > 0.5))  # 4 AE
```

最初の出力は、決まりを守る6通りと、それぞれの重みです。小さな例の表と同じです。

次の2行は単位伝播です。Cだけを足すと、¬A・B・D・¬E と決まります。CとEを足すと、5つを決めた後で車の決まりが満たせなくなり、「矛盾」で止まります。これが「CもEも呼べない」ことの証明です。

「コア」の2行は、同時にはかなわない希望の組です。最後の行は、0-1の整数計画の答えで、重み4のA・Eです。`milp` は最小化なので、重みに負の符号を付けて渡し、結果の符号を戻しています。

## 出典と再現条件

SATと節・連言標準形・単位伝播は、『Handbook of Satisfiability』第2版（S176）に基づきます。節の学習による探索（CDCL）・矛盾の導出による証明・コアを使うMaxSATも、同じ本（S176）にあります。CP-SATが節の学習と線形の緩和を組み合わせることは、OR-Toolsの公式文書（S022）にあります。論理の制約をモデルとして書き、SATのソルバーに渡す方法は、MiniZincの公式文書（S053）にあります。`milp` と HiGHS の使い方は、SciPyの公式文書（S005）と HiGHSの公式文書（S016）に基づきます。

コードの出力は、SciPy 1.18.1 と NumPy 2.5.3 で上のコードを実行して得た値です。図は、同じ節を図の生成スクリプトで全部の割り当てについて確かめて描いています。5人・4つの決まり・3つの希望は教材用の値で、実際の人の希望や重みの決め方は示しません。
