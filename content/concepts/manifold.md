多様体値変数では、球面・直交行列・回転などの集合を解空間として扱い、接空間のステップとレトラクションで幾何構造を保ちます。

## 一つの円で「外へ出る・接方向を作る・戻る」を読む

長さ1の方向ベクトル $x=(x_1,x_2)$ を選び、$f(x)=0.2x_1-x_2$ を小さくするとします。現在点は $x=(1,0)$、一歩の係数は $\eta=0.5$ です。上へ向かうほど費用は下がりますが、選べるのは単位円 $x_1^2+x_2^2=1$ の上だけです。

普通の勾配は $g=(0.2,-1)$。そのまま引くと $y=x-0.5g=(0.9,0.5)$ で、長さは約1.0296です。費用が下がっても、条件を満たす点にはなっていません。

円に沿う曲線 $x(t)$ を微分すると $x^T\dot x=0$ なので、接空間は

$$
T_xS^1=\{\xi:x^T\xi=0\},\qquad
P_xg=g-x(x^Tg)
$$

です。ここで $x^Tg=0.2$ は半径方向の成分。これを除くと $P_xg=(0,-1)$ となり、下降ステップは $\xi=-0.5P_xg=(0,0.5)$ です。「接空間への射影」は、点を円へ戻す処理ではなく、ベクトルから半径方向を引く処理です。

![単位円上の点(1,0)から接線方向へ進み正規化する左図と、周囲の勾配候補を最近点へ戻す右図。同じ正規化でも二つの候補と到達点は異なる。](./media/manifold-circle-step.svg "左は接ステップ(0,0.5)からのレトラクション、右は周囲の勾配候補(0.9,0.5)の最近点。図の比較はこの単位円とユークリッド計量に限ります。")

左図の接線上の候補 $x+\xi=(1,0.5)$ も、まだ円上ではありません。そこで

$$
R_x(\xi)=\frac{x+\xi}{\|x+\xi\|}
=\left(\frac2{\sqrt5},\frac1{\sqrt5}\right)
\approx(0.8944,0.4472)
$$

と正規化します。費用は $0.2$ から約 $-0.2683$ へ下がります。図では「接線方向を決める橙の矢印」と「円へ戻った緑の点」を順に見てください。

### 同じ「戻す」でも、同じアルゴリズムとは限らない

この球面に限れば、非零の $y$ のユークリッド最近点は $y/\|y\|$ です。これは $\|z-y\|^2=1+\|y\|^2-2z^Ty$ を $\|z\|=1$ の下で最小にすることから分かります。ただし右図の候補 $y=(0.9,0.5)$ を正規化すると $(0.8742,0.4856)$ になり、左図とは異なります。正規化の前に、どの一歩を作ったかが違うためです。$y=0$ では最近点が一意でなく、正規化も定義できません。

レトラクションに必要なのは、少なくとも $R_x(0)=x$ と $\left.\frac{d}{dt}R_x(t\xi)\right|_{t=0}=\xi$ という局所的な整合性です。球面では $x^T\xi=0$ から $\|x+\xi\|^2=1+\|\xi\|^2$ なので、正しい接ベクトルなら分母は0になりません。

同じ長さ0.5の接ステップの指数写像は $(\cos0.5,\sin0.5)\approx(0.8776,0.4794)$ です。正規化レトラクションは角度 $\arctan0.5$ だけ進むので、有限の一歩では一致しません。近くで接方向を再現することと、測地線をその長さだけ厳密に進むことを分けます。

この区別は[射影勾配法](#/learn/projected-gradient)と[Riemann勾配法](#/learn/riemannian-gradient)を読むときにも重要です。一般の多様体では、QRによる戻しをユークリッド最近点射影と呼ぶこともできません。集合、計量、写像を具体的に指定する必要があります。

## 直感: 解は曲がった集合の上にある

多様体は、各点の近くでは低次元のユークリッド空間のように見える集合です。変数$x$を単に$\mathbb{R}^n$のベクトルとして更新するのではなく、$x\in\mathcal{M}$という集合の上にある点として扱います。

次の模式図は、この考え方を3次元の球面に広げて描いたものです。上の単位円の数値を描いた図ではありません。

![青緑の球面上の点から接平面へ橙のステップが伸び、曲線の矢印で球面上の新しい点へ戻る模式図](./media/manifold-tangent-retraction.png "接空間で候補を作り、レトラクションで多様体へ戻す教育用模式図です。球面以外の集合や計量の選択までは示しません。")

典型的な集合と自由度は次のとおりです。

| 集合 | 変数の例 | 自由度・注意 |
| --- | --- | --- |
| 球面 $S^{n-1}$ | 単位ベクトル、正規化された埋め込み表現 | $n-1$。符号や局所座標の選び方に注意 |
| Stiefel多様体 | 直交列を持つ行列 | $X^TX=I$。行列の成分数より自由度が小さい |
| Grassmann多様体 | 部分空間、低次元の基底 | 基底の取り方が違っても同じ部分空間を表す |
| $SO(2)$ / $SO(3)$ | 2D / 3Dの回転 | 行列、四元数、リー代数で表せる |
| SPD多様体 | 正定値共分散行列 | 固有値が正。PSDの境界は別の扱いになる |

確率ベクトルの単体も特殊な集合ですが、0の境界には角があります。したがって、単体の境界まで扱うときは、滑らかな多様体として無条件に扱わず、[単体・確率ベクトル](#/learn/concept.simplex)の射影やミラー法の幾何と照合します。

## ユークリッド空間での更新で壊れるもの

無制約のステップ $y=x-\eta g$ は、一般には$\mathcal{M}$の外へ出ます。球面なら$\|y\|_2=1$が失われます。直交行列なら$Y^TY=I$が崩れ、回転行列なら行列式が1でなくなる場合があります。SPD 行列なら対称性や正定値性を失う可能性があります。

| 破綻する条件 | その場で見る量 | 単純な修正が意味すること |
| --- | --- | --- |
| 球面 | $\|x\|_2-1$ | 正規化は球面上へ戻すが、選んだ計量の厳密な測地線とは限らない |
| Stiefel | $\|X^TX-I\|$ | QRや極分解の因子はレトラクション候補だが、実装と計量を確認する |
| $SO(3)$ | $R^TR-I$、$\det R-1$ | 行列射影とリー代数更新は別の更新則である |
| SPD | 対称性、最小固有値 | 正の対角を持つ下三角因子によるCholesky表現はSPDの内部を表すが、PSD境界を直接表さない |

成分ごとの範囲内への切り詰めや罰則だけでは、集合の構造を保てるとは限りません。修正後の点が可行でも、修正によって目的関数の変化やステップの意味が変わるため、射影距離も記録します。

## 接空間から集合へ戻す

多様体上の現在点$x$では、ユークリッド空間から誘導される計量を使う埋込み多様体なら、通常の勾配を接空間$T_x\mathcal{M}$へ直交射影してリーマン勾配を得ます。別の計量では対応する変換が必要です。接空間のベクトル$\xi$を作ったら、次のいずれかで集合上の点へ戻します。

- **パラメータ化**: 四元数、Cholesky、低次元局所座標などで、別の変数から$\mathcal{M}$を表します。
- **射影**: 周囲の空間の候補を集合へ戻します。非一意性や射影の計算費用を確認します。
- **レトラクション**: $x$と接ベクトル$\xi$から、近傍の集合上の点$R_x(\xi)$を作ります。
- **指数写像**: 選んだリーマン計量の測地線を厳密にたどります。レトラクションと同じとは限りません。

```python
import numpy as np

x = np.array([1.0, 0.0])
g = np.array([0.2, -1.0])
grad = g - x * (x @ g)
xi = -0.5 * grad

def retract(x, xi):
    if not np.isclose(x @ x, 1.0) or not np.isclose(x @ xi, 0.0):
        raise ValueError("unit point and tangent step required")
    y = x + xi
    return y / np.linalg.norm(y)

next_x = retract(x, xi)
assert abs(x @ grad) < 1e-12
assert abs(np.linalg.norm(next_x) - 1.0) < 1e-12
print(next_x, g @ next_x)
for h in (1e-2, 1e-3, 1e-4):
    error = np.linalg.norm((retract(x, h * xi) - x) / h - xi)
    print(h, error)
```

出力は約 `(0.8944, 0.4472)`、費用は約 `-0.2683`。局所微分の誤差は約 `1.25e-3, 1.25e-4, 1.25e-5` と小さくなります。これは接方向の局所的な再現を調べる検査で、最適化の収束証明ではありません。

この例は球面の正規化によるレトラクションだけを示します。SPD、Stiefel、Grassmann、回転群では、接空間射影・計量・レトラクションの組を対応させます。自作する場合は、有限差分による勾配検査と、レトラクション後の構造残差を別々に確認します。

## 表現の非一意性と特異点

多様体の式を満たしても、表現が一意とは限りません。

- 四元数の$q$と$-q$は同じ回転を表します。
- Grassmannでは、同じ部分空間を異なる基底行列が表します。
- 回転の局所座標は、特定の角度付近で不安定になる場合があります。
- SPDのCholesky パラメータ化（対角が正の下三角因子で $X=LL^T$ と表す）は、正定値の内部を保ちますが、固有値0のPSD境界を同じ形では表せません。
- 固定ランク行列は、ランクが変わる場所で同じ滑らかな多様体として扱えません。

このため、座標上の距離やパラメータの差を、そのまま解の差と解釈しません。回転なら測地距離、部分空間なら主角など、対象に合う診断を選びます。

## 可行な反復点と収束は別の判定

レトラクションで毎回可行な点を作れても、最適性や大域性が保証されたわけではありません。少なくとも次を分けて記録します。

| 判定 | 主に見るもの | 分かること |
| --- | --- | --- |
| 幾何学的な可行性 | ノルム、直交残差、行列式、最小固有値 | 反復点が指定した集合にいるか |
| 一階の進展 | リーマン勾配のノルム、目的、測地線に沿う更新 | 局所的な停止条件へ近づいているか |
| 二階法の判断 | 実際の減少量・予測減少量、信頼領域半径 | モデルがステップを予測できているか |
| 表現の健全性 | 局所座標切替、符号の取り決め、条件数 | 座標の問題を解の問題と取り違えていないか |

切替の兆候は、構造残差の増大、レトラクションの誤差の蓄積、局所座標近傍でのステップ不安定、初期点による結果の大きな差です。[Riemann勾配法](#/learn/riemannian-gradient)は一次法の入口、[Riemann 信頼領域法](#/learn/riemannian-trust-region)は二階情報や局所的な頑健性を確認したいときの候補です。

::: warning
各反復の可行性は、局所解・大域最適性・連続モデルでの安全性を保証しません。多様体の選択、計量、レトラクション、停止条件、実装の数値誤差を分けて検証します。
:::
