PDE制約付き最適化は、設計を変えたときの温度や変位を偏微分方程式で求め、その状態を通して目的を評価する定式化です。状態計算の収束と設計の可行性を分け、離散化した問題の解を連続モデルの保証と混同しません。

## 30秒でつかむ

部屋を目標の温度へ近づけるため、場所ごとにヒーターの強さを決めます。
各場所の温度は、ヒーターの強さと同じではありません。
壁の温度と周囲への熱の伝わり方から、温度分布が決まります。

ここではヒーターの強さが**設計変数**で、温度分布が**状態変数**です。
設計から状態を求める関係を、偏微分方程式（partial differential equation, PDE）として制約に含めます。

- **決めるもの**: 材料密度、形状、熱源や境界の入力
- **良くしたいもの**: 温度のずれ、構造の柔らかさ、流れの損失など
- **守ること**: 偏微分方程式と境界条件、設計に必要な制約

設計を一回変えるたびに、状態の計算が必要です。
目的値の評価にも、物理方程式を解く費用が含まれます。

長さ1の棒の両端を温度0に固定し、内部の2点にヒーターを置いた最小の例で、設計と状態の関係を動かして見ます。
まず「熱源の強さ q（両方の点で同じ）」のスライダーを動かしてください。熱源を決めるたびに温度 $u$ が計算し直され、目的の二つの項が変わります。
二つの熱源は別々には動かせず、いつも同じ強さです。
「▶ 再生」を押すと、$q$ が0から自動で増え、$q=4.5$ で少し止まります。

::: explorable pde-heat-source-balance
「棒の温度 u」は、熱源の強さ q から計算した内部2点の温度で、緑の縦線が目標温度 1 とのずれです。下の矢印が熱源で、点線が熱源から温度を決める向き（Ku = q を解く）を表します。「目的 J の内訳」は、温度のずれの項（緑）と熱源の罰則（橙）を積んだ長さで、その下の赤い棒が状態方程式の残差です。「J(q) の曲線」のマーカーが合計を指します。「u の決め方」を切り替えると、温度を手で決める対比ができます。内部2点の離散問題だけを示す図で、連続な棒の解やメッシュを細かくした結果は描きません。
:::

確かめてほしいことは四つあります。

1. $q=0$ では温度が $(0,\ 0)$ のままです。ずれの項は $1.000$、罰則は $0.000$ で、合計は $1.000$ です。「棒の温度 u」の緑の縦線が最も長くなります。
2. $q=9$ にすると温度は目標の $(1,\ 1)$ に重なり、緑の縦線が消えます。ずれの項は $0.000$ です。ところが罰則が $1.000$ になり、合計は $q=0$ と同じ $1.000$ に戻ります。
3. $q=4.5$ に合わせると、温度は $(0.5,\ 0.5)$ で、ずれの項と罰則はともに $0.250$ です。「J(q) の曲線」では緑と橙の曲線がここで交わり、合計 $0.500$ が最小になります。「▶ 再生」では、マーカーがこの谷で止まって見えます。
4. 「u の決め方」を「u を自由に決める」に切り替えます。初期値は $u=1$ と $q=0$ です。ずれの項も罰則も $0.000$ なので、合計 $0.000$ と完璧に見えます。
   しかし赤い棒の状態残差は約 $12.73$ です。「棒の温度 u」には、橙の実線の矢印が無く、点線の矢印だけが伸びています。点線の長さは、$u=1$ を保つのに必要な熱源 $9$ です。
   $q$ を $9$ に上げると、二つの矢印が揃って残差が $0$ になります。合計は $1.000$ に戻ります。

どうして合計は $q=9$ ではなく $q=4.5$ で最小なのでしょうか。熱源が同じ強さ $q$ のとき $u=q/9$ なので、ずれの項は $(1-q/9)^2$、罰則は $(q/9)^2$ と書けます。この二つの和が最小になる点を、式で確かめます。

## 標準形を読む

設計 $q$ と状態 $u$ を選び、物理方程式を満たす組の中で目的を最小にします。

$$
\min_{q,u}\;J(u,q)
\quad\text{s.t.}\quad
R(u,q)=0\quad\text{（偏微分方程式）}
$$

| 記号 | 意味 | 例では |
|---|---|---|
| $q$ | 最適化で変える設計または入力 | 最適な熱源 $(4.5,\ 4.5)$ |
| $u$ | 設計から計算される温度、変位、圧力などの状態 | $(0.5,\ 0.5)$ |
| $J(u,q)$ | 状態の性能と設計の費用を測る目的 | 最適な点で $0.5$ |
| $R(u,q)$ | 状態方程式と必要な境界条件を表す残差 | $Ku-q=(0,\ 0)$ |

実際の問題では、体積や応力の制約と設計の上下限も加わります。
$R=0$ を満たすことだけで、すべての設計制約を守ったとは言えません。

状態が設計から一意に求まる範囲では、$u=u(q)$ を目的へ代入できます。
こうして設計だけの問題にしたものを、縮約定式化と呼びます。
状態を独立な未知数として残す定式化もあります。
状態の可解性や微分可能性は、選んだ物理モデルと境界条件に依存します。

## 小さな例

長さ1の棒で、両端の温度を0に固定します。
熱源 $q$ と温度 $u$ の関係を、定常のPoisson方程式で表します。

$$
-\frac{d^2u}{ds^2}=q(s),\qquad u(0)=u(1)=0
$$

読み方は、「温度の山の曲がり具合 $-u''$ が熱源 $q$ に等しく、両端は温度0」です。
熱源が強いほど、山は高く盛り上がります。

内部を2点、間隔 $h=1/3$ で離散化します。
熱源と温度は、それぞれ2成分になります。

$$
Ku=q,\qquad K=9\begin{pmatrix}2&-1\\-1&2\end{pmatrix}
$$

$K$ は $-d^2/ds^2$ を間隔 $h$ で近似した行列で、係数の $9$ は $1/h^2$ です。
熱源 $q$ を決めると、温度は $u=K^{-1}q$ とただ一つに決まります。
図の点線は、この $q$ から $u$ へ向かう関係です。

内部の目標温度を $(1,1)$ とし、熱源の大きさにも罰則を付けます。
連続の目的は $\tfrac12\int(u-1)^2ds+\tfrac{\beta}{2}\int q^2ds$ です。
これを間隔 $h$ の和で近似すると、二つの項に共通の $h$ が掛かります。
その $h$ を省き、$\beta=1/81$ とした離散目的が、次の二次関数です。

$$
J_h(u,q)=\frac12\|u-(1,1)\|^2+\frac{1}{162}\|q\|^2
$$

読み方は、「温度が目標からずれた量の二乗の半分」と「熱源の二乗に $1/162$ を掛けた費用」の和です。
$1/162=\tfrac12\cdot\tfrac1{81}$ で、後のコードの `alpha = 1/81` に $\tfrac12$ を掛けた形です。

熱源を同じ強さ $q$ にすると $u=q/9$ で、$J=(1-q/9)^2+(q/9)^2$ です。

| 熱源 $q$ | 状態 $u$ | 温度のずれの項 | 熱源の罰則 | 合計 |
|---|---|---:|---:|---:|
| $(0,0)$ | $(0,0)$ | 1.00 | 0.00 | 1.00 |
| $(4.5,4.5)$ | $(0.5,0.5)$ | 0.25 | 0.25 | 0.50 |
| $(9,9)$ | $(1,1)$ | 0.00 | 1.00 | 1.00 |

目標にぴったり合わせる熱源9より、熱源4.5の方が合計は小さくなります。
熱源を強くする費用も目的に含めたからです。
$u=q/9$ を使うと、表の行を自分で出せます。$q=9$ なら $u=1$、$q=4.5$ なら $u=0.5$ です。

$u=K^{-1}q$ を代入すると、熱源だけの凸な二次問題になります。
正の罰則があるため、離散問題の唯一の最適解は $q=(4.5,4.5)$ です。
これは内部2点の離散問題の解で、連続な棒全体の最適解を証明したものではありません。

## 見分け方

次の問いでは、この型を疑います。

- 密度を変えた後、変位を計算して剛性や応力を評価する
- 形状を変えた後、流体方程式を解いて抵抗を評価する
- 熱源や境界入力を変え、温度分布を目標へ近づける
- 材料係数を、観測された状態に合うように推定する

観測に合わせて設計や係数を決める場合は、[逆問題](#/formulations/PA055)とも重なります。
目的がずれの二乗和でも、一回の残差評価にPDE計算が含まれることを隠しません。

時間とともに変わる操作量が主役なら、[最適制御](#/formulations/PA042)も候補です。
設計を変えずに状態だけを求めたい場合は、最適化ではなく状態方程式の求解です。

## 近い定式化

**一般の制約付き非線形最適化へつながります**。
PDEをメッシュ上で離散化すると、状態と設計を有限個の変数で表せます。
離散残差を等式制約とする[一般の制約付きNLP](#/formulations/PA009)になります。
メッシュ上の最適性と、連続問題の最適性は別に調べます。

**形状最適化はこの型の特別な場合**です。
[形状最適化](#/formulations/PA057)は、境界の形を設計変数にして状態方程式を解きます。
設計変数の形が変わっても、設計と状態を分ける構造は残ります。

**線形状態方程式と二次目的なら凸QPへ帰着できます**。
小さな例は、状態の消去後に[凸二次計画](#/formulations/PA018)として直接解けます。
一般の流体や非線形材料の問題まで、凸になるという意味ではありません。

## 解き方の系統

縮約問題では、状態を求めた後に設計への勾配を計算します。
設計変数が多く目的が少ない場合、[随伴感度](#/learn/adjoint-sensitivity)を使うと、変数ごとの状態計算を避けられます。
状態と随伴の境界条件を含め、計算した勾配を有限差分で検査します。

滑らかな縮約目的には、[L-BFGS](#/learn/lbfgs)や[Newton-CG](#/learn/newton-cg)が候補です。
二階情報を使う場合も、状態と随伴の計算費用を数えます。
状態を未知数として残し、設計の制約も同時に扱う場合は、[非線形内点法](#/learn/interior-point-nlp)などを検討します。
一般の非凸問題では、局所的な停止条件と大域最適性を分けます。

次のコードは、小さな離散問題を二次の最適性条件から直接解きます。
随伴は、状態方程式を転置した系を解く変数です。

```python
import numpy as np

k = 9.0 * np.array([[2.0, -1.0], [-1.0, 2.0]])
target = np.ones(2)
alpha = 1.0 / 81.0
response = np.linalg.solve(k, np.eye(2))
q = np.linalg.solve(
    response.T @ response + alpha * np.eye(2),
    response.T @ target,
)
u = np.linalg.solve(k, q)
adjoint = np.linalg.solve(k.T, u - target)
gradient = alpha * q + adjoint
objective = (
    0.5 * np.linalg.norm(u - target)**2
    + 0.5 * alpha * np.linalg.norm(q)**2
)
print("q:", q, "u:", u, "objective:", objective)  # q: [4.5 4.5] u: [0.5 0.5] objective: 0.5
print("state residual:", np.linalg.norm(k @ u - q))  # state residual: 0.0
print("gradient norm:", np.linalg.norm(gradient))  # gradient norm: 0.0
```

実行結果です。

```text
q: [4.5 4.5] u: [0.5 0.5] objective: 0.5
state residual: 0.0
gradient norm: 0.0
```

この例では、状態残差と勾配ノルムは浮動小数点精度で0です。
目的を1回評価するたびに、状態の線形系（この例では2×2）を1回解きます。
勾配を求めるには、転置した系（随伴）をもう1回解きます。
大規模問題では、このコードのように状態の全応答行列を作らず、疎な行列や行列ベクトル積を使います。
随伴による微分の考え方は[dolfin-adjointの公式解説](https://www.dolfin-adjoint.org/en/latest/documentation/maths/3-gradients.html)に対応します。

[行列なしでPDE設計を解く事例](#/gallery/EC026)では、状態と随伴の残差を計算費用に対応付けます。
[片持ちはりの材料配置](#/gallery/topology-cantilever)では、密度を設計にし、変位からコンプライアンスを評価します。

## つまずきやすい点

**状態計算の収束を、最適化の成功と読む**ことはできません。
小さな例の $q=9$ では、状態残差は $0$ で状態計算は解けています。
それでも目的値は $1.00$ で、$q=4.5$ の $0.50$ の2倍です。
次の三つを別に記録します。

| 判定 | 記録する値 |
|---|---|
| 状態計算を解けたか | 状態残差、終了理由、計算回数 |
| 設計が可行か | 上下限、体積、応力などの違反量 |
| 最適化が進んだか | 目的値、設計への勾配、設計変化量 |

**状態計算の失敗を大きな目的値へ隠す**と、計算できない候補と悪い設計を区別できません。
たとえば $q=12$ の評価が失敗して $10^6$ を返す設定だと、記録は極端に悪い設計に見えます。
計算が成功していれば $u=(4/3,\ 4/3)$ で $J=1.889$ にすぎず、$q=9$ の $1.00$ より悪いだけの設計です。
縮約問題で状態が確定しない評価は、失敗状態と消費した計算予算を記録します。
不完全な状態計算を許す方法なら、その精度方針も明示します。

**状態残差を小さくすれば連続モデルも正しいと思う**ことも避けます。
固定したメッシュでの求解と、メッシュ細分化による離散化誤差の検査は違います。
前節の連続の目的を、間隔 $h$ の重みつきの和で近似します（$\beta=1/81$）。
内部点を2点から51点へ増やすと、中央の最適熱源は $4.5$ から約 $5.38$ へ、中央の温度は $0.5$ から約 $0.574$ へ動きます。
どちらのメッシュでも状態残差は $0$ なので、残差は離散化誤差を教えてくれません。境界条件と物理モデルの妥当性も、別の検証です。

**外側の反復数だけで計算費用を比べる**と、内側の計算を落とします。
勾配つきの評価1回は、状態求解1回と随伴求解1回です。
外側の反復が100回なら、求解は少なくとも200回あります。
状態求解と随伴求解の回数を記録します。
線形反復の回数、失敗した評価、実時間も対応付けて比較します。
