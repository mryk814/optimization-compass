最適制御は、時間とともに変える操作量を選び、状態の動きを通じて累積費用を最小にする定式化です。操作と状態は動力学で結び付いています。時間を離散化した問題の成功と、連続時間での実行可能性を分けて確かめます。

## 30秒でつかむ

台車を、止まった位置から別の位置へ動かし、そこで再び止めたいとします。
最初に加速し、途中から減速する必要があります。
最後の操作量だけでなく、動かし始めてから止まるまでの操作全体を選びます。

- **決めるもの**：時刻ごとの加速度、力、流量のような操作量
- **良くしたいもの**：移動中のエネルギー、追従誤差、所要時間から決まる費用
- **守ること**：動力学、初期状態、終端条件、途中の状態と操作の制限

操作を変えると、その後の状態も変わります。
現在の操作だけを見て良し悪しを決めず、未来の状態への影響を含めて選ぶのが最適制御です。

## 標準形を読む

途中で積み上がる費用と、最後の状態に対する費用を足して最小にします。

$$
\min_{u(\cdot)}\;\int_0^T L\big(x(t),u(t)\big)\,dt+\Phi\big(x(T)\big)
\quad\text{s.t.}\quad\dot x=f(x,u)
$$

| 記号 | 意味 | 台車の例 |
|---|---|---|
| $u(t)$ | 時刻ごとの操作量 | 加速度 |
| $x(t)$ | 動力学で変わる状態 | 位置と速度 |
| $f(x,u)$ | 状態の時間変化を決める式 | 位置の変化率は速度、速度の変化率は加速度 |
| $L(x,u)$ | 途中で積み上がる費用 | 加速度の二乗 |
| $\Phi(x(T))$ | 最後の状態に対する費用 | 目標位置からのずれへの罰則など |
| $T$ | 計画する時間の長さ | 到着までの時間 |

動力学だけでは、出発する状態も到着の条件も決まりません。
実際の問題には $x(0)=x_{\mathrm{init}}$ のような初期条件を加えます。
必要なら終端条件や、全時刻で守る経路制約も加えます。

「目標からのずれを費用に入れる」と「目標へ必ず到着する」は異なります。
前者は他の費用と引き換えにずれを許します。
後者は終端の等式制約です。

## 小さな例

位置を $q$、速度を $v$、操作する加速度を $u$ とします。
1秒間で位置0から位置1へ移り、出発時と到着時は静止させます。
単位は、この教材のために揃えています。

$$
\min_u\;\int_0^1u(t)^2\,dt\quad\text{s.t.}\quad
\dot q=v,\;\dot v=u,\quad
q(0)=v(0)=0,\quad q(1)=1,\;v(1)=0
$$

この例には入力の上下限や障害物はありません。
連続時間での最適操作は $u(t)=6-12t$ です。
積分すると $v(t)=6t-6t^2$、$q(t)=3t^2-2t^3$ になり、終端条件を満たします。
費用は $12$ です。数値積分でも同じ値を確かめました。

この操作が最適なことも、式で確かめられます。
終端条件から $\int_0^1u(t)\,dt=0$ と $\int_0^1(1-t)u(t)\,dt=1$ が得られます。
したがって $\int_0^1(\tfrac12-t)u(t)\,dt=1$ です。
Cauchy–Schwarzの不等式から費用は12以上になり、上の操作はその等号を満たします。
これは、この線形な力学と二乗費用の例での証明です。

### 時間を区切ると、何が変わるか

区間ごとに一定の入力を持ち、前進Euler法で状態を計算します。
区間幅を $h=1/N$ とすると、離散的な動力学は次の形です。

$$
q_{k+1}=q_k+hv_k,\qquad v_{k+1}=v_k+hu_k
$$

入力列を変数として、費用 $h\sum_k u_k^2$ を最小にしました。
下のコードで、区間数を変えて実行した結果です。

| 区間数 $N$ | 離散問題の最小費用 | 厳密積分とEuler節点の位置の最大差 |
|---|---:|---:|
| 2 | 16.000000 | 0.500000 |
| 4 | 12.800000 | 0.200000 |
| 10 | 12.121212 | 0.075758 |

$N=4$ の入力は $(4.8,1.6,-1.6,-4.8)$ です。
前半は加速、後半は減速になっています。
区間数を増やすと、この例では費用が連続時間の最適値12へ近づきます。
一般の非線形問題で、同じ単調な変化が起きるとは限りません。

同じ入力を、区間内では一定として厳密に積分すると、位置は次のように変わります。

| 時刻 | Euler法の位置 | 厳密積分の位置 |
|---|---:|---:|
| 0 | 0.00 | 0.00 |
| 0.25 | 0.00 | 0.15 |
| 0.50 | 0.30 | 0.50 |
| 0.75 | 0.70 | 0.85 |
| 1.00 | 1.00 | 1.00 |

この例では最終位置が一致しても、途中の位置は一致しません。
途中に障害物や状態制限がある問題では、終端だけを検査しても足りない理由が見えます。

## 見分け方

次の言葉があれば、最適制御を疑います。

- 燃料、時間、エネルギーを小さくする操作の時系列を決めたい
- 動力学を守りながら目標へ到着したい
- 状態の履歴と操作の履歴が、微分方程式で結び付いている

[非線形動力学の軌道を設計する事例](#/gallery/EC020)では、状態と操作を時刻ごとの変数に置きます。
[振り子を振り上げる事例](#/gallery/EC029)では、角度と角速度の動力学に加えてトルクと速度を制限します。
小さな例より非線形で、途中の制約もある問題です。

次の兆候があれば、近い別の型を確認します。

- 観測のたびに計画を解き直し、先頭の操作だけ使う → [モデル予測制御](#/formulations/PA043)
- 始点から目標までの経路と操作を設計したい → [軌道最適化](#/formulations/PA044)
- 時間発展ではなく、静的な状態方程式を通じて設計を評価する → [偏微分方程式制約付き最適化](#/formulations/PA045)

## 近い定式化

時間を離散化する直接法では、最適制御は有限次元の[制約付き非線形計画](#/formulations/PA009)になります。
変数は入力列、あるいは入力列と状態列です。
連続時間の微分方程式は、積分結果との接続条件や離散近似の等式制約へ変わります。

軌道最適化は、開ループの最適制御問題として書けます。
開ループとは、計算した操作列を、途中の観測による再計算なしに使う形です。
観測と再計算を繰り返すモデル予測制御では、解く問題の形だけでなく運用も変わります。

線形な動力学と凸二次費用を使う離散問題は、凸二次計画として扱える場合があります。
小さな例はこの構造を持ちます。
非線形な動力学や障害物制約を加えると、一般には局所解と大域解を区別する必要があります。

## 解き方の系統

- **Direct Shooting**：入力列だけを変数にし、状態は初期値から前進計算します。[Direct Shootingの記事](#/learn/direct-shooting)で、変数と計算される状態を分けて読めます。
- **Direct Multiple Shooting**：各区間の開始状態も変数にします。区間内は積分し、隣の区間とつながることを制約にします。[Multiple Shootingの記事](#/learn/multiple-shooting)で接続残差を追えます。
- **Direct Collocation**：状態軌道も区間内の多項式で表し、選んだ点で動力学を満たす条件を置きます。[Direct Collocationの記事](#/learn/direct-collocation)で離散点と区間内の可行性を比べられます。

これらは、有限次元の問題への書き換え方の違いです。
その後で使う非線形計画ソルバーの停止条件と、時間離散化の誤差を分けます。
[CasADiの公式文書](https://web.casadi.org/docs/#optimal-control-with-casadi)でも、直接法の変数と積分の扱いを確認できます。

次のコードは、入力列だけを変数にする短い直接法です。
台車の線形なモデルを、前進Euler法で計算します。

```python
import numpy as np
from scipy.optimize import minimize


def solve(n):
    h = 1.0 / n

    def rollout(u, exact=False):
        position = velocity = 0.0
        positions = [position]
        for value in u:
            position += h * velocity + (0.5 * h**2 * value if exact else 0.0)
            velocity += h * value
            positions.append(position)
        return np.array(positions), velocity

    def terminal(u):
        positions, velocity = rollout(u)
        return np.array([positions[-1] - 1.0, velocity])

    result = minimize(
        lambda u: h * np.sum(u**2),
        np.zeros(n),
        jac=lambda u: 2.0 * h * u,
        method="SLSQP",
        constraints={"type": "eq", "fun": terminal},
        options={"ftol": 1e-12, "maxiter": 200},
    )
    nodes, _ = rollout(result.x)
    exact, _ = rollout(result.x, exact=True)
    error = float(np.max(np.abs(exact - nodes)))
    print(n, result.success, round(float(result.fun), 6), round(error, 6))


for n in (2, 4, 10):
    solve(n)
```

```text
2 True 16.0 0.5
4 True 12.8 0.2
10 True 12.121212 0.075758
```

`exact=True` は、この線形モデルの区間内の厳密解を使います。
実機や別の動力学を検証するコードではありません。
一般の問題では、高精度な積分で再計算し、経路制約も区間内で確認します。

## つまずきやすい点

- **状態と操作を自由に選べると思う**：状態は動力学で操作と結び付きます。状態を変数にした直接法でも、接続条件や動力学の残差を満たす必要があります。
- **終端誤差への罰則を到着保証と読む**：必ず到着させる条件なら、終端制約として明示します。
- **離散点の成功を連続時間へ広げる**：区間内の軌道を再計算します。制約残差が小さくても、離散化誤差やモデルの誤差は残ります。
- **費用だけで手法を比べる**：区間数と積分精度を揃えます。終端誤差、経路制約違反、計算時間も記録します。
- **モデルの可行性を実機の安全性と読む**：モデルの妥当性と、観測や外乱への対応は別の検証です。
