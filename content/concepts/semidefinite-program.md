半正定値計画は、対称行列を変数にし、行列全体が半正定値であることを守りながら線形の目的を最小にする定式化です。共分散の整合性や非凸問題の緩和を扱えますが、緩和の解が元の問題の解とは限りません。

## 30秒でつかむ

二つの量 $a$、$b$ のばらつきを測ったところ、分散はそれぞれ1と4でした。
二つがどれほど一緒に動くかを表す共分散 $r$ は、いくらでも大きくしてよいでしょうか。

$r$ が大きすぎると、重みをつけて引いた量 $a-\tfrac r4 b$ の分散が負になります。
この分散は $1-\tfrac{r^2}{4}$ で、$r=2.5$ なら $-0.5625$ です。
分散が負になる量はないので、そのような $r$ を持つ行列は整合しません。
単純な差 $a-b$ の分散 $5-2r$ は、$r=2.1$ でも $0.8$ と正のままです。重みを選ばないと、破れは見えません。

この整合性を行列全体に課すのが、**半正定値**という条件です。
半正定値計画（semidefinite program, SDP）は、この条件のもとで行列の成分を選びます。

- **決めるもの**: 共分散行列や内積を並べたGram行列などの対称行列
- **良くしたいもの**: 行列成分に比例する費用の合計
- **守ること**: 線形の等式と、行列全体が半正定値であること

成分ごとの大小だけでは、行列の整合性は決まりません。
すべての方向で二次形式が負にならないことが、行列全体への条件です。

対角を $1$ と $4$ に固定した2×2行列 $\begin{pmatrix}1&r\\r&4\end{pmatrix}$ を使います。
$r$ をどこまで大きくできるかを、動かして見ます。
図では2行目の対角成分を $s$ と書き、$X_{11}=1$ のとき半正定値になる範囲を $s\ge r^2$ と描きます。
いまは $s=4$ に固定しているので、可行範囲は $r^2\le4$ です。

まず「共分散 r（非対角成分）」のスライダーを、ゆっくり動かしてください。点が緑の線分の上にある間は、二つの固有値がどちらも正です。
「▶ 再生」を押すと、$r$ が0から自動で増えていきます。

::: explorable sdp-psd-boundary
「(r, s) 平面」の緑の領域が、半正定値になる範囲 s ≥ r² です。点は s = 4 の線の上を r に合わせて動きます。上端の矢印は目的 −r が小さくなる向きで、縦の点線はその目的が等しい点の集まりです。「固有値」の棒は行列の二つの固有値で、下の二行に和と積が出ます。2×2の断面だけを示す図で、3×3以上の行列は描きません。
:::

確かめてほしいことは三つあります。

1. $r=1$ に合わせてください。「固有値」の二本の棒が約 $0.70$ と $4.30$ で、和は $5$、積は $4-1=3$ です。点は緑の領域の内側にあります。
2. 「▶ 再生」を押し、$r$ を0から増やしてください。縦の点線が右へ進んで目的 $-r$ が下がり、$r=2$ で少し止まります。点は放物線 $s=r^2$ に触れ、小さい方の棒が「0（境界）」になり、積の行が $0$ になります。
3. 再生を続けるか、スライダーを $r=2.5$、$3$ に合わせてください。点と点線が赤くなり、小さい方の固有値が $-0.415$、$-0.854$ と負に沈みます。積は $-2.25$、$-5$ です。行列の成分は正のままです。

どうして $r=2$ が限界なのでしょうか。固有値の和は $5$ から動かないので、積が $0$ になる点で、小さい方の固有値が $0$ に着きます。その積が行列式 $4-r^2$ です。

## 標準形を読む

対称行列 $X$ を選び、半正定値という条件と線形の等式を守って費用を最小にします。

$$
\min_X\;\langle C,X\rangle
\quad\text{s.t.}\quad
\langle A_i,X\rangle=b_i,\quad i=1,\ldots,m,\qquad X\succeq0
$$

| 記号 | 意味 | 例では |
|---|---|---|
| $X$ | 決める対称行列 | 最適解は $X_{11}=1$、$X_{12}=2$、$X_{22}=4$ |
| $C$ | 目的の各成分に掛ける係数の対称行列 | $C_{12}=C_{21}=-\tfrac12$、ほかは $0$ |
| $A_i,b_i$ | 線形等式 $i$ の係数行列と右辺 | $X_{11}=1$ を表す $A_1$ と $b_1=1$、$X_{22}=4$ を表す $A_2$ と $b_2=4$ |
| $\langle A,X\rangle$ | $\operatorname{tr}(A^TX)$。対応する全成分の積の和 | $\langle A_1,X\rangle=1$、$\langle A_2,X\rangle=4$ |
| $X\succeq0$ | すべての方向 $v$ に対して $v^TXv\ge0$ という条件 | 成り立つのは $-2\le r\le2$ のとき |

対称行列なら、半正定値であることは「すべての固有値が非負」と同値です。
目的と等式は行列成分について線形です。
半正定値行列の集合も凸なので、SDPは凸最適化になります。

線形計画では変数を一つずつ0以上にしますが、SDPでは行列全体を「すべての固有値が0以上」にします。
式の読み方は、「対称行列 $X$ を選び、費用 $\langle C,X\rangle$ を最小にする。ただし $m$ 本の線形等式を守り、$X$ は半正定値」です。

解けたかどうかは、主残差と双対残差で判断します。
主問題と双対問題の目的値の差も見ます。
適切な正則性のもとでは、目的値の差が最適性の目安になります。

## 小さな例

分散1と4を対角に固定し、共分散 $r$ をできるだけ大きくします。
最大化を最小化へ直すため、目的を $-r$ とします。

$$
\min_r\;-r
\quad\text{s.t.}\quad
X=\begin{pmatrix}1&r\\r&4\end{pmatrix}\succeq0
$$

読み方は「$r$ を選んで $-r$ を最小にする。ただし行列が半正定値」です。

この2行2列の対称行列は、対角成分が正です。
半正定値であるためには、行列式 $4-r^2$ も非負でなければなりません。
行列式は二つの固有値の積で、固有値の和は対角の和 $1+4=5$ のまま変わりません。
和が $5$ のままなので、積が $0$ になる $r=2$ で、小さい方の固有値が $0$ に着きます。
したがって可行範囲は $-2\le r\le2$ です。

| 共分散 $r$ | 行列式（固有値の積） | 固有値 | 判定 |
|---|---:|---|---|
| -2 | 0 | $(0,5)$ | 可行 |
| 0 | 4 | $(1,4)$ | 可行 |
| 1 | 3 | 約 $(0.6972,4.3028)$ | 可行 |
| 2 | 0 | $(0,5)$ | 可行で、目的が最小 |
| 2.5 | -2.25 | 約 $(-0.4155,5.4155)$ | 半正定値ではない |
| 3 | -5 | 約 $(-0.8541,5.8541)$ | 半正定値ではない |

最良の値は $r=2$、目的値は $-2$ です。
行列は境界にあり、固有値の一つが0になります。
$r=3$ の行列は全成分が正でも、半正定値ではありません。

標準形では、目的の係数行列を $C=\begin{pmatrix}0&-1/2\\-1/2&0\end{pmatrix}$ とします。
内積は二つの非対角成分を足すため、$\langle C,X\rangle=-r$ です。
二つの等式で対角成分を1と4に固定すれば、標準形と同じ問題になります。

## 見分け方

次の問いでは、SDPを疑います。

- 既知の分散を守り、未知の共分散を補いたい
- 点やベクトルの内積を並べた行列を決めたい
- 行列のすべての方向で、エネルギーや分散が負にならない条件を課したい
- 非凸な二次問題を緩和し、大域最適値の下界を得たい

二次の式があるだけではSDPとは限りません。
変数がベクトルで、目的の二次形式が凸なら[凸二次計画](#/formulations/PA018)も候補にします。
ノルムの不等式だけで表せるなら、[二次錐計画](#/formulations/PA020)で表す方が小さいモデルにできます。

「行列の階数を1にする」という条件が必須なら、その条件まで含めた問題は一般に凸ではありません。
半正定値条件だけへ置き換えると、別の問題へ緩和したことになります。

## 近い定式化

**二次錐計画はSDPの特別な場合**です。
ノルム制約は、Schur補行列を使って半正定値制約へ書き換えられます。
ただし、その書き換えで行列の大きさが増えます。
二次錐で足りる問題は、元の構造を保ってソルバーへ渡します。

**SDPは一般錐最適化の特別な場合**です。
[一般の錐最適化](#/formulations/PA022)は、半正定値錐を他の凸錐と組み合わせて扱います。
半正定値条件は、その部品の一つです。

**非凸二次問題からは緩和として現れます**。
[非凸QP・QCQP](#/formulations/PA019)の積 $x_ix_j$ を、持ち上げた行列の成分に置き換えます。
$x$ を含む対称行列の階数1条件を外すと、可行集合が広がります。
有効な緩和なら、最小化問題のSDP最適値は元の問題の下界です。
階数条件を外した解から、元の可行解を回復できるかは別に調べます。

## 解き方の系統

[主双対錐内点法](#/learn/primal-dual-conic)は、主変数と双対変数の残差と相補性を同時に小さくします。
高精度まで解きたいときの候補ですが、大きな行列の線形系を解く費用も見ます。
[ADMM](#/learn/admm)などの分割法は、部分問題の解きやすさを使います。
半正定値錐への射影で固有値分解が必要になる場合は、その費用も記録します。

行列を低階数の積で表すと、変数を減らせる場合があります。
その代わりに元の凸SDPとは違う非凸問題になります。
[Riemann 信頼領域法](#/learn/riemannian-trust-region)のような多様体手法を検討するときも、局所解とSDPの大域最適性を分けます。

小さな例をCVXPYで記述し、半正定値錐に対応するSCSで解きます。
半正定値の演算子が、行列全体への条件です。

```python
import cvxpy as cp
import numpy as np

x = cp.Variable((2, 2), symmetric=True)
constraints = [x >> 0, x[0, 0] == 1.0, x[1, 1] == 4.0]
problem = cp.Problem(cp.Minimize(-x[0, 1]), constraints)
problem.solve(solver="SCS", eps=1e-8, max_iters=10000)
if problem.status != cp.OPTIMAL:
    raise RuntimeError(problem.status)

print(problem.status)  # optimal
print("X:", np.round(x.value, 6).tolist())  # X: [[1.0, 2.0], [2.0, 4.0]]
print("objective:", round(problem.value, 6))  # objective: -2.0
print("eigenvalues:", np.round(np.linalg.eigvalsh(x.value), 6).tolist())  # eigenvalues: [-0.0, 5.0]
```

実行結果を小数点以下6桁へ丸めると、次の値になります。

```text
optimal
X: [[1.0, 2.0], [2.0, 4.0]]
objective: -2.0
eigenvalues: [-0.0, 5.0]
```

丸める前の値では、最小固有値が丸め誤差の範囲でわずかに負になる場合があります。
半正定値条件の違反量と対角の等式残差を、設定した許容誤差と比べます。
記述方法は[CVXPYのSDP例](https://www.cvxpy.org/examples/basic/sdp.html)に対応します。
停止判定と対応する錐は[SCSの公式文書](https://www.cvxgrp.org/scs/)を参照します。

## つまずきやすい点

**半正定値を成分ごとの非負と取り違える**と、別のモデルになります。
小さな例の $r=-2$ は、非対角成分が負でも固有値が $(0,5)$ で半正定値です。
逆に $r=3$ は成分が $1,3,3,4$ とすべて正でも、固有値が約 $-0.854$ で違反します。
成分の符号ではなく、固有値、または錐への距離で行列全体を調べます。

**正定値だけを解と考える**と、境界の最適解を捨ててしまいます。
正定値だけを許すと、$r$ は $2$ 未満に限られ、$-r$ はいくらでも $-2$ に近づくだけで $-2$ には届きません。
最適解 $\begin{pmatrix}1&2\\2&4\end{pmatrix}$ は固有値 $0$ を持つ階数1の行列で、境界の上にあります。

**緩和の目的値を元の問題の達成値と読む**ことも避けます。
緩和の行列が元のベクトルの積へ戻るとは限りません。
小さな例で、$r=2$ の行列は $x=(1,2)$ を使って $xx^\top$ と書けます。階数が1だからです。
一方、$r=0$ の $\operatorname{diag}(1,4)$ は階数2で、どんなベクトルの積にも戻りません。
戻せるかどうかは階数で調べ、戻した候補は元の制約と目的で評価し直します。
SDPの下界と元の可行解の値を並べ、残る差を見ます。

**行列を大きくすれば解けると思い込む**と、計算費用を見誤ります。
この例の対称行列は、$X_{11}$ と $X_{12}$ と $X_{22}$ の3成分でできています。
等式2本が二つを固定するので、自由なのは $r$ だけです。
$n\times n$ の対称行列なら成分は $n(n+1)/2$ 個あり、$n=100$ で5050個です。
次数だけでなく、等式数と疎構造も線形系や錐射影の費用に影響します。
必要精度と残差を揃えて手法を比較します。
