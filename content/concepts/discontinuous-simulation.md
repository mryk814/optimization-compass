決定論的だが不連続なsimulationの最小化は、同じ入力なら必ず同じ値が返るのに、入力を少し動かすと値が飛ぶ関数を範囲の中で最小にする問題です。段差の前後で式が別物になるので、勾配や差分の傾きは頼りになりません。値の比較だけで進む探索でも、行き先は出発点と探索幅に左右されます。

## 30秒でつかむ

乾燥機のダイヤル $x$ を、0 から 1 の間で決めます。工場には1バッチの総コスト $F$ を返すsimulatorがあります。$F$ は電力と不良品の損失を合わせた値で、小さいほど良いとします。

simulatorの中では、ダイヤルが 0.55 に届いた所で運転のプログラムが切り替わります。同じダイヤルを何度入れても同じコストが返り、計算が落ちることもありません。ところが 0.55 をまたぐと、コストが急に変わります。

ダイヤルを少しずつ動かして、坂を下ればよいように見えます。しかし 0.55 の手前の坂が下る先は 0.25 付近の谷で、0.55 の先には別の谷が 0.80 付近にあります。どちらの谷に入るかは、そこまでの動かし方で決まります。

- **決めるもの**: ダイヤル $x$（0 から 1）
- **良くしたいもの**: simulatorが返す1バッチの総コスト $F(x)$
- **守ること**: 範囲 $0\le x\le1$ だけです。運転が切り替わる 0.55 は制約ではなく、$F$ の中に埋まっている段差です

まず図の点線の縦線を見て、白抜きの丸と紺の丸の高さを読んでください。次に、出発の橙の丸から、白い四角の 0.50 と 0.60 に動いたときの高さを比べてください。

![ダイヤルxと1バッチの総コストFの折れ線。xが0.55未満では底が0.25でF=0.4の谷、0.55以上では底が0.80でF=0.2の谷になり、0.55でFは0.58から0.325へ飛び下がる。出発点はx=0.10でF=0.445で、最初に試す0.50と0.60が白い四角で示される。](./figures/discontinuous-dryer-cliff.svg "乾燥機のダイヤル：教材用の式から計算した総コスト。実際のsimulatorや手法の性能は表さない")

1. 0.55 の直前で $F$ は 0.58 に近づきます。ちょうど 0.55 では 0.325 で、段差は $-0.255$ です。白抜きの丸は 0.58 で、実際に返る値は紺の丸の 0.325 です。0.55 ちょうどは、0.55 以上の式に入ります。
2. 出発の 0.10 では $F=0.445$ です。0.50 に動くと 0.525 に上がり、0.60 に動くと 0.28 に下がります。0.50 と 0.60 は 0.1 しか離れていないのに、結果が逆になります。
3. 二つの谷の底は、0.25 で $F=0.4$、0.80 で $F=0.2$ です。0.25 は 0.55 未満の範囲では最小ですが、全体の最小ではありません。

0.55 の近くで傾きを測ると、何が読めるのでしょうか。この疑問に、次の節の式と小さな例が答えます。

## 標準形を読む

次の式は「範囲の中から、simulatorの出力 $F$ が最も小さくなる入力を選ぶ。ただし $F$ は決定論的で、どこかで値が飛ぶ」を表します。

$$
\min_{x\in[\ell,u]}\; F(x),\qquad F \text{ は決定論的だが不連続}
$$

この式は「範囲 $[\ell,u]$ の中で $F(x)$ が最小の $x$ を選ぶ」と読みます。$F$ の値は同じ $x$ なら変わりません。ただし、$x$ をわずかに動かしたとき、$F$ がわずかにしか変わらないとは限りません。

| 記号 | 意味 | 例では |
|---|---|---|
| $x$ | 決める入力 | ダイヤル |
| $[\ell,u]$ | 入力の範囲 | $[0,1]$ |
| $F(x)$ | simulatorが返す値 | 1バッチの総コスト |
| $c$ | 値が飛ぶ入力 | 0.55 |

例の $F$ は、$c=0.55$ で二つの式を切り替えます。

$$
F(x)=\begin{cases}0.40+2(x-0.25)^2 & (x<0.55)\\[2pt] 0.20+2(x-0.80)^2 & (x\ge0.55)\end{cases}
$$

0.55 未満では底が 0.25 の放物線、0.55 以上では底が 0.80 の放物線です。ちょうど 0.55 は 0.55 以上の式に入るので、0.55 での値は 0.325 です。

### 決定論的であることと、滑らかであることは別です

同じ入力を何度呼んでも同じ値が返る性質を決定論的と呼びます。例では、$F(0.30)$ を何度評価しても 0.405 です。

一方で滑らかさは、入力を少し動かしたとき値も少ししか動かない性質です。段差のある $F$ は、決定論的でも滑らかではありません。この二つを分けておくと、値が揺れる問題（[PA013](#/formulations/PA013)）や、値が返らない問題（[PA016](#/formulations/PA016)）と区別できます。

### 傾きは、段差をまたぐかどうかで変わります

勾配法は、傾きを使って次の点を決めます。傾きを数式で得られないときは、前後の2点の値の差から作る差分で代用します。

例で $x=0.54$ の真の傾きは $4(0.54-0.25)=1.16$ です。ところが、差分の幅 $h$ を変えると、同じ点で別の傾きが出ます。$h=0.001$ なら 1.16、$h=0.01$ なら $-11.59$、$h=0.1$ なら $-1.105$ です。$h=0.01$ と $0.1$ は 0.55 をまたぐので、傾きの符号まで逆になります。

### 保証は局所の探索幅まで

微分を使わず値の比較だけで進む探索では、止まった点について言えることは限られます。調べた近傍の点の中に改善がなかった、というところまでです。

[MADS](#/learn/mads)の収束の議論（S060）は、極限点の近くで $F$ がLipschitz連続であるといった条件のもとで、極限点が局所的な停留点（Clarkeの意味）になると述べるものです。大域最小に着くことや、段差を越えることは約束しません。例の $F$ は 0.55 のすぐ近くでLipschitz連続ではないので、探索が 0.55 に集まるなら、この条件は成り立ちません。

## 小さな例

最も簡単な、値の比較だけで進む探索を使います。出発点 $x_0$ と最初の探索幅 $s$ を決め、次を繰り返します。

1. 現在の点から $+s$ と $-s$ の点を、この順に評価する（範囲の外は評価しない）
2. 先に $F$ が下がった点に動く
3. 下がる点がなければ、$s$ を半分にする
4. $s$ が $10^{-4}$ 以下になったら止める

この探索は微分を使いません。値を比べるだけなので、段差があっても動きます。以下は、出発点 0.10 と、探索幅 0.4 と 0.5 の2通りです。

探索幅 0.4 の場合、最初に試す 0.50 は $F=0.525$ で、0.445 より高くなります。$-0.4$ は範囲の外です。そこで幅を 0.2 に半分にして、0.30（$F=0.405$）に動きます。

探索幅 0.5 の場合、最初に試す 0.60 は $F=0.28$ で、0.445 より低くなります。そのまま 0.60 に動きます。

| 探索幅の初期値 | 動いた点 | $F$ | 動いたときの幅 | 累計評価回数 |
|---:|---:|---:|---:|---:|
| 0.4 | 0.30 | 0.405 | 0.2 | 3 |
| 0.4 | 0.25 | 0.400 | 0.05 | 9 |
| 0.5 | 0.60 | 0.280 | 0.5 | 2 |
| 0.5 | 0.85 | 0.205 | 0.25 | 4 |
| 0.5 | 0.7875 | 0.2003 | 0.0625 | 9 |

探索幅 0.4 の探索は、0.25 で $F=0.4$ に動いた後に改善が見つからず、27 回の評価で止まります。幅を $10^{-4}$ 以下まで半分にしても、同じです。探索幅 0.5 の探索は表の後も 0.8 に近づき、$F=0.2$ になって 35 回の評価で止まります。

二つの探索は、同じ出発点と同じ $F$ から始めて、別の谷に着きます。分かれ目は、最初に試す点が 0.50 か 0.60 かです。0.50 は段差の手前にあり、0.60 は段差の先にあります。

1001点の格子に全部当てると、最小は $x=0.8$ の $F=0.2$ です。探索幅 0.5 の探索はその谷に入り、探索幅 0.4 の探索は入りません。ただしこれは、この $F$ とこの2通りの設定についての結果です。どちらの設定が良いかは、この例からは言えません。

## 見分け方

この型は定式化の図鑑で「不連続決定論black-box」と呼ばれています。次の言葉が課題に出てきたら、この型を疑います。

- 閾値を超えると別の処理に入る、場合分けを含むsimulatorの出力を良くしたい
- 内部で離散的な丸めや選択があり、入力を少し変えると出力が飛ぶ
- 同じ入力で再実行すると、毎回同じ値が返る
- 値は必ず返る（失敗はない）

別の型へ進む兆候は、困りごとから探せます。

- 同じ入力でも毎回値が変わる → [noiseを含むblack-box（PA013）](#/formulations/PA013)。例なら、$F(0.30)$ を再評価して値が変わるなら、この型ではありません
- 入力によっては値が返らない → [失敗・NaNを伴うsimulation（PA016）](#/formulations/PA016)。段差の先は値が返っているので、失敗として扱う理由はありません。大きな目的値で埋めると探索を誤らせることがあります
- 角や折れ目はあるが、値は連続でつながっている → [一般非滑らか局所（PA011）](#/formulations/PA011)
- 評価1回が高価で、試せる回数が数十回しかない → [非常に高価な低次元評価（PA014）](#/formulations/PA014)

## 近い定式化

- **noiseを含むblack-box（PA013）は、値が飛ぶ理由が違います**: 同じ入力でばらつくなら、繰り返して平均を取れます。例の $F(0.30)$ を5回評価しても、5回とも 0.405 で、平均を取る意味はありません。段差があるのに繰り返しで均そうとすると、評価の回数を無駄にします。
- **失敗・NaNを伴うsimulation（PA016）は、値が返らない型です**: 例では、0.55 の前後のどちらでも値が返ります。段差の先を「悪い値」で置き換える必要はありません。実際に 0.55 の値は 0.325 で、直前の 0.58 より低いからです。
- **一般非滑らか局所（PA011）は、値が連続でつながる型です**: 絶対値や最大値のような折れ目がある関数が当てはまります。例の $F$ は 0.55 でつながっていないので、この型ではなく、PA012 です。
- **非常に高価な低次元評価（PA014）は、評価の費用が主題です**: 段差を持つ $F$ の評価が高価なら、両方の性質を同時に持ちます。そのときは、評価回数の予算を先に決めます。

## 解き方の系統

表は順位ではなく、段差のある $F$ に対して何を手がかりに進むかの違いです。例の数値は、この記事の $F$ と、指定した出発点・探索幅についてのものです。

| 系統 | 進み方 | 段差に対して |
|---|---|---|
| 勾配法（[BFGS](#/learn/bfgs)など）と差分 | 傾きから次の点を決める | $x=0.54$ の傾きが差分の幅で 1.16、$-11.59$、$-1.105$ と変わる。段差をまたぐ幅では、傾きが向きの手がかりにならない |
| 値の比較だけで進む局所探索（[Pattern Search](#/learn/pattern-search)・[MADS](#/learn/mads)・[Nelder–Mead](#/learn/method.nelder-mead)） | 近傍の点の値を比べて動く | 傾きを使わないので動く。例の探索はこの系統の最小の骨格で、出発点 0.10 から探索幅 0.4 なら 0.25、0.5 なら 0.80 に着く |
| [Bayes最適化](#/learn/bayesian-optimization) | 評価した点から代理モデルを作る | 代理モデルが滑らかさを仮定する場合、段差の前後をなだらかにつないでしまうことがある。段差をどう扱うかは、代理モデルの設計しだい |
| 格子・ランダム探索 | 履歴を使わず広く試す | 1001点の格子なら最小は 0.8 の 0.2 が分かるが、評価を1001回払う |

Nelder–Meadの原論文（S063）の手続きも、関数値の大小だけを使います。表は方法の順位ではありません。

次のコードは、例の $F$ と探索を、標準ライブラリだけで動かします。

```python
CLIFF = 0.55


def dryer(x):
    """1バッチの総コスト F。ダイヤル x が 0.55 以上で運転が切り替わる。"""
    if x < CLIFF:
        return 0.40 + 2.0 * (x - 0.25) ** 2
    return 0.20 + 2.0 * (x - 0.80) ** 2


# 決定論的: 同じ入力は何度呼んでも同じ値。値が返らない点もない
print(dryer(0.30) == dryer(0.30), dryer(0.10), dryer(0.55))  # True 0.445 0.325

# 段差: 0.55 の直前と、ちょうど 0.55
print(round(dryer(0.55 - 1e-9), 4), dryer(0.55))  # 0.58 0.325


def central_slope(x, h):
    return (dryer(x + h) - dryer(x - h)) / (2 * h)


# x = 0.54 の真の傾きは 4(x - 0.25) = 1.16。差分の幅だけが違う
for h in (0.001, 0.01, 0.1):
    print(h, round(central_slope(0.54, h), 3))  # 0.001 1.16 / 0.01 -11.59 / 0.1 -1.105


def compass(x0, step, tol=1e-4):
    """比較だけを使う探索。+step、-step の順に試し、最初の改善を採る。なければ step を半分にする。"""
    x, fx, calls = x0, dryer(x0), 1
    while step > tol:
        for cand in (x + step, x - step):
            if 0.0 <= cand <= 1.0:
                calls += 1
                if dryer(cand) < fx:
                    x, fx = cand, dryer(cand)
                    break
        else:
            step /= 2
    return round(x, 3), round(fx, 3), calls


for x0, step in ((0.10, 0.4), (0.10, 0.5), (0.30, 0.1), (0.30, 0.4)):
    print(x0, step, compass(x0, step))
# 0.1 0.4 (0.25, 0.4, 27)
# 0.1 0.5 (0.8, 0.2, 35)
# 0.3 0.1 (0.25, 0.4, 23)
# 0.3 0.4 (0.8, 0.2, 27)

# 1001点の格子に全部当てた参照: 最小は x = 0.8 の F = 0.2
grid = [i / 1000 for i in range(1001)]
print(min((dryer(x), x) for x in grid))  # (0.2, 0.8)
```

最初の出力は、同じ入力が同じ値を返すことを示します。出発点の値は 0.445 で、ちょうど 0.55 の値は 0.325 です。2番目の出力は、0.55 の直前の 0.58 とちょうど 0.55 の 0.325 で、図の段差と一致します。

`central_slope` の3行は、同じ点 $x=0.54$ で幅だけを変えた差分の傾きです。1.16 は真の傾きに一致し、後ろの2つは 0.55 をまたぐ幅の値です。

`compass` の4行は、小さな例の2通り（出発点 0.10）に、出発点 0.30 の2通りを足したものです。出発点 0.30 でも、探索幅 0.1 なら 0.25 に、0.4 なら 0.80 に着きます。評価回数は 23 から 35 回で、少ない回数で止まった探索が良い値とは限りません。最後の出力は、1001点の格子の最小で、0.8 の 0.2 です。

## つまずきやすい点

- **探索幅を細かくすれば、全体の最小に着くと考える**: 出発点 0.10 から探索幅 0.4 で始めた探索は、幅を細かくしても 0.25 の $F=0.4$ に止まります。段差の先の 0.80 にある $F=0.2$ は、幅を半分にしても見えません。幅を細かくして上がるのは、止まった谷の中の精度だけです。
- **傾きがほぼ 0 の点を、最小と読む**: 0.25 は傾きが 0 で、0.55 未満では最小です。ところが全体の最小の $F=0.2$ は、段差の先の 0.80 にあります。傾きを読んで分かるのは、いま立っている谷の中のことです。
- **差分の傾きの符号をそのまま信じる**: $x=0.54$ の差分は幅しだいで変わり、1.16 と $-11.59$ と $-1.105$ になります。幅 0.001 の差分は「$x$ を減らすと下がる」と言います。幅 0.01 と 0.1 の差分は「$x$ を増やすと下がる」と言います。差分の幅が、どこまで先を見るかを決めているからです。幅を決めたら、2点が段差をまたいでいないかを確かめます。
- **値が飛ぶのをnoiseと見なして繰り返し評価する**: $F(0.30)$ を5回評価しても、5回とも 0.405 です。同じ入力を繰り返しても新しい情報は得られません。評価が高価なら、その分の予算を失います。
- **評価回数が少ない探索を、良い探索と見なす**: 出発点 0.10 では、探索幅 0.4 の探索が 27 回で $F=0.4$ に止まります。探索幅 0.5 の探索は 35 回で $F=0.2$ に止まります。評価回数が少ない側が、高い値で終わっています。評価回数と値は別々に読みます。
- **出発点を一つ決めて終わりにする**: 出発点 0.30 でも、探索幅 0.1 なら 0.25、0.4 なら 0.80 に着きます。出発点と探索幅を変えた複数の探索を比べ、着いた谷の値を見ます。評価回数の予算が許す範囲に限ります。
