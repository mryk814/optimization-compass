混合整数二次計画は、凸二次計画の一部の変数に「整数であること」を加えた定式化です。整数条件を外した凸QPの最適値は下界になりますが、整数解との差が残るため、緩和を解きながら変数を決めていく分枝限定法で最適性を示します。二次の行列 Q が半正定値でないと、緩和そのものが凸でなくなり、この下界の保証は成り立ちません。

## 30秒でつかむ

5つの投資信託（銘柄A〜E）に資金を配分します。値動きのばらつき（分散）を小さくするだけなら、5つすべてに少しずつ配分するのが最良で、これは凸二次計画として解けます。ところが実際には、銘柄を増やすたびに管理の手間がかかります。「保有は3銘柄まで」「買うなら全体の10%以上」という決まりがあり、銘柄ごとの配分にも上限があります。

5銘柄すべてに配分する最良の案を作ってから、重みの小さい銘柄を外して3銘柄にすれば済むでしょうか。そう単純にはいきません。外すと目標の期待収益に届かなくなったり、外した銘柄が実は最良の組合せに入っていたりします。「どれを保有するか」という飛び飛びの決定が入ると、重みを決める連続の問題に、組合せを選ぶ問題が重なります。

この型では、連続の重みと、保有する・しないを表す0-1の値を同時に決めます。0-1の条件を外した凸QPを解くと、最良の値の下限が分かります。その下限と、実際に見つけた解の差を縮めていくと、「これより良い組合せはない」と示せます。

- **決めるもの**: 5銘柄の重み（連続）と、各銘柄を保有するかどうか（0か1）
- **良くしたいもの**: 配分の分散と、保有する銘柄1つにつき一定の固定費を足した合計
- **守ること**: 重みの合計が1、期待収益が目標以上、銘柄ごとの上限、保有するなら重みが最小ロット以上、保有数が3以下

このとき、5銘柄すべてに配分する最良の分散と、3銘柄以内で実際に達成できる最良の値は、どれだけ離れているのでしょうか。また、「全部の組合せを調べた」以外の方法で、最良だと言い切れるのでしょうか。標準形の式と、小さな例の計算で確かめます。

## 標準形を読む

次の式が表すのは「一部の変数を整数に限り、残りは連続のまま、二次の目的を線形の制約のもとで最小にする」です。

$$
\min_{x}\ \tfrac12 x^\top Q x + c^\top x \quad \text{s.t.}\quad Ax\le b,\quad x_j\in\mathbb{Z}\ \ (j\in I)
$$

$I$ に入る変数だけが整数で、$I$ が空なら[凸二次計画](#/learn/concept.convex-quadratic-program)、$Q=0$ なら[混合整数線形計画](#/learn/concept.mixed-integer-linear-program)です。5銘柄の例は、重み $x_i$ と保有の有無 $z_i$ を並べた変数について、次の形に書けます。

$$
\min_{x,z}\ x^\top\Sigma x + f\sum_{i=1}^{5} z_i
\quad\text{s.t.}\quad
\sum_i x_i=1,\ \ \mu^\top x\ge r,\ \ \ell z_i\le x_i\le M_i z_i,\ \ \sum_i z_i\le k,\ \ z_i\in\{0,1\}
$$

標準形の $Q$ は、この例では $2\Sigma$ にあたります（標準形に $\tfrac12$ が付いているためです）。記号は次の意味です。

| 記号 | 意味 | 5銘柄の例では |
|---|---|---|
| $x_i$ | 銘柄 $i$ に配分する重み（連続） | 合計が1になる5つの数 |
| $z_i$ | 銘柄 $i$ を保有するなら1、しないなら0 | 5つの0-1変数 |
| $\Sigma$ | 収益の共分散行列（半正定値） | 標準偏差が10%〜25%の5銘柄から作った $5\times5$ の行列 |
| $\mu,\ r$ | 期待収益と、その目標 | $\mu=(4,5,6,8,9)$ %、$r=6$ % |
| $f$ | 保有する銘柄1つあたりの固定費。分散と同じ尺度に直した値 | 5 |
| $\ell$ | 保有するときの重みの最小ロット | 0.1 |
| $M_i$ | $z_i=1$ のときの重みの上限（big-M） | 各銘柄の上限 0.6, 0.5, 0.5, 0.4, 0.4 |
| $k$ | 保有できる銘柄数の上限 | 3 |

### 0-1変数と big-M

$x_i\le M_i z_i$ と $x_i\ge \ell z_i$ の2本が、$z_i$ と重みを結びます。$z_i=0$ なら $0\le x_i\le0$ なので重みは0です。$z_i=1$ なら $\ell\le x_i\le M_i$ で、最小ロット以上、上限以下の重みを持てます。この $M_i$ を big-M と呼びます。$M_i$ は「$z_i=1$ のとき $x_i$ がとりうる最大値」以上であれば正しいモデルになります。この例では、銘柄ごとの上限 $0.6,\ 0.5,\ 0.5,\ 0.4,\ 0.4$ が、正しい範囲で最も小さな $M_i$ です。$M_i$ の大きさは、緩和の強さと数値の安定性に影響します。

### 「凸」はどこの凸か

$\Sigma$ の固有値は $(57.4,\ 116.6,\ 223.8,\ 323.9,\ 772.2)$ ですべて正で、$\Sigma$ は半正定値（さらに正定値）です。このとき、$z$ を固定すれば各部分問題は凸QPになり、$z_i\in\{0,1\}$ を $0\le z_i\le1$ に緩めた問題も凸QPです。凸QPの最適値は大域的な最小値なので、緩和の最適値は、整数条件を守った問題の最適値の下界になります。

$Q$ が半正定値でない場合は、緩和した問題が凸でなくなります。局所解法が返す値は下界とは限らず、「これより良い解はない」という分枝限定法の判定が崩れます。具体的な様子は、小さな例の最後で別の例を使って確かめます。

## 小さな例

### 5銘柄の例・設定

銘柄ごとの標準偏差、期待収益、重みの上限は次のとおりです。相関は、隣り合う銘柄ほど高く（A–B で 0.5）、離れるほど低く（A–E で 0）なるように決めました。

| 銘柄 | 標準偏差 | 期待収益 | 重みの上限 |
|---|---:|---:|---:|
| A | 10 % | 4 % | 0.6 |
| B | 12 % | 5 % | 0.5 |
| C | 15 % | 6 % | 0.5 |
| D | 20 % | 8 % | 0.4 |
| E | 25 % | 9 % | 0.4 |

以下の表とコードは、この5銘柄と、目標収益 6 %、最小ロット 0.1、保有数の上限 3、固定費 5 に対応します。最初のコードは、データを置きます。

```python
import itertools
from collections import Counter

import numpy as np
from scipy.optimize import linprog, minimize

names = "ABCDE"
vol = np.array([10, 12, 15, 20, 25.0])  # 標準偏差 [%]
corr = np.array(
    [
        [1.0, 0.5, 0.3, 0.1, 0.0],
        [0.5, 1.0, 0.4, 0.2, 0.1],
        [0.3, 0.4, 1.0, 0.3, 0.2],
        [0.1, 0.2, 0.3, 1.0, 0.4],
        [0.0, 0.1, 0.2, 0.4, 1.0],
    ]
)
Sigma = np.outer(vol, vol) * corr  # 共分散 [%^2]
mu = np.array([4, 5, 6, 8, 9.0])  # 期待収益 [%]
cap = np.array([0.6, 0.5, 0.5, 0.4, 0.4])  # 銘柄ごとの重みの上限
lot, target, k, fee = 0.1, 6.0, 3, 5.0  # 最小ロット、目標収益、保有数の上限、固定費

print(np.linalg.eigvalsh(Sigma).round(1))
# [ 57.4 116.6 223.8 323.9 772.2]
print(vol**2, Sigma[0, 4])
# [100. 144. 225. 400. 625.] 0.0
```

固有値がすべて正なので、$\Sigma$ は半正定値です。A–E の共分散が0で、A の分散が100、E の分散が625である点は、後の手計算で使います。

### 5銘柄の例・全部の組合せを解いて最適性を確かめる

保有数が3以下の部分集合は $5+10+10=25$ 通りです。各部分集合で、重みの凸QPを解き、固定費を足します。

```python
def solve_qp(idx, lo, up, lin):
    """idx の銘柄だけで x'Σx + lin'x を最小化する凸QP。実行不能なら None。"""
    idx = list(idx)
    Q, c = Sigma[np.ix_(idx, idx)], lin[idx]
    bounds = [(lo[i], up[i]) for i in idx]
    start = linprog(  # まず実行可能な点を線形計画で探す
        np.zeros(len(idx)),
        A_ub=[-mu[idx]],
        b_ub=[-target],
        A_eq=[np.ones(len(idx))],
        b_eq=[1.0],
        bounds=bounds,
    )
    if start.status == 2:  # 実行不能
        return None
    cons = [
        {"type": "eq", "fun": lambda x: x.sum() - 1.0},
        {"type": "ineq", "fun": lambda x: mu[idx] @ x - target},
    ]
    res = minimize(
        lambda x: (x @ Q @ x + c @ x) / 100,  # 値の大きさをそろえて SLSQP を安定させる
        start.x,
        jac=lambda x: (2 * Q @ x + c) / 100,
        bounds=bounds,
        constraints=cons,
        method="SLSQP",
        options={"ftol": 1e-12, "maxiter": 300},
    )
    assert res.success, res.message
    return res.fun * 100, res.x


def enumerate_subsets(up, kmax):
    """保有数が kmax 以下の部分集合をすべて解く。(分散+固定費, 部分集合, 重み) を昇順に返す。"""
    lo, zero = np.full(5, lot), np.zeros(5)
    rows = []
    for size in range(1, kmax + 1):
        for sub in itertools.combinations(range(5), size):
            r = solve_qp(sub, lo, up, zero)
            if r:
                rows.append((r[0] + fee * size, sub, r[1]))
    return sorted(rows, key=lambda row: row[0])


rows = enumerate_subsets(cap, k)
print(len(rows), "of", sum(len(list(itertools.combinations(range(5), s))) for s in (1, 2, 3)))
# 10 of 25
for total, sub, x in rows:
    print("".join(names[i] for i in sub), round(total - fee * len(sub), 2), round(total, 2), x.round(3))
# ADE 105.75 120.75 [0.55  0.252 0.198]
# ACE 110.73 125.73 [0.408 0.32  0.272]
# ACD 114.75 129.75 [0.35 0.3  0.35]
# BCE 115.69 130.69 [0.5   0.333 0.167]
# ABE 116.0 131.0 [0.28 0.4  0.32]
# BCD 116.29 131.29 [0.493 0.26  0.247]
# ABD 119.2 134.2 [0.2 0.4 0.4]
# AE 136.0 146.0 [0.6 0.4]
# BDE 140.99 155.99 [0.5   0.326 0.174]
# CDE 182.76 197.76 [0.5   0.328 0.172]
```

MIQP ソルバーは使わず、部分集合ごとの凸QPを SciPy の SLSQP で解き、全部の組合せを比べた結果です。各部分集合のQPは凸なので、SLSQP が見つけた点はその部分集合での大域的な最小です。同じ10個の値は、有効な制約の組を全部試して厳密に解く別の計算（図の生成スクリプト `scripts/generate_lesson_figures.py`）でも一致します。

25通りのうち実行可能なのは10通りです。1銘柄だけの5通りは、重みの上限が合計1に届きません。2銘柄では A と E の組だけが残り、ほかの9通りは上限の合計か期待収益が足りません。3銘柄でも A, B, C の組は、期待収益が6に届かず実行不能です。

最良は A, D, E の3銘柄で、重みは $(0.550,\ 0.252,\ 0.198)$、分散 $105.75$ に固定費 $3\times5=15$ を足した $120.75$ です。2位の A, C, E は $125.73$ です。25通りすべてを調べたので、保有数3以下の最適値は $120.75$ だと言い切れます。

実行可能な組合せの一つは、手で計算して確かめられます。A と E の組は、重みの合計が1、期待収益が $4x_A+9x_E\ge6$ ですから、$x_E\ge0.4$ が必要です。E の上限が0.4なので $x_E=0.4$、$x_A=0.6$（A の上限ちょうど）に決まります。分散は、A–E の共分散が0なので次のとおりです。

$$
0.6^2\times100 + 0.4^2\times625 = 36 + 100 = 136
$$

固定費 $2\times5=10$ を足して $146$ となり、表の A, E の行と一致します。期待収益は $4\times0.6+9\times0.4=6.0$ で、目標にちょうど届きます。

### 5銘柄の例・連続緩和の下界

組合せを全部調べる代わりに、$z_i\in\{0,1\}$ を $0\le z_i\le1$ に緩めます。$x_i\le M_i z_i$ から $z_i\ge x_i/M_i$ が分かります。固定費 $f z_i$ を小さくしたいので、緩和では $z_i=x_i/M_i$ まで下げられます。つまり、緩和した問題は、固定費の代わりに線形の項 $f\,x_i/M_i$ を足した凸QPです。

```python
def relaxation(big_m):
    """z_i = x_i / M_i まで下げた連続緩和。固定費は fee * x_i / M_i になる。"""
    big_m = np.asarray(big_m, float)
    up = np.minimum(cap, big_m)
    value, x = solve_qp(range(5), np.zeros(5), up, fee / big_m)
    return value, x, (x / big_m).sum()


for label, big_m in [("M=上限", cap), ("M=1", np.ones(5)), ("M=10", np.full(5, 10.0)), ("M=100", np.full(5, 100.0))]:
    value, x, z_sum = relaxation(big_m)
    gap = rows[0][0] - value
    print(label, round(value, 2), x.round(3), round(z_sum, 2), round(gap, 2), f"{gap / rows[0][0]:.1%}")
# M=上限 102.41 [0.304 0.205 0.163 0.172 0.156] 2.06 18.34 15.2%
# M=1 97.09 [0.302 0.209 0.161 0.173 0.156] 1.0 23.66 19.6%
# M=10 92.59 [0.302 0.209 0.161 0.173 0.156] 0.1 28.16 23.3%
# M=100 92.14 [0.302 0.209 0.161 0.173 0.156] 0.01 28.61 23.7%
```

| $M_i$ の取り方 | 連続緩和の下界 | 整数の最適値 | 差 | 差の割合 | $\sum z_i$ |
|---|---:|---:|---:|---:|---:|
| 各銘柄の上限 | 102.41 | 120.75 | 18.34 | 15.2 % | 2.06 |
| 1 | 97.09 | 120.75 | 23.66 | 19.6 % | 1.00 |
| 10 | 92.59 | 120.75 | 28.16 | 23.3 % | 0.10 |
| 100 | 92.14 | 120.75 | 28.61 | 23.7 % | 0.01 |

どの $M_i$ でも、下界は $120.75$ より小さく、整数の最適値を超えません。差が最も小さいのは、$M_i$ を各銘柄の上限にしたときです。$M_i$ を 1 以上にすると、緩和の解 $x$ は、固定費を無視した凸QPの解 $(0.302,\ 0.209,\ 0.161,\ 0.173,\ 0.156)$ と同じになります。このとき $\sum_i z_i=\sum_i x_i/M_i=1/M$ なので、下界は $92.09+5/M$ です。固定費を無視した最小の分散が $92.09$ で、$M$ を大きくするほど固定費の見積もりが $5$, $0.5$, $0.05$ と消えます。

次の図は、同じ表を $M$ ごとに並べたものです。橙の丸が連続緩和の下界、緑の丸が列挙で確かめた整数の最適値で、紺の実線がその差を示します。最後の行は $M=0.4$ の場合で、元の問題より厳しい別の問題です。

保有数の上限 $k=3$ は、緩和の中では働いていません。$M_i$ が各銘柄の上限のとき $\sum z_i=2.06$ で、$k=3$ 以下だからです。緩和の下界は、「3銘柄まで」という条件を知らないまま、固定費だけを小さく見積もった値です。

### 5銘柄の例・big-M を小さくしすぎたとき

$M_i$ を、全銘柄で $0.4$ に取ります。A の重みは最大 $0.4$ に切られ、最適な組合せ A, D, E の重み $0.550$ が使えなくなります。

```python
up04 = np.minimum(cap, 0.4)
rows04 = enumerate_subsets(up04, k)
value04 = relaxation(np.full(5, 0.4))[0]
print(len(rows04), "".join(names[i] for i in rows04[0][1]), round(rows04[0][0], 2), rows04[0][2].round(3), round(value04, 2))
# 9 ACE 125.78 [0.4   0.333 0.267] 104.59
```

実行可能な組合せは9通りに減り、最適値は $120.75$ から $125.78$（A, C, E）へ上がります。連続緩和の下界も $104.59$ と、$M_i=$ 各銘柄の上限のときの $102.41$ より大きくなります。ところが、この下界は元の問題の下界ではありません。元の問題の最適値は $120.75$ で、M を小さくした問題の最適値は $125.78$ です。小さすぎる $M_i$ は、緩和を強くしたのではなく、最適な解を切り落としました。

### 5銘柄の例・緩和の解を丸めると

緩和の解（$M_i$ は各銘柄の上限）は、重みが大きい順に A $0.304$、B $0.205$、D $0.172$、C $0.163$、E $0.156$ です。上位3銘柄 A, B, D を残して、重みを合計1にそろえます。

```python
value, x, _ = relaxation(cap)
top3 = tuple(sorted(np.argsort(-x)[:3]))
x_round = np.zeros(5)
x_round[list(top3)] = x[list(top3)] / x[list(top3)].sum()
print("".join(names[i] for i in top3), x_round.round(3), round(mu @ x_round, 2))
# ABD [0.446 0.301 0.    0.253 0.   ] 5.31
sub = solve_qp(top3, np.full(5, lot), cap, np.zeros(5))
print(round(sub[0] + fee * 3, 2), sub[1].round(3))
# 134.2 [0.2 0.4 0.4]
```

丸めた配分の期待収益は $5.31$ %で、目標の $6$ % に届きません。A, B, D の組合せで重みを解き直しても、目的値は $134.2$ で、最適値 $120.75$ より約11%大きい値です。最適な組合せに入っている E は、緩和の解では重みが最も小さい銘柄でした。緩和の解は組合せを選ぶ手がかりにはなりますが、答えそのものにはなりません。

### 凸でない Q の場合・2銘柄を選ぶ例（この節だけ別の例）

ここでは、重みを使わず、5銘柄から2銘柄を選ぶ0-1変数 $z$ だけの問題に変えます。選んだ2銘柄に半分ずつ配分するときの分散に比例する $z^\top\Sigma z$ を最小にします。5銘柄の例と同じ $\Sigma$ を使います。

```python
def relax_values(Q, starts=300):
    """0 <= z <= 1, sum z = 2 の連続緩和を、ランダムな初期点から局所解法で解いた目的値。"""
    found = []
    for seed in range(starts):
        z0 = np.clip(np.random.default_rng(seed).dirichlet(np.ones(5)) * 2, 0, 1)
        z0 *= 2 / z0.sum()
        res = minimize(
            lambda z: z @ Q @ z,
            z0,
            jac=lambda z: 2 * Q @ z,
            bounds=[(0, 1)] * 5,
            constraints=[{"type": "eq", "fun": lambda z: z.sum() - 2}],
            method="SLSQP",
            options={"ftol": 1e-12, "maxiter": 300},
        )
        if res.success:
            found.append(res.fun)
    return found


pair_values = {}
for pair in itertools.combinations(range(5), 2):
    z = np.zeros(5)
    z[list(pair)] = 1
    pair_values["".join(names[i] for i in pair)] = float(z @ Sigma @ z)
print(sorted(pair_values.items(), key=lambda kv: kv[1])[:3])
# [('AB', 364.0), ('AC', 415.0), ('BC', 513.0)]
```

10通りの組合せを調べると、最良は A, B の $364$、次が A, C の $415$ です。この問題は、$Q=\Sigma$ が半正定値なので凸です。連続緩和を解くと、局所解法の結果はどの初期点でも同じ値になります。

```python
for shift in (0.0, -57.0):  # Σ + shift*I。2銘柄を選ぶ(z'z=2)とき、目的に -shift*2 を足すと値が同じ
    Q = Sigma + shift * np.eye(5)
    values = relax_values(Q)
    print(shift, round(float(np.linalg.eigvalsh(Q).min()), 2), round(min(values) - 2 * shift, 2), round(max(values) - 2 * shift, 2))
# 0.0 57.43 296.81 296.81
# -57.0 0.43 333.8 333.8
```

緩和の最適値は $296.81$ で、整数の最適値 $364$ より小さい下界です。0-1変数では $z_i^2=z_i$ なので、対角に $-57$ を足して線形の項を補う書き換えをしても、0-1の点では目的値が変わりません。$\Sigma-57I$ はなお半正定値（最小の固有値 $0.43$）で、緩和の下界は $333.8$ に上がります。凸のままなら、書き換えで緩和を強くできます。

次に、$\Sigma$ の代わりに $Q_{\text{bad}}=\Sigma-300I$ を使います。2銘柄を選ぶと $z^\top z=2$ なので、0-1の点での目的値は $\Sigma$ の場合より一律に $600$ 小さくなるだけで、最適な組合せは変わりません。ところが $Q_{\text{bad}}$ の最小固有値は負で、緩和は凸ではありません。

```python
Q_bad = Sigma - 300 * np.eye(5)  # 2銘柄を選ぶと、値は Σ の場合より 600 小さくなるだけ
values = relax_values(Q_bad)
print(round(float(np.linalg.eigvalsh(Q_bad).min()), 1), len(values), sorted(Counter(round(float(v) + 600, 2) for v in values).items()))
# -242.6 265 [(364.0, 190), (415.0, 63), (513.0, 12)]
```

300回の初期点のうち265回が収束し、緩和の局所解は $364$、$415$、$513$ の3通りに分かれました。どれも局所解法が止まる点です。この中から $415$ を返した実行を下界として使うと、整数の最適値 $364$ より大きい「下界」ができ、最適な組合せ A, B を含む枝を切り捨てます。凸な $Q$ なら、最適値は初期点によらず一つに決まります。

この書き換えが使えるのは、変数が0-1で $z_i^2=z_i$ が成り立つ場合です。5銘柄の例の重み $x_i$ のように連続変数が二次の項に入るなら、対角に定数を足しても目的値は同じになりません。非凸な $Q$ が連続変数にかかる場合は、連続変数の範囲も分けながら下界を作る方法が必要になります。

## つまずきやすい点

- **緩和の解を丸めて答えにする**: 5銘柄の緩和の解（A $0.304$、B $0.205$、D $0.172$、C $0.163$、E $0.156$）から上位3銘柄 A, B, D を残すと、期待収益が $5.31$ % で目標の $6$ % に届きません。A, B, D で重みを解き直しても $134.2$ で、最適な A, D, E の $120.75$ より約11%大きくなります。緩和の解は、下界を求める道具として使い、答えは組合せごとの凸QPで求めます。
- **big-M を「安全のため」に大きくする**: $M_i$ を各銘柄の上限から 100 にすると、連続緩和の下界は $102.41$ から $92.14$ に下がり、整数の最適値 $120.75$ との差は $15.2$ %から $23.7$ %に開きます。大きな $M_i$ は、$z_i$ がわずかでも 0 からずれると大きな重みを許します。整数の許容誤差を $10^{-5}$ とすると、$M_i=100$ では $z_i=10^{-5}$ のまま重みが $0.001$ まで許されます。$M_i$ は、モデルから保証できる最小の値に取ります。
- **big-M を小さくして緩和を締めたつもりになる**: $M_i$ を全銘柄で $0.4$ にすると、下界は $104.59$ に上がって見えます。ところが A の重みが $0.4$ に切られ、最適値が $120.75$ から $125.78$ へ変わります。下界が上がったのは、元の問題の下界が改善したのではなく、最適解を切り落とした別の問題の値になったからです。$M_i$ を決めるときは、小さくしてよい根拠を、制約やデータから示します。
- **保有数の上限を、最適な銘柄数と読む**: 上限を $k=3$ にしたので3銘柄が最良、と読むのは早計です。上限をはずすと、最良は4銘柄の A, C, D, E で $116.55$ になり、$k=3$ の $120.75$ より $4.20$ 小さくなります。$k$ は設計者が決める入力で、最適な銘柄数を表す値ではありません。
- **$Q$ が半正定値か確かめずに、局所解を下界として使う**: $Q_{\text{bad}}=\Sigma-300I$ では、緩和の局所解が $364$、$415$、$513$ に分かれ、$415$ や $513$ を下界に使うと最適な組合せを切り捨てます。$Q$ の最小固有値が負なら、凸QPとして扱えません。

## 課題から定式化する

「保有数を絞った分散最小の配分を作りたい」という課題だけでは、まだこの型とは決まりません。次の4つを順に確かめます。

1. **何を決めるか**: 各銘柄の重みです。さらに「その銘柄を保有するか」という飛び飛びの決定があるかを確かめます。保有数の上限、固定費、最小ロットのどれかがあれば、0-1変数が要ります。
2. **何を小さくするか**: 分散のような、変数の二次式です。目的が線形（たとえば期待収益の最大化だけ）なら、MILP になります。
3. **現実の条件は何か**: 重みの合計、期待収益、銘柄ごとの上限を、線形の等式・不等式で書けるかを確かめます。分散を上限として制約側に置くと、制約が二次になるため別の型です。
4. **$Q$ は半正定値か**: 共分散行列は半正定値ですが、データから推定すると小さな負の固有値が出ることがあります。最小の固有値を確かめて、負なら凸として扱えません。

こうして、変数に連続と0-1が混ざり、目的が半正定値の二次式、制約がすべて線形になれば、この記事の型です。

## 困りごとから関連する問題へ

実際の課題で、次の条件が必要になったら、対応する記事へ進めます。

- 保有する・しないの決定がなく、重みだけを決める → [凸二次計画](#/learn/concept.convex-quadratic-program)
- 目的が線形で、二次の項がない → [混合整数線形計画](#/learn/concept.mixed-integer-linear-program)
- 分散を目的ではなく制約（分散は〇〇以下）に置く → [混合整数非線形計画](#/formulations/PA025)
- $Q$ が半正定値でない → [非凸QP/QCQP](#/formulations/PA019)
- 容量の制約が1本で、選ぶ・選ばないだけを決める → [ナップサック問題・集合被覆問題](#/formulations/PA032)

### MIQP と関連する問題の関係

- [凸二次計画](#/learn/concept.convex-quadratic-program): 整数条件を外すと凸QPになり、その最適値が下界になります。5銘柄の例では、$M_i$ を各銘柄の上限にした緩和が $102.41$、固定費を無視した凸QPが $92.09$ です。整数の最適値は $120.75$ で、どちらの下界とも差が残りました。
- [混合整数線形計画](#/learn/concept.mixed-integer-linear-program): $Q=0$ にするとMILPです。MILPの緩和は線形計画で、MIQPの緩和は凸QPです。分枝限定法の各ノードで解く問題が、線形計画から凸QPに変わります。
- [混合整数非線形計画](#/formulations/PA025): 目的が二次で、制約がすべて線形なら、MINLP の特別な場合としてこの型です。制約に非線形が入ると、この型の範囲を出ます。
- [非凸QP/QCQP](#/formulations/PA019): 整数変数がなくても、$Q$ が半正定値でないと、局所解が大域解とは限りません。MIQP の $Q$ が半正定値でなければ、緩和がこの型になります。

## 数値計算の方法を選ぶ

MIQP の方法は、緩和の凸性に応じて分かれます。

| 系統 | 進み方 | 向く条件・避ける条件 |
|---|---|---|
| [分枝限定法](#/learn/branch-and-bound) | 緩和した凸QPを解き、0-1変数を一つずつ決めながら、下界で枝を切る | $Q$ が半正定値なら、各ノードの下界が正しく、最適性を示せます。非凸なら、この下界は成り立ちません |
| [branch-and-cut](#/learn/branch-and-cut) | 分枝に加えて、整数解を切り捨てずに緩和を締める制約を足す | 緩和が弱いときに、締める制約を足して下界と暫定解の差を縮めます |
| [Outer Approximation](#/learn/outer-approximation-minlp) | 整数を固定した連続QPと、凸な項を切除平面で近似したMILPを交互に解く | 目的が凸のときの方法で、MINLP の一般的な枠組みです |
| [空間分枝限定法](#/learn/spatial-branch-and-bound) | 連続変数の範囲も分け、非凸な項に凸な下界を作る | $Q$ が非凸のときの候補です。連続変数の分割も要り、計算は重くなります |
| 部分集合の全列挙 | 保有数以下の組合せごとに、凸QPを解く | 銘柄数が小さいときだけです。5銘柄は25通り、30銘柄から10銘柄以内で53,009,101通り、50銘柄から10銘柄以内で13,432,735,555通りに増えます |
| 局所探索・遺伝的アルゴリズム | 良い組合せの候補を作る | 最適性の証明は出ません。実行可能な良い解（上界）を得る用途です |

ソルバーに渡すときは、二次の目的を扱える汎用のMIPソルバー（SCIP、Gurobi、MOSEK など）を使えます。凸だけを扱えるか、非凸も扱えるかは、ソルバーとバージョンで違うので、各ソルバーの文書で確かめます。ライブラリの既定の設定は、この型での最適を意味しません。選ぶときは、$Q$ が凸か、big-M の根拠があるか、変数の数、最適性の証明が要るか、を確かめます。

次のコードは、全列挙を使わず、緩和の下界で枝を切る分枝限定法を小さく実装して、同じ最適値に着きます。各ノードでは、保有を決めた銘柄の重みに最小ロットを課し、未定の銘柄には $f\,x_i/M_i$ の線形の項を足した凸QPを解きます。分枝の対象は、緩和の $z_i=x_i/M_i$ が0.5に最も近い銘柄です。

```python
# 分枝限定法の小さな実装：緩和QPの値を下界にして、z を一つずつ決める
best = [np.inf, None]
log = []


def node_bound(chosen, dropped):
    free = [i for i in range(5) if i not in chosen and i not in dropped]
    idx = sorted(chosen + free)
    lo = np.array([lot if i in chosen else 0.0 for i in range(5)])
    lin = np.array([fee / cap[i] if i in free else 0.0 for i in range(5)])
    r = solve_qp(idx, lo, cap, lin) if idx else None
    return None if r is None else (r[0] + fee * len(chosen), dict(zip(idx, r[1])), free)


def branch(chosen, dropped):
    if len(chosen) == k:  # 上限に達したら、残りは保有しない
        dropped = dropped + [i for i in range(5) if i not in chosen and i not in dropped]
    tag = f"保有={''.join(names[i] for i in chosen) or '-'} 除外={''.join(names[i] for i in dropped) or '-'}"
    node = node_bound(chosen, dropped)
    if node is None:
        log.append(f"{tag}: 実行不能")
        return
    bound, x, free = node
    if bound >= best[0] - 1e-9:
        log.append(f"{tag}: 下界 {bound:.2f} >= 暫定 {best[0]:.2f} で枝刈り")
    elif not free:
        best[:] = [bound, x]
        log.append(f"{tag}: 葉 {bound:.2f} を暫定解に")
    else:
        j = min(free, key=lambda i: abs(x[i] / cap[i] - 0.5))  # z が 0.5 に最も近い銘柄
        log.append(f"{tag}: 下界 {bound:.2f}、{names[j]} で分枝 (z={x[j] / cap[j]:.3f})")
        branch(chosen + [j], dropped)
        branch(chosen, dropped + [j])


branch([], [])
print(*log, sep="\n")
# 保有=- 除外=-: 下界 102.41、A で分枝 (z=0.506)
# 保有=A 除外=-: 下界 104.78、D で分枝 (z=0.439)
# 保有=AD 除外=-: 下界 107.48、E で分枝 (z=0.379)
# 保有=ADE 除外=BC: 葉 120.75 を暫定解に
# 保有=AD 除外=E: 下界 122.93 >= 暫定 120.75 で枝刈り
# 保有=A 除外=D: 下界 116.68、C で分枝 (z=0.486)
# 保有=AC 除外=D: 下界 119.13、B で分枝 (z=0.436)
# 保有=ACB 除外=DE: 実行不能
# 保有=AC 除外=DB: 下界 124.11 >= 暫定 120.75 で枝刈り
# 保有=A 除外=DC: 下界 128.89 >= 暫定 120.75 で枝刈り
# 保有=- 除外=A: 下界 120.10、C で分枝 (z=0.574)
# 保有=C 除外=A: 下界 122.18 >= 暫定 120.75 で枝刈り
# 保有=- 除外=AC: 下界 152.24 >= 暫定 120.75 で枝刈り
print(len(log), round(best[0], 2), {names[i]: round(float(v), 3) for i, v in best[1].items()})
# 13 120.75 {'A': 0.55, 'D': 0.252, 'E': 0.198}
```

13個の部分問題を解くだけで、全列挙と同じ最適値 $120.75$ と、A, D, E の配分に着きます。根の下界は $102.41$ で、最初の葉で暫定解 $120.75$ が得られると、下界がそれ以上の枝は切られます。残りの枝は、切られた時点の下界がどれも $120.75$ 以上なので、ここより良い解を含みません。25通りを調べる代わりに13個で済んだのは、この5銘柄の例での回数です。ほかの問題や分枝の選び方で同じ割合になる保証はありません。この比較から、分枝限定法が全列挙より速いとは言えません。
