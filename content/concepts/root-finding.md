方程式の求根は、残差がゼロになる未知量を探す定式化です。目的値を小さくする最適化へ書き換えることもできますが、小さな二乗和や停止の成功だけでは、方程式を要求精度で満たしたとは言えません。

## 30秒でつかむ

水槽が二つつながっていて、それぞれの流入量と流出量がつり合う水位を求める場面を考えます。
二つの水位を $x_1,\ x_2$ とすると、各水槽の流入量と流出量の差は、水位で決まる $F_1(x)$ と $F_2(x)$ になります。
水位を上げたい、あるいは下げたいのではありません。
二つの差が同時に0になる水位の組が答えです。
この差を**残差**、残差が0になる値を**根**と呼びます。

- **決めるもの**：平衡状態やつり合いを定める未知量
- **良くしたいもの**：すべての方程式の残差を0に近づけること
- **守ること**：各残差が、その式に必要な精度で小さいこと

小さな残差を持つ点と、方程式を満たす点は区別します。
どの程度なら「つり合った」と扱うのか、成分ごとの単位と許容値を先に決めます。

以降の数値例では、二つの差を $F_1=x_1^2+x_2-1$ と $F_2=x_1+x_2^2-1$ とします。
水位は $(0.7,\ 0.7)$ から始めます。
二つの水位が等しいとき、二つの式はどちらも $t^2+t-1$ になります。
最初の図は、この対角線上だけを取り出した断面です。
まず「▶ 再生」を押してください。始点 $t_0=0.7$ の点から接線が引かれ、接線が残差 $F=0$ の線と交わる点まで印が滑り、そこから曲線へ落ちます。この一周が1手です。

::: explorable newton-root-residual
「残差 F(t) = t²+t−1 の曲線」の縦軸は残差 F で、緑の破線が根 t*≈0.618、橙の印がいま動いている点です。「自動で拡大」では手ごとに根の周りを拡大するので、点と接線がいつも見える大きさで描かれます。「残差 |F| の小ささ」の棒は、残差の小ささを桁数で表します。
「二変数の平面 (x₁, x₂)」は、断面では見えない動きを描きます。A、B、C の三つの始点から同じ手順を3手進めます。灰色の破線の曲線はヤコビ行列に逆行列がない場所で、✕ は $(0.5,\ 0.5)$ です。始点は三つだけで、収束する始点の全体の地図は示しません。
:::

確かめてほしいことは六つあります。

1. 1手目で、橙の印は接線に沿って $0.620833$ へ滑り、曲線へ落ちます。残差は $0.19$ から $0.00627$ に縮みます。
2. 2手目、3手目と進むと、「残差 F(t) = t²+t−1 の曲線」の題にある拡大率が ×6、×167、×133,495 と上がります。倍率を上げても接線と曲線はほとんど重なります。
3. 「残差 |F| の小ささ」では、棒の長さが桁数です。桁数は $-\log_{10}|F|$ で、$0.00627$ なら $2.2$ 桁です。棒の端には残差が書かれ、桁数は図の下の説明文に出ます。
   棒は $t_0$ から順に $0.7$ 桁、$2.2$ 桁、$5.1$ 桁、$10.9$ 桁と伸びます。1手ごとの増え方は約3倍、約2.3倍、約2.1倍で、根の近くでは2倍に近づきます。
4. 「拡大」を「拡大しない」にすると、2手目以降の点は根と重なって区別できません。「方法」を「二分法」に替えると、区間は1回ごとに半分になり、8回後の中点の残差は $0.00685$（約 $2.2$ 桁）です。Newton法の3手と二分法の8回は、1回あたりの計算が違うので、二分法が劣るという意味ではありません。二分法は導関数が要らず、区間に根があることが保証されます。
5. 「方法」を「Newton法」に戻し、「二変数の平面」を見てください。同じ手順でも、A は根 $(0.618,\ 0.618)$ に着き、B は根 $(1,\ 0)$ に着きます。C が着くのは根 $(-1.618,\ -1.618)$ です。始点が変わると、着く根も変わります。
6. 「始点 $t_0$」のつまみを $0.5$ に合わせます。「残差 F(t) = t²+t−1 の曲線」では、傾き $F'(0.5)=2$ で普通に進みますが、「二変数の平面」の橙の印は ✕ から動きません。断面は、ヤコビ行列に逆行列がないことを隠します。

どうして1手で桁数がほぼ倍になるのでしょうか。接線が $F=0$ と交わる点を式で書くと、理由が分かります。

一変数では、接線が $F=0$ と交わる点が次の値です。

$$
t_{k+1}=t_k-\frac{F(t_k)}{F'(t_k)}
$$

いまの残差を傾きで割った分だけ戻る、という読み方です。
この例では、根からのずれを $e_k=t_k-t^*$ とすると、$e_{k+1}=e_k^2/(2t_k+1)$ が成り立ちます。
たとえば $e_0=0.08197$ から $e_1=0.08197^2/2.4\approx0.0028$ になります。
ずれが二乗されるので、桁数が倍近くになります。

## 標準形を読む

未知数と同じ数の方程式を、同時に満たす点を探します。

$$
\text{find }x\quad\text{s.t.}\quad F(x)=0,\qquad F:\mathbb{R}^n\to\mathbb{R}^n
$$

| 記号 | 意味 | 例では |
|---|---|---|
| $x$ | $n$ 個の未知量を並べたベクトル | 初期値 $(0.7,\ 0.7)$ |
| $F_i(x)$ | 方程式 $i$ の左辺と右辺の差 | $F_1(x_0)=F_2(x_0)=0.19$ |
| $F(x)$ | 残差を並べたベクトル | $(0.19,\ 0.19)$ |
| $J(x)$ | 各残差を各未知量で微分したヤコビ行列（ヤコビアン） | 対角成分 $1.4$、非対角成分 $1$ |

この形には最小化するスカラー目的がありません。
方程式の数と未知数の数は、同じにそろえます。
一致しない場合でも問題は立てられますが、解の一意性や残差の解釈が変わります。

実装へ渡す前に、物理的な範囲も決めておきます。
たとえば水位が負になる根は、数学的には根でも採用できないかもしれません。
`scipy.optimize.root` は、一般の上下限制約を入力するAPIではありません。
範囲が必要なら、変数の表現や制約を扱える解法を選びます。

## 小さな例

[求根の事例](#/gallery/EC028)と同じ、二つの方程式を使います。

$$
F_1(x)=x_1^2+x_2-1,\qquad F_2(x)=x_1+x_2^2-1
$$

初期値を $(0.7,0.7)$ とします。
両成分が等しい点では、二つの式は同じ $t^2+t-1=0$ になります。
正の根は $t=(\sqrt5-1)/2\approx0.618033989$ です。

Newton型の一手は、現在の残差を線形近似で打ち消すように決めます。

$$
J(x_k)p_k=-F(x_k),\qquad x_{k+1}=x_k+p_k
$$

最初の一手を手計算で追います。
$J(x_0)$ の対角成分は $2\times0.7=1.4$、非対角成分は $1$ で、$F(x_0)=(0.19,\ 0.19)$ です。
二つの式が対称なので $p_0$ の二成分は等しく、$(1.4+1)\,p=-0.19$ から $p=-0.0791667$ です。
したがって $x_1=(0.620833,\ 0.620833)$ になります。

この一手を3回実行すると、次の値になります。
残差は小数点以下9桁へ丸めています。

| 更新 | $x_1=x_2$ | $F_1=F_2$ |
|---|---:|---:|
| 1 | 0.620833333 | 0.006267361 |
| 2 | 0.618037485 | 0.000007817 |
| 3 | 0.618033989 | 0.000000000 |

3回目の残差表示が0でも、有限桁の表示だけで厳密な0とは判断しません。
下のコードでは、丸める前の各成分を許容値 $10^{-8}$ と比べます。

この方程式には $(0,1)$ と $(1,0)$ という根もあります。
さらに、両成分が $( -1-\sqrt5)/2$ に等しい根もあります。
一つの初期値から一つの根を得ても、すべての根を列挙したことにはなりません。

## 見分け方

次の言葉があれば、求根として定式化できます。

- 平衡点、定常状態、つり合いを求めたい
- 方程式の左右を一致させたい
- 式の数と未知数の数が同じで、残差とヤコビ行列が得られる

次の兆候があれば、別の問いになっている場合があります。

- 式が未知数より多く、観測誤差のため完全には一致しない → [非線形最小二乗](#/formulations/PA033)
- 線形な式だけである → [線形方程式](#/formulations/PA002)
- 未知数が多く、データだけで一つに決まらない → [逆問題](#/formulations/PA055)
- 不等式も含めて費用を小さくしたい → [制約付き非線形計画](#/formulations/PA009)

式の二乗を足す前に、残差0が必要なのか、観測への近さを測りたいのかを決めます。
この違いで、成功の判定が変わります。

## 近い定式化

残差の二乗和を目的にすると、求根を非線形最小二乗へ書き換えられます。

$$
\min_x\;\frac12\|F(x)\|_2^2
$$

根では、この目的の大域最小値0を達成します。
ただし、根がない場合や初期値が不適切な場合は、0でない局所最小に止まることがあります。
その点を根とは呼べません。

たとえば $F(x)=x^2+1$ は、実数の根を持ちません。
二乗和 $\tfrac12(x^2+1)^2$ は $x=0$ で最小になりますが、残差は1です。
`least_squares` で解くと、次のとおりです。

```python
import numpy as np
from scipy.optimize import least_squares

fit = least_squares(lambda x: np.array([x[0] ** 2 + 1.0]), [1.0])
print(fit.success, np.round(fit.x, 6), round(float(fit.cost), 6))  # True [0.] 0.5
print(np.round(fit.fun, 6))  # [1.]
```

ソルバーは成功を返し、$x=0$ で目的値は $0.5$ です。残差は $1$ のままです。
最小化の成功と求根の成功が違う例です。

逆向きの書き換えもあります。
[制約のない滑らかな最小化](#/formulations/PA006)の停留条件は $\nabla f(x)=0$ で、求根の形です。
この条件の根には、最小点だけでなく最大点や鞍点も含まれます。
最適化では、求根の後に曲率なども調べます。

## 解き方の系統

- **Newton型の求根法**：ヤコビ行列で残差を線形近似して一手を決めます。根の近くでヤコビ行列が正則などの条件が整えば速く収束します。遠い初期値からの到達は無条件には保証されません。
- **ヤコビ行列を近似する求根法**：Broyden法などは、評価履歴から近似を更新します。大規模問題にはKrylov系の選択肢もあります。
- **最小二乗への書き換え**：[Gauss–Newton法](#/learn/gauss-newton)や[Levenberg–Marquardt法](#/learn/least-squares)で二乗和を下げます。終了後に、残差0の要求を別に検査します。

[最適化のNewton法の記事](#/learn/newton-method)では曲率から一手を決めます。
求根で使うのは、目的のヘッセ行列ではなく残差のヤコビ行列です。
どちらも連立一次方程式を解きますが、線形化する対象が異なります。

次のコードは、小さな例をSciPyのPowell hybrid法で解きます。
上の表は教材用のNewton更新であり、`hybr` の内部反復そのものではありません。

```python
import numpy as np
from scipy.optimize import root

np.set_printoptions(precision=9)


def equations(x):
    return np.array([
        x[0] ** 2 + x[1] - 1.0,
        x[0] + x[1] ** 2 - 1.0,
    ])


def jacobian(x):
    return np.array([[2.0 * x[0], 1.0], [1.0, 2.0 * x[1]]])


result = root(equations, [0.7, 0.7], jac=jacobian, method="hybr")
tolerance = np.full(2, 1e-8)
meets_equations = bool(np.all(np.abs(equations(result.x)) <= tolerance))
print(result.success, np.round(result.x, 9))
print(meets_equations)
```

```text
True [0.618033989 0.618033989]
True
```

二つ目の`True`は、各方程式の許容値を満たしたという別の判定です。
実務では`message`も保存し、停止理由を残します。
手法ごとの設定と戻り値は、[SciPyの公式リファレンス](https://docs.scipy.org/doc/scipy/reference/generated/scipy.optimize.root.html)にあります。

## つまずきやすい点

- **小さい二乗和だけで成功とする**：$F(x)=x^2+1$ では $x=0$ が二乗和の最小で、値は $0.5$ ですが、残差は $1$ のままです。成分ごとの許容値と比べます。単位が違う残差は一つのノルムにまとめません。
- **一つの始点の結果を唯一の根とする**：小さな例で純粋な Newton 法を30手進めます。$(0.7,\ 0.7)$ からは $(0.618,\ 0.618)$ に着き、$(0.9,\ 0.1)$ からは $(1,\ 0)$ に着きます。
  $(-1,\ -1)$ からは $(-1.618,\ -1.618)$ です。始点だけで根が変わるので、水位が負の根を外すなどの採用条件を先に決めます。
- **ヤコビ行列の特異性を見落とす**：$(0.5,\ 0.5)$ では $J$ の全成分が $1$ です。$Jp=-F=(0.25,\ 0.25)$ から決まるのは $p_1+p_2=0.25$ だけで、一手が一つに決まりません。
  対角の断面では $F'=2$ で普通に見えるので、断面だけでは気づけません。少し離れた $(0.501,\ 0.5)$ でも、一手は $(-0.0005,\ 0.2495)$ と大きく跳びます。ランクや条件数を見て、始点や変数の尺度を見直します。
- **最小二乗の停止条件を求根の許容値と同じにする**：$x=0$ では勾配 $2x(x^2+1)$ が $0$ ですが、残差は $1$ です。勾配や一手が小さいことと、残差が小さいことは別です。
- **根を最適点として扱う**：$f(x)=x^3$ の停留条件 $3x^2=0$ の根 $x=0$ は、最小点でも最大点でもありません。停留条件を解いた場合は、最大点や鞍点を除く検査が必要です。
