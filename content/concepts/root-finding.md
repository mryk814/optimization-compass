方程式の求根は、残差がゼロになる未知量を探す定式化です。目的値を小さくする最適化へ書き換えることもできますが、小さな二乗和や停止の成功だけでは、方程式を要求精度で満たしたとは言えません。

## 30秒でつかむ

流入量と流出量がつり合う水位を求める場面を考えます。
水位を上げたい、あるいは下げたいのではありません。
流入量と流出量の差が0になる水位が答えです。
この差を**残差（residual）**、残差が0になる値を**根（root）**と呼びます。

- **決めるもの**：平衡状態やつり合いを定める未知量
- **良くしたいもの**：すべての方程式の残差を0に近づけること
- **守ること**：各残差が、その式に必要な精度で小さいこと

小さな残差を持つ点と、方程式を満たす点は区別します。
どの程度なら「つり合った」と扱うのか、成分ごとの単位と許容値を先に決めます。

## 標準形を読む

未知数と同じ数の方程式を、同時に満たす点を探します。

$$
\text{find }x\quad\text{s.t.}\quad F(x)=0,\qquad F:\mathbb{R}^n\to\mathbb{R}^n
$$

| 記号 | 意味 |
|---|---|
| $x$ | $n$ 個の未知量を並べたベクトル |
| $F_i(x)$ | 方程式 $i$ の左辺と右辺の差 |
| $F(x)$ | 残差を並べたベクトル |
| $J(x)$ | 各残差を各未知量で微分したヤコビ行列（Jacobian） |

この形には最小化するスカラー目的がありません。
まず、方程式の数と未知数の数が一致するかを確認します。
一致しない場合でも問題は立てられますが、解の一意性や残差の解釈が変わります。

実装へ渡す前に、物理的な範囲も確認します。
たとえば水位が負になる根は、数学的には根でも採用できないかもしれません。
`scipy.optimize.root` は、一般の上下限制約を入力するAPIではありません。
範囲が必要なら、変数の表現や制約を扱える解法を検討します。

## 小さな例

[求根の事例](#/gallery/EC028)と同じ、二つの方程式を使います。

$$
F_1(x)=x_1^2+x_2-1,\qquad F_2(x)=x_1+x_2^2-1
$$

初期値を $(0.7,0.7)$ とします。
両成分が等しい点では、二つの式は同じ $t^2+t-1=0$ になります。
正の根は $t=(\sqrt5-1)/2\approx0.618033989$ です。

Newton型の一手は、現在の残差を線形近似で打ち消すように決めます。

$$
J(x_k)p_k=-F(x_k),\qquad x_{k+1}=x_k+p_k
$$

この一手を3回実行すると、次の値になります。
残差は小数点以下9桁へ丸めています。

| 更新 | $x_1=x_2$ | $F_1=F_2$ |
|---|---:|---:|
| 1 | 0.620833333 | 0.006267361 |
| 2 | 0.618037485 | 0.000007817 |
| 3 | 0.618033989 | 0.000000000 |

3回目の残差表示が0でも、有限桁の表示だけで厳密な0とは判断しません。
下のコードでは、丸める前の各成分を許容値 $10^{-8}$ と比べます。

この方程式には $(0,1)$ と $(1,0)$ という根もあります。
さらに、両成分が $( -1-\sqrt5)/2$ に等しい根もあります。
一つの初期値から一つの根を得ても、すべての根を列挙したことにはなりません。

## 見分け方

次の言葉があれば、求根としての定式化を確認します。

- 平衡点、定常状態、つり合いを求めたい
- 方程式の左右を一致させたい
- 式の数と未知数の数が同じで、残差とヤコビ行列が得られる

次の兆候があれば、別の問いになっている場合があります。

- 式が未知数より多く、観測誤差のため完全には一致しない → [非線形最小二乗](#/formulations/PA033)
- 線形な式だけである → [線形方程式](#/formulations/PA002)
- 未知数が多く、データだけで一つに決まらない → [逆問題](#/formulations/PA055)
- 不等式も含めて費用を小さくしたい → [制約付き非線形計画](#/formulations/PA009)

式の二乗を足す前に、残差0が必要なのか、観測への近さを測りたいのかを確認します。
この違いで、成功の判定が変わります。

## 近い定式化

残差の二乗和を目的にすると、求根を非線形最小二乗へ書き換えられます。

$$
\min_x\;\frac12\|F(x)\|_2^2
$$

根では、この目的の大域最小値0を達成します。
ただし、根がない場合や初期値が不適切な場合は、0でない局所最小に止まることがあります。
その点を根とは呼べません。

たとえば $F(x)=x^2+1$ は、実数の根を持ちません。
二乗和 $\tfrac12(x^2+1)^2$ は $x=0$ で最小になりますが、残差は1です。
実行した最小二乗ソルバーは成功を返し、目的値は $0.5$ でした。
最小化の成功と求根の成功が違う例です。

逆向きの書き換えもあります。
[制約のない滑らかな最小化](#/formulations/PA006)の停留条件は $\nabla f(x)=0$ で、求根の形です。
この条件の根には、最小点だけでなく最大点や鞍点も含まれます。
最適化では、求根の後に曲率なども確認します。

## 解き方の系統

- **Newton型の求根法**：ヤコビ行列で残差を線形近似して一手を決めます。根の近くでヤコビ行列が正則などの条件が整えば速く収束します。遠い初期値からの到達は無条件には保証されません。
- **ヤコビ行列を近似する求根法**：Broyden法などは、評価履歴から近似を更新します。大規模問題にはKrylov系の選択肢もあります。
- **最小二乗への書き換え**：[Gauss–Newton法](#/learn/gauss-newton)や[Levenberg–Marquardt法](#/learn/least-squares)で二乗和を下げます。終了後に、残差0の要求を別に検査します。

[最適化のNewton法の記事](#/learn/newton-method)では曲率から一手を決めます。
求根では、目的のHessianではなく残差のヤコビ行列を使うことに注意します。
どちらも連立一次方程式を解きますが、線形化する対象が異なります。

次のコードは、小さな例をSciPyのPowell hybrid法で解きます。
上の表は教材用のNewton更新であり、`hybr` の内部反復そのものではありません。

```python
import numpy as np
from scipy.optimize import root

np.set_printoptions(precision=9)


def equations(x):
    return np.array([
        x[0] ** 2 + x[1] - 1.0,
        x[0] + x[1] ** 2 - 1.0,
    ])


def jacobian(x):
    return np.array([[2.0 * x[0], 1.0], [1.0, 2.0 * x[1]]])


result = root(equations, [0.7, 0.7], jac=jacobian, method="hybr")
tolerance = np.full(2, 1e-8)
meets_equations = bool(np.all(np.abs(equations(result.x)) <= tolerance))
print(result.success, np.round(result.x, 9))
print(meets_equations)
```

```text
True [0.618033989 0.618033989]
True
```

二つ目の`True`は、各方程式の許容値を満たしたという別の判定です。
実務では`message`も保存し、停止理由を残します。
手法ごとの設定と戻り値は、[SciPyの公式リファレンス](https://docs.scipy.org/doc/scipy/reference/generated/scipy.optimize.root.html)で確認します。

## つまずきやすい点

- **小さい二乗和だけで成功とする**：成分ごとの許容値と比べます。単位が違う残差は、そのまま一つのノルムにまとめないようにします。
- **初期値を変えずに一意だと考える**：別の根へ行く可能性を確認します。物理的な範囲や採用条件も記録します。
- **ヤコビ行列の特異性を見落とす**：小さな例では $(0.5,0.5)$ のヤコビ行列は特異です。ランクや条件数を確認し、初期値や変数の尺度を見直します。
- **最小二乗の停止条件を求根の許容値と同じにする**：一手が小さいことや勾配が小さいことは、残差が小さいことと同じではありません。
- **根を最適点として扱う**：停留条件を解いた場合は、最大点や鞍点を除く検査が必要です。
